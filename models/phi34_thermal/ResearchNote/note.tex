\begin{abstract}
零温度の $\phi^3+\phi^4$ 理論のノート~\cite{phi34note} で求めた3次元の bounce の作用 $S_3(\alpha)$ を使い、有限温度の一次相転移の温度、強さ、速さと、それが作る重力波を求める。温度の模型は二つ使う。Dine ら~\cite{dine92} の高温展開の一般形 $D(T^2-T_0^2)\phi^2-ET\phi^3+\lambda_T\phi^4/4$ と、場 $\phi$ 自身の熱ループだけで閉じた本模型の温度ポテンシャルである。一般形は零温度の模型と $\alpha(T)=(\lambda_TD/E^2)(1-T_0^2/T^2)$ で対応し、$S_3/T=(E/36)(2\alpha/\lambda_T)^{3/2}S_3(\alpha)$ から、臨界温度、核生成の条件、$\beta/H$ が閉じた式で書ける。相転移の強さは $\alpha_\theta=(15D/\pi^2g_*)(T_0/T_n)^2(\phi_n/T_n)^2$ で、$\phi_n/T_n$ と過冷却の度合い $T_0/T_n$ だけで決まる。SM 的な係数では、$\phi_n/T_n=0.17$、$\beta/H=2.5\times10^6$ の弱い一次相転移になった。$E$ と $\lambda_T$ を変えた走査で最も強い点（$\alpha_\theta=0.071$、$\beta/H=974$、壁の速さ $0.95$）でも、音波と乱流による重力波のピークは $f=20$~mHz で $h^2\Omega_{\mathrm{gw}}=2.0\times10^{-15}$ で、LISA の SNR は $0.014$ にとどまる。SNR $=10$ には $\beta/H\lesssim134$ か $\alpha_\theta\gtrsim2$ が要る。単一場の模型では、木のポテンシャルの変曲点からのずれ $\chi$ で書くと、温度による補正は $\chi$ の偶関数で、奇関数の部分は温度によらない線形項だけになる。そのため、どの温度でも大域的な最小は零温度の真の真空の側にあり、高温の相はそこへなめらかに移る。一次の相転移は二つの真空が縮退する点から $|\Delta\alpha|<3\times10^{-7}$ でしか起きず、強さは $\alpha_\theta=7\times10^{-8}$ で、重力波は出ない。$\alpha<1$ で $\phi=0$ を今の真空とするには、宇宙の最高温度が、$\phi=0$ の側の極小が熱的に崩れる温度 $T_{\mathrm{dec}}$ より低くなければならない。$T_{\mathrm{dec}}$ はスピノーダル温度の $0.17$〜$0.94$ 倍で、零温度のノートの寿命の境界（$\kappa_4=1$ で $\kappa_3=1.476$）では $47$~GeV である。数値は、零温度のノートと相対 $10^{-13}$ で一致する自前の bounce の道具に加え、独立な道具で確かめた。CosmoTransitions とは、bounce の作用と転移の温度が相対 $10^{-7}$ 以内で一致した。DRalgo と Matchotter の次元還元は、温度ポテンシャルの係数と記号で一致した。PT2GWFinder は、$T_c$ と強さを相対 $10^{-6}$ 以内、$T_n$ を $2.4\times10^{-4}$ 以内で再現した。導出はすべて付録に省略なく載せる。
\end{abstract}

\section{目的と問い}\label{sec:intro}

本ノートの問いは二つである。\textbf{第一に、零温度のノートで検算した3次元の bounce の作用を使うと、有限温度の一次相転移の温度、強さ、速さと、それが作る重力波はどう決まるか。第二に、$\phi^3+\phi^4$ 理論そのものの熱的な歴史では、高温の相からどちらの真空に移るか。そして、それは零温度のノートの真空の安定性の限界をどう変えるか。}

第一の問いを立てる理由は、零温度のノートの手順 (9) で、$d=3$ の作用 $S_3(\alpha)$ を Dine ら~\cite{dine92} の近似式と $0.8\%$ 以内で一致させてあるからである。電弱相転移の高温展開のポテンシャル $D(T^2-T_0^2)\phi^2-ET\phi^3+\lambda_T\phi^4/4$ は、温度に依存する係数を持つ $\phi^3+\phi^4$ のポテンシャルそのものなので、$S_3(\alpha)$ をそのまま使える。第二の問いを立てる理由は、零温度のノートで $\alpha<1$ の $\phi=0$ を準安定な真空として扱ったが、宇宙が高温から冷えるとき、そもそも $\phi=0$ に落ち着くかは自明でないからである。

求める量は四つである。(i) 一般形の臨界温度と、零温度の $\alpha$ との対応。(ii) 核生成温度 $T_n$、相転移の強さ $\alpha_\theta$、速さ $\beta/H$。(iii) 音波と乱流による重力波のスペクトルと、LISA の感度との比較。(iv) 場 $\phi$ 自身の熱ループによる温度ポテンシャルでの、相の移り変わりと $(\kappa_3,\kappa_4)$ の熱的な安定性。

本ノートの構成は次の通りである。第~\ref{sec:setup} 節で模型と前提を定める。第~\ref{sec:results} 節で手計算の結果を述べる。第~\ref{sec:plan} 節で検算と計算の計画を定める。第~\ref{sec:dine} 節で一般形の相転移を扱う（手順 (1)〜(3)）。第~\ref{sec:single} 節で単一場の模型の相の移り変わりと熱的な安定性を扱う（手順 (4)〜(6)）。第~\ref{sec:ct} 節で独立な道具と照合する（手順 (7)、(8)）。第~\ref{sec:discussion} 節で結論と残る課題をまとめる。導出は\ref{app:map}〜\ref{app:bounce}、照合の細部は\ref{app:ct} にある。

\section{設定}\label{sec:setup}

零温度のノート~\cite{phi34note} の模型は、ポテンシャル $V=\frac12m^2\phi^2+\frac g{3!}\phi^3+\frac\lambda{4!}\phi^4$ を持つ実スカラー1つで、その形は $\alpha\equiv3\lambda m^2/g^2$ で決まる。有限温度では、高温展開の一般形
\begin{equation}
V(\phi,T)=D\,(T^2-T_0^2)\,\phi^2-ET\phi^3+\frac{\lambda_T}{4}\phi^4
\label{eq:VT}
\end{equation}
を使う~\cite{dine92}。$D$、$E$、$T_0$、$\lambda_T$ は温度にほとんどよらない係数で、SM ではゲージ粒子とトップクォークの熱ループから決まる（\ref{app:map}）。場 $\phi$ 自身の熱ループによる温度ポテンシャルは、後の手順で導く。

\paragraph{前提。}本ノートは次の前提に立つ。
\begin{enumerate}
\item $\hbar=c=k_B=1$ とし、エネルギーと温度の単位は GeV とする。
\item 宇宙は放射優勢で、有効自由度は $g_*=106.75$、ハッブル率は $H=1.66\sqrt{g_*}\,T^2/M_{\mathrm{Pl}}$（$M_{\mathrm{Pl}}=1.22091\times10^{19}$~GeV）とする。
\item 有限温度の崩壊率は $\Gamma(T)=T^4\bigl(S_3/(2\pi T)\bigr)^{3/2}e^{-S_3/T}$ とし~\cite{linde83}、核生成温度 $T_n$ を $\Gamma(T_n)=H(T_n)^4$ で定める。前因子は見積もりで、その不定性は $T_n$ の条件の対数にしか効かない。
\item 一般形の係数は1ループの高温展開の値で、$\lambda_T$ の温度依存（対数）は $T_c$ での値で代表させる。Dine らによれば、$\lambda_T$ の $T_1$、$T_c$、$T_0$ での値の差は小さい。
\item SM 的な係数には、$m_W=80.37$、$m_Z=91.19$、$m_t=172.6$、$m_h=125.25$、$v=246.22$（いずれも GeV）を使う。
\item 相転移の強さと速さは $T_n$ で評価する。式~\eqref{eq:VT} は、$\phi$ によらない放射の自由エネルギー $-\pi^2g_*T^4/90$ を除いた部分とし（$V(0,T)=0$）、対称相のエンタルピー密度は放射のもの $w_+=\frac43\rho_{\mathrm{rad}}$（$\rho_{\mathrm{rad}}=\pi^2g_*T^4/30$）とする。
\item 重力波は、泡の壁が一定の速さ $v_w$ で広がり（暴走しない）、放出されたエネルギーが流体の運動に移る場合の、音波と乱流から求める。$v_w$ は模型からは決めず、$0.95$（デトネーション）と $0.44$（デフラグレーション）の二つを使う。発生時の温度 $T_*$ は $T_n$ とし（再加熱は無視）、その後の宇宙は放射優勢で断熱的に膨張するとする。今日のハッブル定数は $h=0.678$、CMB の温度は $2.725$~K とする。
\item LISA は、4年の観測で稼働率 $75\%$（$T_{\mathrm{obs}}=9.46\times10^7$~s）とし、検出の目安を SNR $=10$ とする。
\item 単一場の模型は、零温度のノートと同じく $\overline{\mathrm{MS}}$（$\mu=m$）で扱い、$\phi=0$ のタドポールを打ち消す線形項を含める。温度ポテンシャルは1ループで、ゼロモードの daisy の和を含める。場 $\phi$ は熱平衡にあるとする。数値では $\kappa_4=1$（$\lambda=0.7763$）に固め、$g/m=1.5261\,\kappa_3$、$\alpha=\kappa_4/\kappa_3^2$、$m=m_h=125.25$~GeV とする。
\end{enumerate}

\section{結果}\label{sec:results}

\paragraph{零温度の模型との対応。}式~\eqref{eq:VT} は、$m^2=M^2(T)\equiv2D(T^2-T_0^2)$、$g=-6ET$、$\lambda=6\lambda_T$ とした零温度の模型のポテンシャルである。したがって
\begin{equation}
\alpha(T)=\frac{\lambda_TM^2}{2E^2T^2}=R\Bigl(1-\frac{T_0^2}{T^2}\Bigr),\qquad R\equiv\frac{\lambda_TD}{E^2}
\label{eq:alphaT}
\end{equation}
で、これは Dine らの $\alpha$ と同じである（\ref{app:map}）。零温度のノートの真空の構造（$\alpha>9/8$ で極小は一つ、$\alpha=1$ で縮退、$\alpha<1$ で $\phi=0$ が準安定）が、そのまま温度の関数として読める。高温（$\alpha>9/8$）から冷えると、$\alpha=9/8$ で二つ目の極小が現れ、$\alpha=1$ で二つの極小が縮退し、$\alpha=0$ で $\phi=0$ が不安定になる。その温度と場の値は
\begin{equation}
T_1^2=\frac{T_0^2}{1-9E^2/(8\lambda_TD)},\quad\phi_1=\frac{3ET_1}{2\lambda_T};\qquad
T_c^2=\frac{T_0^2}{1-E^2/(\lambda_TD)},\quad\phi_c=\frac{2ET_c}{\lambda_T};\qquad
\phi_0=\frac{3ET_0}{\lambda_T}
\label{eq:crit}
\end{equation}
で、Dine らの式 (12)〜(16) を再現する（\ref{app:map}）。

\paragraph{3次元の作用。}零温度のノートの $S_3=(m^3/g^2)S_3(\alpha)$ に上の対応を入れると
\begin{equation}
\frac{S_3}{T}=\frac{M^3}{36E^2T^3}\,S_3(\alpha)=\frac{E}{36}\Bigl(\frac{2\alpha}{\lambda_T}\Bigr)^{3/2}S_3(\alpha)
\label{eq:S3T}
\end{equation}
となる（\ref{app:map}）。温度は $\alpha(T)$ を通してだけ入る。Dine らの近似式 $S_3/T=4.85\,M^3/(E^2T^3)\,f(\alpha)$ は、$S_3(\alpha)=36\times4.85\,f(\alpha)$ にあたる。

\paragraph{核生成と相転移の速さ。}$\Gamma=H^4$ は
\begin{equation}
\frac{S_3}{T}-\frac32\ln\frac{S_3}{2\pi T}=4\ln\frac{M_{\mathrm{Pl}}}{1.66\sqrt{g_*}\,T}
\label{eq:nucl}
\end{equation}
と書ける（\ref{app:nucl}）。右辺は $T\approx160$~GeV で $144$ で、よく使われる $S_3/T\approx140$ の目安にあたる。相転移の速さは、$\lambda_T$ を一定とすると
\begin{equation}
\frac\beta H=T\frac{\dd}{\dd T}\frac{S_3}{T}=\frac{S_3}{T}\Bigl[\frac{3}{2\alpha}+\frac{W(\alpha)}{S_3(\alpha)}\Bigr]\cdot2(R-\alpha)
\label{eq:betaH}
\end{equation}
である（\ref{app:nucl}）。$W=\dd S_3(\alpha)/\dd\alpha$ は零温度のノートの手順 (9) で求めてある。

\paragraph{相転移の強さ。}Caprini ら~\cite{caprini20} の式 (12) に従い、相転移の強さを $\alpha_\theta=4\Delta\theta(T_n)/(3w_+(T_n))$ で測る。$\theta=(e-3p)/4$ はエネルギー運動量テンソルのトレースの $1/4$ で、bag 模型では $\Delta\theta$ が bag 定数そのものになる。ポテンシャルの差を圧力の差 $p_+-p_-=-(V(0,T)-V(\phi_-,T))$ と読み、極小の条件を使うと
\begin{equation}
\Delta\theta=\frac12DT_0^2\phi_-^2,\qquad
\alpha_\theta=\frac{\Delta\theta}{\rho_{\mathrm{rad}}}=\frac{15D}{\pi^2g_*}\Bigl(\frac{T_0}{T_n}\Bigr)^2\Bigl(\frac{\phi_n}{T_n}\Bigr)^2
\label{eq:alphatheta}
\end{equation}
となる（\ref{app:strength}）。式~\eqref{eq:VT} のうち $T_0$ を含む項のほかは $(\phi,T)$ について4次の斉次式で、$T^4$ に比例する自由エネルギーは放射と同じくトレースを持たない。そのため $\Delta\theta$ は $T_0$ という尺度だけから生じる。強さは $\phi_n/T_n$ と過冷却の度合い $T_0/T_n$ だけで決まり、$E$ と $\lambda_T$ には $\phi_n/T_n$ と $T_n$ を通してだけよる。$\alpha>0$ で核生成が起こるかぎり $T_n>T_0$ なので、$\alpha_\theta<(15D/\pi^2g_*)(\phi_n/T_n)^2$ が上限になる。$T_c$ では $4\Delta\theta$ は潜熱 $L=2DT_0^2\phi_c^2$ に等しい。Caprini らの式 (13) の、エネルギーの差による強さ $\alpha_e=4\Delta e(T_n)/(3w_+(T_n))$ は
\begin{equation}
\Delta e=4\Delta\theta-3\Delta V,\qquad \Delta V=V(0,T)-V(\phi_-,T)=\frac{\phi_-^2}{4}\bigl(ET\phi_--M^2\bigr)
\label{eq:alphae}
\end{equation}
から求まる（\ref{app:strength}）。

\paragraph{重力波の式。}泡の壁が広がると、放出されたエネルギーの一部が流体の運動になり、その音波と乱流が重力波を出す。流体の運動エネルギーの割合は $K=\kappa\,\alpha_\theta/(1+\alpha_\theta)$ で~\cite{caprini20}、効率 $\kappa(\alpha_\theta,v_w)$ には Espinosa ら~\cite{espinosa10} の近似式を使う。指数関数的に増える核生成率のもとでは、泡の平均間隔は $H_*R_*=(8\pi)^{1/3}\max(v_w,c_s)/(\beta/H)$ である（\ref{app:gw}）。音波による今日のスペクトルには、Hindmarsh ら~\cite{hhrw17} の数値シミュレーションの式（正誤表で直したもの）を使う。
\begin{equation}
h^2\Omega_{\mathrm{sw}}(f)=h^2\cdot3\times0.687\,F_{\mathrm{gw},0}\,K^2\,(H_*R_*)\,\tilde\Omega_{\mathrm{gw}}\,C\Bigl(\frac f{f_p}\Bigr)\min\bigl(1,H_*\tau_{\mathrm{sh}}\bigr),\qquad
C(s)=s^3\Bigl(\frac7{4+3s^2}\Bigr)^{7/2}
\label{eq:Osw}
\end{equation}
ここで $\tilde\Omega_{\mathrm{gw}}=1.2\times10^{-2}$ は流体の運動が重力波に移る効率、$F_{\mathrm{gw},0}=3.57\times10^{-5}(100/g_*)^{1/3}$ は今日までの薄まり、$f_p=26\,\mu\mathrm{Hz}\,(z_p/10)(H_*R_*)^{-1}(T_*/100\,\mathrm{GeV})(g_*/100)^{1/6}$（$z_p=10$）はピークの周波数である。$0.687$ は $\int C\,\dd\ln s$ の逆数で、全体の量を $3K^2H_*R_*\tilde\Omega_{\mathrm{gw}}$ にそろえる。最後の因子は、衝撃波が $\tau_{\mathrm{sh}}=R_*/\bar U_f$ でできて、音波がハッブル時間より早く終わる場合の補正である~\cite{caprini20}。乱流には Caprini ら~\cite{caprini16} の式を使う。
\begin{equation}
h^2\Omega_{\mathrm{turb}}(f)=3.35\times10^{-4}\,\frac{H_*}{\beta}\,(\epsilon K)^{3/2}\Bigl(\frac{100}{g_*}\Bigr)^{1/3}v_w\,
\frac{(f/f_{\mathrm{turb}})^3}{(1+f/f_{\mathrm{turb}})^{11/3}\,(1+8\pi f/H_{*,0})}
\label{eq:Oturb}
\end{equation}
ここで $\epsilon=0.05$ は流体の運動のうち乱流になる割合、$f_{\mathrm{turb}}=27\,\mu\mathrm{Hz}\,v_w^{-1}(\beta/H)(T_*/100\,\mathrm{GeV})(g_*/100)^{1/6}$、$H_{*,0}=16.5\,\mu\mathrm{Hz}\,(T_*/100\,\mathrm{GeV})(g_*/100)^{1/6}$ である。この形は Caprini, Durrer, Servant~\cite{cds09} の解析的な計算に基づく。LISA の感度には、要求文書~\cite{scird} の歪みの感度 $S_h(f)$ を使い、
\begin{equation}
h^2\Omega_{\mathrm{sens}}(f)=\frac{2\pi^2}{3H_{100}^2}f^3S_h(f),\qquad
\mathrm{SNR}=\Bigl[T_{\mathrm{obs}}\int\dd f\,\Bigl(\frac{h^2\Omega_{\mathrm{gw}}(f)}{h^2\Omega_{\mathrm{sens}}(f)}\Bigr)^2\Bigr]^{1/2}
\label{eq:snr}
\end{equation}
とする~\cite{caprini20}（$H_{100}=100$~km/s/Mpc）。べき乗のスペクトルに対する感度（PLS）は、Thrane と Romano~\cite{thrane13} の作り方で、式~\eqref{eq:snr} の SNR から作る。$F_{\mathrm{gw},0}$、$H_{*,0}$、$f_p$ の係数、$R_*$、$\Omega_{\mathrm{sens}}$ と PLS は\ref{app:gw} で導く。

\paragraph{単一場の温度ポテンシャル。}場 $\phi$ 自身の1ループの温度ポテンシャルは、場による質量の2乗 $\mathcal M^2(\phi)=V''(\phi)=m^2+g\phi+\lambda\phi^2/2$ を使って
\begin{equation}
V(\phi,T)=V(\phi)+t\phi+\frac{\mathcal M^4}{64\pi^2}\Bigl(\ln\frac{\mathcal M^2}{\mu^2}-\frac32\Bigr)+\frac{T^4}{2\pi^2}J_B\Bigl(\frac{\mathcal M^2}{T^2}\Bigr),\qquad
J_B(y)=\int_0^\infty\dd x\,x^2\ln\bigl(1-e^{-\sqrt{x^2+y}}\bigr)
\label{eq:V1loop}
\end{equation}
である~\cite{dolanjackiw}。$t=m^2g/(32\pi^2)$ は、零温度のノートの $\phi=0$ のタドポールを打ち消す線形項である（$\mu=m$）。高温展開と、ゼロモードの daisy の和（熱質量 $\Pi=\lambda T^2/24$）を合わせると
\begin{equation}
V(\phi,T)\simeq V(\phi)+t\phi+\frac{T^2}{24}\mathcal M^2-\frac{T}{12\pi}\bigl(\mathcal M^2+\Pi\bigr)^{3/2}+\frac{\mathcal M^4}{64\pi^2}\Bigl(\ln\frac{T^2}{\mu^2}+2\ln4\pi-2\gamma_E\Bigr)
\label{eq:Vht}
\end{equation}
となる~\cite{arnoldespinosa}（\ref{app:single}）。$\mathcal M^4\ln\mathcal M^2$ は、零温度の部分と熱の部分で打ち消し合う。展開の次の項は $\zeta(3)\mathcal M^6/(768\pi^4T^2)$ である。

\paragraph{変曲点のまわりの構造。}木のポテンシャルの変曲点 $\phi_i=-g/\lambda$（$V'''=g+\lambda\phi=0$）からのずれ $\chi=\phi-\phi_i$ で書く。$\mathcal M^2=\mathcal M_i^2+\lambda\chi^2/2$（$\mathcal M_i^2=m^2(1-3/(2\alpha))$）は $\chi$ の偶関数で、木のポテンシャルには $\chi^3$ の項がなく、$\Pi$ は場によらない。したがって、式~\eqref{eq:V1loop}、\eqref{eq:Vht} のどちらでも
\begin{equation}
V(\chi,T)=b\,\chi+U(\chi^2,T),\qquad b=\frac{m^4}{g}\,\frac{3(1-\alpha)}{\alpha^2}+t
\label{eq:Ising}
\end{equation}
である（\ref{app:single}）。温度は偶関数の部分 $U$ にだけ入り、外場 $b$ の中の Ising 模型と同じ形になる。$s=\mathrm{sign}\,b$ とすると $V(-s|\chi|,T)-V(s|\chi|,T)=-2|b||\chi|$ なので、\textbf{どの温度でも、大域的な最小は $\chi b<0$ の側、すなわち零温度の真の真空の側にある}。高温では最小は $\chi\simeq-b/U''(0)\propto T^{-2}$、つまり変曲点の近くにあり、冷えるとそのまま真の真空の側へ移る。$\alpha<1$ では $b>0$ で、真の真空は $f_-$ である。$\alpha>1$ では $b<0$ で、真の真空は $\phi=0$ である。$t$ があるので、$b=0$ は $\alpha=1$ ではなく、$\alpha=1+O(g^2/((4\pi)^2m^2))$ で起こる。

\paragraph{スピノーダル温度。}選ばれない側の極小は、温度が十分低いときにしか存在しない。木と $T^2$ の項だけ（最低次）では、$a(T)=\mathcal M_i^2+\lambda T^2/24$ として、$V'=b+a\chi+\lambda\chi^3/6$ が三つの実根を持つ条件は $a<0$ かつ $|b|<\frac{2|a|}{3}(2|a|/\lambda)^{1/2}$ である。その上限の温度は
\begin{equation}
\tau_{\mathrm{sp}}^2=\frac{72}{\alpha}\Bigl[\frac3{2\alpha}-1-\Bigl(\frac{3|\hat b|}{2}\sqrt{\frac\alpha6}\Bigr)^{2/3}\Bigr],\qquad
\tau=\frac{gT}{m^2},\qquad \hat b=\frac{gb}{m^4}=\frac{3(1-\alpha)}{\alpha^2}+\frac{g^2}{32\pi^2m^2}
\label{eq:tsp}
\end{equation}
である（\ref{app:single}）。$T=0$ では（$t$ を除くと）$\alpha<9/8$ の条件に戻り、$\hat b=0$ では $\tau_{\mathrm{sp}}=6$ である。

\paragraph{熱的な崩壊の条件。}$T<T_{\mathrm{sp}}$ で選ばれない側の極小にいる宇宙は、3次元の bounce を通して熱的に崩れる。単位 $m^2/g$、$m^6/g^2$ で求めた bounce の作用を $\hat S_3$ とすると
\begin{equation}
\frac{S_3}{T}=\frac{\hat S_3(\alpha,\tau)}{(g/m)\,\tau},\qquad
\ln\frac{\Gamma}{H^4}=4\ln T+\frac32\ln\frac{S_3}{2\pi T}-\frac{S_3}{T}-4\ln\frac{1.66\sqrt{g_*}\,T^2}{M_{\mathrm{Pl}}}
\label{eq:s3single}
\end{equation}
である（\ref{app:bounce}）。木と $T^2$ の項だけなら $\hat S_3$ は $\alpha$ と $\tau$ だけで決まり、$S_3/T$ は $g/m$ に反比例する。ループの項は、$g/m$ による小さな補正を加える。$S_3/T$ は $T_{\mathrm{sp}}$ で0になり、温度が下がると増える。したがって、選ばれない側の極小が宇宙の歴史を生き残る条件は、最高温度が $\Gamma(T_{\mathrm{dec}})=H(T_{\mathrm{dec}})^4$ となる温度 $T_{\mathrm{dec}}$ より低いことである。

\section{検算と計算の計画}\label{sec:plan}

零温度のノートと違い、ツールどうしの比較より、閉じた式と数値の突き合わせと、文献との照合が中心になる。

\paragraph{手順。}次の順に進める。(1) 一般形の臨界温度、核生成温度、$\beta/H$ を求め、閉じた式を数値の極小と数値微分で、$S_3/T$ を Dine らの近似式で確かめる。SM 的な係数で試す。(2) $E$ などを変えて強い相転移を作り、相転移の強さ $\alpha_{\mathrm{PT}}$（定義は文献で確かめる）と $\beta/H$ を求める。(3) 音波と乱流による重力波のスペクトルの近似式を原論文で確かめ、LISA の感度と比べる。(4) 場 $\phi$ 自身の熱ループによる温度ポテンシャル（高温展開と daisy の和）を手で導き、相の移り変わりを追う。(5) 一般のポテンシャルの3次元の bounce を求める道具を作り、手順 (1) の $S_3$ を再現したうえで、単一場の模型の核生成と $(\kappa_3,\kappa_4)$ の熱的な安定性を調べる。(6) 単一場の模型の相転移の重力波を求める。(7) 独立な道具（CosmoTransitions）と照合する。(8) ループ計算ツールのレビュー~\cite{toolsreview} にある熱的な道具（DRalgo、Matchotter、PT2GWFinder、FindBounce）と照合する。

\section{一般形の相転移}\label{sec:dine}

\paragraph{手順 (1)：臨界温度と核生成温度。}Dine らの式 (4)、(8)〜(11) に今の質量を入れると、$D=0.166632$、$E=9.5778\times10^{-3}$、$B=-4.3903\times10^{-3}$、$T_0=163.4953$~GeV、$\lambda=m_h^2/(2v^2)=0.12938$、$\lambda_T(T_c)=0.11457$ となる（表~\ref{tab:dine}）。$R=\lambda_TD/E^2=208.1$ と大きいので、$\alpha$ は $T_0$ のすぐ上で0から $9/8$ まで変わる。式~\eqref{eq:crit} の $T_1=163.9390$~GeV と $T_c=163.8895$~GeV は、ポテンシャルの極小を数値で求めて決めた温度と全桁で一致し、$\phi_c/T_c=2E/\lambda_T=0.1672$ も数値の極小の位置と一致した。

$S_3(\alpha)$ には零温度のノートの手順 (9) の31点を使い、$\alpha$ の間は $\dd S_3/\dd\alpha=W$ を使った3次の Hermite 補間でつないだ。$\alpha>0.99$ では、薄い壁の展開 $(1-\alpha)^2S_3/(32\pi/9)=1+c_1(1-\alpha)+c_2(1-\alpha)^2$ を $\alpha\ge0.94$ で当てはめて使った。その切片は $1.00008$ である。式~\eqref{eq:nucl} を解くと $T_n=163.8723$~GeV で、$T_c$ の $0.0172$~GeV 下である。このとき $\alpha(T_n)=0.9565$、$S_3/T=148.78$、$\phi_n/T_n=0.174$ である。$S_3/T$ は Dine らの近似式の値 $150.09$ と $0.9\%$ で一致した。これは零温度のノートで見た、$\alpha\approx0.96$ での近似式の精度と同じである。式~\eqref{eq:betaH} の $\beta/H=2.5215\times10^6$ は、$S_3/T$ の中心差分（Richardson 外挿）と相対 $4\times10^{-9}$ で一致した。

この結果は、SM のヒッグスの質量では電弱相転移が非常に弱いという、よく知られた結論を再現する。$\phi_n/T_n\approx0.17$ は、電弱バリオン数生成に要る $\phi/T\gtrsim1$ よりずっと小さい。$T_c-T_n$ が $T_c$ の $10^{-4}$ しかなく、$\beta/H$ が $10^6$ もあるので、重力波も事実上作られない。なお、このパラメータでは1ループの高温展開そのものが信頼できず、格子計算によれば $m_h\gtrsim m_W$ では相転移はクロスオーバーになる~\cite{kajantie96}。ここでの数値は、強い相転移を調べる次の手順のための道具の検算と、その出発点である。スクリプトは \texttt{dine\_form.py} である。

\paragraph{手順 (2)：強い相転移の強さと速さ。}強さの定義は Caprini ら~\cite{caprini20} の原文で確かめた。式 (12) の $\alpha_\theta\equiv4\Delta\theta(T_n)/(3w_+(T_n))$ は、bag 模型の $\alpha=\epsilon/(a_+T^4)$（式 (9)）をトレースで一般化したものである。彼らは、流体の解析に効くのは $\Delta\theta$ だとして、この定義を標準に採る。式 (13) の $\alpha_e$ については、弱い相転移では $\Delta e\approx4\Delta\theta$ なので運動エネルギーを過大に見積もる、と注意している。本ノートでも $\alpha_{\mathrm{PT}}=\alpha_\theta$ とし、$\alpha_e$ は比べるために載せる。

検算は三つ行った。(a) 共通の関数（\texttt{tptlib.py}）は、手順 (1) の $T_n$、$\alpha(T_n)$、$S_3/T$、$\beta/H$、$\phi_n/T_n$ を相対 $10^{-14}$ 以内で再現した。(b) 式~\eqref{eq:alphae} の $\Delta V$ は、ポテンシャルの極小を数値で求めた値と相対 $2\times10^{-13}$ 以内で一致した。(c) $\Delta\theta=\Delta V-(T/4)\,\partial\Delta V/\partial T$ と $\Delta e=\Delta V-T\,\partial\Delta V/\partial T$ を、数値の極小から求めた $\Delta V$ の中心差分（Richardson 外挿）で求めた。式~\eqref{eq:alphatheta}、\eqref{eq:alphae} との差は、SM 的な係数で相対 $8\times10^{-9}$、$\lambda_T=0.05$、$E=0.04$ で相対 $1.5\times10^{-10}$ だった。SM 的な係数では $\alpha_\theta=7.14\times10^{-5}$、$\alpha_e/\alpha_\theta=3.999$ である。$T_n$ が $T_c$ に近く $\Delta V\approx0$ なので、$\Delta e$ は潜熱でほぼ決まり、$\alpha_e\approx4\alpha_\theta$ になる。

走査では、$D$ と $T_0$ を SM 的な値に固めた。$\lambda_T=0.02$、$0.05$、$0.1146$（SM 的な値）のそれぞれで、$E$ を SM 的な値 $9.58\times10^{-3}$ から $0.995E_{\max}$ まで等比に60点動かした。$E_{\max}=(8\lambda_TD/9)^{1/2}$ は $R=9/8$ にあたり、$E<E_{\max}$ なら高温での極小は $\phi=0$ だけである。すべての点で核生成が起こり、$S_3/T$ は $146.4$〜$148.8$ にとどまった。結果を図~\ref{fig:strong} に示す。$\lambda_T=0.02$ では $\phi_n/T_n=1.11$〜$7.16$、$\alpha_\theta=2.9\times10^{-3}$〜$7.1\times10^{-2}$、$\beta/H=8.0\times10^4$〜$9.7\times10^2$ である。$\lambda_T=0.05$ では $\phi_n/T_n=0.41$〜$4.23$、$\alpha_\theta=4.0\times10^{-4}$〜$1.8\times10^{-2}$、$\beta/H=4.9\times10^5$〜$7.5\times10^2$ である。$\lambda_T=0.1146$ では $\phi_n/T_n=0.17$〜$2.63$、$\alpha_\theta=7.1\times10^{-5}$〜$5.0\times10^{-3}$（最大は $\phi_n/T_n=2.28$ での $5.6\times10^{-3}$）、$\beta/H=2.5\times10^6$〜$7.7\times10^2$ である。$E$ が最大の点での $T_n/T_c$ は、それぞれ $0.452$、$0.531$、$0.626$ である。

図~\ref{fig:strong} の上の図は、式~\eqref{eq:alphatheta} の通りに読める。$\phi_n/T_n$ が小さいと $T_n\approx T_0$ なので、三つの $\lambda_T$ の曲線は、$T_n\to T_0$ の直線 $(15D/\pi^2g_*)(\phi_n/T_n)^2=2.37\times10^{-3}(\phi_n/T_n)^2$ に重なる。$E$ を大きくすると過冷却が進み、$(T_0/T_n)^2$ が小さくなって、曲線は直線から下に離れる。$\lambda_T=0.1146$ では、$E$ が最大に近づくと、$\phi_n/T_n$ の伸びより $(T_0/T_n)^2$ の減りが勝ち、$\alpha_\theta$ は減りに転じる。$\alpha_\theta\gtrsim0.1$ には $\phi_n/T_n\gtrsim6.5$ が要り、$\lambda_T$ を小さくしなければ届かない。下の図の $\beta/H$ は $\phi_n/T_n$ とともに減る。ただし、三つの $\lambda_T$ のどれでも最小は $7.5\times10^2$〜$9.7\times10^2$ で、$10^3$ 程度より下には届かなかった。

手順 (3) で重力波を求めるため、表~\ref{tab:bench} の4点を選んだ。BP1〜BP3 は、$\lambda_T=0.05$ で $\phi_n/T_n=1$、$2$、$3$ となる点である（$E$ は $\phi_n/T_n$ の根を Brent 法で求めた）。BP4 は走査で最も強い点（$\lambda_T=0.02$、$E=0.995E_{\max}$）である。BP1〜BP3 の $\alpha_e/\alpha_\theta$ は $3.95$、$3.69$、$2.97$ で、過冷却が進むほど4から下がる。式~\eqref{eq:alphae} の $\Delta e=4\Delta\theta-3\Delta V$ は打ち消し合う二つの量の差で、$\Delta V$ が育つと小さくなるからである。BP4 では $\Delta V/\rho_{\mathrm{rad}}=0.091$ が $\alpha_\theta=0.071$ を上回り、$\alpha_e/\alpha_\theta=0.16$ になる。Caprini らが $\alpha_e\approx\alpha_\theta$ とするのは、温度によらない真空のエネルギーが $\Delta V$ を占める $\alpha\gtrsim1$ の場合で、ここには当たらない。

ここでは一般形を、$D$、$E$、$T_0$、$\lambda_T$ を自由に選べる模型として扱った。$\phi_n/T_n\gtrsim1$ では、場に結合する粒子の質量が温度と同じ程度になり、高温展開そのものの精度が落ちる。また、BP4 のように $T_c/T_n\approx2$ まで過冷却すると、$\lambda_T$ の対数の温度依存も効きうる。本ノートでは、一般形の結果を、係数を与えたときの相転移の性質として読む。スクリプトは \texttt{strong\_pt.py}（共通の関数は \texttt{tptlib.py}）である。

\paragraph{手順 (3)：重力波と LISA の感度。}使った式は、すべて原論文で確かめた。$\kappa$ は Espinosa ら~\cite{espinosa10} の付録 A の式 (95)〜(102)、音波は Hindmarsh ら~\cite{hhrw17} の式 (23)、(35)、(36)、(43) と正誤表の式 (2)、衝撃波の補正は Caprini ら~\cite{caprini20} の式 (32)、乱流は Caprini ら~\cite{caprini16} の式 (16)〜(18)、(21)、LISA の感度は要求文書~\cite{scird} の式 (3) である。音波の振幅には、文献の間で食い違いがある。Caprini ら~\cite{caprini20} の式 (29) は、正誤表の $3$ の代わりに $1/c_s=\sqrt3$ を持ち、式 (32) の衝撃波の補正は $H_*R_*/\bar U_f$ の代わりに $H_*R_*/\sqrt K$ である。同じ $\tilde\Omega_{\mathrm{gw}}$ でそのまま使うと、本ノートの基準点では振幅がちょうど $1/2$ になる。Caprini ら~\cite{caprini16} の式 (13)〜(15) には衝撃波の補正がなく、ピークは $30$〜$190$ 倍大きい。本ノートでは、数値シミュレーションの原論文の正誤表による式~\eqref{eq:Osw} を使い、この差を振幅の不定性とみなす。

検算は五つ行った。(a) $\int C\,\dd\ln s=1.45539$ で、その逆数 $0.68710$ は式の $0.687$ と一致した。(b) $T_{\gamma,0}=2.725$~K から $\Omega_{\gamma,0}h^2=2.4711\times10^{-5}$ で、$F_{\mathrm{gw},0}(g_*=100)=3.5670\times10^{-5}$ は $3.57\times10^{-5}$ と相対 $9\times10^{-4}$ で一致した。(c) エントロピーの保存から求めた $H_{*,0}$ は、$T_*=100$~GeV、$g_*=100$ で $16.46\,\mu$Hz で、$16.5\,\mu$Hz と相対 $2\times10^{-3}$ で一致した。$f_p$ の係数 $(z_p/2\pi)H_{*,0}=26.20\,\mu$Hz は、$26\,\mu$Hz と $0.8\%$ で一致した。(d) $\kappa$ の近似式は、$v_w=c_s$ と Jouguet の速さ $v_J$ で、両側の値が相対 $10^{-6}$ 以内で一致し（$10^{-9}$ ずらした分の差）、$v_w=1$ で $\kappa_D$ になる。(e) PLS に接するべき乗のスペクトルの SNR は $10.000000$ である。LISA の $h^2\Omega_{\mathrm{sens}}$ の最小は $2.45$~mHz での $4.38\times10^{-12}$、PLS（SNR $=10$）の最小は $2.62$~mHz での $8.79\times10^{-14}$ である。

基準点の結果を表~\ref{tab:gw} と図~\ref{fig:gw} に示す。どの点でも $H_*\tau_{\mathrm{sh}}=0.009$〜$0.074$ と小さく、衝撃波ができて音波はハッブル時間の数 \% で終わる。乱流のピークは、$v_w=0.95$ のどの点でも音波のおよそ $1/550$ である。ただし、乱流は高い周波数で $f^{-5/3}$ とゆっくり下がるので、BP4 では $0.23$~Hz より上で音波を上回る。$v_w=0.95$ では、BP1〜BP4 のピークの周波数は $786$、$134$、$47$、$20$~mHz、ピークの $h^2\Omega_{\mathrm{gw}}$ は $3.2\times10^{-23}$〜$2.0\times10^{-15}$、SNR は $7.6\times10^{-15}$〜$0.014$ である。$v_w=0.44$ では $\kappa$ は大きくなるが、$R_*$ が $c_s$ で決まり、$f_p$ も高くなるので、SNR はさらに小さい。手順 (2) の走査の180点すべてで SNR を求めると、最大は BP4 の $0.014$ で、検出の目安の SNR $=10$ より3桁小さい。Caprini ら~\cite{caprini16} の大きい振幅を使っても、BP4 の SNR は $0.12$ である。

足りない理由は、$\beta/H$ が大きすぎ、強さも小さいことである。衝撃波で音波が早く終わると、$\Omega_{\mathrm{sw}}\propto K^{3/2}(H_*R_*)^2$ で、$H_*R_*\propto(\beta/H)^{-1}$ が効く。BP4 の $\alpha_\theta$ と $T_n$ のまま SNR $=10$ にするには $\beta/H\le134$ が要る（このとき $f_p=2.7$~mHz で、LISA の最も感度のよい周波数に来る）。BP4 の $\beta/H$ のままなら $\alpha_\theta\ge2.05$ が要る。一般形の走査では $\beta/H\ge7.5\times10^2$、$\alpha_\theta\le0.071$ なので、$D$ と $T_0$ を SM 的な値に固め、$\lambda_T\ge0.02$ とした範囲の一般形では、LISA で見える重力波は作れない。スクリプトは \texttt{gw\_spectrum.py} である。

\section{単一場の模型の相の移り変わり}\label{sec:single}

\paragraph{手順 (4)：温度ポテンシャルと相の移り変わり。}式~\eqref{eq:Vht} を主に使い、完全な1ループの式~\eqref{eq:V1loop}（$J_B$ を数値積分し、daisy の補正を加えたもの）で確かめた。場は単位 $m^2/g$ で $\chi=f+3/\alpha$、温度は $\tau=gT/m^2$、ポテンシャルは単位 $m^6/g^2$ で表す。この単位では、木と $T^2$ の項は $\alpha$ と $\tau$ だけで決まり、ループの項は $g/m$ に比例する。

検算は五つ行った。(a) $J_B(0)=-\pi^4/45$ は数値積分と15桁で一致した。高温展開の $y^2\ln y$ までの残りを $y^3$ で割ると、$y=0.025$ で手で導いた係数 $\zeta(3)/(384\pi^2)$ と相対 $2\times10^{-4}$ で一致し、差は $y$ に比例して減った。$y<0$ の実部が、$J_B$ の解析的な部分のなめらかな続きになっていることも確かめた。(b) 式~\eqref{eq:Ising} の奇関数の部分を、$\phi$ の変数で独立に書いた完全な1ループのポテンシャル（daisy を含む）で確かめた。$[V(\phi_i+\chi)-V(\phi_i-\chi)]/2$ は、$T=0.5$〜$6\,m$ で $b\chi$ と相対 $2\times10^{-12}$ 以内で一致した。(c) 最低次のスピノーダル温度の式~\eqref{eq:tsp} は、ポテンシャルの極小を数値で数えて求めた値と、相対 $5\times10^{-5}$ 以内で一致した（$\hat b=0$ で $6$、$\alpha=9/8$ で $0$）。(d) 高温の最小の位置は、$-b/U''(0)$ と $\tau=50$ で相対 $3\times10^{-6}$ で一致した。$\tau=25$、$50$、$100$ で $f=-3.398$、$-3.348$、$-3.337$ と、$\tau^{-2}$ で変曲点 $f=-3/\alpha=-3.333$ に近づく（$\alpha=0.9$）。(e) 高温展開と daisy によるスピノーダル温度は、完全な1ループと相対 $7\times10^{-6}$ 以内で一致した。新しく現れる極小での $\mathcal M^2/T^2$ は $|y|<0.12$ で、高温展開がよく効く範囲にある。

$\kappa_4=1$ でのスピノーダル温度を、表~\ref{tab:single} と図~\ref{fig:single} の下に示す。最低次の式~\eqref{eq:tsp} に daisy の3乗の項と対数の項を加えると、$\tau_{\mathrm{sp}}$ は $3.5$〜$15\%$ 上がる。物理の温度では、$T_{\mathrm{sp}}=\tau_{\mathrm{sp}}\,m/g$ は $\alpha=0.3$〜$1$ で $1.5$〜$4.0\,m$ で、$b=0$ の近くで最も高い。$\alpha\to9/8$ では、二つ目の極小そのものが消えるので $T_{\mathrm{sp}}\to0$ である。

図~\ref{fig:single} の上の二つは、冷えていくときの極小の位置である。$\alpha=0.9$ では、高温で $f=-3/\alpha$ の近くにあった最小が、なめらかに真の真空 $f_-=-7.24$ へ移る。偽の真空 $f=0$ の側の極小は $\tau_{\mathrm{sp}}=5.19$ より下で現れ、大域的な最小になることはない。$\alpha=1.05$ では逆に、最小は真の真空 $f=0$ へ移り、$f_-$ の側の極小は $\tau_{\mathrm{sp}}=4.27$ より下で現れる。$\tau$ を $0.005$ ずつ下げたとき、大域的な最小の位置の変化は最大でも $0.004$ で、跳びはない。

一次の相転移が起こりうるのは、二つの真空がちょうど縮退する $b=0$ の近くだけである。$\kappa_4=1$ では、$b=0$ は $\alpha_{\mathrm{deg}}=1.00246$ で起こる。そこでは偶関数の部分だけが残り、摂動論のポテンシャルは $\tau_c=6.1460$ で $\chi=0$ から $\chi_b$ へ跳ぶ。その跳びは $\phi/T=\chi_b/\tau_c=0.022$ と非常に弱い。$b\ne0$ で一次の跳びが起こるには、選ばれる側に二つの極小が並ぶ必要がある。それは $U'$ の極大より $|b|$ が小さいとき、すなわち $|b|<9.9\times10^{-7}\,m^4/g$（$|\alpha-\alpha_{\mathrm{deg}}|<3.3\times10^{-7}$）でしか起きない。それ以外では、高温の相から真の真空へなめらかに移る（クロスオーバー）。しかも $b=0$ の近くはゆらぎの強い臨界点の近くで、摂動論の弱い一次の跳びそのものも信頼できない。したがって、単一場の模型の熱的な歴史からは、重力波を出すような一次の相転移は生じない。

この結果は、零温度のノートの真空の安定性の議論を変える。$\alpha<1$ では、今の真空 $\phi=0$ は偽の真空である。宇宙がいったん $T_{\mathrm{sp}}$ より熱くなると、$\phi=0$ の側の極小はなくなり、場は真の真空 $f_-$ の側に移って、冷えてもそこにとどまる。したがって、$\alpha<1$ で $\phi=0$ を今の真空とするには、宇宙の最高温度（再加熱温度）が $T_{\mathrm{sp}}(\alpha)$ より低くなければならない。零温度のノートの寿命の条件の境界 $\kappa_3=1.476$（$\alpha=0.459$）では $T_{\mathrm{sp}}=1.91\,m=239$~GeV、$\kappa_3=1.054$（$\alpha=0.9$）では $T_{\mathrm{sp}}=3.23\,m=404$~GeV である。この条件は、零温度の寿命の条件とは別のもので、$\alpha<1$ のどこでも効く。$T_{\mathrm{sp}}$ より低い温度で $\phi=0$ にいる宇宙が、熱的な揺らぎで真の真空へ崩れないかは、手順 (5) で調べる。スクリプトは \texttt{thermal\_single.py}（共通の関数は \texttt{tptlib.py}）である。

\paragraph{手順 (5)：一般の bounce と熱的な安定性。}一般のポテンシャルの O($d$) の bounce を、撃ち込み法で求める道具を作った（\ref{app:bounce}）。検算は三つ行った。(a) 零温度のノートの木のポテンシャルで、$S_3$ は $\alpha=0.5$、$0.8$、$0.9$ で、$S_4$ は $\alpha=0.5$、$0.8$ で、零温度のノートの値と相対 $3\times10^{-13}$ 以内で一致した。薄い壁に近いところでは、$S_3$ は $\alpha=0.95$ で相対 $1\times10^{-7}$、$S_4$ は $\alpha=0.9$、$0.95$ で相対 $4\times10^{-8}$、$2\times10^{-7}$ で一致した。Derrick の関係 $S=\frac2dT$ も同じ精度で成り立った。(b) 手順 (1) の SM 的な係数と手順 (2) の基準点で、一般形の $S_3/T$ を直接求めた。零温度のノートの格子（$\alpha$ の刻み $0.05$〜$0.01$）の Hermite 補間で求めた手順 (1)、(2) の値との差は、相対 $9\times10^{-7}$〜$7\times10^{-5}$ で、格子点の間の補間の誤差の見積もりと合う。これによる $T_n$ のずれは、$\beta/H$ が大きいので相対 $10^{-6}$ 以下である。(c) 単一場の模型の $S_3/T$ は、高温展開と daisy の式~\eqref{eq:Vht} と完全な1ループの式~\eqref{eq:V1loop} とで、$T=0.37$〜$2.9\,m$ で相対 $5\times10^{-6}$〜$1.4\times10^{-3}$ で一致し、差は低い温度ほど大きい。

図~\ref{fig:stability} の上に、$\kappa_4=1$ での $S_3/T$ を示す。どの $\alpha$ でも、$S_3/T$ は $T_{\mathrm{sp}}$ で0に落ち、温度が下がると単調に増える。$\Gamma=H^4$ となる $S_3/T$ は、$T=0.3$〜$4\,m$ で $144$〜$155$ である。表~\ref{tab:stability} と図~\ref{fig:stability} の下に、$T_{\mathrm{dec}}$ と $T_{\mathrm{sp}}$ を、$\kappa_4=0.5$、$1$、$2$、$4$ で $\kappa_3$ の関数として示す。$\kappa_3$ は、$\alpha=0.99$ から零温度のノートの寿命の境界までとった。$T_{\mathrm{dec}}$ は、$\alpha\to1$ では $T_{\mathrm{sp}}$ に近いが（比 $0.85$〜$0.94$）、$\kappa_3$ を上げると急に下がる。零温度の寿命の境界では、$\kappa_4=0.5$、$1$、$2$、$4$ で $T_{\mathrm{dec}}=55$、$47$、$38$、$30$~GeV で、$T_{\mathrm{sp}}$ の $0.17$〜$0.21$ 倍である。$T_{\mathrm{dec}}$ は完全な1ループの値と、$\kappa_4=1$ の3点で相対 $3\times10^{-7}$〜$1.6\times10^{-3}$ で一致した。

したがって、$\alpha<1$（正確には $b>0$）で $\phi=0$ を今の真空とするには、宇宙の最高温度が $T_{\mathrm{dec}}$ より低くなければならない。$T_{\mathrm{dec}}<T_{\mathrm{sp}}$ なので、これは手順 (4) の条件より強い。零温度のノートの寿命の境界の近くでは、最高温度は $50$~GeV 程度より下に限られる。最高温度が数百 GeV を超える普通の熱的な歴史では、$\phi=0$ が真の真空である $\alpha>\alpha_{\mathrm{deg}}$（$\kappa_4=1$ で $\alpha_{\mathrm{deg}}=1.00246$）しか許されない。零温度の寿命の条件は、宇宙の最高温度が $T_{\mathrm{dec}}$ より低いときにだけ意味を持つ。スクリプトは \texttt{stability\_single.py}（bounce の道具は \texttt{tptlib.py}）である。

\paragraph{手順 (6)：単一場の模型の重力波。}手順 (4)、(5) から、単一場の模型の熱的な歴史は、重力波を出す一次の相転移を含まない。高温の相は、どの温度でも大域的な最小のまま、真の真空へなめらかに移る（クロスオーバー）。一次の跳びは $|\alpha-\alpha_{\mathrm{deg}}|<3.3\times10^{-7}$ でしか起きない。その中心の $b=0$ でも、跳びは $\phi/T=0.022$（$T_c=4.03\,m$）で、強さは $\alpha_\theta=7.2\times10^{-8}$（$\alpha_e=2.9\times10^{-7}$）にすぎない。音波の振幅は $K^2\propto\alpha_\theta^2$ に比例するので、手順 (3) の一般形の最も強い点（$\alpha_\theta=0.071$、SNR $=0.014$）よりさらに桁違いに小さい。選ばれない側の極小（$\alpha<1$ の $\phi=0$）の熱的な崩壊は一次の転移だが、宇宙がその極小にいるのは熱的でない理由による場合だけで、崩壊は温度が上がって $T_{\mathrm{dec}}$ を越えるときに起こる。その重力波は再加熱の速さという新しい仮定に依存するので、本ノートでは扱わない。以上から、単一場の模型の熱的な歴史からは、LISA で見える重力波は生じない。$\alpha_\theta$ はスクリプト \texttt{thermal\_single.py} で、$U$ の温度微分から求めた。

\paragraph{手順 (8)：レビューの熱的な道具との照合。}ループ計算ツールのレビュー~\cite{toolsreview} は、有限温度の計算の道具を、3次元の有効理論を作る層（DRalgo、Matchotter）と、相転移と重力波を求める層（PhaseTracer2、PT2GWFinder、BSMPT、TransitionListener）に分けている。このうち、本ノートの式を直接確かめられる DRalgo~\cite{dralgo}（1.5.0、GroupMath~\cite{groupmath} 1.1.3 とともに）、Matchete~\cite{matchete} 0.6.0 の Matchotter~\cite{matchotter}、PT2GWFinder~\cite{pt2gw} 1.1.0 と、それが使う FindBounce~\cite{findbounce} 1.1.0 を入れて照合した。結果を表~\ref{tab:tools} にまとめる。

(a) 単一場の温度ポテンシャル。DRalgo の例の実スカラー1つの模型~\cite{gould21} は、本ノートの単一場の模型そのものである。DRalgo は3次元の有効理論の係数を、$\lambda_3=T(\lambda-3\lambda^2L_b/32\pi^2)$、$\gamma_3=\sqrt T(g-3g\lambda L_b/32\pi^2)$、質量の2乗 $m^2+\lambda T^2/24-(g^2+\lambda m^2)L_b/32\pi^2$、線形項 $(t+gT^2/24-gm^2L_b/32\pi^2)/\sqrt T$ と与えた。ここで $L_b=2\ln(\mu/T)+2\gamma_E-2\ln4\pi$ は、式~\eqref{eq:Vht} の対数の符号を変えたものである。4次元の $\beta$ 関数も零温度のノートと一致した。これらの1ループの部分と、3次元の1ループの項 $-(T/12\pi)(m_3^2(\phi))^{3/2}$ から作った4次元のポテンシャルは、式~\eqref{eq:Vht} と、$\phi$ 微分の差が記号で0になるまで一致した。熱質量 $\Pi=\lambda T^2/24$、線形項 $gT^2/24$、対数の項の係数を、独立に確かめたことになる。Matchotter の \texttt{DRMatch} も同じ係数を与えた。ただし、Matchotter の対数 $\ln(\bar\Lambda^2/\Lambda_T^2)$（$\Lambda_T=4\pi T$）を $L_b$ と読む必要があり、これは $\bar\Lambda=\mu e^{\gamma_E}$ にあたる。Matchete の説明書には $\bar\Lambda$ の定義が書かれていない。DRalgo の NLO が加える2ループの熱質量は、$\alpha=0.9$（$\kappa_4=1$、$\mu=m$）のスピノーダル温度で $\Pi$ の $0.86\%$ で、最低次の $T_{\mathrm{sp}}$ を $0.43\%$ 下げる。これは、本ノートの1ループの結果に対する高次の補正の目安である。

(b) 一般形の相転移。PT2GWFinder の相の追跡（\texttt{TracePhases}）と \texttt{FindCritical} は、$T_c$ を BP1〜BP4 で相対 $2\times10^{-12}$ 以内、SM 的な係数で $8\times10^{-7}$ で再現した。強さ（トレースの定義）は、5点すべてで式~\eqref{eq:alphatheta} と相対 $10^{-11}$ 以内で一致した。FindBounce による $S_3/T$ は、場の点の数を51から801に増やすと、本ノートの値との差が $5\times10^{-4}$〜$6\times10^{-3}$ から $5\times10^{-6}$〜$8\times10^{-5}$ に減った。$\Gamma=H^4$ で求めた $T_n$ の差は $-9\times10^{-7}$〜$-2.4\times10^{-4}$ だった。PT2GWFinder はハッブル率に $|\Delta V|$ を含めるので、BP4 では $T_n$ が $1.8\times10^{-4}$ だけ下がる。残りは FindBounce の作用の誤差で説明できる。$\beta/H$ は、7温度の $S_3/T$ に2次式を当てはめて求め、SM 的な係数と BP1〜BP3 で相対 $5\times10^{-4}$ 以内、BP4 で $+1.6\%$ だった。BP4 の差は、当てはめの残差（$S_3/T$ で $0.32$）が示す、FindBounce の作用のばらつきの大きさにあたる。

\section{議論と今後}\label{sec:discussion}

\paragraph{結論。}第一の問い（相転移の温度、強さ、速さと重力波）について。高温展開の一般形は零温度の模型と $\alpha(T)$ で対応し、零温度のノートの $S_3(\alpha)$ から核生成温度と $\beta/H$ が閉じた形で決まる。強さは厳密に $\alpha_\theta=(15D/\pi^2g_*)(T_0/T_n)^2(\phi_n/T_n)^2$ で、$\phi_n/T_n$ と過冷却の度合いだけで決まる。SM 的な $D$、$T_0$ では、$\lambda_T\ge0.02$ の範囲で $\beta/H\ge7.5\times10^2$、$\alpha_\theta\le0.071$ で、LISA の SNR は最大 $0.014$ である。第二の問い（単一場の熱的な歴史）について。1ループの温度ポテンシャルは、変曲点のまわりで外場の中の Ising 模型の形になり、高温の相はいつも零温度の真の真空へなめらかに移る。偽の真空 $\phi=0$（$\alpha<1$）は熱的な歴史では選ばれず、今の真空であるには宇宙の最高温度が $T_{\mathrm{dec}}$（零温度の寿命の境界の近くで $50$~GeV 程度）より低くなければならない。普通の熱的な歴史では、零温度のノートの寿命の条件より強く、$\phi=0$ が真の真空であること（$\alpha>\alpha_{\mathrm{deg}}$）が要る。

\paragraph{今後。}第~\ref{sec:plan} 節の手順 (1)〜(8) はすべて終わった。残る課題は三つある。一つ目は、$D$ と $T_0$ も動かした一般形の走査で、LISA に届く $\beta/H\lesssim134$ の領域があるかを調べることである。二つ目は、熱的でない理由で $\phi=0$ にいる宇宙が、再加熱で $T_{\mathrm{dec}}$ を越えて崩れる場合の重力波で、再加熱の速さの模型が要る。三つ目は、高温展開の外（$\phi/T\gtrsim1$）と、$b=0$ の近くの臨界点の非摂動の効果である。

\section{一般形と零温度の模型の対応、臨界温度の導出}\label{app:map}

\paragraph{係数の対応。}式~\eqref{eq:VT} を $V=\frac12m^2\phi^2+\frac g6\phi^3+\frac\lambda{24}\phi^4$ と比べると、$\frac12m^2=D(T^2-T_0^2)$、$\frac g6=-ET$、$\frac\lambda{24}=\frac{\lambda_T}4$ なので、$m^2=M^2=2D(T^2-T_0^2)$、$g=-6ET$、$\lambda=6\lambda_T$ である。よって $\alpha=3\lambda m^2/g^2=18\lambda_TM^2/(36E^2T^2)=\lambda_TM^2/(2E^2T^2)$ で、$M^2$ を入れると式~\eqref{eq:alphaT} を得る。逆に解くと $M^2=2\alpha E^2T^2/\lambda_T$ である。

\paragraph{極小と臨界温度。}零温度のノートの付録~G より、$f=g\phi/m^2$ について、二つ目の極小は $\alpha\le9/8$ で $f_-=-\frac{9}{2\alpha}\bigl(1+\sqrt{1-8\alpha/9}\bigr)$ にあり、$\alpha=1$ で $\phi=0$ と縮退する。$\phi=0$ は $m^2=M^2<0$、すなわち $\alpha<0$ で不安定になる。$\phi=(m^2/g)f=-M^2f/(6ET)$ である。$\alpha=9/8$ は $1-T_0^2/T^2=9/(8R)$ を与え、$T_1^2=T_0^2/(1-9E^2/(8\lambda_TD))$ である。このとき $f_-=-4$ で、$\phi_1=4M^2/(6ET)=\frac23\cdot\frac{2\cdot\frac98E^2T^2}{\lambda_T}\cdot\frac{1}{ET}=\frac{3ET}{2\lambda_T}$ である。$\alpha=1$ は $T_c^2=T_0^2/(1-E^2/(\lambda_TD))$ を与え、$f_-=-6$ から $\phi_c=M^2/(ET)=2ET_c/\lambda_T$ である。$\alpha\to0$ では $f_-\simeq-9/\alpha$ なので、$\phi_0=\frac{9M^2}{6\alpha ET}=\frac{3ET}{\lambda_T}$ である。

\paragraph{3次元の作用。}零温度のノートの $S_3=(m^3/g^2)S_3(\alpha)$ に $m=M$、$g^2=36E^2T^2$ を入れると $S_3/T=M^3S_3(\alpha)/(36E^2T^3)$ で、$M^3=(2\alpha/\lambda_T)^{3/2}E^3T^3$ から式~\eqref{eq:S3T} を得る。

\paragraph{SM 的な係数。}Dine らの式 (4)、(8)〜(11) は
\begin{equation*}
D=\frac{2m_W^2+m_Z^2+2m_t^2}{8v^2},\quad E=\frac{2m_W^3+m_Z^3}{4\pi v^3},\quad B=\frac{3(2m_W^4+m_Z^4-4m_t^4)}{64\pi^2v^4},\quad
T_0^2=\frac{m_h^2-8Bv^2}{4D}
\end{equation*}
と、$\lambda_T=\lambda-\frac{3}{16\pi^2v^4}\bigl[2m_W^4\ln\frac{m_W^2}{a_BT^2}+m_Z^4\ln\frac{m_Z^2}{a_BT^2}-4m_t^4\ln\frac{m_t^2}{a_FT^2}\bigr]$（$\ln a_B=2\ln4\pi-2\gamma_E$、$\ln a_F=2\ln\pi-2\gamma_E$、$\lambda=m_h^2/(2v^2)$）である。$T_c$ は、$\lambda_T(T_c)$ を使った式~\eqref{eq:crit} を反復で解いて求めた。

\section{核生成の条件と相転移の速さの導出}\label{app:nucl}

\paragraph{核生成の条件。}$\Gamma=T^4(S_3/(2\pi T))^{3/2}e^{-S_3/T}$ と $H=1.66\sqrt{g_*}T^2/M_{\mathrm{Pl}}$ を $\Gamma=H^4$ に入れて対数をとると、$4\ln T+\frac32\ln\frac{S_3}{2\pi T}-\frac{S_3}{T}=4\ln H$、すなわち式~\eqref{eq:nucl} を得る。$T=163.9$~GeV では $M_{\mathrm{Pl}}/(1.66\sqrt{g_*}T)=4.34\times10^{15}$ で、右辺は $144.0$ である。$S_3/T=148.8$ では左辺の対数の項が $4.7$ なので、両辺が釣り合う。$T_n$ は、$\ln(\Gamma/H^4)$ を $T$ の関数として Brent 法で解いて求めた。$\phi_n$ は $T_n$ での $f_-$ から $\phi=-M^2f_-/(6ET)$ で求めた。

\paragraph{相転移の速さ。}$S_3/T=(E/36)(2/\lambda_T)^{3/2}\alpha^{3/2}S_3(\alpha)$ を $\alpha$ で微分すると $\frac{\dd}{\dd\alpha}\frac{S_3}{T}=\frac{S_3}{T}\bigl[\frac3{2\alpha}+\frac{W}{S_3(\alpha)}\bigr]$ である（$\lambda_T$ は一定とする）。式~\eqref{eq:alphaT} から $T\frac{\dd\alpha}{\dd T}=2R\frac{T_0^2}{T^2}=2(R-\alpha)$ なので、式~\eqref{eq:betaH} を得る。数値の確かめでは、$S_3/T$ の中心差分を刻み $h=10^{-6}T_n$ と $h/2$ で求めて Richardson 外挿した。

\section{相転移の強さの導出}\label{app:strength}

\paragraph{熱力学の量。}各相の圧力は自由エネルギー密度の符号を変えたもので、前提 6 より $p_\pm=p_{\mathrm{rad}}-V_\pm$ である。ここで $p_{\mathrm{rad}}=\pi^2g_*T^4/90$、$V_+=V(0,T)=0$、$V_-=V(\phi_-(T),T)$ である。$e=T\,\dd p/\dd T-p$、$w=e+p=T\,\dd p/\dd T$ から
\begin{equation*}
e_\pm=\rho_{\mathrm{rad}}+V_\pm-T\frac{\dd V_\pm}{\dd T},\qquad
\theta_\pm=\frac{e_\pm-3p_\pm}{4}=V_\pm-\frac T4\frac{\dd V_\pm}{\dd T},\qquad
w_+=\frac43\rho_{\mathrm{rad}}
\end{equation*}
である。放射の部分は $e=3p$ なので $\theta$ に寄与しない。$\dd V_-/\dd T$ は $\phi_-$ の温度変化も含む全微分だが、$\partial V/\partial\phi=0$ が $\phi_-$ で成り立つので、$\dd V_-/\dd T=\partial V/\partial T|_{\phi=\phi_-}$ である。差を対称相から破れた相を引いたものとすると、$\Delta V=-V_-$、$\Delta\theta=-\theta_-=\Delta V-\frac T4\frac{\dd\Delta V}{\dd T}$、$\Delta e=-(e_--e_+)=\Delta V-T\frac{\dd\Delta V}{\dd T}$ である。Caprini らの式 (12)、(13) は $\alpha_\theta=4\Delta\theta/(3w_+)=\Delta\theta/\rho_{\mathrm{rad}}$、$\alpha_e=\Delta e/\rho_{\mathrm{rad}}$ になる。bag 模型（$V_+-V_-=\epsilon$ が温度によらない）では $\Delta\theta=\Delta e=\epsilon$ で、式 (9) の $\alpha$ に戻る。

\paragraph{極小での値。}$M^2=2D(T^2-T_0^2)$ と書くと、$V=\frac12M^2\phi^2-ET\phi^3+\frac{\lambda_T}4\phi^4$ で、極小の条件 $\phi^{-1}\partial V/\partial\phi=M^2-3ET\phi+\lambda_T\phi^2=0$ から $\frac{\lambda_T}4\phi_-^4=-\frac14M^2\phi_-^2+\frac34ET\phi_-^3$ である。これを入れると
\begin{equation*}
V_-=\frac14M^2\phi_-^2-\frac14ET\phi_-^3,\qquad
\frac T4\frac{\partial V}{\partial T}\Big|_{\phi_-}=\frac T4\bigl(2DT\phi_-^2-E\phi_-^3\bigr)=\frac12DT^2\phi_-^2-\frac14ET\phi_-^3
\end{equation*}
で、$\theta_-=\frac12D(T^2-T_0^2)\phi_-^2-\frac12DT^2\phi_-^2=-\frac12DT_0^2\phi_-^2$ を得る。よって $\Delta\theta=\frac12DT_0^2\phi_-^2$ で、$\rho_{\mathrm{rad}}=\pi^2g_*T^4/30$ で割ると式~\eqref{eq:alphatheta} になる。$\Delta V=-V_-=\frac{\phi_-^2}4(ET\phi_--M^2)$ も同時に得られる。$e_--\rho_{\mathrm{rad}}=V_--T\,\partial V/\partial T|_{\phi_-}=4\theta_--3V_-$、$e_+=\rho_{\mathrm{rad}}$ なので、$\Delta e=4\Delta\theta-3\Delta V$ で、式~\eqref{eq:alphae} を得る。

\paragraph{トレースが $T_0$ だけから来る理由。}$T_0=0$ なら $V(\phi,T)=T^4U(\phi/T)$ の形で、$V_-=T^4U(u_-)$（$u_-$ は $U$ の極小で、温度によらない）なので、$\theta_-=V_--\frac T4\cdot4V_-=0$ である。$\theta_-$ は $T$ について4次でない項、すなわち $-DT_0^2\phi^2$ だけから生じる。

\paragraph{$\alpha$ を通した別の導き方。}零温度のノートの変数で書くと、$\phi=(m^2/g)f$、$m^6/g^2=(2\alpha^3/9)E^4T^4/\lambda_T^3$ から $\Delta V=(E^4T^4/\lambda_T^3)h(\alpha)$、$h(\alpha)=-\frac{2\alpha^3}{9}v(f_-)$、$v(f)=\frac{f^2}2+\frac{f^3}6+\frac{\alpha f^4}{72}$ である。$T\,\dd\alpha/\dd T=2(R-\alpha)$ より $T\,\dd\Delta V/\dd T=4\Delta V+(E^4T^4/\lambda_T^3)h'(\alpha)\cdot2(R-\alpha)$ で、$\Delta\theta=-\frac{E^4T^4}{2\lambda_T^3}h'(\alpha)(R-\alpha)$ である。$v'(f_-)=0$ から $h'=-\frac29\bigl[3\alpha^2v(f_-)+\alpha^3f_-^4/72\bigr]$ で、極小の条件 $\alpha f_-^2/18=-f_-/2-1$ を使うと $v(f_-)=f_-^2(6+f_-)/24$、$\alpha f_-^4/72=-f_-^2(f_-+2)/8$ なので
\begin{equation*}
h'(\alpha)=-\frac29\cdot\frac{\alpha^2f_-^2}{8}\bigl[(6+f_-)-(f_-+2)\bigr]=-\frac{\alpha^2f_-^2}{9}=-\frac94\Bigl(1+\sqrt{1-\tfrac{8\alpha}9}\Bigr)^2
\end{equation*}
である。$\phi_-=-\alpha f_-ET/(3\lambda_T)$ より $-h'=(\lambda_T\phi_-/(ET))^2$ で、$R-\alpha=RT_0^2/T^2=\lambda_TDT_0^2/(E^2T^2)$ を入れると $\Delta\theta=\frac12DT_0^2\phi_-^2$ に戻る。

\paragraph{臨界温度での確かめ。}$T_c$（$\alpha=1$、$\phi_c=2ET_c/\lambda_T$、$M^2=2E^2T_c^2/\lambda_T$）では $ET_c\phi_c=M^2$ なので $\Delta V=0$ で、$\Delta e=4\Delta\theta=2DT_0^2\phi_c^2$ は潜熱 $L$ である。一方、潜熱を直接求めると、$L=-T_c\,\dd\Delta V/\dd T=T_c\,\partial V/\partial T|_{\phi_c}=T_c(2DT_c\phi_c^2-E\phi_c^3)=2\phi_c^2T_c^2(D-E^2/\lambda_T)$ である。$T_0^2=T_c^2(1-E^2/(\lambda_TD))$ より両者は等しい。

\paragraph{数値の確かめ。}$\Delta V$ は、$\phi_-$ の閉じた式の $0.5$〜$1.5$ 倍の区間で、$V(\phi,T)$ の極小を有界な Brent 法で求めた。$\dd\Delta V/\dd T$ は、刻み $h=10^{-5}(T_n-T_0)$ と $h/2$ の中心差分を Richardson 外挿して求めた。

\section{重力波の換算の導出}\label{app:gw}

\paragraph{流体の運動エネルギー。}Caprini ら~\cite{caprini20} の式 (10)、(11) では、泡1つのまわりの流体の運動エネルギーを、放出されたエネルギーで割ったものを効率 $\kappa$ とし、全エネルギーに対する割合を $K=\kappa\alpha/(1+\alpha)$ とする。Espinosa ら~\cite{espinosa10} の近似式は bag 模型の強さで書かれているが、Caprini らに従い $\alpha=\alpha_\theta$ を入れる。式 (22) の $K=\Gamma\bar U_f^2$ で、相対論的な流体の断熱指数 $\Gamma=w/e=4/3$ を使うと $\bar U_f=(3K/4)^{1/2}$ である。衝撃波ができるまでの時間は、流れの長さ $R_*$ を速さ $\bar U_f$ で割った $\tau_{\mathrm{sh}}=R_*/\bar U_f$ である（Caprini らの表 1、Hindmarsh らの式 (22)）。

\paragraph{泡の平均間隔。}核生成率が $\Gamma(t)=\Gamma_\star e^{\beta(t-t_\star)}$ で増え、泡が速さ $v_w$ で広がるとする（宇宙膨張は無視する）。時刻 $t$ に偽の真空が残る割合は $e^{-I(t)}$ で、$I(t)=\int_{-\infty}^t\dd t'\,\Gamma(t')\,\frac{4\pi}3v_w^3(t-t')^3$ である。$x=t-t'$ とおくと $I=\frac{4\pi}3v_w^3\Gamma(t)\int_0^\infty x^3e^{-\beta x}\dd x=\frac{8\pi v_w^3}{\beta^4}\Gamma(t)$ である。泡の数密度は、偽の真空で生まれる泡を数えて $n_b=\int\dd t\,\Gamma(t)e^{-I(t)}$ である。$u=I(t)$ とおくと $\dd u=\beta u\,\dd t$、$\Gamma=\beta^4u/(8\pi v_w^3)$ なので、$n_b=\frac{\beta^3}{8\pi v_w^3}\int_0^\infty e^{-u}\dd u=\frac{\beta^3}{8\pi v_w^3}$ である。平均間隔は $R_*=n_b^{-1/3}=(8\pi)^{1/3}v_w/\beta$ である。デフラグレーションでは、壁の前の衝撃波が音速で先に広がるので、$v_w$ を $c_s$ に置き換える（Caprini らの式 (6)）。$\beta=\dd\ln\Gamma/\dd t$ は、$\dd T/\dd t=-HT$ から $\beta=H\,T\,\dd(S_3/T)/\dd T$ で、式~\eqref{eq:betaH} の $\beta/H$ に $H_*$ を掛けたものである。

\paragraph{今日までの薄まり。}重力波は放射と同じく $a^{-4}$ で薄まるので、$\Omega_{\mathrm{gw},0}=\Omega_{\mathrm{gw},*}\,\rho_*a_*^4/(\rho_{c,0}a_0^4)$ である。$\rho_*=\frac{\pi^2}{30}g_*T_*^4$ で、エントロピーの保存 $g_sT^3a^3=$ 一定から $a_*/a_0=(g_{s0}/g_{s*})^{1/3}T_{\gamma,0}/T_*$ である（$T_{\gamma,0}$ は今日の CMB の温度）。よって
\begin{equation*}
F_{\mathrm{gw},0}=\frac{\pi^2}{30}g_*T_{\gamma,0}^4\Bigl(\frac{g_{s0}}{g_{s*}}\Bigr)^{4/3}\frac1{\rho_{c,0}}=\Omega_{\gamma,0}\Bigl(\frac{g_{s0}}{g_{s*}}\Bigr)^{4/3}\frac{g_*}{2},\qquad
\Omega_{\gamma,0}=\frac{\pi^2}{15}\frac{T_{\gamma,0}^4}{\rho_{c,0}}
\end{equation*}
である。$g_{s*}=g_*$ とすると、$g_*$ への依存は $g_*\cdot g_*^{-4/3}=g_*^{-1/3}$ である。$T_{\gamma,0}=2.725$~K、$\rho_{c,0}=3H_0^2M_{\mathrm{Pl}}^2/(8\pi)$ から $\Omega_{\gamma,0}h^2=2.4711\times10^{-5}$ で、$h=0.678$、$g_{s0}=3.91$、$g_*=100$ で $F_{\mathrm{gw},0}=3.567\times10^{-5}$ である。

\paragraph{周波数の換算。}周波数は $a^{-1}$ で下がる。$H_*$ を今日の周波数に直すと
\begin{equation*}
H_{*,0}=H_*\frac{a_*}{a_0}=1.66\sqrt{g_*}\,\frac{T_*^2}{M_{\mathrm{Pl}}}\Bigl(\frac{g_{s0}}{g_{s*}}\Bigr)^{1/3}\frac{T_{\gamma,0}}{T_*}
\end{equation*}
で、$T_*=100$~GeV、$g_*=100$ では $16.46\,\mu$Hz である（GeV から Hz へは $\hbar$ で直す）。$H_{*,0}$ は $T_*$ と $g_*^{1/2-1/3}=g_*^{1/6}$ に比例する。音波のスペクトルは $kR_*=z_p$ でピークを持つ（Hindmarsh らの VI 節）。$k$ は角波数なので、生じたときの周波数は $z_p/(2\pi R_*)$ で、今日は $f_p=\frac{z_p}{2\pi}\frac{H_{*,0}}{H_*R_*}$ である。$z_p=10$ で係数は $26.2\,\mu$Hz になり、Hindmarsh らの式 (43) の $26\,\mu$Hz にあたる。

\paragraph{感度と SNR。}特性歪み $h_c$ を $\langle h_{ij}h_{ij}\rangle=2\int h_c^2\,\dd\ln f$ で定め、感度曲線の規約 $h_c^2=fS_h$ をとる。このとき $\langle\dot h_{ij}\dot h_{ij}\rangle=2\int\dd f\,(2\pi f)^2S_h$ で、$\rho_{\mathrm{gw}}=\langle\dot h_{ij}\dot h_{ij}\rangle/(32\pi G)$ から $\dd\rho_{\mathrm{gw}}/\dd\ln f=\pi f^3S_h/(4G)$ である。$\rho_{c,0}=3H_0^2/(8\pi G)$ で割ると $\Omega=2\pi^2f^3S_h/(3H_0^2)$ で、両辺に $h^2$ を掛けると式~\eqref{eq:snr} の左の式になる。Caprini らの式 (34) は、この規約で要求文書の $S_h$ を使っている。SNR は Caprini らの式 (33) で、$T_{\mathrm{obs}}$ は観測期間に稼働率を掛けたものである。積分は $10^{-5}$〜$1$~Hz で、対数で等間隔な6001点の台形公式で行った。

\paragraph{べき乗のスペクトルに対する感度。}SNR は振幅に比例するので、$\Omega_\beta(f/f_{\mathrm{ref}})^\beta$ の SNR を $\rho_{\mathrm{th}}$ にする振幅は
\begin{equation*}
\Omega_\beta=\rho_{\mathrm{th}}\Bigl[T_{\mathrm{obs}}\int\dd f\,\frac{(f/f_{\mathrm{ref}})^{2\beta}}{\Omega_{\mathrm{sens}}(f)^2}\Bigr]^{-1/2}
\end{equation*}
である。PLS はその包絡線 $\Omega_{\mathrm{PLS}}(f)=\max_\beta\Omega_\beta(f/f_{\mathrm{ref}})^\beta$ である（Thrane と Romano の式 (29)、(30) で、SNR を式~\eqref{eq:snr} に替えたもの）。PLS に接するべき乗のスペクトルは、ちょうど SNR $=\rho_{\mathrm{th}}$ を持つ。$\rho_{\mathrm{th}}=10$、$f_{\mathrm{ref}}=1$~mHz とし、$\beta$ は $-8$〜$8$ を $0.05$ 刻みでとった。

\section{単一場の温度ポテンシャルの導出}\label{app:single}

\paragraph{1ループの自由エネルギー。}場による質量 $\mathcal M^2$ の自由な場の自由エネルギー密度は、松原の振動数 $\omega_n=2\pi nT$ を使って
\begin{equation*}
F=\frac T2\sum_{n=-\infty}^\infty\mu^{2\epsilon}\int\frac{\dd^dk}{(2\pi)^d}\ln\bigl(\omega_n^2+k^2+\mathcal M^2\bigr),\qquad d=3-2\epsilon
\end{equation*}
である。$E=(k^2+\mathcal M^2)^{1/2}$ として、$\sum_n1/(\omega_n^2+E^2)=\coth(E/2T)/(2ET)$ から $\frac{\dd}{\dd E}\frac T2\sum_n\ln(\omega_n^2+E^2)=\frac12\coth\frac E{2T}=\frac12+\frac1{e^{E/T}-1}$ である。これを積分すると $\frac T2\sum_n\ln(\omega_n^2+E^2)=\frac E2+T\ln(1-e^{-E/T})$（$E$ によらない定数を除く）となる。$E/2$ の項は零温度の1ループ（Coleman–Weinberg）で、$\overline{\mathrm{MS}}$ では $\frac{\mathcal M^4}{64\pi^2}(\ln\frac{\mathcal M^2}{\mu^2}-\frac32)$ である。残りは $x=k/T$ として $T\int\frac{\dd^3k}{(2\pi)^3}\ln(1-e^{-E/T})=\frac{T^4}{2\pi^2}J_B(\mathcal M^2/T^2)$ で、式~\eqref{eq:V1loop} を得る。ポテンシャルは場 $\phi$ でのこの値で、$\mathcal M^2=V''(\phi)$ である。$\mathcal M^2<0$ では $J_B$ の実部をとる。

\paragraph{高温展開。}次元正則化の公式 $\mu^{2\epsilon}\int\frac{\dd^dk}{(2\pi)^d}\ln(k^2+A)=-\frac{\Gamma(-d/2)}{(4\pi)^{d/2}}A^{d/2}\mu^{2\epsilon}$ を、$A=\omega_n^2+\mathcal M^2$ に使う。$d=3$ で $\Gamma(-3/2)/(4\pi)^{3/2}=1/(6\pi)$ である。$n=0$ の項（ゼロモード）は $-\frac T2\cdot\frac1{6\pi}\mathcal M^3=-\frac{T\mathcal M^3}{12\pi}$ で、極を持たない。$n\ne0$ の項は $A^{d/2}=\sum_k\binom{d/2}{k}\mathcal M^{2k}|\omega_n|^{d-2k}$ と展開し、$\sum_{n\ne0}|\omega_n|^{d-2k}=2(2\pi T)^{d-2k}\zeta(2k-d)$ を使う。$k=0$ は $\zeta(-3)=1/120$ から $-\pi^2T^4/90$、$k=1$ は $\binom{3/2}{1}=3/2$、$\zeta(-1)=-1/12$ から $T^2\mathcal M^2/24$ を与える。$k=2$ は $\zeta(4-d)=\zeta(1+2\epsilon)=\frac1{2\epsilon}+\gamma_E$ の極を持つ。$\Gamma(-\frac32+\epsilon)=\Gamma(-\frac32)[1+\epsilon\psi(-\frac32)]$（$\psi(-\frac32)=-\gamma_E-2\ln2+\frac83$）、$\binom{d/2}{2}=\frac38(1-\frac83\epsilon)$、$(4\pi)^{-d/2}=(4\pi)^{-3/2}(1+\epsilon\ln4\pi)$、$\mu^{2\epsilon}=1+2\epsilon\ln\mu$、$(2\pi T)^{d-4}=(2\pi T)^{-1}(1-2\epsilon\ln2\pi T)$ を入れると、
\begin{equation*}
F_{k=2}=-\frac{\mathcal M^4}{64\pi^2}\Bigl[\frac1\epsilon-\gamma_E+\ln4\pi+2\gamma_E-2\ln4\pi+\ln\frac{\mu^2}{T^2}\Bigr]
\end{equation*}
となる。$\overline{\mathrm{MS}}$ の対抗項で $\frac1\epsilon-\gamma_E+\ln4\pi$ を除くと、$F_{k=2}=\frac{\mathcal M^4}{64\pi^2}(\ln\frac{T^2}{\mu^2}+2\ln4\pi-2\gamma_E)$ である。$k=3$ は $\binom{3/2}{3}=-\frac1{16}$、$\zeta(3)$ から $\frac{\zeta(3)\mathcal M^6}{768\pi^4T^2}$ を与える。これらの和は、零温度の部分と熱の部分の和である。零温度の部分 $\frac{\mathcal M^4}{64\pi^2}(\ln\frac{\mathcal M^2}{\mu^2}-\frac32)$ を引くと、熱の部分の展開
\begin{equation*}
J_B(y)=-\frac{\pi^4}{45}+\frac{\pi^2}{12}y-\frac\pi6y^{3/2}-\frac{y^2}{32}\ln\frac y{a_b}+\frac{\zeta(3)}{384\pi^2}y^3+O(y^4),\qquad \ln a_b=2\ln4\pi+\frac32-2\gamma_E
\end{equation*}
を得る（$\frac{T^4}{2\pi^2}\cdot\frac{\pi^2}{12}y=\frac{T^2\mathcal M^2}{24}$ などと対応させた）。$\ln a_b=5.4076$ である。全体では $\mathcal M^4\ln\mathcal M^2$ が打ち消し合い、式~\eqref{eq:Vht} の対数の項が残る。

\paragraph{daisy の和。}ゼロモードは、硬い（$n\ne0$）モードから熱質量を受け取る。熱質量は $T^2$ の項 $\frac{T^2}{24}\mathcal M^2(\phi)$ を場で2回微分したもので、$\Pi=\frac{T^2}{24}\frac{\dd^2\mathcal M^2}{\dd\phi^2}=\frac{\lambda T^2}{24}$ である。$\mathcal M^2$ は $\phi$ の2次式なので、$\Pi$ は場によらない。$\Pi$ を挿入したリングの図を足し上げると $\frac T2\int\frac{\dd^3k}{(2\pi)^3}\sum_{N\ge1}\frac{(-1)^{N+1}}N\bigl(\frac{\Pi}{k^2+\mathcal M^2}\bigr)^N=\frac T2\int\frac{\dd^3k}{(2\pi)^3}\ln\frac{k^2+\mathcal M^2+\Pi}{k^2+\mathcal M^2}$ で、ゼロモードの項は $-\frac{T}{12\pi}(\mathcal M^2+\Pi)^{3/2}$ に置き換わる~\cite{arnoldespinosa}。3点の結合 $V'''=g+\lambda\phi$ による硬いモードのループは $T^2$ に比例しないので、熱質量には入らない。完全な1ループの数値では、式~\eqref{eq:V1loop} に $-\frac T{12\pi}[(\mathcal M^2+\Pi)^{3/2}-(\mathcal M^2)^{3/2}]$（実部）を加えた。

\paragraph{変曲点のまわりの構造。}$\phi=\phi_i+\chi$、$\phi_i=-g/\lambda$ とすると、$\mathcal M^2=m^2+g\phi_i+\frac\lambda2\phi_i^2+(g+\lambda\phi_i)\chi+\frac\lambda2\chi^2=m^2-\frac{g^2}{2\lambda}+\frac\lambda2\chi^2$ で、$\lambda=\alpha g^2/(3m^2)$ から $\mathcal M_i^2=m^2(1-\frac3{2\alpha})$ である。木のポテンシャルは4次式なので $V(\phi_i+\chi)=V(\phi_i)+V'(\phi_i)\chi+\frac12V''(\phi_i)\chi^2+\frac16V'''(\phi_i)\chi^3+\frac\lambda{24}\chi^4$ で、$V'''(\phi_i)=0$ である。$V'(\phi_i)=m^2\phi_i+\frac g2\phi_i^2+\frac\lambda6\phi_i^3=-\frac{m^2g}\lambda+\frac{g^3}{3\lambda^2}=\frac{3m^4}{g}\Bigl(\frac1{\alpha^2}-\frac1\alpha\Bigr)$ に線形項 $t$ を加えて、式~\eqref{eq:Ising} の $b$ を得る。$t\phi=t\chi+$定数である。1ループの項はすべて $\mathcal M^2$ と場によらない $\Pi$ の関数なので、$\chi$ の偶関数である。$\overline{\mathrm{MS}}$ の結合は $\mu$ とともに走るが、零温度のノートの1ループの結果では $g/\lambda$ は走らないので、変曲点 $\phi_i$ は $\mu$ によらない。

$V(\chi)=b\chi+U(\chi^2)$ なら、どの $\chi$ でも $V(-s|\chi|)-V(s|\chi|)=-2s b|\chi|=-2|b||\chi|$（$s=\mathrm{sign}\,b$）である。よって、$\chi b>0$ の側のどの点にも、それより低い点が反対側にあり、大域的な最小は $\chi b\le0$ の側にある。$T=0$ でも同じなので、その側が零温度の真の真空である。$\alpha<1$（$b>0$、$t$ は小さい）では $\chi<0$、すなわち $\phi$ の小さい側で、真の真空は $f_-$ である。

\paragraph{最低次のスピノーダル温度。}木と $T^2$ の項だけでは $V=b\chi+\frac12a\chi^2+\frac\lambda{24}\chi^4$ で、$a=\mathcal M_i^2+\frac{\lambda T^2}{24}$ である。$V'=b+a\chi+\frac\lambda6\chi^3$ は、$a<0$ なら $\chi=\pm(-2a/\lambda)^{1/2}$ で極値 $b\mp\frac{2|a|}3(\frac{2|a|}\lambda)^{1/2}$ をとる。三つの実根（二つの極小）を持つ条件は $|b|<\frac{2|a|}3(\frac{2|a|}\lambda)^{1/2}$ である。単位 $m^2/g$、$m^6/g^2$ では $\lambda\to\alpha/3$、$b\to\hat b$、$a\to1-\frac3{2\alpha}+\frac{\alpha\tau^2}{72}$ なので、等号は $|a|^{3/2}=\frac{3|\hat b|}2(\frac\alpha6)^{1/2}$ で、式~\eqref{eq:tsp} を得る。$\tau=0$、$t=0$ では、$\alpha=9/8$ で両辺が等しく（$|\hat b|=\frac8{27}$、$|a|=\frac13$）、零温度の二つ目の極小が現れる条件 $\alpha<9/8$ に戻る。$\hat b=0$ では $a=0$、すなわち $\frac{\alpha\tau^2}{72}=\frac3{2\alpha}-1$ で、$\alpha=1$ では $\tau_{\mathrm{sp}}=6$ である。

\paragraph{高温の最小。}$V'=b+U'(\chi)$、$U'(\chi)\simeq U''(0)\chi$ から、最小は $\chi\simeq-b/U''(0)$ にある。式~\eqref{eq:Vht} では $U''(0)=\mathcal M_i^2+\frac{\lambda T^2}{24}-\frac{\lambda T}{8\pi}(\mathcal M_i^2+\Pi)^{1/2}+\frac{\lambda\mathcal M_i^2}{32\pi^2}(\ln\frac{T^2}{\mu^2}+2\ln4\pi-2\gamma_E)$ で、高温では $T^2$ に比例するので、$\chi\propto T^{-2}\to0$ である。

\paragraph{数値の細部。}$J_B$ は、$y\ge0$ では定義のまま数値積分した。$y<0$ では、$x<\sqrt{-y}$ で $E=is$、$\mathrm{Re}\ln(1-e^{-is})=\ln(2\sin\frac s2)$ なので、$s=(-y-x^2)^{1/2}$ と $u=(x^2+y)^{1/2}$ に変数を変えて、端の対数の特異性を除いて積分した（$-(2\pi)^2<y<0$）。速さのため、解析的な部分 $J_B-[-\frac\pi6\mathrm{Re}\,y^{3/2}-\frac{y^2}{32}\ln|y|]$ を $-30\le y\le120$ の3次のスプラインで補間した。数値積分との差は $3\times10^{-9}$ 以下である。極小は、$\chi$ の格子（2001〜4001点）で探し、有界な Brent 法で詰めた。スピノーダル温度は、極小が二つある最高の $\tau$ を二分法で求めた。完全な1ループは、$y\ge-30$ となる $\tau$ でだけ使った。$b=0$ の近くの一次の跳びは、偶関数の部分の傾き $U'(\chi)$ の解析的な式を $\chi>0$ の細かい格子（$10^{-8}$〜$1.5$）で調べ、$U'$ が増え、減り、また増える温度を探した。選ばれる側に二つの極小が並ぶ条件は、ある温度で $|b|$ が $U'$ の極大より小さいことである。

\section{一般のポテンシャルの bounce と熱的な崩壊の導出}\label{app:bounce}

\paragraph{O($d$) の bounce。}$d$ 次元のユークリッドの作用 $S=\int\dd^dx\,[\frac12(\partial\phi)^2+V(\phi)-V(\phi_f)]$ の O($d$) 対称な停留点は、$\phi''+\frac{d-1}r\phi'=V'(\phi)$、$\phi'(0)=0$、$\phi(\infty)=\phi_f$ を満たす。作用は $S=\Omega_{d-1}\int_0^\infty r^{d-1}\dd r\,[\frac12\phi'^2+V-V(\phi_f)]$（$\Omega_2=4\pi$、$\Omega_3=2\pi^2$）である。有限温度の崩壊は $d=3$ で、$S_3/T$ が指数に入る。

\paragraph{Derrick の関係。}$\phi_\lambda(r)=\phi(r/\lambda)$ とすると、運動の部分 $T$ は $\lambda^{d-2}T$ に、ポテンシャルの部分 $U$ は $\lambda^dU$ になる。$\lambda=1$ で作用が停留することから $(d-2)T+dU=0$ で、$S=T+U=\frac2dT$ である。数値ではこれを独立な確かめに使った。

\paragraph{撃ち込み法。}$\phi(0)=\phi_0$ を、真の極小 $\phi_t$ と、真の側で $V=V(\phi_f)$ となる点 $\phi_z$ の間で選ぶ。逆さのポテンシャル $-V$ の中を摩擦 $(d-1)\phi'/r$ を受けて動く粒子と見ると、$\phi_0$ が $\phi_z$ に近いと $\phi_f$ に届かずに引き返し（undershoot）、$\phi_t$ に近いと $\phi_f$ を越える（overshoot）。その境目が bounce である。$\phi_0=\phi_t+(\phi_z-\phi_t)e^{-u}$ として、$u$ を二分法で求めた。薄い壁では $\phi_0-\phi_t$ が指数的に小さいので、$\phi_t$ の近くでは線形化した解 $\phi-\phi_t=\delta\,\Gamma(\frac d2)(\frac2{\mu r})^{d/2-1}I_{d/2-1}(\mu r)$（$\mu^2=V''(\phi_t)$、$\delta=\phi_0-\phi_t$）を使う。これは $\phi''+\frac{d-1}r\phi'=\mu^2(\phi-\phi_t)$ の原点で正則な解で、$d=3$ では $\sinh(\mu r)/(\mu r)$ である。$|\phi-\phi_t|$ が $|\phi_z-\phi_t|$ の $10^{-3}$ になる半径から、DOP853（相対 $10^{-12}$）で数値積分した。作用は、引き返す点までの台形公式で求め、それより内側の芯は $V(\phi_t)-V(\phi_f)$ の体積として加えた。

\paragraph{単位と崩壊の条件。}単一場の模型では、$\phi=(m^2/g)\chi$、$r=\rho/m$、$V=(m^6/g^2)v$ とすると $S_3=(m^3/g^2)\hat S_3$（$\hat S_3=4\pi\int\rho^2\dd\rho\,[\frac12(\dd\chi/\dd\rho)^2+v-v_f]$）で、$T=(m^2/g)\tau$ なので $S_3/T=\hat S_3/((g/m)\tau)$ である。木と $T^2$ の項だけなら、$v$ は $\alpha$ と $\tau$ だけで決まるので、$\hat S_3$ も $\alpha$ と $\tau$ だけで決まり、$S_3/T$ は $g/m$ に反比例する。偽の真空がハッブル体積の中で1ハッブル時間の間に崩れる確率は、$\Gamma/H^4$ の程度である。$S_3/T$ は $T_{\mathrm{sp}}$ で0に落ち、温度が下がると増えるので、$\Gamma/H^4$ は温度が下がるほど小さい。したがって、$\phi=0$ が生き残る条件は、宇宙の最高温度が、$\Gamma(T_{\mathrm{dec}})=H(T_{\mathrm{dec}})^4$ となる温度 $T_{\mathrm{dec}}$ より低いことである。$T_{\mathrm{dec}}$ は、$\ln(\Gamma/H^4)$ を $\tau$ の関数として Brent 法で解いて求めた（$\tau$ の幅は $0.3$ から $0.97\tau_{\mathrm{sp}}$）。

\section{独立な道具との照合の細部}\label{app:ct}

\paragraph{設定。}\texttt{SingleFieldInstanton.findProfile} は、既定の許容誤差では作用の相対誤差が $6\times10^{-4}$ ほどあるので、\texttt{xtol}$=$\texttt{phitol}$=10^{-10}$、\texttt{npoints}$=4000$ とした。経路の変形の \texttt{fullTunneling} では、経路に沿ったポテンシャルのスプライン（既定は100点）を使わず、ポテンシャルを直接評価した（\texttt{V\_spline\_samples=None}）。一般形の相の追跡は、温度の刻みの初期値と飛び（\texttt{dtstart}、\texttt{tjump}）を温度の範囲の $10^{-6}$ 倍とした。既定の $10^{-3}$ 倍（$0.2$~GeV）では、SM 的な係数の $T_0$〜$T_1$ の幅 $0.44$~GeV を飛び越え、破れた相が $T_c$ の手前で途切れた。追跡の上限は $1.05\,T_1$ とした。BP4 では $T_1=1637$~GeV が $T_c$ よりずっと高いので、上限を $T_c$ の近くにすると対称な相が見つからない。核生成の基準には、本ノートの $\Gamma=H^4$ を \texttt{nuclCriterion} として渡した。作用が0（障壁がない）のときは崩壊が速い側（負）、無限大（崩れない）のときは遅い側（正）を返すようにした。

\paragraph{道具を使ううえでの注意。}numpy 2 では \texttt{np.product} が除かれているが、CosmoTransitions の \texttt{helper\_functions} はこれを使う。導入したパッケージは書き換えず、照合のスクリプトで読み込む前に \texttt{np.product = np.prod} とした。単一場の模型で \texttt{findAllTransitions} を使うと、$\alpha=1.05$ で例外が起きて止まった。準安定な相が消える終点の温度で、その相の位置から最小を探し直すと大域的な最小に落ち、ほぼ同じ2点の間でトンネルを試みて、作用の積分の中の括りが失敗する。この例外を処理する部分が、その温度の結果を記録していないので、続く辞書の参照も失敗する。そこで、終点の $0.999$ 倍を上限として \texttt{tunnelFromPhase} を直接呼んだ。

\paragraph{レビューの道具の導入。}DRalgo 1.5.0、FindBounce 1.1.0、PT2GWFinder 1.1.0 は、配布の paclet を \texttt{PacletInstall} で入れた。GroupMath 1.1.3 と Matchete 0.6.0（Matchotter を含む。GitLab の master の2026年9月24日のコミット 742c31e）は、\texttt{\textasciitilde/Library/Wolfram/Applications} に置いた。どれも Mathematica 14.2.1 で動かした。DRalgo と Matchete は同じカーネルで読み込まないようにし、スクリプトを分けた。Matchete は、フロントエンドのない wolframscript ではロゴを描けずに ``Loading failed!'' と出すが、計算には影響しない。

\paragraph{次元還元の取り決め。}DRalgo の NLO の質量と線形項のうち、$T^2$ に比例する項と3次元の結合を含む項は2ループなので、1ループの照合ではそれ以外の項を取り出した。Matchotter は1ループの因子 $1/(4\pi)^2$ を \texttt{hbar} と書き、$1/\epsilon$ の極を残すので、$\overline{\mathrm{MS}}$ としてそれを除いた。2ループの熱質量の見積もりでは、3次元の走る対数 $\ln(\mu_3/\mu)$ を0とした。最低次のスピノーダル温度は、式~\eqref{eq:tsp} の $a(T)$ の熱質量を $\Pi(1+\delta)$ に替えて求め直した。

\paragraph{PT2GWFinder の取り決め。}崩壊率は本ノートと同じ $T^4(S_3/2\pi T)^{3/2}e^{-S_3/T}$ である。ハッブル率は、放射のエネルギー密度に $|\Delta V|$ を加え、換算 Planck 質量 $2.4353\times10^{18}$~GeV で求める。\texttt{FindNucleation} の二分法の許容誤差は探す範囲の $10^{-3}$ なので、範囲を本ノートの $T_n$ の $\pm0.2\%$ に絞った。\texttt{SearchPhases} は、核生成を $\int(\dd T/T)\Gamma/H^4=1$ で決め、重力波の量を浸透温度で評価する。強さ \texttt{Alpha} は、場を固めたポテンシャルの温度微分を数値で求めたトレースの定義で、Caprini ら~\cite{caprini20} の式 (12) の定義と同じである。相を純関数で渡すと、\texttt{FindCritical} は定義域を \texttt{FunctionDomain} で決めるため、BP2 と BP3 で失敗した。そこで、PT2GWFinder 自身の \texttt{TracePhases} で作った相を使った。batch で動かすと進み具合の表示が行を上書きするので、結果は CSV から読んだ。

\paragraph{FindBounce の注意。}FindBounce は、偽の真空から与えた端の点までの直線の経路を、折れ線の場で近似して bounce を求める。$\alpha=0.5$ の木のポテンシャルで端を真の極小 $f_-=-15.7$ に置くと、点の数31で $-0.42\%$、1001で $-2.1\%$ と、点を増やすほど正しい値から離れた。端を $f(0)+0.3(f_--f(0))=-11.0$ にすると、1001点で $-5\times10^{-4}$ だった。$\alpha=0.9$ では bounce の中心が真の極小に近いので、どちらの端でも1001点で $2\times10^{-6}$ だった。
