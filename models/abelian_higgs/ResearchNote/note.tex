\begin{abstract}
スピノル QED と標準模型のノート~\cite{qednote,smnote} に続き、自発的に破れたゲージ理論の最も簡単な模型として、$U(1)$ のゲージ場 $A_\mu$ と電荷1の複素スカラー $\Phi$ からなるアーベル・ヒッグス模型を $d=4$ で調べる。一般の $R_\xi$ ゲージで Goldstone ボソン $G$ とゴーストを残し、紫外発散を次元正則化と $\MSbar$ で処理し、タドポールは打ち消さずに図として含める（Fleischer--Jegerlehner（FJ）の処方~\cite{fj81}）。$\MSbar$ のパラメータは破れていないラグランジアンの $e$、$\lambda$、$m^2$ で、真空期待値は $v=\sqrt{m^2/\lambda}$、$\MSbar$ の質量は $M_A=ev$、$M_h^2=2m^2$ である。本ノートではまず、Feynman 則（10個の頂点のクラス）、BRST 変換と Slavnov--Taylor 恒等式、べき数え上げ、1ループのタドポールと2点関数、$\MSbar$ の対抗項、繰り込み群、極質量、木の振幅を手で求めた。標準模型と違い、2点関数はすべて $D$ 次元で数行の閉じた式になり、ゲージ依存の消え方を式の上で追える。タドポールを付けた図を含めると、(i) ゲージ場の横波の自己エネルギー $\Sigma_T$ は、すべての運動量で $\xi$ によらない（$A$--$h$ のループの $\xi$ の部分は $h$--$G$ のループと打ち消し、$G$ のシーガルの $A_0(\xi M_A^2)$ はタドポールと打ち消す）。(ii) ヒッグスの自己エネルギーの $\xi$ 依存は $(p^2-M_h^2)[A_0(\xi M_A^2)-\frac12(p^2+M_h^2)B_0(p^2;\xi M_A^2,\xi M_A^2)]/(Kv^2)$ だけで、質量殻上で消える。(iii) 縦波、混合、Goldstone の2点関数は、BRST 不変性から導いた $p^2\Sigma_L-2M_Ap^2\Sigma^{AG}-M_A^2\Sigma^{GG}=0$ を $D$ 次元で厳密に満たす。タドポールを除くと右辺は $-M_A^2T/v$ になり、$\Sigma^{GG}(0)=0$（Goldstone の定理）もタドポールを含めて初めて成り立つ。対抗項は $\delta Z_A=-\frac{e^2}{3K}\DUV$、$\delta Z_\Phi=(3-\xi)\frac{e^2}K\DUV$、$\delta_{m^2}=\frac{4\lambda-3e^2}K\DUV$、$\delta_\lambda=\frac{10\lambda-6e^2+3e^4/\lambda}K\DUV$（$K=(4\pi)^2$）で、FJ では裸の真空期待値を裸の木のポテンシャルの最小点にとるので、これらだけで $A$、$h$、$G$ の2点関数がすべて有限になる。$\beta_e=e^3/(3K)$、$\beta_\lambda=(20\lambda^2-12e^2\lambda+6e^4)/K$、$\beta_{m^2}=m^2(8\lambda-6e^2)/K$ で、$\MSbar$ の質量の走りにはタドポールから $1/\lambda$ の項が入る。基準点（$e=\frac12$、$M_A=\mu=1$、$M_h=\frac52$）の1ループの極質量は $M_{h,\mathrm p}=2.559100$、$M_{A,\mathrm p}=0.993696$ で、$\xi=0,\frac12,1,3$ で同じ値になり、$\im\Sigma^H(M_h^2)/M_h$ は木の $\Gamma(h\to AA)=0.0155549$ と一致する。木のレベルでは、縦波の $AA\to AA$ の振幅の閉じた式を求め、高エネルギーで $GG\to GG$ の $-6\lambda$ に $M_A^2/E^2$ の速さで近づくこと（等価定理）を確かめた。検算と応用（有効ポテンシャルのゲージ依存と Nielsen 恒等式、Coleman--Weinberg の機構、摂動のユニタリー性、有限温度の相転移、Abrikosov--Nielsen--Olesen の渦糸）の十一の手順を定め、その最初の手順として FeynRules の模型ファイルを作った。10個の頂点のクラスはすべて手計算の表と記号として一致し（わざと3か所を誤らせた表では3個の差が出た）、MadGraph 3.8.1 の6個の過程の木の図の数は、ユニタリーゲージと Feynman \section{目的と問い}\label{sec:intro}

本ノートの問いは二つである。\textbf{第一に、自発的に破れたゲージ理論の $d=4$ の1ループで、タドポール、Goldstone ボソン、ゴースト、ゲージパラメータ $\xi$ が繰り込みの構造にどう現れるか。とくに、2点関数のゲージ依存がどこに残り、どの組み合わせで消えるかを、閉じた式で示し、これまでのノートと同じ手順でツールと突き合わせられるか。第二に、この模型に固有の物理、すなわち有効ポテンシャルのゲージ依存、放射による対称性の破れ、摂動のユニタリー性、有限温度の相転移、位相的な渦糸を、同じ道具でどこまで再現し、拡張できるか。}

第一の問いを立てる理由は二つある。一つ目は、スピノル QED のノート~\cite{qednote} の模型は破れていない可換ゲージ理論で、ゲージ依存は場の繰り込みと赤外の極の分け方にしか現れなかったからである。ゲージ対称性が自発的に破れると、ゲージ場が質量を持ち、Goldstone ボソンとゴーストが $\xi$ に依存する質量 $\sqrt\xi M_A$ で現れ、タドポールが0でなくなる。二つ目は、標準模型のノート~\cite{smnote} でこれらを一般の $R_\xi$ ゲージで確かめたが、場の数が多く、ゲージ依存の打ち消しは主に FeynCalc の記号の比較と数値で確かめたからである。アーベル・ヒッグス模型は、標準模型の中性の部分（$Z$、$H$、$G^0$）だけを取り出した模型に当たり（$g/(2c_W)\to e$）、すべての2点関数が数行の式になるので、打ち消しの仕組みを式の上で追える。

第二の問いを立てる理由は、これまでのノートで作った道具の自然な拡張になるからである。有効ポテンシャルのゲージ依存と Nielsen 恒等式~\cite{nielsen75} は、標準模型のノートで $\beta_t$ の処方の真空期待値がゲージに依存して走ったことの一般的な説明である。Coleman--Weinberg の機構~\cite{cw73} は、この模型で最初に示された。有限温度の相転移は、$\phi^3+\phi^4$ 理論の有限温度のノート~\cite{thermalnote} の一般形 $D(T^2-T_0^2)\phi^2-ET\phi^3+\lambda_T\phi^4/4$ の係数を、中身の決まった粒子（ここではゲージ場の3次の項 $E$）から与える。Abrikosov--Nielsen--Olesen の渦糸~\cite{abrikosov57,no73} は、これまでのノートの bounce とインスタントンに続く、位相的な古典解である。

求める量は五つである。(i) Feynman 則、BRST 変換と Slavnov--Taylor 恒等式、べき数え上げ。(ii) 1ループのタドポールと2点関数（$h$、$A$ の横波と縦波、$A$--$G$ の混合、$G$、ゴースト）の $D$ 次元の閉じた式と、その紫外発散と $\MSbar$ の対抗項。(iii) 繰り込み群の係数、$\MSbar$ の質量の走り、極質量とそのゲージによらないこと、光学定理。(iv) 木の振幅 $h\to AA$、$AA\to AA$（縦波と等価定理）。(v) 応用として、有効ポテンシャルと Nielsen 恒等式、Coleman--Weinberg の機構、摂動のユニタリー性、有限温度の相転移、渦糸。手計算とツールの間で求める一致は、これまでのノートと同じく、発散部分と対抗項では記号として完全な一致、有限部分では基準点での倍精度の一致である。

本ノートの構成は次の通りである。第~\ref{sec:setup} 節で模型と前提を定める。第~\ref{sec:results} 節で上の (i)〜(iv) と (v) の有効ポテンシャル、Coleman--Weinberg の機構、摂動のユニタリー性の手計算の結果を述べる。第~\ref{sec:plan} 節で、これらと (v) を各ツールと突き合わせる計画を定める。第~\ref{sec:checks} 節で検算の結果を示す（現時点では手順 (1)〜(9)）。第~\ref{sec:discussion} 節で次の手順をまとめる。導出は\ref{app:rules}〜\ref{app:unitarity} に、検算の細部は\ref{app:details} にある。

\section{設定}\label{sec:setup}

模型は、$U(1)$ のゲージ場 $A_\mu$ と、電荷1の複素スカラー $\Phi$ からなる理論である。ラグランジアン密度は
\begin{equation}
\mathcal L=-\frac14F_{\mu\nu}F^{\mu\nu}+(D_\mu\Phi)^\dagger(D^\mu\Phi)+m^2\Phi^\dagger\Phi-\lambda(\Phi^\dagger\Phi)^2+\mathcal L_{\mathrm{gf}}+\mathcal L_{\mathrm{FP}},\qquad
D_\mu=\partial_\mu-ieA_\mu
\label{eq:L}
\end{equation}
とする。$m^2>0$、$\lambda>0$ で、ポテンシャルの最小点は $|\Phi|^2=v^2/2$、$v\equiv\sqrt{m^2/\lambda}$ にある。$\Phi=(v+h+iG)/\sqrt2$ と展開すると、ゲージ場は質量 $M_A=ev$、Higgs 粒子 $h$ は質量 $M_h=\sqrt{2\lambda}\,v=\sqrt2\,m$ を持ち、$G$ は Goldstone ボソンで、$|D\Phi|^2$ から混合 $-M_AA^\mu\partial_\mu G$ が生じる。ゲージ固定とゴーストの項は
\begin{equation}
\mathcal L_{\mathrm{gf}}=-\frac1{2\xi}\bigl(\partial_\mu A^\mu+\xi M_AG\bigr)^2,\qquad
\mathcal L_{\mathrm{FP}}=-\bar c\,\bigl(\partial^2+\xi M_A^2+\xi eM_A\,h\bigr)c
\label{eq:gf}
\end{equation}
である（$R_\xi$ ゲージ~\cite{fls72}）。$\mathcal L_{\mathrm{gf}}$ の交差項は部分積分で $+M_AA^\mu\partial_\mu G$ になり、$|D\Phi|^2$ の混合を打ち消す。その代わり $G$ は質量 $\sqrt\xi M_A$ を持つ。$\mathcal L_{\mathrm{FP}}=-\bar c\,sF$ は、ゲージ固定の関数 $F=\partial_\mu A^\mu+\xi M_AG$ の BRST 変換（$sA_\mu=\partial_\mu c$、$s\Phi=iec\Phi$、すなわち $sG=ec(v+h)$）から作った（\ref{app:brst}）。ゴーストは質量 $\sqrt\xi M_A$ を持ち、$h$ とだけ結合し、$A$ とは結合しない。

\paragraph{繰り込み。}裸の量と繰り込まれた量を
\begin{equation}
A_0=Z_A^{1/2}A,\quad \Phi_0=Z_\Phi^{1/2}\Phi,\quad e_0=\mu^\epsilon Z_ee,\quad \lambda_0=\mu^{2\epsilon}(1+\delta_\lambda)\lambda,\quad m_0^2=(1+\delta_{m^2})m^2,\qquad Z_eZ_A^{1/2}=1
\label{eq:bare}
\end{equation}
で結ぶ。$Z_i=1+\delta Z_i$ とし、$Z_eZ_A^{1/2}=1$ は可換ゲージ理論の Ward 恒等式による（$e_0A_0=\mu^\epsilon eA$ で共変微分は繰り込まれない）。$\mathcal L_{\mathrm{gf}}$ と $\mathcal L_{\mathrm{FP}}$ は繰り込まれた場と繰り込まれた $M_A$ で書き、対抗項を付けない（標準模型のノートと同じ）。タドポールは FJ の処方で扱う。すなわち、裸の真空期待値を裸の木のポテンシャルの最小点 $v_0=\sqrt{m_0^2/\lambda_0}$ にとり、タドポールの対抗項を置かない。このとき $\Phi=(v+\delta v+h+iG)/\sqrt2$、$\delta v=\frac v2(\delta_{m^2}-\delta_\lambda-\delta Z_\Phi)$ で、1ループのタドポール $T$ はすべての図に図として含める（\ref{app:ren}）。

\paragraph{前提。}本ノートは次の前提に立つ。
\begin{enumerate}
\item 計量は $(+,-,-,-)$、$\hbar=c=1$ とする。
\item 場はゲージ場 $A_\mu$ と、$U(1)$ の電荷1の複素スカラー $\Phi$ だけとする。$e>0$ で、共変微分の符号は FeynRules の規約 $D_\mu=\partial_\mu-ieA_\mu$ に合わせる（スピノル QED と標準模型のノートと同じ）。
\item ゲージは $R_\xi$ ゲージとする（$\xi=1$ が 't Hooft--Feynman ゲージ、$\xi=0$ が Landau ゲージ、$\xi\to\infty$ がユニタリーゲージ）。$G$ とゴーストの質量の2乗は $\xi M_A^2$ である。物理量は $\xi$ によらないはずで、それを確かめる。
\item 時空次元は $d=4$ とし、ループ積分は次元正則化で行い、$D=4-2\epsilon$ とする。すべての場が質量を持つ（$\xi=0$ でも1ループの量に赤外発散は生じない）ので、極はすべて紫外の極 $\DUV\equiv1/\epsilon-\gamma_E+\ln4\pi$ である。$C$ 変換（$\Phi\to\Phi^*$、$A\to-A$、すなわち $h\to h$、$G\to-G$）で奇な関数は0である。
\item 紫外発散は $\MSbar$ で処理する。$\MSbar$ のパラメータは $e$、$\lambda$、$m^2$ で、$\MSbar$ の質量 $M_A^2\equiv e^2m^2/\lambda$、$M_h^2\equiv2m^2$ はそれらの関数として定める。タドポールは上の FJ の処方で扱う。
\item 数値を比べるときの基準点は $e=\frac12$、$M_A=\mu=1$、$M_h=\frac52$（$v=2$、$\lambda=\frac{25}{32}$、$m^2=\frac{25}8$）、$\xi=1$ とし、ゲージの検算では $\xi=0,\frac12,3$ も使う（質量と $\mu$ は $M_A$ を単位とする）。$M_h>2M_A$ なので $h\to AA$ が開き、$A$ は安定である。
\end{enumerate}

\subsection{Feynman 則、Slavnov--Taylor 恒等式、べき数え上げ}\label{sec:rules}

\paragraph{Feynman 則。}式~\eqref{eq:L}、\eqref{eq:gf} を展開すると（\ref{app:rules}）
\begin{equation}
\begin{aligned}
\mathcal L={}&\frac12(\partial h)^2-\frac12M_h^2h^2+\frac12(\partial G)^2-\frac12\xi M_A^2G^2-\frac14F^2+\frac12M_A^2A^2-\frac1{2\xi}(\partial A)^2+\bar c\bigl(-\partial^2-\xi M_A^2\bigr)c\\
&+eA^\mu\bigl(G\partial_\mu h-h\partial_\mu G\bigr)+eM_A\,hA^2+\frac{e^2}2\bigl(h^2+G^2\bigr)A^2-\lambda v\,h\bigl(h^2+G^2\bigr)-\frac\lambda4\bigl(h^2+G^2\bigr)^2-\xi eM_A\,h\,\bar cc
\end{aligned}
\label{eq:Lexp}
\end{equation}
となる。伝播関数と頂点を表~\ref{tab:rules} に示す。ゲージ場の伝播関数は、質量 $M_A$ のユニタリーゲージの部分 $U$ と、質量 $\sqrt\xi M_A$ の部分 $X$ に分けられる。
\begin{equation}
\frac{-i}{k^2-M_A^2}\Bigl[g_{\mu\nu}-(1-\xi)\frac{k_\mu k_\nu}{k^2-\xi M_A^2}\Bigr]
=\underbrace{\frac{-i}{k^2-M_A^2}\Bigl[g_{\mu\nu}-\frac{k_\mu k_\nu}{M_A^2}\Bigr]}_{U}
+\underbrace{\frac{-i}{k^2-\xi M_A^2}\,\frac{k_\mu k_\nu}{M_A^2}}_{X}
\label{eq:propsplit}
\end{equation}
$\xi$ は $X$ の質量にしか現れず、$X$ は $G$ とゴーストと同じ質量を持つ。本ノートの $\xi$ 依存の打ち消しは、すべて $X$、$G$、ゴーストの間で起こる。頂点は10個のクラスで、ゴーストと $h$ の結合だけが $\xi$ に比例する。

\paragraph{BRST 対称性と Slavnov--Taylor 恒等式。}$\mathcal L_{\mathrm{gf}}+\mathcal L_{\mathrm{FP}}$ は BRST 変換で閉じた形に書け、そこから $\langle T\,F(x)F(y)\rangle=-i\xi\,\delta^4(x-y)$ がすべての次数で厳密に成り立つ（\ref{app:brst}）。2点関数を
\begin{equation}
\begin{gathered}
\Gamma^{AA}_{\mu\nu}\supset-i\Bigl[\Bigl(g_{\mu\nu}-\frac{k_\mu k_\nu}{k^2}\Bigr)\Sigma_T+\frac{k_\mu k_\nu}{k^2}\Sigma_L\Bigr],\qquad
\Gamma^{hh}\supset i\Sigma^H,\qquad \Gamma^{GG}\supset i\Sigma^{GG},\\
\Gamma^{A_\mu G}\supset k_\mu\Sigma^{AG},\qquad \Gamma^{\bar cc}\supset i\Sigma^c,\qquad \Gamma^h=iT
\end{gathered}
\label{eq:Gamma2}
\end{equation}
と書く（$\Gamma$ は1PI の図の和、すなわち Feynman 則の積。$\Gamma^{A_\mu G}$ は $G$ から運動量 $k$ が入り $A$ から出る向き）。木の2点関数は $\Gamma^{hh}=i(k^2-M_h^2)$ などで、伝播関数は $i/(k^2-M_h^2+\Sigma^H)$ になる。$\langle FF\rangle$ が補正を受けないことを2点関数で書くと、1ループで
\begin{equation}
k^2\Sigma_L(k^2)-2M_A\,k^2\,\Sigma^{AG}(k^2)-M_A^2\,\Sigma^{GG}(k^2)=0
\label{eq:stid}
\end{equation}
となる（\ref{app:brst}）。ここでの2点関数は、タドポールを $h$ の線でつないだ図（図~\ref{fig:oneloop} の右端）を含む。FJ の処方では真空期待値をループで補正しないので、恒等式はタドポールを含めた連結な関数について成り立つ。タドポールを除いた1PI の部分では右辺が $-M_A^2T/v$ になる。$k^2=0$ では $\Sigma^{GG}(0)=0$ で、Goldstone ボソンの質量の補正は、タドポールの付いた図を含めて初めて0になる（Goldstone の定理）。可換ゲージ理論なので、ゴーストの2点関数はこの恒等式に入らない。

\paragraph{べき数え上げ。}外線 $E$ 本の図の表面的な発散次数は、$R_\xi$ ゲージで
\begin{equation}
\omega=4-E-\sum_{\text{頂点}}[g_v]
\label{eq:omega}
\end{equation}
である（$[g_v]$ は頂点の結合の質量次元で、$hhh$、$GGh$、$AAh$、$\bar cch$ では1、ほかは0。\ref{app:counting}）。$\omega\ge0$ となるのは、タドポール（$E=1$）、2点関数（$E=2$）、3点と4点の関数である。$C$ 変換で奇な関数（$A$、$AAA$、$Ahh$、$AGG$、$Gh$、$hhG$ など）は0である。$AAAA$ は $\omega=0$ だが、ゲージ不変性により有限である。残りの発散は、式~\eqref{eq:bare} の対称な対抗項と、真空期待値のずれ $\delta v$ が作る項でちょうど吸収される（\ref{app:ren}）。ゴーストの2点関数と3点関数も発散するが、1ループの物理量にはゴーストは閉じたループとしてしか現れないので、本ノートでは扱わない。

\subsection{タドポールと2点関数}\label{sec:se}

\paragraph{タドポール。}伝播関数の分母を $D_a(k)\equiv k^2-m_a^2+i0$ と書き、1点と2点のスカラー積分を
\begin{equation}
\mu^{2\epsilon}\int\frac{\dd^Dk}{(2\pi)^D}\frac{1}{D_a(k)}=\frac iKA_0(m_a^2),\qquad
\mu^{2\epsilon}\int\frac{\dd^Dk}{(2\pi)^D}\frac{1}{D_a(k)\,D_b(k+p)}=\frac iKB_0(p^2;m_a^2,m_b^2)
\label{eq:IN}
\end{equation}
と定義する。1ループのタドポールは、一般の $R_\xi$ ゲージで（\ref{app:se}）
\begin{equation}
KT=\frac1v\Bigl[(D-1)M_A^2A_0(M_A^2)+\frac32M_h^2A_0(M_h^2)+\frac{M_h^2}2A_0(\xi M_A^2)\Bigr]
\label{eq:T}
\end{equation}
である。ゲージ場のループの $X$ の部分 $\xi M_A^2A_0(\xi M_A^2)/v$ は、ゴーストのループがちょうど打ち消し、$\xi$ 依存は $G$ のループの質量 $\sqrt\xi M_A$ だけに残る。$\MSbar$ の有限部分では $(D-1)A_0\to3A_0-2M_A^2$ である。これは標準模型のノートのタドポールの式から $W$ とフェルミオンを除き、$Z\to A$ としたものに一致する。タドポールを運動量0の $h$ の線で2点関数につなぐと、$h$ の伝播関数 $i/(-M_h^2)$ と $iT$ の積から頂点が $\Delta v=T/M_h^2$ 倍になり
\begin{equation}
\begin{gathered}
\Sigma^H\supset-\frac{3M_h^2}v\Delta v,\qquad
\Sigma_T,\ \Sigma_L\supset-\frac{2M_A^2}v\Delta v,\qquad
\Sigma^{GG}\supset-\frac{M_h^2}v\Delta v,\\
\Sigma^{AG}\supset-\frac{M_A}v\Delta v,\qquad
\Sigma^c\supset-\frac{\xi M_A^2}v\Delta v
\end{gathered}
\label{eq:tadins}
\end{equation}
を与える。$\Sigma^H$ 以外は、木の質量の $v$ を $v+\Delta v$ に置き換えたことと同じである。

\paragraph{2点関数。}図~\ref{fig:oneloop} の図を Feynman 則で書き、ゲージ場の伝播関数を式~\eqref{eq:propsplit} で分けて、$X$ の部分の $k_\mu$ を頂点の運動量と縮約して分母に直すと、$D$ 次元で（\ref{app:se}）
\begin{equation}
\begin{aligned}
K\Sigma^H(p^2)={}&\frac1{v^2}\Bigl\{\frac12\bigl[4(D-1)M_A^4-4M_A^2p^2+p^4\bigr]B_0(p^2;M_A^2,M_A^2)+\frac92M_h^4B_0(p^2;M_h^2,M_h^2)\\
&-\bigl[2(D-1)M_A^2+p^2\bigr]A_0(M_A^2)-3M_h^2A_0(M_h^2)\\
&+(p^2-M_h^2)\Bigl[A_0(\xi M_A^2)-\frac{p^2+M_h^2}2B_0(p^2;\xi M_A^2,\xi M_A^2)\Bigr]\Bigr\},\\[3pt]
K\Sigma_T(p^2)={}&\frac{e^2}{(D-1)p^2}\Bigl\{\bigl[\lK(p^2,M_A^2,M_h^2)+4(D-1)M_A^2p^2\bigr]B_0(p^2;M_A^2,M_h^2)-(p^2+M_A^2-M_h^2)A_0(M_A^2)\\
&-\bigl[(2D-1)p^2-M_A^2+M_h^2\bigr]A_0(M_h^2)\Bigr\}-2(D-1)\frac{e^2M_A^2}{M_h^2}A_0(M_A^2),\\[3pt]
K\Sigma^{GG}(p^2)={}&\frac1{v^2}\Bigl\{\lK(p^2,M_A^2,M_h^2)B_0(p^2;M_A^2,M_h^2)+p^2(2M_h^2-p^2)B_0(p^2;M_h^2,\xi M_A^2)\\
&-(p^2+M_A^2-M_h^2)A_0(M_A^2)+(M_A^2-M_h^2)A_0(M_h^2)+p^2A_0(\xi M_A^2)\Bigr\},\\[3pt]
K\Sigma^c(p^2)={}&\xi^2e^2M_A^2\,B_0(p^2;M_h^2,\xi M_A^2)
\end{aligned}
\label{eq:se}
\end{equation}
となる。$\Sigma^H$、$\Sigma_T$、$\Sigma^{GG}$ はタドポールの付いた図を含み、$\Sigma^c$ は1PI の図だけの値である。$\Sigma_L$ と $\Sigma^{AG}$ は\ref{app:se} に示し、式~\eqref{eq:stid} で $\Sigma^{GG}$ と結ばれる。

式~\eqref{eq:se} の要点は四つある。一つ目に、$\Sigma_T$ はすべての $p^2$ で $\xi$ によらない。$A$--$h$ のループ（図 (j)）の $X$ の部分は、$X$ が $k_\rho k_\sigma$ に比例するので、横波の部分が $h$--$G$ のループ（図 (k)）の横波の部分と被積分関数のレベルで打ち消す。残る $\xi$ 依存は $G$ のシーガルの $e^2A_0(\xi M_A^2)$ だけで、これはタドポールの付いた図の $\xi$ の部分 $-\frac{2M_A^2}{vM_h^2}\cdot\frac{M_h^2}{2v}A_0(\xi M_A^2)=-e^2A_0(\xi M_A^2)$ と打ち消す。二つ目に、$\Sigma^H$ の $\xi$ 依存は $(p^2-M_h^2)$ に比例する一つの項だけである。$A$--$A$ のループ（図 (e)）の $U$ と $X$ の交差項は $A$--$G$ のループ（図 (f)）の $U$ の部分と $B_0(p^2;M_A^2,\xi M_A^2)$ ごと打ち消し、$B_0(p^2;\xi M_A^2,\xi M_A^2)$ の係数は $X$--$X$、$A$--$G$ の $X$、ゴースト、$G$--$G$ のループの和で $\frac12(M_h^4-p^4)$ にまとまる。したがって、質量殻上の $\Sigma^H(M_h^2)$ と $\Sigma_T(M_A^2)$、すなわち極質量は $\xi$ によらない。三つ目に、$\Sigma^{GG}$ は $D$ によらず、$\Sigma^{GG}(0)=0$ である（$p^2=0$ では $\lK B_0=(M_A^2-M_h^2)[A_0(M_A^2)-A_0(M_h^2)]$）。四つ目に、$\Sigma^H$ の $B_0(p^2;M_A^2,M_A^2)$ だけが $p^2=M_h^2>4M_A^2$ で虚部を持ち、$\xi$ に依存する $B_0(p^2;\xi M_A^2,\xi M_A^2)$ の虚部（$M_h^2>4\xi M_A^2$ で生じる）は係数 $(p^2-M_h^2)$ により質量殻上で消える。

\paragraph{紫外の極。}$A_0(m^2)$ の極は $m^2\DUV$、$B_0$ の極は $\DUV$ なので、式~\eqref{eq:T}、\eqref{eq:se} の極の係数（$K/\DUV$ 倍）は
\begin{equation}
\begin{gathered}
KT\big|_{\DUV}=\frac{6M_A^4+3M_h^4+\xi M_A^2M_h^2}{2v},\qquad
K\Sigma^H\big|_{\DUV}=(\xi-3)e^2p^2+\frac{M_h^2(2M_h^2-\xi M_A^2)}{v^2},\\
K\Sigma_T\big|_{\DUV}=\frac{e^2}3p^2-M_A^2\Bigl(6\lambda-3e^2+\frac{3e^4}\lambda\Bigr),\qquad
K\Sigma_L\big|_{\DUV}=-M_A^2\Bigl(6\lambda-3e^2+\frac{3e^4}\lambda\Bigr),\\
K\Sigma^{AG}\big|_{\DUV}=-\frac{M_A}2\Bigl(6\lambda-6e^2+\frac{3e^4}\lambda+\xi e^2\Bigr),\qquad
K\Sigma^{GG}\big|_{\DUV}=(\xi-3)e^2p^2,\qquad
K\Sigma^c\big|_{\DUV}=\xi^2e^2M_A^2
\end{gathered}
\label{eq:uv}
\end{equation}
である。タドポールの極は $\xi$ によるが、$\Sigma_T$ と $\Sigma_L$ の極は $\xi$ によらない。$\Sigma^{GG}$ には定数の極がない。

\subsection{対抗項と繰り込み群}\label{sec:ren}

\paragraph{$\MSbar$ の対抗項。}式~\eqref{eq:bare} の対抗項は、2点関数に
\begin{equation}
\begin{gathered}
\Sigma^H_{\mathrm{ct}}=\delta Z_\Phi(p^2-M_h^2)-\delta_{m^2}M_h^2,\qquad
\Sigma_{T,\mathrm{ct}}=\delta Z_Ap^2-(\delta_{m^2}-\delta_\lambda)M_A^2,\qquad
\Sigma_{L,\mathrm{ct}}=-(\delta_{m^2}-\delta_\lambda)M_A^2,\\
\Sigma^{AG}_{\mathrm{ct}}=-\frac12(\delta Z_\Phi+\delta_{m^2}-\delta_\lambda)M_A,\qquad
\Sigma^{GG}_{\mathrm{ct}}=\delta Z_\Phi\,p^2
\end{gathered}
\label{eq:ctse}
\end{equation}
を加える（\ref{app:ren}）。$\delta_{m^2}-\delta_\lambda$ は、FJ の処方で裸の真空期待値が $\sqrt{m_0^2/\lambda_0}$ であることから来る（$M_A^2=e^2v^2$ の対抗項）。式~\eqref{eq:uv} の極を消す条件は、$\Sigma^H$ の $p^2$ と定数の項、$\Sigma_T$ の $p^2$ と定数の項の四つで、その解は
\begin{equation}
\delta Z_A=-\frac{e^2}{3K}\DUV,\qquad
\delta Z_\Phi=(3-\xi)\frac{e^2}K\DUV,\qquad
\delta_{m^2}=\frac{4\lambda-3e^2}K\DUV,\qquad
\delta_\lambda=\frac{10\lambda-6e^2+3e^4/\lambda}K\DUV
\label{eq:ct}
\end{equation}
である。$\delta Z_e=-\frac12\delta Z_A=\frac{e^2}{6K}\DUV$ で、$\xi$ に依存するのは $\delta Z_\Phi$ だけである。残りの $\Sigma_L$、$\Sigma^{AG}$、$\Sigma^{GG}$ の極もこれで消え、条件は過剰に決まっていて矛盾しない。対抗項の部分 \eqref{eq:ctse} は、それ自身で恒等式~\eqref{eq:stid} を満たす。FJ の処方では、真空期待値の対抗項は場の繰り込みと違い、$v_0/v=1+\frac12(\delta_{m^2}-\delta_\lambda)$ で $\xi$ によらない。

\paragraph{3点と4点の対抗項。}裸のラグランジアンを最小点 $v+\delta v$ のまわりで展開すると、3点と4点の頂点の対抗項は、表~\ref{tab:rules} の木の頂点に
\begin{equation}
\begin{gathered}
c_3=\tfrac12(\delta_\lambda+3\delta Z_\Phi+\delta_{m^2})\ \ (hhh,\ GGh),\qquad
c_4=\delta_\lambda+2\delta Z_\Phi\ \ (hhhh,\ GGGG,\ GGhh),\\
c_A=\tfrac12(\delta Z_\Phi+\delta_{m^2}-\delta_\lambda)\ \ (AAh),\qquad
\delta Z_\Phi\ \ (AAhh,\ AAGG,\ AGh)
\end{gathered}
\label{eq:ctv}
\end{equation}
を掛けたものになる（\ref{app:ren}）。式~\eqref{eq:ct} を入れると $Kc_3/\DUV=7\lambda+\frac{3e^4}{2\lambda}-\frac32\xi e^2$、$Kc_4/\DUV=10\lambda+\frac{3e^4}\lambda-2\xi e^2$、$Kc_A/\DUV=3e^2-\frac12\xi e^2-3\lambda-\frac{3e^4}{2\lambda}$ である。$c_3$ と $c_A$ に入る $\delta v/v$ は、3点の関数に加わるタドポールの付いた図（$hhhh$、$GGhh$、$AAhh$ の頂点にタドポールをつなぐ図で、木の頂点 $-6i\lambda v$、$-2i\lambda v$、$2ieM_Ag^{\mu\nu}$ の $\Delta v/v$ 倍）の極を打ち消す。$AAAA$ には対抗項がなく、関数は有限である。

\paragraph{繰り込み群。}裸の量が $\mu$ によらないことから（\ref{app:ren}）
\begin{equation}
\beta_e=\frac{e^3}{3K},\qquad
\beta_\lambda=\frac{20\lambda^2-12e^2\lambda+6e^4}K,\qquad
\beta_{m^2}=m^2\,\frac{8\lambda-6e^2}K,\qquad
\gamma_\Phi=(\xi-3)\frac{e^2}K,\qquad
\gamma_A=\frac{e^2}{3K}
\label{eq:rge}
\end{equation}
を得る。$\beta_e=e\gamma_A$ は $Z_eZ_A^{1/2}=1$ の言い換えで、1個の複素スカラーの寄与は Dirac フェルミオン1個の $\frac14$ である。$\MSbar$ の質量は
\begin{equation}
\frac{\dd\ln M_h^2}{\dd\ln\mu}=\frac{8\lambda-6e^2}K,\qquad
\frac{\dd\ln M_A^2}{\dd\ln\mu}=\frac{2\beta_e}e+\frac{\beta_{m^2}}{m^2}-\frac{\beta_\lambda}\lambda=\frac1K\Bigl(-12\lambda+\frac{20}3e^2-\frac{6e^4}\lambda\Bigr)
\label{eq:mrun}
\end{equation}
で走り、どちらもゲージによらない。$M_A$ の $1/\lambda$ の項はタドポールの $3M_A^4A_0(M_A^2)/v$ から来る（標準模型のノートと同じ構造）。基準点では $\beta_\lambda=0.0648$、$\dd\ln M_h^2/\dd\ln\mu=0.0301$、$\dd\ln M_A^2/\dd\ln\mu=-0.0519$ である。タドポールの付いた図を含めた $\Sigma(M^2)$ の極の係数は $\frac12\dd M^2/\dd\ln\mu$ に等しい。実際、式~\eqref{eq:uv} から $K\Sigma^H(M_h^2)|_{\DUV}=M_h^2(4\lambda-3e^2)$、$K\Sigma_T(M_A^2)|_{\DUV}=M_A^2(-6\lambda+\frac{10}3e^2-\frac{3e^4}\lambda)$ で、どちらも式~\eqref{eq:mrun} の半分である。

\paragraph{走りの解。}$t=\ln(\mu/\mu_0)$ として、1ループの解は
\begin{equation}
e^2(t)=\frac{e_0^2}{1-2e_0^2t/(3K)},\qquad
\frac{40\lambda-12e^2}{\Delta_\lambda}=\tan\Bigl(\frac{\Delta_\lambda t}{2K}+\arctan\frac{40\lambda_0-12e^2}{\Delta_\lambda}\Bigr),\qquad
\Delta_\lambda=\sqrt{336}\,e^2
\label{eq:runsol}
\end{equation}
である（$\lambda$ の式は $e$ の走りを無視したもの。\ref{app:ren}）。$e$ は $t_e=3K/(2e_0^2)$ に、$\lambda$ は $t_\lambda=(2K/\Delta_\lambda)[\frac\pi2-\arctan((40\lambda_0-12e^2)/\Delta_\lambda)]$ に Landau 極を持つ。$\beta_\lambda$ の $\lambda$ の2次式は判別式が $144e^4-480e^4<0$ で、どの $\lambda$ でも正である。したがって $\lambda$ は $\mu$ とともに単調に増え、標準模型のトップの湯川結合のように紫外で $\lambda$ を負にするものはない。大きな場での真空の不安定は1ループの走りでは生じない。逆に、$\lambda$ が有限（あるいは木の部分波のユニタリー性の限界 $\lambda\le2\pi$ 以下、手順 (9)）のまま切断 $\Lambda$ まで届くことを求めると、$M_h/M_A=\sqrt{2\lambda}/e$ に上限がつく（自明性の限界）。2ループでは $\beta_e=e^3/(3K)+4e^5/K^2$ である（一般の公式~\cite{mv1} の $-2C_2(S)S_2(S)$ の項）。

\subsection{極質量と光学定理}\label{sec:pole}

1ループの極質量は
\begin{equation}
M_{h,\mathrm p}^2=M_h^2-\re\Sigma^H(M_h^2),\qquad M_{A,\mathrm p}^2=M_A^2-\re\Sigma_T(M_A^2)
\label{eq:pole}
\end{equation}
である（$\Sigma$ は $\MSbar$ の有限部分で、タドポールの付いた図を含む。\ref{app:pole}）。第~\ref{sec:se} 節の一つ目と二つ目の点から、どちらも $\xi$ によらない。$\mu$ にもよらない（$\ln\mu^2$ の係数が式~\eqref{eq:mrun} と打ち消す）。基準点では
\begin{equation}
\frac{\re\Sigma^H(M_h^2)}{M_h^2}=-0.047839,\quad \re\Sigma_T(M_A^2)=0.012568,\qquad
M_{h,\mathrm p}=2.559100,\quad M_{A,\mathrm p}=0.993696
\label{eq:polenum}
\end{equation}
で、$\xi=0,\frac12,1,3$ で全桁同じ値になった。比べると、質量殻から外れた $K\Sigma^H(p^2=1)$ は $\xi=\frac12,1,3$ で $-52.26$、$-56.92$、$-61.06$ と変わるが、$K\Sigma_T(p^2=4)=1.9080$ は変わらない。タドポールの付いた図を除くと、極質量は $\xi$ に依存する。

虚部は光学定理を満たす。$p^2=M_h^2$ で虚部を持つのは $B_0(p^2;M_A^2,M_A^2)$ だけで、$\im B_0=\pi\beta$（$\beta=\sqrt{1-4M_A^2/M_h^2}$）から
\begin{equation}
\frac{\im\Sigma^H(M_h^2)}{M_h}=\frac{\beta\,(M_h^4-4M_A^2M_h^2+12M_A^4)}{32\pi v^2M_h}=\Gamma(h\to AA)
\label{eq:optical}
\end{equation}
となり、下の木の幅~\eqref{eq:width} に一致する（基準点で $0.0155549089$）。

\subsection{木の振幅}\label{sec:tree}

\paragraph{$h\to AA$。}頂点 $2ieM_Ag^{\mu\nu}$ と偏極の和 $\sum\varepsilon_\mu\varepsilon_\nu^*=-g_{\mu\nu}+k_\mu k_\nu/M_A^2$ から（\ref{app:tree}）
\begin{equation}
\Gamma(h\to AA)=\frac{e^2M_h^3}{32\pi M_A^2}\,\beta\,(1-4x+12x^2),\qquad x=\frac{M_A^2}{M_h^2},\quad \beta=\sqrt{1-4x}
\label{eq:width}
\end{equation}
である。同種粒子の因子 $\frac12$ を含む。基準点では $x=\frac4{25}$、$\beta=\frac35$ で $\Gamma=1.56375/(32\pi)=0.0155549$ である。$e^2/M_A^2=1/v^2$ なので、標準模型の $\Gamma(H\to ZZ)$ と同じ形である。

\paragraph{$AA\to AA$ と等価定理。}$A(k_1)A(k_2)\to A(k_3)A(k_4)$ は $h$ の $s$、$t$、$u$ チャンネルの交換の3個の図からなり（どちらのゲージでも $G$ は交換されない）
\begin{equation}
\mathcal M=-4e^2M_A^2\Bigl[\frac{(\varepsilon_1\cdot\varepsilon_2)(\varepsilon_3^*\cdot\varepsilon_4^*)}{s-M_h^2}+\frac{(\varepsilon_1\cdot\varepsilon_3^*)(\varepsilon_2\cdot\varepsilon_4^*)}{t-M_h^2}+\frac{(\varepsilon_1\cdot\varepsilon_4^*)(\varepsilon_2\cdot\varepsilon_3^*)}{u-M_h^2}\Bigr]
\label{eq:Maa}
\end{equation}
である。重心系ですべてを縦波にすると、偏極ベクトルの積を Mandelstam 変数で書き直して
\begin{equation}
\mathcal M_{LLLL}=-\frac{4e^2}{M_A^2}\Bigl[\frac{(s/2-M_A^2)^2}{s-M_h^2}+\frac{(t/2+M_A^2\cos\theta)^2}{t-M_h^2}+\frac{(u/2-M_A^2\cos\theta)^2}{u-M_h^2}\Bigr]
\label{eq:MLL}
\end{equation}
となる（\ref{app:tree}）。各項は $s$ に比例して増えるが、$s+t+u=4M_A^2$ により $s$ の1次の項は打ち消し、$s\to\infty$ で
\begin{equation}
\mathcal M_{LLLL}\to-\frac{3e^2M_h^2}{M_A^2}=-6\lambda,\qquad
\mathcal M(GG\to GG)=-6\lambda-\frac{M_h^4}{v^2}\Bigl[\frac1{s-M_h^2}+\frac1{t-M_h^2}+\frac1{u-M_h^2}\Bigr]
\label{eq:et}
\end{equation}
となる。$e^2$ の項も $s+t+u$ と偏極ベクトルの $M_A^2$ の補正の和で打ち消し、極限は Goldstone ボソンの散乱の値に等しい（等価定理~\cite{clt74,lqt77}）。基準点で $\theta=0.7$ とすると、二つの振幅は $E=3$ で $-3.1666$ と $-3.7573$、$E=100$ で $-4.684242$ と $-4.685394$ で、差は $M_A^2/E^2$ に比例して小さくなり、$-6\lambda=-4.6875$ に近づく。式~\eqref{eq:MLL} は、偏極ベクトルを陽に作った式~\eqref{eq:Maa} の数値と相対 $10^{-15}$ で一致した。

\paragraph{$AA\to hh$、$hh\to hh$。}$A(k_1,\varepsilon_1)A(k_2,\varepsilon_2)\to h(p_1)h(p_2)$（$t=(k_1-p_1)^2$、$u=(k_1-p_2)^2$）は、ユニタリーゲージでは接触項、$s$ チャンネルの $h$、$t$、$u$ チャンネルの $A$ の4個の図からなり
\begin{equation}
\begin{aligned}
\mathcal M(AA\to hh)={}&2e^2(\varepsilon_1\cdot\varepsilon_2)\Bigl(1+\frac{3M_h^2}{s-M_h^2}\Bigr)
+\frac{4e^2[M_A^2\,\varepsilon_1\cdot\varepsilon_2+(\varepsilon_1\cdot p_1)(\varepsilon_2\cdot p_2)]}{t-M_A^2}\\
&+\frac{4e^2[M_A^2\,\varepsilon_1\cdot\varepsilon_2+(\varepsilon_1\cdot p_2)(\varepsilon_2\cdot p_1)]}{u-M_A^2}
\end{aligned}
\label{eq:Mahh}
\end{equation}
である（\ref{app:tree}）。$R_\xi$ ゲージでは $t$、$u$ チャンネルに $G$ の交換が加わって6個の図になるが、ゲージ場の交換の $X$ の部分 $-4e^2(\varepsilon_1\cdot p_1)(\varepsilon_2\cdot p_2)/(t-\xi M_A^2)$ と $G$ の交換がチャンネルごとに打ち消し、式~\eqref{eq:Mahh} だけが残る。$hh\to hh$ は
\begin{equation}
\mathcal M(hh\to hh)=-6\lambda-\frac{9M_h^4}{v^2}\Bigl[\frac1{s-M_h^2}+\frac1{t-M_h^2}+\frac1{u-M_h^2}\Bigr]
\label{eq:Mhh}
\end{equation}
である。縦波の $AA\to hh$ も各項が $s/M_A^2$ に比例して増え、和で打ち消して、高エネルギーで Landau ゲージ（$G$ の質量0）の
\begin{equation}
\mathcal M(GG\to hh)=-2\lambda-\frac{3M_h^4}{v^2(s-M_h^2)}-\frac{M_h^4}{v^2}\Bigl(\frac1t+\frac1u\Bigr)
-\frac{e^2(s-u+M_h^4/t)}{t-M_A^2}-\frac{e^2(s-t+M_h^4/u)}{u-M_A^2}
\label{eq:Mgghh}
\end{equation}
の $-1$ 倍に近づく。$-1$ は、縦波の偏極 $\varepsilon_L\approx k/M_A$ と Goldstone ボソンの間の位相 $i$ が2本の外線に付くことによる（$AA\to AA$ では $i^4=1$）。$s\to\infty$ では $\mathcal M(GG\to hh)\to-2\lambda+e^2[(3+\cos\theta)/(1-\cos\theta)+(3-\cos\theta)/(1+\cos\theta)]$ で、$AA\to AA$ と違い $t$、$u$ チャンネルのゲージ場の交換から $e^2$ の項が残る。

\subsection{NLO の崩壊幅}\label{sec:nlo}

$h(p)\to A(k_1)A(k_2)$ の1ループの振幅を、物理的な偏極で消えない二つの形状因子で
\begin{equation}
\mathcal M^{\mu\nu}=F_g\,g^{\mu\nu}+F_b\,k_2^\mu k_1^\nu+(k_1^\mu,\ k_2^\nu\ \text{に比例する項}),\qquad
\mathcal M_0^{\mu\nu}=2eM_A\,g^{\mu\nu}
\label{eq:ff}
\end{equation}
と書く（FeynArts の形、Feynman 則の積の $1/i$ 倍）。$\MSbar$（FJ）で繰り込んだ S 行列要素の1ループの部分は
\begin{equation}
F_g^{\mathrm R}=F_g^{\mathrm{1PI}}+F_g^{\mathrm{tad}}+c_A\,2eM_A+\frac12\bigl(\delta R_h+2\delta R_A\bigr)2eM_A,\qquad
\delta R_h=-\bigl[\Sigma^{H\prime}+\delta Z_\Phi\bigr]_{M_h^2},\quad \delta R_A=-\bigl[\Sigma_T'+\delta Z_A\bigr]_{M_A^2}
\label{eq:nloamp}
\end{equation}
と $F_b$ である（\ref{app:nlo}）。$F_g^{\mathrm{tad}}$ は $AAhh$ の頂点にタドポールをつないだ図、$c_A$ は式~\eqref{eq:ctv}、$\delta R$ は外線の留数（$\Sigma'=\dd\Sigma/\dd p^2$）である。$F_b$ は紫外で有限で $\xi$ によらない。$e$ を $\MSbar$ の $e(\mu)$、$M_A$ と $M_h$ を極質量とする（on-shell の質量の処方）と、幅は
\begin{equation}
\Gamma=\Gamma_0\bigl(e(\mu),M_{A,\mathrm p},M_{h,\mathrm p}\bigr)\,(1+\delta_{\mathrm{OS}}),\qquad
\delta_{\mathrm{OS}}=\frac{\re[F_g^{\mathrm R}+F_bS_b/S_g]}{eM_A}+\frac{\re\Sigma_T(M_A^2)}{M_A^2}
\label{eq:nlowidth}
\end{equation}
になる。$\Gamma_0$ は式~\eqref{eq:width}、$S_g=3-M_h^2/M_A^2+M_h^4/(4M_A^4)$ と $S_b=M_h^2(M_h^2-4M_A^2)(M_h^2-2M_A^2)/(8M_A^4)$ は偏極の和、最後の項は木の結合 $2eM_A$ の $M_A$ を $\MSbar$ から極質量に直す分である（$\Sigma$ は $\MSbar$ の有限部分）。$\delta_{\mathrm{OS}}$ には三つの性質がある。一つ目に、$\xi$ によらない。二つ目に、タドポールを含まない。$F_g^{\mathrm{tad}}/(eM_A)=2\Delta v/v$ が $\Sigma_T$ のタドポールの部分 $-2M_A^2\Delta v/v$ と打ち消すからである。したがって、タドポールを対抗項で消す処方（NLOCT と MadLoop）でも同じ値になる。三つ目に、$\mu$ には $\Gamma_0$ の $e^2(\mu)$ の走りを打ち消す $\dd\delta_{\mathrm{OS}}/\dd\ln\mu=-2e^2/(3K)$ だけを通じて依存する。形状因子 $F_g^{\mathrm{1PI}}$、$F_b$ は手で閉じた形にはせず、FeynCalc（一般の $\xi$）と FormCalc（Feynman ゲージ）で求めた（手順 (5)）。基準点（$\mu=1$）では $\delta_{\mathrm{OS}}=0.0201540$、$\Gamma=0.0158684$ で、木より $2.0\%$ 大きい。

\subsection{有効ポテンシャルと Nielsen 恒等式}\label{sec:effpot}

一定の背景場 $\phi$ のまわりで $\Phi=(\phi+h+iG)/\sqrt2$ とし、場に依存する質量を $m_h^2=-m^2+3\lambda\phi^2$、$m_G^2=-m^2+\lambda\phi^2=\partial_\phi V_0/\phi$、$m_A^2=e^2\phi^2$ と書く（$V_0=-\frac12m^2\phi^2+\frac14\lambda\phi^4$）。ゲージ固定は二つを比べる。Fermi ゲージ $F=\partial\!\cdot\!A$ では $G$ と $A$ の縦波が $-e\phi A\!\cdot\!\partial G$ で混ざり、この組の質量は
\begin{equation*}
m_\pm^2=\frac12\Bigl[m_G^2\pm\sqrt{m_G^4-4\xi m_A^2m_G^2}\Bigr]
\end{equation*}
で、ゴーストは質量を持たない。背景場の $R_\xi$ ゲージ $F=\partial\!\cdot\!A+\xi e\phi G$（式~\eqref{eq:gf} の $v$ を $\phi$ に置き換えたもの）では混合が打ち消し、$G$ の質量が $m_G^2+\xi m_A^2$、縦波とゴースト（重み $-2$）の質量が $\xi m_A^2$ になる。$\MSbar$ の1ループの有効ポテンシャルは
\begin{equation}
V_1=\frac1{4K}\sum_in_im_i^4\Bigl(\ln\frac{m_i^2}{\mu^2}-c_i\Bigr)
\label{eq:V1}
\end{equation}
である（\ref{app:effpot}）。$h$ と横波は両方のゲージで $(n_i,c_i)=(1,\frac32)$、$(3,\frac56)$ である。$G$ と縦波の組は、Fermi ゲージで $m_\pm^2$ が $(1,\frac32)$ ずつ、背景場の $R_\xi$ ゲージで $m_G^2+\xi m_A^2$ が $(1,\frac32)$、$\xi m_A^2$ が $(-1,\frac32)$ である。$\xi=0$ ではどちらも Landau ゲージの $m_G^2$ の $(1,\frac32)$ になる。

\paragraph{Nielsen 恒等式。}ゲージ固定とゴーストの項は $s[\bar c(F+\frac\xi2B)]$ なので、$\xi$ を変えた差も BRST 変換の像である。BRST 不変性から、有効作用 $\Gamma$ について
\begin{equation}
\frac{\partial\Gamma}{\partial\xi}=\int\dd^4z\,\frac{\delta\Gamma}{\delta\phi_i(z)}K_i(z),\qquad
K_i(z)=i\Bigl\langle s\phi_i(z)\int\dd^4y\,\bar c\Bigl(\frac{\partial F}{\partial\xi}+\frac B2\Bigr)(y)\Bigr\rangle
\label{eq:nielsen}
\end{equation}
が成り立つ~\cite{nielsen75}（$B=-F/\xi$。\ref{app:effpot}）。一定の場では $\partial_\xi V=C\,\partial_\phi V$、$C=K_h$ で、1ループでは $\partial_\xi V_1=C\,\partial_\phi V_0$ である。$sh=-ecG$ なので、$C$ はゴーストと $G$（Fermi ゲージでは $G$ と $\partial\!\cdot\!A$ の混合）の泡1個で
\begin{equation}
C_{\mathrm{bg}}=-\frac{e^2\phi}{2K}B_0(0;\xi m_A^2,m_G^2+\xi m_A^2),\qquad
C_{\mathrm F}=\frac{e^2\phi}{2K}B_0(0;m_+^2,m_-^2)
\label{eq:C}
\end{equation}
になる（$\MSbar$ の有限部分で $B_0(0;a,b)=1-[a\ln(a/\mu^2)-b\ln(b/\mu^2)]/(a-b)$）。木の最小点 $\phi=v$（$m_G^2=0$）で、$C_{\mathrm{bg}}(v)=\frac{e^2v}{2K}\ln\frac{\xi M_A^2}{\mu^2}$ は有限である。$C_{\mathrm F}$ は $m_\pm^2\simeq\pm i\sqrt{\xi m_A^2m_G^2}$ から $-\frac{e^2v}{4K}[\ln(\xi M_A^2m_G^2/\mu^4)-2]$ のように対数で発散する。式~\eqref{eq:nielsen} から四つのことが分かる。

一つ目に、極値の値はゲージによらない。$\partial_\phi V_0(v)=0$ なので、$V_0(v)+V_1(v)$ は $\xi$ にもゲージ固定の形にもよらない（$v$ では $G$ の組の質量が0になるか打ち消し合い、どのゲージでも Landau ゲージの値になる）。極値の値は $V_{\min}=V_0(v)+V_1(v)+O(\hbar^2)$ である。

二つ目に、極値の位置は $\beta_t$ の処方の真空期待値である。背景場の $R_\xi$ ゲージでは $-\partial_\phi V_1(v)$ が同じ $\xi$ の式~\eqref{eq:T} の $T$ に厳密に一致し、最小点は $\phi_{\min}=v+\Delta v=v_\beta$ である（$v$ では $G$ とゴーストの質量の $\phi$ 微分のうち $\xi$ の部分が打ち消す）。極値の条件を $\xi$ で微分すると $\partial_\xi\phi_{\min}=-C(\phi_{\min})$ で、1ループでは $\partial_\xi\Delta v=-C_{\mathrm{bg}}(v)$ である。Fermi ゲージでは、$m_G^2=0$ で $G$ と縦波の組の伝播関数が $1/k^4$ になり、$-\partial_\phi V_1$ は $v$ の近くで
\begin{equation}
-\partial_\phi V_1^{\mathrm F}\simeq T_{\mathrm L}+\frac{\xi M_A^2M_h^2}{4Kv}\Bigl[\ln\frac{\xi M_A^2|m_G^2|}{\mu^4}-2\Bigr]
\label{eq:Tfermi}
\end{equation}
と対数で発散する（$T_{\mathrm L}$ は $\xi=0$ の $T$）。$V_0+\hbar V_1$ の最小点は $\hbar\ln\hbar$ でずれ、$\hbar$ の冪で展開できない~\cite{afs15,egk16}。

三つ目に、背景場は場と違う割合で走る。式~\eqref{eq:V1} の紫外の極 $\sum n_im_i^4$ は、Landau ゲージの値と $\mp2\xi e^2\phi\,\partial_\phi V_0$（Fermi、背景場の $R_\xi$）だけ違う。Fermi ゲージの差は $\delta Z_\Phi$ の $\xi$ の部分で消える。背景場の $R_\xi$ ゲージでは符号が逆なので、$\mu$ によらないためには背景場の異常次元 $\gamma_v=\gamma_\Phi-2\xi e^2/K=-(3+\xi)e^2/K$ が要る。極値の位置 $v_\beta$ は
\begin{equation}
\frac{\dd\ln v_\beta}{\dd\ln\mu}=\frac{\dd\ln v}{\dd\ln\mu}+\frac{\dd}{\dd\ln\mu}\frac{\Delta v}v=\frac{3e^2-6\lambda-3e^4/\lambda}K+\frac{6\lambda+3e^4/\lambda+\xi e^2}K=\frac{(3+\xi)e^2}K
\label{eq:vbeta}
\end{equation}
で走り、場の $-\gamma_\Phi=(3-\xi)e^2/K$ と $2\xi e^2/K$ だけ違う。これは標準模型のノートの $v_\beta$ の走りの式から $W$ とフェルミオンを除いたもの（$\frac14\xi_Z(g^2+g'^2)\to\xi e^2$）である。また、Sperling--Stöckinger--Voigt の一般の結果 $\beta_v=[\gamma+\hat\gamma]v$、$\gamma^{(1)}=g^2(3-\xi)C_2(S)/K$、$\hat\gamma^{(1)}=2\xi g^2C_2(S)/K$~\cite{ssv13} に本ノートの $C_2(S)=1$ を入れた値に一致する。$\hat\gamma$ は、ゲージ固定の項が背景場（真空期待値）を含む $R_\xi$ 型のゲージだけに現れ、Fermi ゲージと Landau ゲージでは0である。

四つ目に、2点関数の $\xi$ 依存は運動方程式に比例する。式~\eqref{eq:nielsen} を $h$ で2回微分し、木の真空で評価すると、FJ の $\Sigma^H$（タドポールの付いた図を含む）について、$D$ 次元で
\begin{equation}
\frac{\partial\Sigma^H}{\partial\xi}=2(p^2-M_h^2)K_{hh}(p^2),\qquad
KK_{hh}=\frac{e^2}2\Bigl[B_0(0;\xi M_A^2,\xi M_A^2)-(p^2+M_h^2)\,C_0(0,p^2,p^2;\xi M_A^2,\xi M_A^2,\xi M_A^2)\Bigr]
\label{eq:nielsen2}
\end{equation}
を得る（\ref{app:effpot}）。$K_{hh}$ は $K_h$ に外線の $h$ を1本付けたもの、$C_0$ は $\mu^{2\epsilon}\int\frac{\dd^Dk}{(2\pi)^D}\frac1{D(k)^2D(k+p)}=\frac iKC_0$ である。1PI の部分だけでは $\Gamma_{hhh}K_h=-\frac{3M_h^2}vK_h$ が加わり、タドポールの付いた図がそれを打ち消す。$KK_{hh}$ の極 $e^2/2$ は $\delta Z_\Phi$ の $\xi$ 微分と打ち消す。$\partial_{m^2}B_0(p^2;m^2,m^2)=2C_0$ なので、これは式~\eqref{eq:se} の $\xi$ の項の $\xi$ 微分そのものである。質量殻上で0になるので、極質量はゲージによらない。一方、$p^2=0$ の値、すなわち最小点での有効ポテンシャルの曲率 $M_{\mathrm{curv}}^2=V''(\phi_{\min})$ はゲージに依存する。背景場の $R_\xi$ ゲージで $\hbar$ について展開した値 $M_{\mathrm{curv}}^2=M_h^2+V_1''(v)+3T/v$ は
\begin{equation*}
\frac{\dd M_{\mathrm{curv}}^2}{\dd\xi}=2C_{\mathrm{bg}}'(v)M_h^2,\qquad
C_{\mathrm{bg}}'(v)=\frac{e^2}{2K}\Bigl[\ln\frac{\xi M_A^2}{\mu^2}+2+\frac{M_h^2}{2\xi M_A^2}\Bigr]
\end{equation*}
で変わる。Landau ゲージと Fermi ゲージでは、$V_1''(v)$ がそれぞれ $\ln|m_G^2|$ と $1/m_G^2$ で発散する（Goldstone ボソンの赤外の発散）。

\subsection{Coleman--Weinberg の機構}\label{sec:cw}

$m^2=0$ の模型では、木のポテンシャル $V_0=\frac14\lambda\phi^4$ の最小点は原点にあるが、1ループの補正が対称性を破る~\cite{cw73}。場に依存する質量は $m_h^2=3\lambda\phi^2$、$m_G^2=\lambda\phi^2$、$m_A^2=e^2\phi^2$ である。$\lambda\sim e^4/K$ と数えると、式~\eqref{eq:V1} のうちゲージ場の $(3,\frac56)$ の項だけが $V_0$ と同じ次数になり
\begin{equation}
V_{\mathrm{LO}}=\frac{\phi^4}4\Bigl[\lambda+\frac{3e^4}K\Bigl(\ln\frac{e^2\phi^2}{\mu^2}-\frac56\Bigr)\Bigr]
\label{eq:VLO}
\end{equation}
である。スカラーのループは $\lambda^2$、$G$ と縦波の組のゲージ依存の部分は $\xi e^2\lambda$ の次数で、どちらも次の次数以下である。最小点、質量、最小点の値は
\begin{equation}
\ln\frac{e^2v^2}{\mu^2}=\frac13-\frac{K\lambda}{3e^4},\qquad
M_h^2=V''(v)=\frac{6e^4}Kv^2,\qquad
\frac{M_h^2}{M_A^2}=\frac{3e^2}{8\pi^2},\qquad
V(v)=-\frac{M_h^2v^2}{16}
\label{eq:cw}
\end{equation}
である（\ref{app:cw}）。無次元の $\lambda$ が質量の次元を持つ $v$ に置き換わる（次元転移）。$\mu=M_A$ では $\lambda(M_A)=e^4/K$ である。この次数では $\beta_\lambda=6e^4/K$ なので、$\ln(e^2v^2/\mu^2)+K\lambda/(3e^4)$ は $\mu$ によらない。

Coleman と Weinberg は、4点結合を $\lambda_{\mathrm{CW}}=\dd^4V/\dd\phi^4|_{\phi=M}$（木で $V_0=\lambda_{\mathrm{CW}}\phi^4/4!$）で定め、
\begin{equation*}
V=\frac{\lambda_{\mathrm{CW}}}{4!}\phi^4+\frac{3e^4}{64\pi^2}\phi^4\Bigl(\ln\frac{\phi^2}{M^2}-\frac{25}6\Bigr)
\end{equation*}
と書いた~\cite{cw73}。式~\eqref{eq:VLO} とは $\lambda_{\mathrm{CW}}=6\lambda+\frac{18e^4}K(\ln\frac{e^2M^2}{\mu^2}+\frac{10}3)$ で結ばれる。$M=\langle\phi\rangle$ ととると $\lambda_{\mathrm{CW}}=\frac{33}{8\pi^2}e^4$ で、質量の比は同じ $3e^2/(8\pi^2)$ になる。

\paragraph{1ループの全体とゲージ依存。}$m^2=0$ ではすべての質量が $m_i^2=k_i\phi^2$ の形なので、1ループのポテンシャルは厳密に $\frac{\phi^4}4[\Lambda+\beta\ln\phi^2]$（$\beta=\sum_in_ik_i^2/K$）で、最小点で $V''=2\beta v^2$ である。したがって
\begin{equation}
\frac{M_h^2}{M_A^2}=\frac{3e^2}{8\pi^2}\Bigl[1+\frac{10\lambda^2+2s\,\xi e^2\lambda}{3e^4}\Bigr]
\label{eq:cwratio}
\end{equation}
である。$s=0$ は Landau、$+1$ は背景場の $R_\xi$、$-1$ は Fermi ゲージである（Fermi ゲージは $m_+^4+m_-^4=m_G^4-2\xi m_A^2m_G^2$ から）。$\lambda\sim e^4/K$ では、$\xi$ による補正は $\pm\frac23\xi e^2/K$ で次の次数であり、主要な次数の比 $3e^2/(8\pi^2)$ はゲージによらない。次の次数では2ループのゲージ場の $e^6$ の項も同じ大きさになるので、ゲージによらない比を得るには2ループの有効ポテンシャルが要る~\cite{afs15}。Nielsen 恒等式から見ると、CW の最小点では $\partial_\phi V_0=\lambda v^3$ が $\partial_\phi V_1$ と釣り合って0でないので、1ループで打ち切った $\partial_\xi V=C\,\partial_\phi V_0$ は $e^2/K$ だけ小さい次数で残る。

\paragraph{繰り込み群による改良。}式~\eqref{eq:cw} は $\ln(e^2v^2/\mu^2)$ が小さいとき、すなわち $\mu\simeq M_A$ で使う式である。$\mu_0$ で与えた $\lambda_0$ が $e_0^4/K$ よりずっと大きいと、$\mu_0$ のままでは $\tau_0=K\lambda_0/(6e_0^4)$ の大きな対数が現れる。改良するには、$e$、$\lambda$、場を1ループの方程式~\eqref{eq:rge}（$m^2=0$。場は Landau ゲージの $\gamma_\Phi=-3e^2/K$）で $\mu^*=e(\mu^*)v(\mu^*)$ まで走らせ、そこで1ループのポテンシャルを最小にする。$\beta_\lambda$ の $-12e^2\lambda$ は場の繰り込みの $-4\gamma_\Phi\lambda$ と打ち消し、$\lambda\phi^4$ の係数は $(20\lambda^2+6e^4)/K$ で走る。CW のスケールは $\lambda(\mu^*)\simeq e(\mu^*)^4/K$ となる $\mu^*$ で決まり、質量の比は $3e(M_A)^2/(8\pi^2)$ になる。$\mu$ を $M_A$ から離して1ループの式を使うと、$V_1$ の中の $m_A^2=e^2\phi^2$ が $\frac{20}3e^2/K$ の速さで走る分（2ループの有効ポテンシャルの対数が打ち消す）が残り、$t=\ln(\mu/M_A)$ として $\ln v$ が $\frac{20}3\frac{e^2}K(t^2-\frac t6)$ 程度ずれる（\ref{app:cw}）。

\subsection{摂動のユニタリー性}\label{sec:unitarity}

\paragraph{$Ah\to Ah$。}$A(k_1,\varepsilon_1)h(k_2)\to A(k_3,\varepsilon_3)h(k_4)$（$t=(k_1-k_3)^2$、$u=(k_1-k_4)^2$）は、ユニタリーゲージでは接触項、$t$ チャンネルの $h$、$s$ と $u$ チャンネルの $A$ の4個の図からなり
\begin{equation}
\begin{aligned}
\mathcal M(Ah\to Ah)={}&2e^2(\varepsilon_1\cdot\varepsilon_3^*)\Bigl(1+\frac{3M_h^2}{t-M_h^2}\Bigr)
+\frac{4e^2[M_A^2\,\varepsilon_1\cdot\varepsilon_3^*-(\varepsilon_1\cdot k_2)(\varepsilon_3^*\cdot k_4)]}{s-M_A^2}\\
&+\frac{4e^2[M_A^2\,\varepsilon_1\cdot\varepsilon_3^*-(\varepsilon_1\cdot k_4)(\varepsilon_3^*\cdot k_2)]}{u-M_A^2}
\end{aligned}
\label{eq:Mah}
\end{equation}
である（式~\eqref{eq:Mahh} の交差。\ref{app:unitarity}）。

\paragraph{部分波。}$J=0$ の部分波を
\begin{equation*}
a_0=\frac{N_iN_f\,\kappa}{32\pi}\int_{-1}^1\dd c\,\mathcal M,\qquad \kappa=\frac{2\sqrt{p_ip_f}}{\sqrt s},\qquad c=\cos\theta
\end{equation*}
とする（$N=1/\sqrt2$ は同種粒子の $A_LA_L$、$hh$、$N=1$ は $A_Lh$。$p_i$、$p_f$ は重心系の運動量）。結合したチャンネルの行列の固有値 $a$ が $|\re a|\le\frac12$ を満たすことを、摂動のユニタリー性の条件とする。荷電共役（$A\to-A$、$G\to-G$）で $A_LA_L$ と $hh$ は偶、$A_Lh$ は奇なので、行列は $2\times2$ と $1\times1$ に分かれる。$c$ を止めて $s\to\infty$ とすると、等価定理により縦波の振幅は $G$ の振幅（$A_LA_L\to hh$ は $-1$ 倍）に近づき
\begin{equation}
\begin{gathered}
\mathcal M_{LLLL},\ \mathcal M(hh\to hh)\to-6\lambda,\\
\mathcal M(A_LA_L\to hh)\to2\lambda-\frac{2e^2(3+c^2)}{1-c^2},\qquad
\mathcal M(A_Lh\to A_Lh)\to-2\lambda-\frac{e^2(3+c^2)}{1+c}
\end{gathered}
\label{eq:mlim}
\end{equation}
になる。$\lambda$ の部分の部分波の行列は
\begin{equation}
a_0^{(\lambda)}=\frac\lambda{16\pi}\begin{pmatrix}-3&1\\1&-3\end{pmatrix}\ \ (A_LA_L,\ hh),\qquad a_0^{(\lambda)}(A_Lh)=-\frac\lambda{8\pi}
\label{eq:a0lam}
\end{equation}
で、固有値は $-\lambda/(4\pi)$ と $-\lambda/(8\pi)$ である。前者は $U(1)$ の電荷0の状態 $|\Phi|^2$（$(A_LA_L-hh)/\sqrt2$）、後者は電荷 $\pm2$ の状態 $\Phi^2$、$\Phi^{*2}$（$(A_LA_L+hh)/\sqrt2$ と $A_Lh$）に当たる。したがって木のユニタリー性は
\begin{equation*}
\lambda\le2\pi,\qquad M_h\le\sqrt{4\pi}\,v,\qquad \frac{M_h}{M_A}\le\frac{\sqrt{4\pi}}e
\end{equation*}
を要求する（Lee--Quigg--Thacker~\cite{lqt77} と同じ論法。$e=\frac12$ で $M_h/M_A\le7.09$）。

\paragraph{ゲージ場の交換の対数。}式~\eqref{eq:mlim} の $e^2$ の項は、$t$、$u$ チャンネルの $A$ の交換の前方と後方の極で、有限の $s$ では $1\mp c\sim M_A^2/s$ で切れる。そのため $A_LA_L\to hh$ と $A_Lh\to A_Lh$ の部分波には $-\frac{e^2}{8\pi}\ln\frac s{M_A^2}$ が加わり、電荷0の固有値を正の向きに、電荷2の固有値を負の向きにずらす。これが無視できるのは $\ln(s/M_A^2)\ll\lambda/e^2$ のときである。また、$M_h>2M_A$ では $A_Lh\to A_Lh$ の $u$ チャンネルの $A$ が物理領域で質量殻上に来うる（$u$ は $2M_A^2+2M_h^2-s$ から $(M_h^2-M_A^2)^2/s$ まで動く）ので、$\sqrt s>(M_h^2-M_A^2)/M_A$ で考える。

\paragraph{1ループの補正。}$s$ がすべての質量より大きく $\lambda\gg e^2$ のとき、散乱は $V=\frac\lambda4(h^2+G^2)^2$ の質量のない2成分の理論と同じになる。$\MSbar$ の1ループの振幅は
\begin{equation*}
\mathcal M^{(1)}_{abcd}=\frac1{2K}\sum_{ef}\bigl[\lambda_{abef}\lambda_{efcd}B(s)+\lambda_{acef}\lambda_{efbd}B(t)+\lambda_{adef}\lambda_{efbc}B(u)\bigr],\qquad B(x)=2-\ln\frac{-x-i0}{\mu^2}
\end{equation*}
である（$\lambda_{abcd}$ は $V$ の4階微分、木は $-\lambda_{abcd}$）。$-t=\frac s2(1-c)$ の角度の平均は $\langle\ln(-t/s)\rangle=-1$ なので、$\mu^2=s$ で
\begin{equation}
a^{(1)}=\bigl(a^{(0)}\bigr)^2\Bigl(\frac{13}{2\pi}+i\Bigr)\ \ (\text{電荷0}),\qquad a^{(1)}=\bigl(a^{(0)}\bigr)^2\Bigl(\frac{14}\pi+i\Bigr)\ \ (\text{電荷2})
\label{eq:a1}
\end{equation}
になる（\ref{app:unitarity}）。虚部は弾性のユニタリー性 $\im a=|a|^2$ の1ループの形で、$\mu$ 依存は $\beta_\lambda=20\lambda^2/K$（式~\eqref{eq:rge} で $e=0$）による $\lambda$ の走りと打ち消す。$|a^{(1)}|=|a^{(0)}|$ となるのは $\lambda=5.47$（電荷0）と $5.50$（電荷2）で、木の限界 $\lambda=2\pi$ では1ループの補正が木より15\%大きい。$\re(a^{(0)}+a^{(1)})$ は電荷0で $-\pi/26$ より下がらないので、1ループを含めた $|\re a|\le\frac12$ は条件にならない。摂動が使えるのは $\lambda\lesssim5.5$、すなわち $M_h\lesssim3.3v$ までである。

\paragraph{一致の基準。}発散部分と対抗項は、$1/\epsilon$ の係数が記号として完全に一致することを求める。有限部分は、基準点で、ツールどうしと手計算の数値が倍精度の丸め誤差の範囲（相対 $10^{-12}$ 程度）で一致することを求める。FeynCalc の PaVe 関数の $\epsilon^0$ の係数は、これまでのノートと同じく $\MSbar$ の値に直してから比べる。$\xi$ によらないはずの量は、$\xi=0,\frac12,1,3$ で同じ値になることを求める。MadGraph の断面積は、自分で数値積分した値と統計誤差の範囲で一致することを求める。

\paragraph{手順。}次の順に進める。(1) 模型ファイル \texttt{AbelianHiggs.fr} を作り、FeynArts の模型と UFO を書き出して、Feynman 則を表~\ref{tab:rules} と比べ、MadGraph の図の数をユニタリーゲージと Feynman ゲージで確かめる。(2) 木の振幅：$\Gamma(h\to AA)$、$AA\to AA$ のすべての偏極、$AA\to hh$、$hh\to hh$ を FeynCalc で記号として、偏極ベクトルを陽に作った数値で確かめ、MadGraph の幅と断面積を両方のゲージで比べる。等価定理を高エネルギーで確かめる。(3) 1ループのタドポールと2点関数を、本ノートの FeynArts の模型と FeynCalc で一般の $\xi$ で求め、式~\eqref{eq:T}、\eqref{eq:se} と図ごとに比べ、恒等式~\eqref{eq:stid} を確かめる。有限部分を Package-X、LoopTools、COLLIER で比べる。(4) 3点と4点の1PI 関数（$hhh$、$GGh$、$AAh$、$AGh$、$hhhh$ など）の紫外の極を一般の $\xi$ で求め、対抗項~\eqref{eq:ct} で消えること、$AAAA$ が有限であることを確かめる。NLOCT の対抗項と比べる。(5) 極質量と光学定理を確かめ、NLO の $\Gamma(h\to AA)$ を一般の $\xi$ で求め（FormCalc でも）、NLOCT で作った UFO の MadLoop と比べる。(6) 繰り込み群：極質量と S 行列要素の $\mu$ 依存から $\beta$ 関数を読み取り、一般の公式~\cite{mv1,mv3} と比べる。$e$ と $\lambda$ の走り、Landau 極、$\lambda$ が負になる条件（真空の安定性）を求める。(7) 有効ポテンシャル：背景場の $R_\xi$ ゲージと Fermi ゲージで1ループの有効ポテンシャルを求め、Nielsen 恒等式~\cite{nielsen75} を確かめ、極値の値とその点での質量がゲージによらないことを示す。$\beta_t$ の処方の真空期待値のゲージ依存~\cite{ssv13} との関係を調べる。(8) Coleman--Weinberg の機構~\cite{cw73}：$m^2=0$ の模型で放射による対称性の破れを求め、$M_h^2/M_A^2=3e^2/(8\pi^2)$ を確かめ、繰り込み群で改良する。(9) 摂動のユニタリー性：$A_LA_L$、$hh$、$Ah$ の結合したチャンネルの部分波を求め、木の限界 $\lambda\le2\pi$ と1ループの補正を調べる。(10) 有限温度の相転移：温度ポテンシャルを求め、ゲージ場の3次の項 $E=e^3/(4\pi)$ を有限温度のノート~\cite{thermalnote} の一般形と結び、ゲージ依存の問題を調べる。DRalgo~\cite{dralgo} の次元簡約と比べる。(11) Abrikosov--Nielsen--Olesen の渦糸~\cite{abrikosov57,no73}：古典解と張力を $\lambda/e^2$ の関数として求め、BPS 点 $M_h=M_A$ の張力 $\pi v^2|n|$ と第一種・第二種の境界を確かめる。

\paragraph{手順 (1)：模型ファイル。}FeynRules の模型ファイル \texttt{Src/AbelianHiggs.fr} を作った。ラグランジアンは式~\eqref{eq:L} からゲージ固定の項（頂点を持たない）と対抗項を除き、ゴーストの項 $\mathcal L_{\mathrm{FP}}$ を加えたものである。ゲージ群は $U(1)$ で、$\Phi$ に電荷 $Q_X=1$ を与えて共変微分で結合を書き、$\Phi=(v+h+iG)/\sqrt2$ を定義として与えた。外部パラメータは $e$、$M_A$、$M_h$、$\xi$ で、$v=M_A/e$、$\lambda=M_h^2/(2v^2)$、$m^2=\lambda v^2$ を内部パラメータとした（\ref{app:details}）。FeynRules のチェック（エルミート性、運動項の規格化、質量スペクトル）はすべて通った。頂点は10個のクラスで、すべてが表~\ref{tab:rules} と記号として一致した（差がすべて0）。比べる手続きが誤りを見逃さないことは、表の3か所（$AGh$ の符号、$GGh$ の因子2、ゴーストの頂点の $\xi$）をわざと誤らせた写しで、ちょうど3個の差が出ることで確かめた。FeynArts の模型では、ゴーストと $h$ の結合が $-i\,\texttt{EL}\,\texttt{MA}\,\texttt{GaugeXi[A]}$ になるように \texttt{xiA} を \texttt{GaugeXi[A]} に置き換えた。伝播関数は FeynArts の一般の模型の $R_\xi$ の形で、$G$ とゴーストの質量は $\sqrt{\xi}M_A$ である（\texttt{GaugeXi[S[2]]}$=$\texttt{GaugeXi[U[1]]}$=$\texttt{GaugeXi[A]}）。FeynRules は電荷の単位 \texttt{ee} を FeynArts の \texttt{EL} に置き換えた。UFO は Feynman ゲージ（$\xi=1$）で、\texttt{gauge = [0, 1]} を宣言する。MadGraph 3.8.1 は、その UFO から表~\ref{tab:diagrams} の数の図を両方のゲージで生成し、すべて手で数えた数と一致した。スクリプトは \texttt{generate\_AbelianHiggs.wl}（FeynRules）と \texttt{model\_mg5.mg5}（MadGraph）である。

\paragraph{手順 (2)：木の振幅。}本ノートの FeynArts の模型から FeynCalc で、$h\to AA$、$AA\to AA$、$AA\to hh$、$hh\to hh$ と、Landau ゲージの $GG\to GG$、$GG\to hh$ の振幅を一般の $R_\xi$ ゲージで作り、式~\eqref{eq:width}、\eqref{eq:Maa}、\eqref{eq:Mahh}、\eqref{eq:Mhh}、\eqref{eq:et}、\eqref{eq:Mgghh} と比べた（\texttt{tree\_feyncalc.wl}、表~\ref{tab:tree}）。差はすべて記号として0で、$AA\to hh$ の6個の図の和は、振幅でも偏極の和をとった $\sum|\mathcal M|^2$ でも、$\xi$ で微分すると0になった。次に、ヘリシティの偏極ベクトルを陽に作り（\texttt{tree\_numeric.py}。完全性 $\sum_\lambda\varepsilon^\mu\varepsilon^{\nu*}=-g^{\mu\nu}+k^\mu k^\nu/M_A^2$ は $2\times10^{-15}$ で成り立つ）、$AA\to AA$ の81個、$AA\to hh$ の9個のヘリシティの和を、FeynCalc が偏極の和で厳密に求めた値と10点で比べた。$\sqrt s\le20$ では相対 $3\times10^{-16}$〜$5\times10^{-15}$ で一致した。$\sqrt s=200$、$2000$ では差が $9\times10^{-14}$、$1.3\times10^{-11}$ に増えるが、これは縦波の各図が $s/M_A^2$ に比例して増えて和で打ち消すための倍精度の桁落ちで、大きさは $s/(4M_A^2)\times10^{-16}$ 程度である。$AA\to hh$ の6個の図を陽に組むと、$\xi=0,\frac12,1,3,10$ で式~\eqref{eq:Mahh} と $1.5\times10^{-13}$ で一致し、ゲージ場の交換の $X$ の部分と $G$ の交換の和はチャンネルごとに $3\times10^{-14}$ 以下（振幅は $O(1)$）だった。等価定理は表~\ref{tab:et} の通りで、縦波の振幅と Goldstone ボソンの振幅の差は $E$ が10倍になるごとに100分の1になり、$-6\lambda$ と $0.318452$（$\cos\theta=0.4$ の $GG\to hh$ の極限）に近づいた。

\paragraph{手順 (6)：繰り込み群。}三つの方法で確かめた（\texttt{run\_rg\_check.sh}）。一つ目は物理量の $\mu$ 依存である（\texttt{rg\_numeric.wl}）。$\MSbar$ の有限部分は $\mu$ に $A_0$ の $m^2\ln\mu^2$ と $B_0$ の $\ln\mu^2$ だけを通じて依存する。$M_{h,\mathrm p}$、$M_{A,\mathrm p}$、$\Gamma(h\to AA)$ が $\mu$ によらないことを求めると、$\dd M_h^2/\dd\ln\mu$、$\dd M_A^2/\dd\ln\mu$、$2\beta_e/e=-\dd\delta_{\mathrm{OS}}/\dd\ln\mu$ が一般の $\xi$ で $\xi$ によらずに決まり、$M_h^2=2m^2$、$M_A^2=e^2m^2/\lambda$ から $\beta_e$、$\beta_{m^2}$、$\beta_\lambda$ が式~\eqref{eq:rge} と記号として一致した。二つ目は一般の公式である（\texttt{rg\_general.py}）。Machacek--Vaughn の1ループの公式~\cite{mv1,mv3} を、$\Phi$ の二つの実の成分、生成子 $\theta=\bigl(\begin{smallmatrix}0&-i\\ i&0\end{smallmatrix}\bigr)$、ポテンシャルを微分して作った $\lambda_{abcd}$、$m^2_{ab}$ の陽なテンソルで組み、式~\eqref{eq:rge} を記号として再現した（$\beta_{\lambda_{abcd}}$ は16個の成分すべてで対称な形になる）。三つ目は数値の整合である。基準点の $\MSbar$ のパラメータを1ループの式で $\mu=\frac12,2,4$ に走らせ、各 $\mu$ で極質量と幅を求めると、変化は表~\ref{tab:rg} のとおり2ループの大きさ（$0.2\%$ 以下）に収まった。パラメータを走らせないと、極質量は $\ln\mu$ の1次で $1$〜$4\%$ 変わる。

\paragraph{手順 (7)：有効ポテンシャルと Nielsen 恒等式。}三つのスクリプトで確かめた（\texttt{run\_effpot\_check.sh}）。一つ目は有効ポテンシャルの記号の計算である（\texttt{effpot.wl}）。二つのゲージの $G$ と縦波の2次形式の行列式から第~\ref{sec:effpot} 節の質量を確かめ、式~\eqref{eq:V1} の $V_1$ について次を確かめた。(a) 繰り込み群の方程式は、Landau ゲージと Fermi ゲージでは $\gamma_\Phi$ で、背景場の $R_\xi$ ゲージでは $\gamma_v=-(3+\xi)e^2/K$ で成り立つ（どちらも場によらない真空のエネルギーの走り $-m^4/K$ を除く）。$\gamma_\Phi$ を使うと、背景場の $R_\xi$ ゲージでは $2\xi e^2\phi\,\partial_\phi V_0/K$ が残る。$v_\beta=v+T/M_h^2$ の走りは記号として式~\eqref{eq:vbeta} になり、生成子 $\theta$ から求めた $C_2(S)=\theta^2=1$ を入れた SSV の式と一致した。(b) $\partial_\xi V_1/\partial_\phi V_0$ は、背景場の $R_\xi$ ゲージで式~\eqref{eq:C} に記号として一致し、Fermi ゲージで数値（$\phi=1.5$〜$3$、$\xi=\frac12,3$）で $10^{-30}$ 以内に一致した。(c) 背景場の $R_\xi$ ゲージの $-\partial_\phi V_1(v)$ は式~\eqref{eq:T} に、$\partial_\xi(T/M_h^2)$ は $-C_{\mathrm{bg}}(v)$ に、$\dd M_{\mathrm{curv}}^2/\dd\xi$ は $2C_{\mathrm{bg}}'(v)M_h^2$ に、記号として一致した。$V_1(v)$ は三つのゲージで同じだった。(d) Fermi ゲージの $-\partial_\phi V_1$ と式~\eqref{eq:Tfermi} の差は、$\phi-v=-10^{-2},-10^{-4},-10^{-6}$ で $5.9\times10^{-3}$、$5.8\times10^{-5}$、$5.6\times10^{-7}$ になり、$\phi>v$ では $\sqrt{\phi-v}$ の速さで0に近づいた（$\xi=1$）。$v$ の近くで、Fermi ゲージの $m_G^2V_1''$ は $-\xi M_A^2M_h^4/(4Kv^2)=-0.015460$ に、Landau ゲージの $V_1''-\frac{M_h^4}{2Kv^2}\ln|m_G^2|$ は定数 $0.59197$ に近づいた。

二つ目は2点関数の Nielsen 恒等式である（\texttt{nielsen\_feyncalc.wl}）。$K_h$ の図（ゴーストと $G$ の泡）と $K_{hh}$ の3個の図を表~\ref{tab:rules} の Feynman 則で書き、FeynCalc で $D$ 次元の $A_0$、$B_0$、$C_0$ に直した。図ごとの値は\ref{app:effpot} の式と一致し、和は式~\eqref{eq:nielsen2} になった。部分積分の式と $B_0(0;m^2,m^2)=\frac{D-2}{2m^2}A_0(m^2)$ を使うと、手順 (3) で本ノートの FeynArts の模型から求めた $T$ と $\Sigma^H$ について、$\partial_\xi T=-M_h^2K_h$、$\partial_\xi\Sigma^H_{\mathrm{1PI}}=\Gamma_{hhh}K_h+2(p^2-M_h^2)K_{hh}$、$\partial_\xi\Sigma^H_{\mathrm{tad}}=-\Gamma_{hhh}K_h$ が $D$ 次元で厳密に成り立った。紫外の極は (c) の図だけにあり、$KK_{hh}|_{\DUV}=e^2/2$ である。三つ目は数値である（\texttt{nielsen\_numeric.wl}）。Package-X の $C_0(0,p^2,p^2;x,x,x)$ は部分積分の式と $10^{-29}$ で一致した。手順 (3) の $K\Sigma^H$ の $\MSbar$ の有限部分を $\xi$ の中心差分で微分した値は、$\xi=\frac12,1,3$、$p^2=0,1,3,M_h^2,10$（閾値 $4\xi M_A^2$ の上下）の15点で、$2(p^2-M_h^2)KK_{hh}$ と $10^{-16}$（差分の精度）以内で一致し、$p^2=M_h^2$ では0だった。

基準点の値を表~\ref{tab:effpot} と図~\ref{fig:effpot} に示す。$V(v)=V_0(v)+V_1(v)=-3.1083905$ は三つのゲージのすべての $\xi$ で同じである。最小点のずれ $\Delta v=T/M_h^2$ は $\xi=\frac12$〜$10$ で2倍変わり、$\xi=1$ では $C_{\mathrm{bg}}(v)=0$（$\mu=M_A$）なので $\xi$ について停留する。曲率 $M_{\mathrm{curv}}^2$ も $\xi$ によって変わり、極質量の2乗 $6.5490$ とは $\Sigma^H$ の $p^2$ 依存の分だけ違う。$V_0+V_1$ をそのまま数値で最小にすると、最小点の値も $\xi$ とゲージで変わる（$\hbar^2$ の項が混ざる）。$V_0+\hbar V_1$ の最小点を $\hbar=4^{-k}$（$k=0$〜$6$）で求めると、背景場の $R_\xi$ ゲージ（$\xi=1$）では $(\phi_{\min}-v)/\hbar=-0.021030,\ -0.022199,\ \ldots,\ -0.022624$ が $T/M_h^2=-0.0226245$ に、$[V_{\min}-V_0(v)-\hbar V_1(v)]/\hbar^2$ が $-T^2/(2M_h^2)=-0.0015996$ に近づいた。Landau ゲージも $T_{\mathrm L}/M_h^2=-0.0242077$ に近づく。Fermi ゲージでは、$(\phi_{\min}-v)/\hbar$ が $-0.0259$ から $-0.0341$ まで、$\hbar$ を $\frac14$ にするごとに $\xi M_A^2\ln4/(4Kv)=0.0011$ に近い幅で動き続けた。式~\eqref{eq:Tfermi} で $M_h^2(\phi_{\min}-v)=\hbar\,T_{\mathrm F}(\phi_{\min})$ とした方程式の解とは、$\hbar=4^{-6}$ で $5\times10^{-7}$ まで近づいた。

\paragraph{手順 (8)：Coleman--Weinberg の機構。}二つのスクリプトで確かめた（\texttt{run\_cw\_check.sh}）。一つ目は \texttt{cw.wl} である。(a) 式~\eqref{eq:VLO} から式~\eqref{eq:cw} を記号として求めた。$V_1$ のゲージ場の項以外は Landau ゲージで $\lambda^2$ の次数で、背景場の $R_\xi$ と Fermi ゲージの $\sum n_im_i^4$ は Landau ゲージと $\pm2\xi e^2\lambda\phi^4$ だけ違う。(b) CW の処方の定数 $-\frac{25}6$、$\lambda_{\mathrm{CW}}$ と $\lambda$ の関係、$\lambda_{\mathrm{CW}}=\frac{33}{8\pi^2}e^4$ を記号として再現した。(c) $\beta$ は、Landau と背景場の $R_\xi$ ゲージで記号として、Fermi ゲージで数値で、式~\eqref{eq:cwratio} の形になった。$\mu=1$、$\lambda=e^4/K$（主要な次数の最小点が $ev=1$）とし、$e=\frac12$〜$\frac1{32}$ で1ループのポテンシャルを数値で最小にした比は、5個のゲージ（Landau、背景場の $R_\xi$ と Fermi の $\xi=1,3$）で式~\eqref{eq:cwratio} と $10^{-25}$ 以内で一致した。$3e^2/(8\pi^2)$ からのずれの $K/e^2$ 倍は、$e=\frac1{32}$ で $0.66669$、$2.00002$（背景場）、$-0.66665$、$-1.99998$（Fermi）、$2\times10^{-5}$（Landau）で、図~\ref{fig:cw} の左の通り $\pm\frac23\xi$ に近づく。(d) $e=\frac12$ の点の結合と場を1ループの方程式で $\mu=2^{-6}$〜$2^6$ に走らせ、そこで最小点を求めた。$\mu_0=1$ の規格化に直した $v$ は $\mu=1$ で $2.00005$ で、$\ln v$ は $\mu=2^{-2},2^{-4},2^{-6}$ で $0.023$、$0.087$、$0.187$、$\mu=2^2,2^4,2^6$ で $0.020$、$0.083$、$0.191$ だけ大きくなった。上の見積もり $\frac{20}3\frac{e^2}K(t^2-\frac t6)$ はそれぞれ $0.023$、$0.086$、$0.190$、$0.018$、$0.076$、$0.175$ である。各 $\mu$ での $V''/(e^2v^2)$ は $0.009489$〜$0.009590$ で、主要な次数の $0.009499$ から1\%以内だった。結合を走らせないと、$v$ は $\mu$ に比例して $0.031$ から $128$ まで変わる。

\paragraph{手計算で分かったこと。}対称性が破れたことで、スピノル QED のノートになかった構造が三つ現れた。一つ目はタドポールで、FJ の処方では真空期待値をループで補正しない代わりに、タドポールの付いた図がすべての関数に入る。Slavnov--Taylor 恒等式~\eqref{eq:stid}、Goldstone の定理 $\Sigma^{GG}(0)=0$、極質量のゲージ不変性は、どれもタドポールの付いた図を含めて初めて成り立つ。二つ目はゲージパラメータの入り方で、ゲージ場の伝播関数を質量 $M_A$ の部分と質量 $\sqrt\xi M_A$ の部分に分けると、$\xi$ は $X$、$G$、ゴーストの質量にしか現れない。その結果、$\Sigma_T$ はすべての運動量で $\xi$ によらず、$\Sigma^H$ の $\xi$ 依存は $(p^2-M_h^2)$ に比例する一つの項にまとまる。これは、ゲージ依存が運動方程式に比例する形でしか現れないという Nielsen 恒等式~\cite{nielsen75} の、2点関数での現れで、手順 (7) で式~\eqref{eq:nielsen2} として確かめた。三つ目は真空期待値の繰り込みで、FJ の処方では $v_0=\sqrt{m_0^2/\lambda_0}$ が場の繰り込みと違う割合で繰り込まれ、$\MSbar$ の質量 $M_A$ の走りにタドポールから $-6e^4/\lambda$ の項が入る。対抗項は対称な $Z_A$、$Z_\Phi$、$\delta_{m^2}$、$\delta_\lambda$ だけで、ゲージ固定の項を繰り込まれた場で書いても、$A$、$h$、$G$ の2点関数はすべて有限になった。

\paragraph{手順 (2) で分かったこと。}木のレベルでも、ゲージ依存の打ち消しはゲージ場の伝播関数の $X$ の部分と $G$ の間で起こり、$AA\to hh$ ではチャンネルごとに完全に打ち消した。縦波の振幅は各図が $s/M_A^2$ に比例して増え、和で打ち消して Goldstone ボソンの振幅に近づく（等価定理。外線2本では位相 $i^2=-1$ が付く）。この打ち消しは倍精度の計算に $s/(4M_A^2)$ 倍の桁落ちを生み、陽な偏極ベクトルの数値と MadGraph の行列要素に同じ大きさで現れた。ツールについては、MadGraph 3.8.1 が光子を持たない模型で $t$ チャンネルの $h$ を含む過程の MadEvent の出力に失敗することが分かった（部分過程をまとめなければ動く）。

\paragraph{手順 (3) で分かったこと。}FeynRules が書き出した模型は、手で書いた Feynman 則と同じ1ループの2点関数を図ごとに与え、手計算の閉じた式と Slavnov--Taylor 恒等式がそのまま確かめられた。数値では、タドポールの部分が1PI の部分と同じ大きさを持ち（$\Sigma_T$ では1PI の部分より大きく、符号が逆）、どちらも $\xi$ によって質量の2乗の数\%変わるのに、和は30桁でゲージによらない。FJ の処方の $\MSbar$ の質量を使うなら、タドポールの付いた図を省くことはできない。

\paragraph{手順 (4) で分かったこと。}2点関数の極だけで決めた四つの対抗項 \eqref{eq:ct} が、3点と4点のすべての関数の極を一般の $\xi$ で消し、対称な対抗項と FJ の真空期待値のずれ $\delta v$ だけで模型が繰り込めることを、2点関数を超えて確かめた。$\delta v$ の部分は、3点の関数のタドポールの付いた図と対になっている。NLOCT は同じ模型からタドポールを対抗項で消す処方の極を与え、その差はちょうどタドポールの付いた図の極だった。二つの処方は極の置き場所が違うだけで、物理量は同じになるはずである（手順 (5) で確かめる）。NLOCT は $A$--$G$ の混合の UV の頂点を書き出さないので、NLOCT の UFO で内線にこの混合が現れる過程を計算するときは、自分で加える必要がある。

\paragraph{手順 (5) で分かったこと。}物理量の NLO の補正では、1PI の図、タドポール、外線の留数がそれぞれ $\xi$ で数\%変わり、和だけがゲージによらない。タドポールは質量の処方を通じて消え、極質量で書いた幅は FJ でもタドポールを対抗項で消す処方でも同じになり、MadLoop がそれを $10^{-11}$ で確かめた。$\mu$ 依存は $e$ の走りの1次の打ち消しとして厳密に現れる。

\paragraph{手順 (6) で分かったこと。}$\beta$ 関数は、ゲージによらない三つの物理量の $\mu$ 依存だけから一意に決まり、一般の公式と一致した。$\beta_\lambda$ はどの $\lambda$ でも正なので、フェルミオンのないこの模型では $\lambda$ は紫外で増え続け、真空の不安定ではなく Landau 極（自明性）が $M_h/M_A$ を上から抑える。

\paragraph{手順 (7) で分かったこと。}有効ポテンシャルのゲージ依存は、Nielsen 恒等式~\eqref{eq:nielsen} の係数 $C$（ゴーストと $G$ の泡1個）で完全に表される。極値の値と極質量はゲージによらないが、極値の位置（$\beta_t$ の処方の真空期待値）と曲率はゲージによる。手順 (3) で見た $\Sigma^H$ の $\xi$ 依存の形 $(p^2-M_h^2)\times(\cdots)$ は、この恒等式を2点関数で書いたもので、括弧の中は Nielsen の関数 $K_{hh}$ の3個の図の和だった。背景場の $R_\xi$ ゲージの最小点は FJ のタドポールから決まる $v_\beta$ にちょうど一致し、場と $2\xi e^2/K$ だけ違う割合で走る。これにより、標準模型のノートで見た $v_\beta$ の $\xi$ に依存する走りと SSV の $\hat\gamma$ が、同じ一つの式~\eqref{eq:vbeta} になる。Fermi ゲージでは $\hat\gamma=0$ で、背景場は場と同じに走る。その代わりに、最小点で Goldstone ボソンと縦波の組が $1/k^4$ の伝播関数を持ち、1ループのタドポールが赤外で発散して、最小点が $\hbar\ln\hbar$ でずれる。$\hbar$ で展開すれば、どのゲージでも極値の値は $V_0(v)+V_1(v)$ である。手順 (10) の有限温度の相転移でも、ゲージによらない量はこの展開で作る必要がある~\cite{afs15,egk16}。

\paragraph{手順 (8) で分かったこと。}$m^2=0$ の模型では、ゲージ場のループが $\lambda\sim e^4/K$ のときに木の項と釣り合い、$M_h^2/M_A^2=3e^2/(8\pi^2)$ の軽いヒッグス粒子を与える。この比は主要な次数でゲージによらず、Coleman と Weinberg の処方でも同じで、彼らの $\lambda=\frac{33}{8\pi^2}e^4$ も本ノートの $\MSbar$ の式から出る。すべての質量が $\phi^2$ に比例するので、1ループのポテンシャルは厳密に $\phi^4(\Lambda+\beta\ln\phi^2)$ の形になり、比の次の次数の補正（ゲージ依存 $\pm\frac23\xi e^2/K$ を含む）が閉じた式で読める。手順 (7) と同じく、ゲージ依存は Nielsen 恒等式の通り次の次数に現れ、それを消すには2ループが要る。繰り込み群では、$\beta_\lambda>0$ なので、紫外で与えた正の $\lambda_0$ は赤外へ向かって $e^4/K$ まで下がり、そこが CW のスケールになる。大きな対数を残した1ループの式は $\ln v$ が $\frac{20}3\frac{e^2}Kt^2$ 程度ずれ、$\mu=M_A$ まで走らせる必要がある。

\paragraph{手順 (9) で分かったこと。}縦波のゲージ場とヒッグス粒子の散乱は、高エネルギーで $U(1)$ の電荷で分類でき、電荷0の $|\Phi|^2$ のチャンネルが最も強く、木で $\lambda\le2\pi$ を与える。縦波の振幅は各図が $s/M_A^2$ で増えて打ち消し、$\lambda$ の定数に近づく（等価定理）。ただしゲージ場の $t$、$u$ チャンネルの交換は前方の極から $e^2\ln s$ を残し、$e=\frac12$ では $M_h/M_A$ の限界を10\%程度動かす。1ループでは補正が $(a^{(0)})^2$ に比例し、$\lambda\simeq5.5$ で木と同じ大きさになるので、摂動で扱える $\lambda$ の上限は木の $2\pi$ より少し小さい。手順 (6) の自明性の限界の $\lambda<2\pi$ の曲線は、この木の条件を走る $\lambda(\mu)$ に課したものである。

\paragraph{今後。}次は手順 (10) で、温度ポテンシャルを求め、ゲージ場の3次の項 $E=e^3/(4\pi)$ を有限温度のノート~\cite{thermalnote} の一般形と結び、ゲージ依存の問題を調べ、DRalgo~\cite{dralgo} の次元簡約と比べる。

\section{Feynman 則の導出}\label{app:rules}

\paragraph{ラグランジアンの展開。}$\Phi=(v+h+iG)/\sqrt2$ を代入すると、共変微分は
\begin{equation*}
D_\mu\Phi=\frac1{\sqrt2}\Bigl[(\partial_\mu h+eA_\mu G)+i\bigl(\partial_\mu G-eA_\mu(v+h)\bigr)\Bigr]
\end{equation*}
で、
\begin{equation*}
\begin{aligned}
|D\Phi|^2&=\frac12(\partial h+eAG)^2+\frac12\bigl(\partial G-eA(v+h)\bigr)^2\\
&=\frac12(\partial h)^2+\frac12(\partial G)^2-M_AA\cdot\partial G+eA^\mu(G\partial_\mu h-h\partial_\mu G)+\frac{e^2}2\bigl[(v+h)^2+G^2\bigr]A^2
\end{aligned}
\end{equation*}
となる。最後の項は $\frac12M_A^2A^2+eM_AhA^2+\frac{e^2}2(h^2+G^2)A^2$ である。ポテンシャルは $|\Phi|^2=\frac12[(v+h)^2+G^2]$ と $m^2=\lambda v^2$ から
\begin{equation*}
-m^2|\Phi|^2+\lambda|\Phi|^4=-\frac{\lambda v^4}4+\lambda v^2h^2+\lambda v\,h(h^2+G^2)+\frac\lambda4(h^2+G^2)^2
\end{equation*}
で、$h$ の1次の項と $G^2$ の項は0、$h^2$ の係数は $\frac12M_h^2=\lambda v^2$ である。ゲージ固定の項は
\begin{equation*}
-\frac1{2\xi}(\partial A+\xi M_AG)^2=-\frac1{2\xi}(\partial A)^2-M_AG\,\partial\cdot A-\frac12\xi M_A^2G^2
\simeq-\frac1{2\xi}(\partial A)^2+M_AA\cdot\partial G-\frac12\xi M_A^2G^2
\end{equation*}
で（$\simeq$ は全微分を除いて等しいこと）、$|D\Phi|^2$ の混合 $-M_AA\cdot\partial G$ を打ち消す。ゴーストの項は $\mathcal L_{\mathrm{FP}}=-\bar c\,sF$、$sF=\partial^2c+\xi M_A\,sG=\partial^2c+\xi M_Ae(v+h)c$ から式~\eqref{eq:gf} になる。以上で式~\eqref{eq:Lexp} を得る。

\paragraph{伝播関数。}ゲージ場の2次の項は運動量空間で $\frac12\tilde A_\mu(-k)K^{\mu\nu}\tilde A_\nu(k)$、$K^{\mu\nu}=-(k^2-M_A^2)g^{\mu\nu}+(1-1/\xi)k^\mu k^\nu$ で、伝播関数は $i(K^{-1})_{\nu\rho}$ である。$g=P_T+P_L$（$P_L=kk/k^2$）と分けると $K=-(k^2-M_A^2)P_T-\frac1\xi(k^2-\xi M_A^2)P_L$ なので、
\begin{equation*}
i(K^{-1})=\frac{-i}{k^2-M_A^2}P_T+\frac{-i\xi}{k^2-\xi M_A^2}P_L
\end{equation*}
で、これは式~\eqref{eq:propsplit} の左辺に等しい。右辺の分け方は $P_L$ の係数の恒等式
\begin{equation*}
-\frac{1}{M_A^2(k^2-M_A^2)}+\frac{1}{M_A^2(k^2-\xi M_A^2)}=-\frac{1-\xi}{(k^2-M_A^2)(k^2-\xi M_A^2)}
\end{equation*}
で確かめられる。$\xi\to\infty$ で $X\to0$ となり、ユニタリーゲージの伝播関数 $U$ が残る。$G$ とゴーストの2次の項は $\frac12G(-\partial^2-\xi M_A^2)G$、$\bar c(-\partial^2-\xi M_A^2)c$ で、伝播関数はどちらも $i/(k^2-\xi M_A^2)$ である。

\paragraph{頂点。}頂点は相互作用項の係数に $i$ と同種の場の入れ替えの数を掛け、微分を $\partial_\mu\to-ip_\mu$（入る運動量）で置き換えたものである。$-\lambda vh^3$ は $i(-\lambda v)3!=-6i\lambda v$、$-\lambda vhG^2$ は $-2i\lambda v$、$-\frac\lambda4h^4$ は $-6i\lambda$、$-\frac\lambda2h^2G^2$ は $i(-\frac\lambda2)2!\,2!=-2i\lambda$、$eM_AhA^2$ は $2ieM_Ag^{\mu\nu}$、$\frac{e^2}2h^2A^2$ は $i\frac{e^2}2\,2!\,2!\,g^{\mu\nu}=2ie^2g^{\mu\nu}$ を与える。$eA^\mu(G\partial_\mu h-h\partial_\mu G)$ は $ie[(-ip_h)-(-ip_G)]^\mu=e(p_h-p_G)^\mu$、$-\xi eM_Ah\bar cc$ は $-i\xi eM_A$ を与える。以上が表~\ref{tab:rules} である。

\section{BRST 対称性と Slavnov--Taylor 恒等式の導出}\label{app:brst}

\paragraph{BRST 変換。}ゲージ変換 $\Phi\to e^{i\alpha}\Phi$、$A_\mu\to A_\mu+\partial_\mu\alpha/e$ の $\alpha$ を $ec$（$c$ は Grassmann 数）に置き換えて
\begin{equation*}
sA_\mu=\partial_\mu c,\qquad s\Phi=iec\,\Phi,\qquad sc=0,\qquad s\bar c=B
\end{equation*}
とする（$B$ は補助場で $sB=0$）。$s^2=0$ で、$s$ は $A$、$\Phi$ の汎関数としてのゲージ不変な項を0にする。$h$、$G$ では $s(h+iG)=iec(v+h+iG)$ から $sh=-ecG$、$sG=ec(v+h)$ である。
\begin{equation*}
s\Bigl[\bar c\Bigl(F+\frac\xi2B\Bigr)\Bigr]=B\,F+\frac\xi2B^2-\bar c\,sF
\end{equation*}
をラグランジアンに加え、$B$ について積分すると $B=-F/\xi$ で $\mathcal L_{\mathrm{gf}}+\mathcal L_{\mathrm{FP}}$ になる。

\paragraph{$\langle FF\rangle$ の恒等式。}BRST 不変性から $\langle s[\bar c(x)F(y)]\rangle=0$、すなわち $\langle B(x)F(y)\rangle=\langle\bar c(x)\,sF(y)\rangle$ である。ゴーストの作用は $-\int\bar c\,sF$ で、$\delta S/\delta\bar c(y)=-sF(y)$ である。Schwinger--Dyson の式 $\int\mathcal D\bar c\,\delta[\bar c(x)e^{iS}]/\delta\bar c(y)=0$ から $\langle\bar c(x)\,sF(y)\rangle=i\delta^4(x-y)$ が、相互作用によらず厳密に成り立つ（符号は木のゴーストの伝播関数で確かめられる。$sF=(\partial^2+\xi M_A^2)c+\cdots$ と $\langle c\,\bar c\rangle=i/(k^2-\xi M_A^2)$ から、Grassmann 数の入れ替えの $-1$ を含めて $+i$）。$B$ の積分で $\langle B(x)F(y)\rangle=-\frac1\xi\langle F(x)F(y)\rangle$ なので、$\langle T\,F(x)F(y)\rangle=-\xi\cdot i\delta^4(x-y)=-i\xi\delta^4(x-y)$ である。木のレベルでは、$F(k)=-ik^\mu A_\mu+\xi M_AG$ と伝播関数~\eqref{eq:propsplit} から $k^\mu k^\nu(-i\xi P_{L,\mu\nu})/(k^2-\xi M_A^2)+\xi^2M_A^2\,i/(k^2-\xi M_A^2)=-i\xi$ で確かめられる。

\paragraph{2点関数の恒等式。}完全な伝播関数を $\mathcal D=\mathcal D_0+\mathcal D_0\,\Gamma\,\mathcal D_0+\cdots$ と書く（$\Gamma$ は式~\eqref{eq:Gamma2} の1ループの部分を $(A_\mu,G)$ の行列にしたもの）。$\langle FF\rangle$ が補正を受けないので、1ループで $u^a\Gamma_{ab}w^b=0$ である。ここで $u^a$、$w^b$ は木の伝播関数に $F$ を左右から作用させたもので
\begin{equation*}
u=\frac{\xi}{k^2-\xi M_A^2}\bigl(-k_\nu,\ iM_A\bigr),\qquad w=\frac{\xi}{k^2-\xi M_A^2}\bigl(k_\nu,\ iM_A\bigr)
\end{equation*}
である（$F(x)$ の $\partial_x$ は $-ik$、$F(y)$ の $\partial_y$ は $+ik$ を与える）。$\Gamma^{GA}_\nu(k)=\Gamma^{AG}_\nu(-k)=-k_\nu\Sigma^{AG}$ を使うと
\begin{equation*}
-k^\mu k^\nu\Gamma^{AA}_{\mu\nu}-iM_Ak^\mu\Gamma^{AG}_\mu+iM_Ak^\nu\Gamma^{GA}_\nu-M_A^2\Gamma^{GG}
=i\bigl[k^2\Sigma_L-2M_Ak^2\Sigma^{AG}-M_A^2\Sigma^{GG}\bigr]=0
\end{equation*}
で式~\eqref{eq:stid} を得る。$\mathcal D$ は連結な伝播関数なので、$\Gamma$ はタドポールを付けた図を含む。式~\eqref{eq:tadins} のタドポールの部分を代入すると左辺に $k^2(-2M_A^2)+2M_Ak^2M_A+M_A^2M_h^2$ の $\Delta v/v$ 倍、すなわち $M_A^2T/v$ が残るので、1PI の部分だけでは右辺が $-M_A^2T/v$ になる。$k^2=0$ では $\Sigma^{GG}(0)=0$ である。

\section{べき数え上げ}\label{app:counting}

$L$ ループ、内線 $I$ 本、頂点 $V$ 個、外線 $E$ 本の図で、頂点 $v$ の場の数を $n_v$、微分の数を $d_v$ とする。$R_\xi$ ゲージの伝播関数はすべて $1/k^2$ で落ちるので、表面的な発散次数は $\omega=4L-2I+\sum_vd_v$ である。$L=I-V+1$、$2I+E=\sum_vn_v$ を使うと $\omega=4-E+\sum_v(n_v+d_v-4)$ で、繰り込み可能な頂点では $n_v+d_v+[g_v]=4$ なので式~\eqref{eq:omega} を得る。$C$ 変換で $A$、$G$ は奇、$h$ は偶なので、$A$ と $G$ の数の和が奇数の関数は0である。$AAAA$ は $\omega=0$ だが、ゲージ不変性から外線ごとに場の強さが付き、実質の次数は $-4$ で有限である。

\section{タドポールと2点関数の導出}\label{app:se}

\paragraph{方針。}ゲージ場の線は式~\eqref{eq:propsplit} の $U$（質量 $M_A$）と $X$（質量 $\sqrt\xi M_A$、$k_\mu k_\nu/M_A^2$ 付き）に分ける。$X$ の $k_\mu$ が頂点に付くと、次の恒等式で分母に直る。$AAh$ の頂点では $k\cdot(k+p)=\frac12[D_\xi(k)+D_\xi(k+p)-(p^2-2\xi M_A^2)]$、$AGh$ の頂点では $k\cdot(k+2p)=D_\xi(k+p)-(p^2-\xi M_A^2)$ などである（$D_\xi(k)=k^2-\xi M_A^2$）。分母が一つ消えた項は $A_0$ になり、質量のない積分（スケールのない積分）は0である。テンソル積分は Passarino--Veltman の方法で $A_0$、$B_0$ に直す。$\MSbar$ の有限部分は、$D$ の係数 $c(D)=c(4)+(D-4)c'(4)$ と極の係数 $r$ から $c(4)X_{\mathrm{fin}}-2c'(4)r$ で得る。

\paragraph{タドポール。}図~\ref{fig:oneloop} の (a)〜(c) は（$K/v$ 倍で）次の通りである。$h$：$\frac32M_h^2A_0(M_h^2)$、$G$：$\frac12M_h^2A_0(\xi M_A^2)$、$A$ の $U$：$(D-1)M_A^2A_0(M_A^2)$、$A$ の $X$：$\xi M_A^2A_0(\xi M_A^2)$、ゴースト：$-\xi M_A^2A_0(\xi M_A^2)$。たとえば $A$ の $U$ は $\frac12\cdot2ieM_A\cdot g^{\mu\nu}\cdot(-i)(g_{\mu\nu}-k_\mu k_\nu/M_A^2)/D_A(k)=eM_A(D-k^2/M_A^2)/D_A(k)$ で、$k^2/D_A=1+M_A^2/D_A$ と $\int1=0$ から $eM_A(D-1)\int1/D_A$ になる。$X$ は $eM_Ak^2/(M_A^2D_\xi)$ で、同様に $eM_A\xi\int1/D_\xi$ になる。ゴーストは $(-1)\cdot(-i\xi eM_A)\cdot i\int1/D_\xi$ である。和が式~\eqref{eq:T} である。

\paragraph{$h$ の自己エネルギー。}図ごとの値（$Kv^2$ 倍）を表~\ref{tab:seh} に示す。$B_0(p^2;M_A^2,\xi M_A^2)$ と $A_0(M_A^2)$ の $\xi$ を含む部分は、(e) の $UX$ と (f) の $U$ で打ち消す。$B_0(p^2;\xi M_A^2,\xi M_A^2)$ の係数は (d) の $GG$、(e) の $XX$、(f) の $X$、(g) の和で
\begin{equation*}

\paragraph{対抗項のラグランジアン。}式~\eqref{eq:bare} を代入すると、裸のラグランジアンは

\paragraph{$h\to AA$。}振幅は $\mathcal M=2eM_A\,\varepsilon_1^*\cdot\varepsilon_2^*$ で、偏極の和は $\sum|\mathcal M|^2=4e^2M_A^2[2+(k_1\cdot k_2)^2/M_A^4]$、$k_1\cdot k_2=\frac12(M_h^2-2M_A^2)$ である。幅は $\Gamma=\frac12\cdot\frac1{2M_h}\cdot\frac{\beta}{8\pi}\sum|\mathcal M|^2$ で、$2+(M_h^2-2M_A^2)^2/(4M_A^4)=M_h^4(1-4x+12x^2)/(4M_A^4)$ から式~\eqref{eq:width} を得る。

\section{有効ポテンシャルと Nielsen 恒等式の導出}\label{app:effpot}

\paragraph{質量。}一定の背景場のまわりの2次の項のうち、$h$ と横波は通常の形で、$G$ と縦波だけがゲージ固定による。$|D\Phi|^2$ は $-e\phi A^\mu\partial_\mu G$ を含む。Fermi ゲージ $\mathcal L_{\mathrm{gf}}=-(\partial\!\cdot\!A)^2/(2\xi)$ で、Euclid の運動量で $A_\mu=(k_\mu/|k|)a$ と書くと、$(G,a)$ の2次形式の行列は
\begin{equation*}
\begin{pmatrix}k^2+m_G^2&ie\phi|k|\\-ie\phi|k|&k^2/\xi+m_A^2\end{pmatrix},\qquad
\det=\frac1\xi\bigl(k^4+k^2m_G^2+\xi m_A^2m_G^2\bigr)=\frac1\xi(k^2+m_+^2)(k^2+m_-^2)
\end{equation*}
で、ゴーストは質量を持たず $\phi$ によらない。Minkowski の伝播関数は、$P=(k^2-m_+^2)(k^2-m_-^2)$ として $\langle GG\rangle=i(k^2-\xi m_A^2)/P$、$\langle G\,\partial\!\cdot\!A\rangle=i\xi m_Ak^2/P$（$\partial\!\cdot\!A$ から $G$ へ運動量 $k$）である。$m_G^2=0$ では $P=k^4$ になる。背景場の $R_\xi$ ゲージ $F=\partial\!\cdot\!A+\xi e\phi G$ では、$-F^2/(2\xi)$ の交差項 $-e\phi G\,\partial\!\cdot\!A$ が部分積分で混合を打ち消し、$G$ に $-\frac12\xi m_A^2G^2$ が加わる。$sF=\partial^2c+\xi e\phi\,sG=[\partial^2+\xi e^2\phi(\phi+h)]c$ で、ゴーストの質量は $\xi m_A^2$ である。縦波の $k^2/\xi+m_A^2\propto k^2+\xi m_A^2$ と合わせ、$G$、縦波、ゴースト（$-2$）が式~\eqref{eq:V1} の重みを与える。

\paragraph{Nielsen 恒等式。}$\mathcal L_{\mathrm{gf}}+\mathcal L_{\mathrm{FP}}=s\Psi$、$\Psi=\bar c(F+\frac\xi2B)$（\ref{app:brst}）なので、$\partial_\xi S=s\int\partial_\xi\Psi$、$\partial_\xi\Psi=\bar c(\partial_\xi F+\frac12B)$ である。源を付けた $Z[J]=\int e^{iS+i\int J\phi}$ で、BRST 変換による変数の変換（測度と $S$ は不変）から、Grassmann 数の $X$ について $\langle sX\rangle_J=\langle X\,i\!\int\!J_is\phi_i\rangle_J$ である。$X=\int\partial_\xi\Psi$ とすると $\partial_\xi Z=i\langle sX\rangle_J=\int J_i\langle s\phi_iX\rangle_J$ で、$W=-i\ln Z$、$\Gamma=W-\int J\phi$、$J_i=-\delta\Gamma/\delta\phi_i$ から式~\eqref{eq:nielsen} を得る。$B$ は $\partial_\xi\Psi$ に1次で入るだけなので、$B$ の積分で $B=-F/\xi$ に置き換えてよい。$\partial_\xi F+\frac B2$ は、固定した $R_\xi$（式~\eqref{eq:gf}）で $\frac12(M_AG-\partial\!\cdot\!A/\xi)$、背景場の $R_\xi$ で $\frac12(e\phi G-\partial\!\cdot\!A/\xi)$、Fermi ゲージで $-\partial\!\cdot\!A/(2\xi)$ である。

\paragraph{1点の関数。}一定の場では $\Gamma=-\int V$ なので $\partial_\xi V=K_h\,\partial_\phi V$ である。1ループの $K_h=i\langle(-ecG)X\rangle$ は、$c$ と $X$ の $\bar c$、$G$ と $X$ の $G$（または $\partial\!\cdot\!A$）を結ぶ泡1個である。背景場の $R_\xi$ では
\begin{equation*}
K_h=-ie\,\frac{e\phi}2\int\frac{\dd^Dk}{(2\pi)^D}\frac{i}{k^2-\xi m_A^2}\,\frac{i}{k^2-m_G^2-\xi m_A^2}=-\frac{e^2\phi}{2K}B_0(0;\xi m_A^2,m_G^2+\xi m_A^2)
\end{equation*}
で、Fermi ゲージでは $K_h=\frac{ie}{2\xi}\int\frac{\dd^Dk}{(2\pi)^D}\frac{i}{k^2}\frac{i\xi m_Ak^2}P=\frac{e^2\phi}{2K}B_0(0;m_+^2,m_-^2)$ である。これが式~\eqref{eq:C} で、極は場の繰り込みの $\xi$ 依存に入る。固定した $R_\xi$ の $K_h=-\frac{M_A^2}{2Kv}B_0(0;\xi M_A^2,\xi M_A^2)$ の有限部分は $C_{\mathrm{bg}}(v)$ に等しい。式~\eqref{eq:nielsen} を $h$ で1回微分すると $\partial_\xi T=\Gamma_{hh}(0)K_h=-M_h^2K_h$、すなわち $\partial_\xi\Delta v=-K_h$ である。極値の条件 $\partial_\phi V(\phi_{\min})=0$ を $\xi$ で微分すると $V''\partial_\xi\phi_{\min}+\partial_\phi(CV')=0$ で、$\partial_\xi\phi_{\min}=-C$、$\dd V(\phi_{\min})/\dd\xi=CV'=0$ である。

\paragraph{背景場のタドポール。}$f(m^2)=m^4(\ln\frac{m^2}{\mu^2}-\frac32)/(4K)$、$f'(m^2)=-A_0(m^2)/(2K)$ とする。背景場の $R_\xi$ の $V_1$ の $\phi$ 微分のうち、$G$ の項 $f'(m_G^2+\xi m_A^2)(2\lambda\phi+2\xi e^2\phi)$ と縦波とゴーストの項 $-f'(\xi m_A^2)\,2\xi e^2\phi$ は、$v$ で $\xi e^2$ の部分が打ち消し、$f'(\xi M_A^2)\,2\lambda v=-\frac{M_h^2}{2Kv}A_0(\xi M_A^2)$ になる。これは固定した $R_\xi$ の $G$ のループの寄与で（固定した $R_\xi$ では縦波とゴーストが打ち消す）、$h$ と横波の項（$c=\frac56$ が $(D-1)A_0\to3A_0-2M_A^2$ を与える）と合わせて $-\partial_\phi V_1(v)=T$ である。

\paragraph{Fermi ゲージの $v$ の近く。}$m_G^2\to0$ で、$m_\pm^2\simeq\frac12m_G^2\pm i\sqrt{\xi m_A^2m_G^2}$（$m_G^2>0$）または実の $\pm\sqrt{\xi m_A^2|m_G^2|}$（$m_G^2<0$）である。どちらでも $\re[f(m_+^2)+f(m_-^2)]\simeq-\frac{\xi m_A^2m_G^2}{4K}[\ln(\xi m_A^2|m_G^2|/\mu^4)-3]$ である。$\partial_\phi m_G^2=2\lambda v=M_h^2/v$ で1回微分すると式~\eqref{eq:Tfermi}、2回微分すると $V_1''\simeq-\xi M_A^2M_h^4/(4Kv^2m_G^2)$ を得る。Landau ゲージの $f(m_G^2)$ からは $V_1''\simeq\frac{M_h^4}{2Kv^2}\ln|m_G^2|$ が出る。

\paragraph{2点関数。}式~\eqref{eq:nielsen} を $h(z_1)$、$h(z_2)$ で微分し、木の真空で1ループまでとると $\partial_\xi\Gamma_{hh}=\Gamma_{hhh}K_h+2\Gamma_{hh}K_{hh}$ である（$\Gamma_{hh}=p^2-M_h^2$、$\Gamma_{hhh}=-3M_h^2/v$。$\Gamma_hK_{hhh}$ は2ループ）。$\Gamma_{hh}$ の1ループの部分は1PI の $\Sigma^H$ で、タドポールの付いた図 $-3T/v$ の $\xi$ 微分 $-\frac3v\partial_\xi T=\frac{3M_h^2}vK_h$ が第1項を打ち消す。$K_{hh}$ は、固定した $R_\xi$ の $X=\int\bar c\,\frac12(M_AG-\partial\!\cdot\!A/\xi)$ と外線の $h$ の3個の図である。(a) $h$ をゴーストの線に $\bar cch$ の頂点でつなぎ、$G$ を直接 $X$ の $G$ に結ぶ。(b) $G$ の線に $GGh$ の頂点でつなぐ。(c) $G$ を $AGh$ の頂点で $A$ に変え、$X$ の $\partial\!\cdot\!A$ に結ぶ（伝播関数の $X$ の部分だけが残る）。$x=\xi M_A^2$ として
\begin{equation*}
KK_{hh}^{(a)}=-\frac{e^2}2xC_0,\qquad KK_{hh}^{(b)}=-\frac{e^2}2M_h^2C_0,\qquad
KK_{hh}^{(c)}=\frac{e^2}2\bigl[B_0(0;x,x)+(x-p^2)C_0\bigr]
\end{equation*}
で（$C_0=C_0(0,p^2,p^2;x,x,x)$。(c) は分子 $k\cdot(2p-k)=p^2-x-[(k-p)^2-x]$ を分母に直した）、和が式~\eqref{eq:nielsen2} である。$D$ 次元で $\partial_{m^2}A_0(m^2)=\frac{D-2}{2m^2}A_0(m^2)=B_0(0;m^2,m^2)$、$\partial_{m^2}B_0(p^2;m^2,m^2)=2C_0$、部分積分で

\end{equation*}
である。したがって式~\eqref{eq:se} の $\xi$ の項 $(p^2-M_h^2)[A_0(x)-\frac12(p^2+M_h^2)B_0(p^2;x,x)]/(Kv^2)$ の $\xi$ 微分は $(p^2-M_h^2)\frac{e^2}K[B_0(0;x,x)-(p^2+M_h^2)C_0]=2(p^2-M_h^2)K_{hh}$ になる。

\paragraph{曲率。}$\partial_\xi V_1=CV_0'$ を $\phi$ で2回微分すると、$v$ で $\partial_\xi V_1''=2C'M_h^2+CV_0'''$ である。$3T/v=V_0'''\Delta v$ の $\xi$ 微分は $-V_0'''C$ なので、$\dd M_{\mathrm{curv}}^2/\dd\xi=2C'(v)M_h^2$ である。$C_{\mathrm{bg}}$ を $m_G^2$ で展開すると $C_{\mathrm{bg}}=\frac{e^2\phi}{2K}[\ln(\xi m_A^2/\mu^2)+m_G^2/(2\xi m_A^2)+O(m_G^4)]$ で、$C'_{\mathrm{bg}}(v)$ が第~\ref{sec:effpot} 節の式になる。

\paragraph{紫外の極と背景場の繰り込み。}$\MSbar$ の $V_1$ の極は $-\DUV\sum n_im_i^4/(4K)$ である。$\sum n_im_i^4$ は Landau ゲージの $m_h^4+3m_A^4+m_G^4$ に、Fermi ゲージでは $m_+^4+m_-^4-m_G^4=-2\xi m_A^2m_G^2$、背景場の $R_\xi$ ゲージでは $(m_G^2+\xi m_A^2)^2-\xi^2m_A^4-m_G^4=2\xi m_A^2m_G^2$ を加えたもので、$m_A^2m_G^2=e^2\phi\,\partial_\phi V_0$ である。背景場を $\phi_0=\sqrt{Z}\phi$ と繰り込むと $V_0$ に $\frac12\delta Z\,\phi\,\partial_\phi V_0$ が加わる。$\xi$ の部分を消すには、Fermi ゲージで $\delta Z_\Phi$ の $\xi$ の部分 $-\xi e^2\DUV/K$、背景場の $R_\xi$ ゲージで符号が逆の $+\xi e^2\DUV/K$ が要る。したがって背景場の $R_\xi$ ゲージの背景場は $\delta Z_v=(3+\xi)e^2\DUV/K$ で繰り込まれ、$\gamma_v=-(3+\xi)e^2/K$ である。$\frac12(\delta Z_v-\delta Z_\Phi)=\xi e^2\DUV/K$ は、SSV の真空期待値の余分の対抗項 $\delta v^{(1)}-\frac12\delta Z_\Phi^{(1)}v=\xi g^2C_2(S)v\DUV/K$~\cite{ssv13} に当たる。式~\eqref{eq:vbeta} の二つの項は、$v^2=m^2/\lambda$ の $\beta_{m^2}/m^2-\beta_\lambda/\lambda$ の半分と、式~\eqref{eq:T} の $A_0(m^2)$ の $m^2\ln\mu^2$ から来る $\dd(KT)/\dd\ln\mu=(6M_A^4+3M_h^4+\xi M_A^2M_h^2)/v$ である。

\section{Coleman--Weinberg の機構の導出}\label{app:cw}

\paragraph{主要な次数。}$V=\frac{\phi^4}4[\Lambda+\beta\ln\phi^2]$ の形では、$V'=\phi^3[\Lambda+\beta\ln\phi^2+\frac\beta2]$ なので、最小点は $\ln v^2=-\Lambda/\beta-\frac12$ で、$V''(v)=3v^2(\Lambda+\beta\ln v^2)+\frac72\beta v^2=2\beta v^2$、$V(v)=-\frac18\beta v^4$ である。式~\eqref{eq:VLO} は $\beta=3e^4/K$、$\Lambda=\lambda+\frac{3e^4}K(\ln\frac{e^2}{\mu^2}-\frac56)$ で、式~\eqref{eq:cw} を得る。

\paragraph{CW の処方。}$\phi^4\ln(\phi^2/M^2)$ の4階微分は $\phi=M$ で $100$、$\phi^4$ の4階微分は $24$ なので、ループの部分の4階微分を $\phi=M$ で0にする定数は $-\frac{100}{24}=-\frac{25}6$ である。$\phi^4$ の係数を式~\eqref{eq:VLO} と比べて $\lambda_{\mathrm{CW}}$ と $\lambda$ の関係を得る。$\phi=M$ で $V'=0$ とすると $\frac{\lambda_{\mathrm{CW}}}6+\frac{3e^4}K(-\frac{25}6+\frac12)=0$、すなわち $\lambda_{\mathrm{CW}}=66e^4/K=\frac{33}{8\pi^2}e^4$ である。

\paragraph{1ループの全体。}$m_i^2=k_i\phi^2$ なら $m_i^4(\ln\frac{m_i^2}{\mu^2}-c_i)=k_i^2\phi^4(\ln\phi^2+\ln\frac{k_i}{\mu^2}-c_i)$ なので、$\beta=\sum n_ik_i^2/K$、$\Lambda=\lambda+\sum n_ik_i^2(\ln\frac{k_i}{\mu^2}-c_i)/K$ である。Landau ゲージでは $(k_i,n_i)=(3\lambda,1)$、$(\lambda,1)$、$(e^2,3)$ で $\sum n_ik_i^2=10\lambda^2+3e^4$ である。背景場の $R_\xi$ では、$G$、縦波、ゴーストが $(\lambda+\xi e^2)^2-\xi^2e^4=\lambda^2+2\xi e^2\lambda$ を与える。Fermi ゲージでは $k_++k_-=\lambda$、$k_+k_-=\xi e^2\lambda$ から $k_+^2+k_-^2=\lambda^2-2\xi e^2\lambda$ である（$k_\pm$ が複素共役のときは $\re$ をとる）。$M_h^2/M_A^2=2\beta/e^2$ から式~\eqref{eq:cwratio} を得る。

\paragraph{走り。}$m^2=0$ でも式~\eqref{eq:rge} の $\beta_e$、$\beta_\lambda$、$\gamma_\Phi$ がそのまま使える。$\phi_\mu=z\phi_{\mu_0}$、$\dd\ln z/\dd\ln\mu=-\gamma_\Phi=3e^2/K$（Landau ゲージ）とすると、$\lambda z^4$ は $(\beta_\lambda-4\gamma_\Phi\lambda)z^4=(20\lambda^2+6e^4)z^4/K$ で走り、$V_1$ の明示的な $\mu$ 依存と（場によらない真空のエネルギーを除いて）打ち消す。残るのは $V_1$ の中の質量の走りで、$m_A^2=e^2z^2\phi_{\mu_0}^2$ は $\dd\ln m_A^2/\dd\ln\mu=2\beta_e/e-2\gamma_\Phi=\frac{20}3e^2/K$ で走る。$\partial V_1/\partial m_A^2=\frac{3m_A^2}{4K}(2\ln\frac{m_A^2}{\mu^2}-\frac23)$ から、$\mu_0$ の規格化で $\dd V/\dd t=\frac{5e^2m_A^4}{K^2}(2\ln\frac{m_A^2}{\mu^2}-\frac23)$（$t=\ln(\mu/M_A)$）が残る。$\ln(m_A^2/\mu^2)=\ln(e^2\phi^2/M_A^2)-2t$ として $t$ で積分すると、$\Lambda$ と $\beta$ が $\delta\Lambda=\frac{20e^6}{K^2}[(2\ln\frac{e^2}{M_A^2}-\frac23)t-2t^2]$、$\delta\beta=\frac{40e^6}{K^2}t$ だけずれる。$\delta\ln v^2=-\delta\Lambda/\beta+(\Lambda/\beta)\delta\beta/\beta$ に $\Lambda/\beta=\ln\frac{e^2}{M_A^2}-\frac12$ を入れると、$\delta\ln v=\frac{20}3\frac{e^2}K(t^2-\frac t6)$ になる（$e$ の走りなどの、さらに高い次数の項を除く）。

\section{摂動のユニタリー性の導出}\label{app:unitarity}

\paragraph{$Ah\to Ah$。}ユニタリーゲージで、接触項は $AAhh$ の頂点から $2e^2(\varepsilon_1\cdot\varepsilon_3^*)$、$t$ チャンネルの $h$ は $AAh$ と $hhh$ の頂点から $\frac{(2eM_A)(6\lambda v)}{t-M_h^2}(\varepsilon_1\cdot\varepsilon_3^*)=\frac{6e^2M_h^2}{t-M_h^2}(\varepsilon_1\cdot\varepsilon_3^*)$ である。$s$ チャンネルの $A$ は、$q=k_1+k_2$ として、$(2ieM_A)^2\varepsilon_1^\mu\,\frac{-i(g_{\mu\nu}-q_\mu q_\nu/M_A^2)}{s-M_A^2}\,\varepsilon_3^{*\nu}$ から、$\varepsilon_1\cdot q=\varepsilon_1\cdot k_2$、$\varepsilon_3^*\cdot q=\varepsilon_3^*\cdot k_4$ を使って式~\eqref{eq:Mah} の第2項になる。$u$ チャンネル（$q=k_1-k_4$）も同じである。式~\eqref{eq:Mahh} で $A(k_2)$ を終状態に、$h(p_1)$ を始状態に移しても同じ式になる。$R_\xi$ ゲージでは $s$、$u$ チャンネルに $G$ の交換が加わり、ゲージ場の伝播関数の $X$ の部分と打ち消す（式~\eqref{eq:Mahh} と同じ）。

\paragraph{部分波の規格化。}$S=1+iT$、2粒子の状態を $\langle p'|p\rangle=2E(2\pi)^3\delta^3$ で規格化すると、$J$ の部分波は $a_J=\frac{N_iN_f\kappa}{32\pi}\int\dd c\,P_J(c)\mathcal M$ で、開いたすべての2粒子のチャンネルについて $\im a_J^{ii}=\sum_n|a_J^{in}|^2$ である。同種粒子の状態の規格化は $N=1/\sqrt2$ で、終状態の角度は全域で積分する。行列 $a_J$ は対称なので、その固有値 $a$ について $\im a\ge|a|^2$、したがって $|\re a|\le\frac12$ である。

\paragraph{高エネルギーの極限。}縦波の偏極ベクトル $\varepsilon_L=(|\boldsymbol k|,E\hat{\boldsymbol k})/M_A=k/M_A+O(M_A/E)$ を使うと、各図は $s/M_A^2$ で増え、和で打ち消す（\ref{app:tree}）。極限の $\lambda$ の部分は $G$ と $h$ の接触項 $-6\lambda$（$GGGG$、$hhhh$）、$-2\lambda$（$GGhh$、$GhGh$）で、$A_LA_L\to hh$ は等価定理の位相 $i^2=-1$ で $+2\lambda$ になる。$e^2$ の部分は、式~\eqref{eq:Mgghh} の $-e^2(s-u)/t-e^2(s-t)/u$（$t=-\frac s2(1-c)$、$u=-\frac s2(1+c)$）が $2e^2(3+c^2)/(1-c^2)$ になることと同じである。式~\eqref{eq:a0lam} は、$N_iN_f=\frac12$（$A_LA_L$、$hh$）、$1$（$A_Lh$）と、$c$ によらない振幅の部分波 $\mathcal M/(16\pi)$ から出る。前方の極は、有限の $s$ では $\frac1{1-c}\to\frac1{1-c+\delta}$（$\delta\sim M_A^2/s$）となり、$\int_{-1}^1\dd c/(1-c+\delta)\simeq\ln(s/M_A^2)$ である。$A_LA_L\to hh$ では両端で $\frac{2e^2(3+c^2)}{1-c^2}\simeq\frac{4e^2}{1\mp c}$ なので、部分波は $-\frac{1}{64\pi}\cdot8e^2\ln\frac s{M_A^2}=-\frac{e^2}{8\pi}\ln\frac s{M_A^2}$ だけずれる。$A_Lh$ も後方の $\frac{4e^2}{1+c}$ から同じ係数になる。

\paragraph{1ループ。}$\lambda_{abcd}=2\lambda(\delta_{ab}\delta_{cd}+\delta_{ac}\delta_{bd}+\delta_{ad}\delta_{bc})$ の2個の頂点を質量のない泡1個でつなぐと、$s$ チャンネルは $\frac12(-i\lambda)^2\int\frac{i^2}{k^2(k+p)^2}=\frac{i}{2K}\lambda\lambda B_0(s;0,0)$ で、$\MSbar$ の有限部分は $B(s)=2-\ln(s/\mu^2)+i\pi$ である（$s>0$）。$t$、$u$ チャンネルは $B(t)$、$B(u)$ で実である。$\lambda_{abef}\lambda_{efcd}$ などの和の $\mu$ 依存は、$\beta_{abcd}=\frac1K\sum(\lambda_{abef}\lambda_{efcd}+\lambda_{acef}\lambda_{efbd}+\lambda_{adef}\lambda_{efbc})$（Machacek--Vaughn~\cite{mv3}）と打ち消す。$\lambda_{abcd}$ の成分で $\beta_\lambda=20\lambda^2/K$ になる。$s$ チャンネルの虚部 $\frac{i\pi}{2K}\lambda\lambda$ の部分波は、中間状態の規格化 $\frac12$ を含めて $A^{(0)}A^{(0)}$ に等しい。$U(1)$ の対称性で $A^{(0)}$ と $A^{(1)}$ は同じ固有ベクトルを持ち、電荷0の $(hh+GG)/\sqrt2$ と電荷2の $(hh-GG)/\sqrt2$、$hG$ で式~\eqref{eq:a1} になる。

\section{検算の細部}\label{app:details}

\paragraph{手順 (1) の模型ファイル。}パラメータの名前は、$e$ が \texttt{ee}（ブロック \texttt{AHINPUTS}）、$\xi$ が \texttt{xiA}（ブロック \texttt{GAUGE}、値1）、質量が \texttt{MA}、\texttt{MH} で、\texttt{vev}$=$\texttt{MA/ee}、\texttt{lam}$=$\texttt{MH\^{}2/(2 vev\^{}2)}、\texttt{muH2}$=$\texttt{lam vev\^{}2} を内部パラメータとした。基準点の値を入れてある（$h$ の幅 \texttt{WH} は式~\eqref{eq:width} の値 $0.0155549$）。MadGraph の結合の次数は、標準模型のノートと同じく $e$ を \texttt{QED}$=1$、$\lambda$ を \texttt{QED}$=2$ と数える（$\lambda=e^2M_h^2/(2M_A^2)$）。$U(1)$ の電荷は \texttt{Q} でなく \texttt{QX} とし、UFO ではすべての粒子の電荷を0にした（$h$、$G$ は $\Phi$ の実の成分で、決まった電荷を持たない）。MadGraph の粒子名は、ゲージ場が \texttt{zp}（PDG 32）、$h$ が \texttt{h}（PDG 25）、$G$ が \texttt{G0}（PDG 250）である。ゲージ場を \texttt{a} と呼ばないのは、MadGraph が光子として扱う（質量0の粒子の切断を当てる）のを避けるためである。\texttt{FeynmanGauge = True} は UFO に \texttt{gauge = [0, 1]} を宣言させるだけで、ラグランジアンはいつも $G$ とゴーストを含む。MadGraph はユニタリーゲージでは \texttt{Goldstone -> A} の付いた $G$ とゴーストを自分で除く。ゲージ固定の項は頂点を持たないので模型ファイルに書かない。そのため FeynRules の質量スペクトルのチェックは $G$ の質量項を見ないが、ゴーストの質量項 $\xi M_A^2\bar cc$ は含まれ、$\xi=1$ で \texttt{MA} と一致した。

\paragraph{手順 (2) の細部。}偏極ベクトルは、運動量 $k=(E,|\boldsymbol k|\boldsymbol n)$、$\boldsymbol n=(\sin\vartheta\cos\varphi,\sin\vartheta\sin\varphi,\cos\vartheta)$ について $\varepsilon(\pm)=(0,\mp(\boldsymbol e_\vartheta\pm i\boldsymbol e_\varphi)/\sqrt2)$、$\varepsilon(0)=(|\boldsymbol k|,E\boldsymbol n)/M_A$ とし、出ていくゲージ場には複素共役を使った。FeynCalc の偏極の和は \texttt{DoPolarizationSums}（質量のあるベクトル場の $-g+kk/M_A^2$）で、厳密値は有理数の運動量（$\cos\theta$ を有理数にとる）で20桁求めた（\texttt{results/tree\_feyncalc\_points.csv}）。MadGraph の \texttt{SMATRIX} は始状態のヘリシティの平均と終状態の同種粒子の因子を含むので、$\sum|\mathcal M|^2$ を $18$（$AA\to AA$、$AA\to hh$）、$2$（$hh\to hh$）で割って比べた（行列要素のファイルの \texttt{IDEN}）。standalone の \texttt{param\_card.dat} の $h$ の幅は0にした（式は幅0）。断面積の計算では幅 $0.0155549$ のままにしたが、その影響は $s$ チャンネルで $(M_h\Gamma_h/(s-M_h^2))^2\le2\times10^{-6}$ で（$t$、$u$ チャンネルでは MadGraph が幅を0にする）、統計誤差より小さい。ビームは \texttt{lpp}$=0$ の固定のエネルギー（$\sqrt s/2$ ずつ）で、$zp$ と $h$ には既定の切断がかからない。

\paragraph{図の数え方。}$AA\to AAh$ の図は、$AA\to AA$ の3個の図（$s$、$t$、$u$ の $h$）に外線の $h$ を付ける場所で数えた。$h$ の線から $hhh$ で出す図が3個、4本の外線の $A$ から $AAh$ で出す図が $4\times3=12$ 個、二つの $AAh$ の頂点を $AAhh$ に置き換える図が $2\times3=6$ 個で、合わせて21個である。Feynman ゲージでは、外線の $A$ から出す12個のそれぞれで内線の $A$ を $G$ に置き換えられる（$A\to Gh$ の $AGh$ の頂点と、$G$ ともう一つの外線の $A$ と内線の $h$ を結ぶ $AGh$ の頂点）ので、12個増えて33個である。ほかに $G$ を含む図はない（$AAG$ の頂点がなく、$AAGG$ の頂点を使うと頂点が一つ多くなる）。
