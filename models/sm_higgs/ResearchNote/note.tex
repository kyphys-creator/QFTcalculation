\title{標準模型のヒッグスの崩壊：NLO の部分幅と分岐比\\（$\MSbar$、FJ のタドポール、一般の $R_\xi$ ゲージ、$d=4$）}
\author{}
\date{2026年10月19日}

\begin{document}
\maketitle

\begin{abstract}
SM ノート~\cite{smnote}、CKM ノート~\cite{ckmnote}、NLO ノート~\cite{nlonote} は、$\MSbar$ のパラメータと Fleischer--Jegerlehner（FJ）のタドポールの処方で、1ループの繰り込みと、$Z$、$W$、$t$ の崩壊の NLO の幅を求めた。本ノートでは、同じ模型ファイル、処方、道具で、ヒッグスの崩壊 $H\to f\bar f$、$WW^*$、$ZZ^*$、$\gamma\gamma$、$Z\gamma$、$gg$ の NLO の部分幅、全幅、分岐比を求める計画を立てる。手計算では、木の幅と1ループで誘起される崩壊の振幅、$H\to q\bar q$ の QCD の補正で $\MSbar$ の湯川結合が $\ln(m_q^2/M_H^2)$ を吸収すること、$H\to f\bar f$ にはタドポールが入らないが $H\to VV^*$ には $HHVV$ の頂点を通して入ること、$H\to gg$ の重いトップの有効理論での NLO を述べ、八つの手順の計画を定めた。手順 (1) では、模型、木の振幅（一般の $R_\xi$ ゲージで27個の記号の一致）、MadGraph との一致（相対 $10^{-14}$）を確かめた。$\mu=M_H$ の $\MSbar$ の湯川結合で書いた木の $\Gamma(H\to b\bar b)=1.85$~MeV は極質量で書いた値の3分の1で、$V$ の有限の幅は $H\to4f$ の幅を幅0の式より $WW$ で $6\%$、$ZZ$ で $21\%$ 上げる。手順 (2) では、$H\to\gamma\gamma$、$Z\gamma$、$gg$ の1ループの振幅が一般の $R_\xi$ ゲージで対抗項なしに有限でゲージによらず（$Z\gamma$ は光子の脚の $\gamma$--$Z$ の混合の図を含めて）、ループごとに文献の関数と、全体で MadLoop と一致することを確かめた。手順 (3) では、質量0の $H\to q\bar q$ の QCD の補正 $\frac{17}4C_F\alpha_s/\pi$ を $d$ 次元で厳密に求め、$\MSbar$ の湯川結合で $b\bar b$ の幅の $\mu$ の依存が $19\%$ から $5\%$ に減ることを示した。
\end{abstract}

\section{目的と問い}\label{sec:intro}

本ノートの問いは三つである。\textbf{第一に、$\MSbar$ の湯川結合で書いた $H\to f\bar f$ の NLO の幅は、質量のあるクォークの大きな対数を吸収し、光子と弱い補正を含めてゲージによらず有限になるか。第二に、木のない $H\to\gamma\gamma$、$Z\gamma$、$gg$ の1ループの振幅は、対抗項なしで紫外で有限で、一般の $R_\xi$ ゲージでゲージによらないか。$H\to gg$ の大きな NLO の QCD の補正はどれだけか。第三に、FJ の処方の $\MSbar$ の $v$ はタドポールのために物理的な $v$ より約 $6\%$ 大きいが、それで書いた $H\to WW^*$、$ZZ^*$ の木の幅は1ループでどう正されるか。全幅と分岐比はいくらになるか。}

第一の問いを立てる理由は、$H\to b\bar b$ が全幅の半分以上を占め、その幅が湯川結合の2乗に比例するからである。$b$ の極質量 $4.78$~GeV で書いた湯川結合と、$\mu=M_H$ の $\MSbar$ の湯川結合（$m_b$ にして約 $2.75$~GeV）では、木の幅が3倍違う。この差は、極質量で書いた QCD の補正に現れる $\ln(m_b^2/M_H^2)\approx-6.5$ の大きな対数である。$\MSbar$ の湯川結合は本ノートの模型のラグランジアンのパラメータそのもので、FJ の処方でもタドポールによらない。NLO ノートの手順 (2)、(3) の赤外の扱いを、スカラーの流れに広げて確かめる。

第二の問いは、ヒッグスの発見の過程である $H\to\gamma\gamma$ と生成の $gg\to H$ に関わる。これらは1ループで初めて起こるので、繰り込みの対抗項がなく、紫外の極が図の和で消えることと、$W$ のループ（Goldstone とゴーストを含む）がゲージによらないことが、模型の確かめになる。$H\to gg$ の NLO の QCD の補正は大きい。重いトップの極限の係数（文献~\cite{spira95}、参照）を本ノートの $\alpha_s(M_H)$ で使うと $+64\%$ になる。

第三の問いは、FJ の処方に特有のものである。FJ の処方では、$\MSbar$ の $v$ と質量 $M_W=gv/2$ がゲージによらないかわりに、タドポールの大きな寄与を含む（$\mu=M_t$ で $v_{\mathrm{FJ}}=261.9$~GeV、$G_F$ からの $v_G=246.2$~GeV）。$H\to f\bar f$ を湯川結合で書くとタドポールは入らないが、$HVV$ の結合 $g^2v/2$ には入る。$HHVV$ の頂点に付いたタドポールの図が、この差をどう打ち消すかを確かめる。

求める量は五つである。(i) 木の幅（$H\to f\bar f$、$H\to VV^*$）と1ループで誘起される崩壊の LO の幅。(ii) $H\to q\bar q$、$\ell^+\ell^-$ の QCD と QED の NLO の補正（質量0と質量あり）。(iii) $H\to f\bar f$ の電弱の補正。(iv) $H\to gg$ の NLO の QCD の補正。(v) 全幅と分岐比と、その $\mu$ と処方への依存。SM ノート、CKM ノート、NLO ノートの結果（自己エネルギー、$\MSbar$ のパラメータ、UFO、赤外の扱いの道具）は求め直さず、引用して使う。一致の基準はそれらのノートと同じである。

本ノートの構成は次の通りである。第~\ref{sec:setup} 節で模型、処方、入力を定める。第~\ref{sec:results} 節で手計算の結果を述べる。第~\ref{sec:plan} 節でツールと突き合わせる計画を定める。第~\ref{sec:checks} 節に各手順の結果を、第~\ref{sec:discussion} 節にまとめを書く。導出は\ref{app:lo} にある。

\section{設定}\label{sec:setup}

\paragraph{模型と処方。}模型は CKM ノートの模型ファイル \texttt{SM\_CKM.fr} を \texttt{Src/} に写したものである（中身は同じで、頭の注記と読み込む場所だけを替えた。NLO ノートと同じ）。パラメータは破れていないラグランジアンの $\MSbar$ のもの（$g'$、$g$、$g_s$、$\lambda$、$\mu^2$、湯川行列）で、タドポールは FJ の処方で扱う。ゲージは一般の $R_\xi$、次元正則化は $d=4-2\epsilon$ で、紫外と赤外の発散をともに次元正則化で扱う。$K=(4\pi)^2$ と書く。

\paragraph{入力。}パラメータは NLO ノートの入力（\texttt{models/sm\_nlo/Src/nlo\_inputs.py}。SM ノートの手順 (7) の $M_W$ の処方の値を $\mu=M_t$ から1ループの方程式で走らせたもの）を使う。$\mu=M_H$ では $g=0.64900$、$g'=0.35871$、$g_s=1.18853$（$\alpha_s=0.11241$）、$\lambda=0.13435$、$y_t=0.94871$、$y_b=0.015822$、$y_c=0.003416$、$y_\tau=0.009970$ である（$m=yv_G/\sqrt2$ にすると $m_b=2.755$、$m_c=0.595$、$m_\tau=1.736$~GeV）。崩壊するヒッグスと運動学の質量は極質量（PDG 2024~\cite{pdg24} の $M_H=125.20$~GeV など）とする。$\mu$ は既定で $M_H$ とし、$M_H/2$、$2M_H$ に変えた変化を NLO の不定性の目安にする。

\paragraph{崩壊幅の定義。}NLO ノートと同じく、$\Gamma=\frac1{2M_H}\int\dd\Phi\,\overline{|\mathcal M|^2}$、$\Gamma_{\mathrm{NLO}}=\Gamma_0+\Gamma_V+\Gamma_R$ とし、$\mathcal M_1$ は裸の頂点に on-shell の LSZ の因子を掛け、$\MSbar$ の対抗項を足したものである。ヒッグスは安定とみなす（$\Gamma_H/M_H\approx3\times10^{-5}$）。

\section{結果}\label{sec:results}

\subsection{木の崩壊幅}\label{sec:lo}

$Hf\bar f$ の頂点を $-i\frac{y_f}{\sqrt2}$、$HVV$ の頂点を $ig_{HVV}g^{\mu\nu}$（$g_{HWW}=\frac{g^2v}2$、$g_{HZZ}=\frac{g_Z^2v}2$、$g_Z=\sqrt{g^2+g'^2}$）と書くと、木の幅は（\ref{app:lo}）
\begin{equation}
\Gamma_0(H\to f\bar f)=N_c\frac{y_f^2M_H}{16\pi}\beta_f^3,\qquad \beta_f=\sqrt{1-\frac{4m_f^2}{M_H^2}},
\label{eq:lo}
\end{equation}
\begin{equation}
\begin{gathered}
\Gamma_0(H\to VV^*)=\frac{3g_{HVV}^2g_V^2M_H}{512\pi^3M_V^2}\,\delta'_V\,R_T\Bigl(\frac{M_V^2}{M_H^2}\Bigr),\\
R_T(x)=\frac{3(1-8x+20x^2)}{\sqrt{4x-1}}\arccos\frac{3x-1}{2x^{3/2}}-\frac{(1-x)(2-13x+47x^2)}{2x}-\frac32(1-6x+4x^2)\ln x
\end{gathered}
\label{eq:vv}
\end{equation}
である（$g_W=g$、$\delta'_W=1$、$\delta'_Z=\frac7{12}-\frac{10}9s^2+\frac{40}{27}s^4$。$V^*$ は $f\bar f'$ に崩壊する仮想の $V$ で、$WW^*$ は $W^+W^{-*}$ と $W^{+*}W^-$ の和）。式~\eqref{eq:vv} は Keung--Marciano の式~\cite{km84,djouadi08} を本ノートの結合で書いたもので、木の関係 $g_{HVV}=g_VM_V$ では $3G_F^2M_V^4M_H\delta'_VR_T/(16\pi^3)$ になる。手順 (1) で、質量0のフェルミオンの3体の Dalitz の積分と相対 $3\times10^{-14}$ で一致した。湯川結合は $\mu$ での $\MSbar$ の値、運動学の質量は極質量である。$\mu=M_H$ の $\MSbar$ の $y_b$ で書いた $\Gamma_0(H\to b\bar b)=1.854$~MeV は、極質量 $y=\sqrt2m_b/v_G$ で書いた値 $5.58$~MeV の $0.33$ 倍で、$c\bar c$ では $0.13$ 倍、$\tau^+\tau^-$ では $0.95$ 倍である。$G_F$ と極質量で書いた式~\eqref{eq:vv} は $\Gamma(H\to WW^*)=0.797$~MeV、$\Gamma(H\to ZZ^*)=0.087$~MeV になる（on-shell の $s^2=1-M_W^2/M_Z^2$）。ただし式~\eqref{eq:vv} は on-shell の $V$ を幅0で扱う。$V$ の伝播関数に Breit--Wigner の幅を付けた $H\to4f$ の幅（式~\eqref{eq:h4ffact}）は、式~\eqref{eq:vv} より $WW$ で $5.9\%$、$ZZ$ で $20.8\%$ 大きい。また $Z^*\to b\bar b$、$\tau^+\tau^-$ の質量は $\Gamma(H\to ZZ^*)$ を $3.1\%$ 下げる（手順 (1)）。木の図を図~\ref{fig:lo} に示す。

\subsection{1ループで誘起される崩壊}\label{sec:loop}

$H\to\gamma\gamma$ と $H\to gg$ の振幅は、フェルミオンと $W$ のループで初めて現れる。$\tau_i=M_H^2/(4m_i^2)$ として~\cite{ellis76,svvz79,djouadi08}
\begin{equation}
\begin{gathered}
\Gamma(H\to\gamma\gamma)=\frac{\alpha^2M_H^3}{256\pi^3v^2}\Bigl|\sum_fN_cQ_f^2A_{1/2}(\tau_f)+A_1(\tau_W)\Bigr|^2,\qquad
\Gamma(H\to gg)=\frac{\alpha_s^2M_H^3}{72\pi^3v^2}\Bigl|\frac34\sum_qA_{1/2}(\tau_q)\Bigr|^2,\\
A_{1/2}(\tau)=\frac{2[\tau+(\tau-1)f(\tau)]}{\tau^2},\qquad A_1(\tau)=-\frac{2\tau^2+3\tau+3(2\tau-1)f(\tau)}{\tau^2},\qquad f(\tau)=\arcsin^2\sqrt\tau\quad(\tau\le1)
\end{gathered}
\label{eq:loop}
\end{equation}
になる（$\tau>1$ では $f=-\frac14[\ln\frac{1+\sqrt{1-1/\tau}}{1-\sqrt{1-1/\tau}}-i\pi]^2$）。重い粒子の極限 $\tau\to0$ で $A_{1/2}\to\frac43$、$A_1\to-7$ で、ループの粒子の質量によらない（低エネルギーの定理）。$W$ とトップの寄与は逆の符号で、$A_1(\tau_W)=-8.33$、$3\cdot\frac49A_{1/2}(\tau_t)=1.84$（$A_{1/2}(\tau_t)=1.377$）である。$H\to Z\gamma$ は
\begin{equation}
\Gamma(H\to Z\gamma)=\frac{G_F^2M_W^2\alpha M_H^3}{64\pi^4}\Bigl(1-\frac{M_Z^2}{M_H^2}\Bigr)^3\Bigl|\sum_fN_c\frac{Q_f\hat v_f}{c_W}A^{Z\gamma}_{1/2}(\tau_f,\lambda_f)+A^{Z\gamma}_1(\tau_W,\lambda_W)\Bigr|^2,\qquad\hat v_f=2T_3-4Q_fs_W^2
\label{eq:zg}
\end{equation}
で、$A^{Z\gamma}$ は二変数の関数 $I_1$、$I_2$ で書ける（\ref{app:zg}。ここだけ $\tau=4m^2/M_H^2$、$\lambda=4m^2/M_Z^2$~\cite{djouadi08}）。木の頂点がないので1ループの振幅には対抗項がなく、紫外の極は図の和で消えなければならない（$H\to Z\gamma$ では、光子の脚の $\gamma$--$Z$ の混合の図も和に入る）。$W$ のループは Goldstone とゴーストを含め、$\xi$ によらないはずである。手順 (2) で、これらがすべて成り立ち、ループごとに式~\eqref{eq:loop}、\eqref{eq:zg} と一致することを確かめた。$\alpha(0)$、$G_F$、極質量で書いた LO の幅は $\Gamma(H\to\gamma\gamma)=9.39\times10^{-3}$~MeV、$\Gamma(H\to Z\gamma)=6.36\times10^{-3}$~MeV、$\alpha_s(M_H)$ で $\Gamma(H\to gg)=0.169$~MeV である（$gg$ は $b$、$c$ のループで、トップだけの $0.195$~MeV より $13.6\%$ 小さい）。$\alpha$ を $\MSbar$ の $\hat\alpha(M_H)$ にすると $\gamma\gamma$ は $15.5\%$ 大きく、$\alpha_s$ の $\mu$ を $M_H/2$、$2M_H$ にすると $gg$ は $+20\%$、$-15\%$ 動く。これらは LO の不定性で、手順 (6)、(8) で扱う。

\subsection{$H\to q\bar q$ の QCD の補正と $\MSbar$ の湯川結合}\label{sec:hqq}

質量0のクォークの極限で、$\MSbar$ の湯川結合 $\bar y_q(\mu)$ で書いた NLO の QCD の補正は
\begin{equation}
\Gamma(H\to q\bar q)=\Gamma_0(\bar y_q(\mu))\Bigl[1+C_F\frac{\alpha_s}\pi\Bigl(\frac{17}4+\frac32\ln\frac{\mu^2}{M_H^2}\Bigr)\Bigr]
\label{eq:hqq}
\end{equation}
である~\cite{bl80}（$C_F\frac{17}4=\frac{17}3$。光子では $C_F\alpha_s\to Q_f^2\alpha$）。手順 (3) で、実の放射、頂点の補正、$\MSbar$ の湯川結合の対抗項の和として、$d$ 次元で $\epsilon$ について厳密に確かめた（\ref{app:hqq}）。$\ln\mu^2$ の係数は $\bar y_q^2$ の走り $\dd\ln\bar y_q^2/\dd\ln\mu^2=-\frac32C_F\alpha_s/\pi$ と打ち消す。極質量 $m_q$ との関係 $\bar y_q(\mu)=y_q^{\mathrm{pole}}[1-C_F\frac{\alpha_s}\pi(1+\frac34\ln\frac{\mu^2}{m_q^2})]$ を入れると、$m_q\ll M_H$ で
\begin{equation}
\Gamma(H\to q\bar q)=\Gamma_0(y_q^{\mathrm{pole}})\Bigl[1+C_F\frac{\alpha_s}\pi\Bigl(\frac94+\frac32\ln\frac{m_q^2}{M_H^2}\Bigr)\Bigr]
\label{eq:hqqpole}
\end{equation}
になり、$b$ では括弧の中が $\frac94-9.8$ の大きな負の値になる。$\MSbar$ の湯川結合はこの対数を走りとして吸収するので、式~\eqref{eq:hqq} の補正は $\mu=M_H$ で $+20.3\%$ にとどまる。質量のある場合の補正は、NLO ノートの手順 (3) の方法（Package-X の仮想の補正、$d$ 次元の軟らかい放射、数値の硬い放射）を、ベクトルの流れからスカラーの流れに替えて求める。赤外の極の構造（質量0の二重極、質量のある放射体の軟い単極）はベクトルの場合と同じである。

\subsection{電弱の補正とタドポール}\label{sec:ew}

$H\to f\bar f$ の S 行列要素は、形状因子を $\mathcal M=-\frac i{\sqrt2}\bar u(p_1)(F_SP_L+F_S^*P_R)v(p_2)$（$P_L$、$P_R$ の係数は $CP$ の保存で共役）と書くと、
\begin{equation}
F_S=y_f\Bigl[1+F^{\mathrm{vtx}}+\tfrac12\delta Z_H+\tfrac12\bigl(\delta Z^L_f+\delta Z^R_f\bigr)\Bigr]+\delta y_f^{\MSbar},\qquad \delta Z_H=-\Sigma_H'(M_H^2)
\label{eq:hffren}
\end{equation}
である（$\delta Z^{L,R}_f$ は NLO ノートの on-shell の形、$\delta y_f^{\MSbar}$ は湯川行列の $\beta$ 関数の極）。光子の部分（光子の交換と光子による場の定数、実の光子の放射）は、ヒッグスが電荷を持たないので、$Z$ の崩壊と同じく単独でゲージによらない組をなし、式~\eqref{eq:hqq} の QED の形になる。標準模型には $HHf\bar f$ の頂点がないので、$H\to f\bar f$ の頂点の補正にタドポールの図はない。$\Sigma_H$ のタドポールの部分は $p^2$ によらないので $\delta Z_H$ にも入らず、タドポールは質量（運動学の極質量）を通してしか入らない。湯川結合で書いた $H\to f\bar f$ は、FJ の処方でもタドポールによらない。

一方、$H\to VV^*$ の $HVV$ の結合 $g_{HVV}=g_V^2v/2$ は $v$ を含み、FJ の処方の $\MSbar$ の $v_{\mathrm{FJ}}$ はタドポールのために $G_F$ からの $v_G$ より大きい（$\mu=M_t$ で $(v_{\mathrm{FJ}}/v_G)^2=1.131$）。$\MSbar$ の $g(M_H)$、$s^2(M_H)$、$v_{\mathrm{FJ}}$ と極質量で書いた木の幅は、$G_F$ で書いた木より $H\to WW^*$ で $9.2\%$、$H\to ZZ^*$ で $12.6\%$ 大きい（手順 (1)）。ラグランジアンの $\frac{g^2}4(v+H)^2W^+W^-$ には $HHWW$ の頂点があり、それに付いたタドポールの図が $HVV$ の頂点の1ループの補正に入る。この図は $p^2$ によらない定数で、$g_{HVV}$ の $v_{\mathrm{FJ}}$ を $M_W$ の極質量に合う $v$ に近づける向きに働き、木の差を打ち消すはずである（手順 (7) で確かめる）。完全な電弱の NLO（$H\to4f$ の1ループ）は本ノートの範囲の外に置き、$HVV$ の頂点の普遍的な部分（タドポール、$\delta Z_H$、$\delta Z_V$、$\MSbar$ の対抗項）で処方の違いを確かめる。

\subsection{$H\to gg$ の NLO の QCD の補正}\label{sec:hgg}

$m_t\to\infty$ の有効理論 $\mathcal L_{\mathrm{eff}}=\frac{\alpha_s}{12\pi}\frac Hv\bigl(1+\frac{11}4\frac{\alpha_s}\pi\bigr)G^a_{\mu\nu}G^{a\mu\nu}$ では、仮想の補正と実の放射 $H\to ggg$、$gq\bar q$ の和は
\begin{equation}
\Gamma(H\to gg)=\Gamma_0(H\to gg)\Bigl[1+\Bigl(\frac{95}4-\frac76N_F\Bigr)\frac{\alpha_s}\pi\Bigr]\qquad(\mu=M_H)
\label{eq:hgg}
\end{equation}
になる~\cite{spira95}（参照。$N_F=5$、本ノートの $\alpha_s(M_H)=0.1124$ で $+64\%$）。$\Gamma_0$ にはトップとボトムの質量による式~\eqref{eq:loop} の厳密な形を使い、補正の因子を有効理論から付ける。$gq\bar q$ の終状態は、$H\to q\bar q g$ と重なる部分の扱いを手順 (6) で決める。

\paragraph{一致の基準。}NLO ノートと同じである。発散部分は $1/\epsilon$ の係数が記号として一致すること（仮想と実の放射の極の打ち消し、1ループで誘起される振幅の紫外の極の打ち消しは記号として0になること）を、有限部分は倍精度の丸め誤差の範囲（相対 $10^{-12}$ 程度）で一致することを求める。数値の積分では精度を明示する。ゲージによらないはずの量は、記号として $\xi$ を含まないこと、または異なる $\xi$ で同じ値になることを求める。測定値とは、本ノートで計算しない高次の補正の大きさの範囲で比べる。

\paragraph{手順。}次の順に進める。(1) 写した模型ファイルから FeynArts の模型と UFO を書き出して NLO ノートのものと同一であることを確かめ、$H\to f\bar f$ の振幅の2乗を式~\eqref{eq:lo} と、$H\to Vf\bar f'$ の3体の幅を式~\eqref{eq:vv} と比べる。MadGraph の木の $H\to f\bar f$ と $H\to4f$ の幅と比べ、$\MSbar$ の湯川結合と極質量の湯川結合で木の幅を求める。(2) $H\to\gamma\gamma$、$Z\gamma$、$gg$ の1ループの振幅を一般の $R_\xi$ ゲージで求め、紫外の極が対抗項なしで消えること、$\xi$ によらないこと、式~\eqref{eq:loop} とその極限に一致することを確かめ、MadGraph のループで誘起される過程と比べる。(3) 質量0のクォークの $H\to q\bar q$ の QCD の補正を $d$ 次元で $\epsilon$ について厳密に求め、極の打ち消しと式~\eqref{eq:hqq} を確かめる（NLO ノートの手順 (2) のスカラーの流れ版）。(4) 質量のある $H\to b\bar b$、$c\bar c$、$\tau^+\tau^-$ の QCD と QED の補正を、NLO ノートの手順 (3) の方法で求め、式~\eqref{eq:hqqpole} の対数と、$\MSbar$ の湯川結合での補正を確かめ、MadLoop と比べる。(5) $H\to f\bar f$ の電弱の補正を一般の $R_\xi$ ゲージで求め、紫外の有限性、ゲージによらないこと、タドポールが入らないことを確かめ、MadLoop の電弱の仮想の補正と比べる。(6) $H\to gg$ の NLO の QCD の補正を重いトップの有効理論で求め、式~\eqref{eq:hgg} を確かめる。(7) $H\to WW^*$、$ZZ^*$ で、FJ の $v$ で書いた木と $G_F$ で書いた木の差が、$HHVV$ の頂点のタドポールを含む $HVV$ の頂点の普遍的な1ループの補正で打ち消すことを確かめ、$W$、$Z$ のハドロンへの崩壊に NLO ノートの QCD の因子を付ける。(8) 全幅と分岐比をまとめ、$\mu$ と処方の依存から不定性を見積もって、文献の値と測定値（参照）と比べる。

\section{検算}\label{sec:checks}

第~\ref{sec:plan} 節の手順を順に行う。スクリプトは \texttt{Src/} にあり、手順 (1) は \texttt{run\_lo\_check.sh}（約3分）で、手順 (2) はその後に \texttt{run\_loopind\_check.sh}（約10分。半分は MadGraph の模型の読み込み）で、手順 (3) は \texttt{run\_hqq\_check.sh}（約3分）で再現できる。

\subsection{手順 (1)：模型と木の幅}\label{sec:step1}

\paragraph{(a) 模型。}\texttt{generate\_SM\_CKM.wl} で、写した \texttt{SM\_CKM.fr} から FeynRules の頂点、FeynArts の模型、UFO を書き出した。93個の頂点のクラスは NLO ノートの FeynRules の出力と同一で（Mathematica の \texttt{===}）、FeynArts の模型の3個のファイルと UFO の8個のファイルも、日付と場所の行を除いて NLO ノートのもの（それ自体 CKM ノートのものと同一）と同一だった。

\paragraph{(b) 振幅の2乗。}\texttt{lo\_feyncalc.wl} は、本ノートの FeynArts の模型で木の振幅の2乗（スピン、偏極、色の和）を FeynCalc で記号として求め、\ref{app:lo} の手計算の式と比べる（表~\ref{tab:lochk}）。$H\to f\bar f$（$b$、$c$、$\tau$、$\mu$）では、湯川結合と運動学の質量を独立の記号にして $\sum|\mathcal M|^2=N_cy_f^2(M_H^2-4m_f^2)$ と一致した。$H\to Vf\bar f'$ では、$W^+e^-\bar\nu_e$、$W^+\tau^-\bar\nu_\tau$、$W^+b\bar c$、$Z\nu_e\bar\nu_e$、$Z\tau^-\tau^+$、$Zb\bar b$ の6個を、一般の $R_\xi$ ゲージ（$\xi_W$、$\xi_Z$ は記号）ですべての質量を残して求めた（湯川結合は木の関係 $y=\sqrt2m/v$。図~\ref{fig:hvff}）。6個とも $\xi_W$、$\xi_Z$ による微分は記号として0で、$V^*$ の伝播関数の $\xi$ の項、Goldstone の図、湯川結合でフェルミオンから $V$ が出る図の和でゲージの依存が消える。$W^+b\bar c$ は $|V_{cb}|^2$ に比例し、フェルミオンの質量を0にすると6個とも式~\eqref{eq:hvffhand} に一致した。$H\to4f$ では、$\nu_ee^+\mu^-\bar\nu_\mu$（$WW$）と $e^-e^+\mu^-\mu^+$（$ZZ$）を質量0で求め、$\xi$ によらないことと式~\eqref{eq:h4f} を確かめた。27個の差はすべて記号として0である。式~\eqref{eq:h4f} の $V-A$ の流れの運動量の対は、初めに書いた $(p_1\cdot p_4)(p_2\cdot p_3)$ では FeynCalc と合わず、$(p_1\cdot p_3)(p_2\cdot p_4)$（$\mu$ 粒子の崩壊と同じ対）が正しかった。

\paragraph{(c) MadGraph。}\texttt{lo\_mg5.py} は、NLO ノートと同じ $H$ の param\_card（$M_Z$ は極質量、$M_W=M_Z\hat c(M_H)$、$\alpha^{-1}=\hat\alpha^{-1}(M_H)$。UFO の湯川結合は運動学の質量から $\sqrt2m/v$ で決まる）で MadGraph と比べる。\texttt{compute\_widths} の $H\to b\bar b$、$c\bar c$、$\tau^+\tau^-$、$\mu^+\mu^-$ は、同じ値の式~\eqref{eq:lo} と相対 $2.9\times10^{-15}$ で一致した。standalone の出力（ユニタリーゲージ）の振幅の2乗は、$H\to W^+\tau^-\bar\nu_\tau$、$W^+b\bar c$、$Z\nu_e\bar\nu_e$、$Zb\bar b$ の Dalitz の7点ずつで FeynCalc の Feynman ゲージの式と $2.0\times10^{-14}$ で、$H\to\nu_ee^+\mu^-\bar\nu_\mu$、$e^-e^+\mu^-\mu^+$ の4体の6点ずつで固定の幅の Breit--Wigner の伝播関数を付けた式~\eqref{eq:h4f} と $1.1\times10^{-14}$ で一致した。3体の比較で param\_card に $V$ の幅を残すと、仮想の $V^*$ の伝播関数の $M_V^2\Gamma_V^2/(q^2-M_V^2)^2$ の分（約 $10^{-3}$）だけずれるので、3体では幅を0にした。madevent で積分した4レプトンの幅（カットなし）は、式~\eqref{eq:h4ffact} の数値積分と、$\nu_ee^+\mu^-\bar\nu_\mu$ で $-2.2\times10^{-4}$（統計の誤差 $1.6\times10^{-3}$ の $-0.14\sigma$）、$e^-e^+\mu^-\mu^+$ で $-2.4\times10^{-4}$（$-0.14\sigma$）の差で一致した。

\paragraph{(d) $H\to f\bar f$ の幅。}\texttt{lo\_widths.py} は式~\eqref{eq:lo} を $\mu=M_H$、$M_H/2$、$2M_H$ の $\MSbar$ の湯川結合と極質量で求める（表~\ref{tab:lohff}）。$\MSbar$ の $y_b(M_H)$ で書いた $\Gamma_0(H\to b\bar b)=1.854$~MeV は、極質量の湯川結合 $\sqrt2m_b/v_G$ で書いた $5.583$~MeV の $0.332$ 倍で、$c\bar c$ では $0.127$ 倍、$\tau^+\tau^-$ と $\mu^+\mu^-$ では $0.954$ 倍と $0.934$ 倍である。$\mu$ を $M_H/2$、$2M_H$ にした変化は $b\bar b$ で $+10.5\%$、$-8.8\%$、$c\bar c$ で $+9.3\%$、$-7.9\%$ と大きい。これは湯川結合の QCD の走りで、手順 (3)、(4) の QCD の補正の $\ln\mu^2$ の項が打ち消すはずである。レプトンでは $-1.2\%$、$+1.0\%$ である。

\paragraph{(e) $H\to VV^*$ と $H\to4f$ の幅。}質量0のフェルミオンの3体の Dalitz の積分（式~\eqref{eq:hvffhand}。$W^*$ は3個のレプトンと2個のクォークの二重項、$Z^*$ はトップ以外の11個のフェルミオン、$WW^*$ は電荷の二つの割り当ての和）は、$G_F$ と $\MSbar$ の二組の結合で、式~\eqref{eq:vv} と相対 $3\times10^{-14}$ で一致した（表~\ref{tab:lohvv}）。$G_F$ の結合と極質量では $\Gamma(H\to WW^*)=0.79711$~MeV、$\Gamma(H\to ZZ^*)=0.086892$~MeV である。$\MSbar$ の $g(M_H)$、$s^2(M_H)$、$v_{\mathrm{FJ}}$ で書くと $0.87049$、$0.097831$~MeV で、$G_F$ の値の $1.092$、$1.126$ 倍になる。$(v_{\mathrm{FJ}}/v_G)^2=1.131$ のタドポールの分が、結合と極質量の比を通して残っている。この差は手順 (7) で扱う。

フェルミオンの質量を残した FeynCalc の式を積分すると（$G_F$ の結合）、$H\to W^+\tau^-\bar\nu_\tau$ は $-0.65\%$、$W^+b\bar c$ は $-5.2\%$、$Z\tau^-\tau^+$ は $-4.0\%$、$Zb\bar b$ は $-19.6\%$ 変わる。$Z^*\to b\bar b$ では、大きい軸性の結合の部分が $\beta^3$ で抑えられ、しかも $Z^*$ の不変質量が小さい（$\sqrt{q^2}\le M_H-M_Z=34$~GeV）ので、効きが大きい。$b$ と $\tau$ の質量で $\Gamma(H\to ZZ^*)$ は $3.1\%$ 下がる。

式~\eqref{eq:vv} は on-shell の $V$ を幅0で扱う。$V$ の伝播関数に固定の幅の Breit--Wigner を付けた $H\to4f$ の幅（式~\eqref{eq:h4ffact}。質量0のフェルミオンで、$\Gamma_V$ は同じ結合の LO の幅 $\Gamma_W=2.0443$~GeV、$\Gamma_Z=2.4433$~GeV）は、すべての対の和で $WW$ が $0.84379$~MeV、$ZZ$ が $0.10496$~MeV（同種の $Z$ の $\frac12$ を付け、同種のフェルミオンの干渉と $WW$ と $ZZ$ の干渉は入れない）で、式~\eqref{eq:vv} より $5.9\%$、$20.8\%$ 大きい。幅を分岐比を変えずに0.1倍にすると差は $0.64\%$、$2.19\%$ になり、幅に比例して式~\eqref{eq:vv} に近づく。$M_H=125$~GeV では、一方の $V$ が $M_V$ より軽くなると、他方の $V^*$ の位相空間と伝播関数が急に大きくなるので、幅の効果が $\Gamma_V/M_V$（$2.5\%$、$2.7\%$）の数倍に増える。手順 (7)、(8) では、$H\to VV^*$ の幅に式~\eqref{eq:vv} ではなく4フェルミオンの形を使う。

\subsection{手順 (2)：1ループで誘起される崩壊}\label{sec:step2}

\paragraph{(a) 振幅と紫外の極。}\texttt{loopind\_feyncalc.wl} は、本ノートの FeynArts の模型（\texttt{GaugeXi} を残したもの）で、$H\to\gamma\gamma$（44個）、$Z\gamma$（74個）、$gg$（18個）の1ループの図をすべて作り（\texttt{CreateTopologies[1, 1 -> 2]}）、一般の $R_\xi$ ゲージで FeynCalc の \texttt{TID} で $A_0$、$B_0$、$C_0$ に還元する（図~\ref{fig:loopw}）。on-shell で $\varepsilon_i\cdot k_i=0$ として、振幅を $\mathcal M=F_g(\varepsilon_1^*\cdot\varepsilon_2^*)+F_{21}(k_2\cdot\varepsilon_1^*)(k_1\cdot\varepsilon_2^*)$ と書くと、ほかの構造（$\epsilon$ テンソルを含む項）は残らなかった。$F_g$、$F_{21}$ の $1/\epsilon$ の係数（FeynCalc の \texttt{PaVeUVPart}）は、3過程とも、質量と $\xi_W$、$\xi_Z$ を記号のままにして0だった。$H\to Z\gamma$ では、1PI の図の極 $\propto(2+\xi_W)c_W^2$ と、光子の脚の $\gamma$--$Z$ の混合の図（$H\to ZZ^*$、$Z^*\to\gamma$。$Z$ の伝播関数は $k_2^2=0$ で $-1/M_Z^2$）の極 $\propto-(2+\xi_W)M_W^2/M_Z^2$ が、$c_W=M_W/M_Z$ で打ち消す。一般の $R_\xi$ ゲージでは外に出る光子の状態に $Z$ の成分が混ざるので、S 行列要素にはこの図が要る。$\gamma\gamma$ と $gg$ では、$\xi$ の依存は還元の段階で記号として消えた（$F_g$、$F_{21}$ に $\xi$ が残らない）。$Z\gamma$ では $\xi_W$ が $B_0$、$C_0$ の質量 $\sqrt{\xi_W}M_W$ に残るので、数値で確かめる。

\paragraph{(b) 数値。}\texttt{loopind.wl} は、Package-X（30桁）で $F_g$、$F_{21}$ を $H$ の param\_card の値（有理数）で求める（表~\ref{tab:lichk}）。$M_H=125.2$~GeV と $300$~GeV（$W$ のループが閾値より上で複素）、$\gamma\gamma$ と $gg$ では $M_H=1$~GeV（重いループの極限）で、$(\xi_W,\xi_Z)=(1,1)$、$(2,3)$、$(1/2,4)$ と $\mu=M_H$、$1000$~GeV の6通りの値の差は $10^{-29}$ より小さく、光子とグルーオンの Ward の恒等式 $F_g+(k_1\cdot k_2)F_{21}=0$ も $10^{-29}$ で成り立った。フェルミオンごと（湯川結合に付けた印で分ける）と $W$ のループ（Goldstone、ゴーストを含む）ごとに $F_g$ を規格化すると、式~\eqref{eq:loop} の $N_cQ_f^2A_{1/2}(\tau_f)$、$A_1(\tau_W)$ と、式~\eqref{eq:zg} の項と、共通の位相（$\gamma\gamma$、$gg$ で $-1$、$Z\gamma$ で $+1$。FeynArts の振幅の $i$ の取り方）を除いて、使った精度（約18桁）の範囲で一致した（$t$、$b$、$c$、$\tau$、$\mu$、$e$）。$M_H=1$~GeV では $W$ のループが $A_1=-7.00006$、トップが $A_{1/2}=1.333336$ で、極限 $-7$、$\frac43$ に近づく。

\paragraph{(c) MadLoop。}\texttt{loopind\_madloop.py} は、CKM ノートの NLO の UFO で、MadLoop のループで誘起される過程（\texttt{h > a a [sqrvirt=QED]}、\texttt{h > z a [sqrvirt=QED]}、\texttt{h > g g [sqrvirt=QCD]}、Feynman ゲージ、COLLIER）の $\sum|\mathcal M|^2$ を求め、$2|F_g|^2$（$\gamma\gamma$、$Z\gamma$）、$16|F_g|^2$（$gg$）と比べる。MadGraph の行列要素は終状態の同種のボソンの $\frac12$ を含むので、$\gamma\gamma$、$gg$ では2倍して比べる。$H$ の param\_card では、$\gamma\gamma$ と $gg$ は相対 $2.8\times10^{-13}$、$8.6\times10^{-13}$ で一致し、$\mu_R=M_H$、$1000$~GeV によらなかった。$Z\gamma$ は $-1.3\%$（$\mu_R=M_H$）、$-10.3\%$（$1000$~GeV）ずれ、$\mu_R$ に依存した。MadLoop の $Z\gamma$ には UFO の UV の頂点 $HZ\gamma$（$\frac i2g_{HZZ}\delta Z_{ZA}$、2個の図）が入るが、この UFO の場の定数 $\delta Z_{ZA}$ は CKM ノートの MadLoop の点（$1/\alpha=128$、$M_Z=91$、$M_W=80$、$M_H=125$~GeV など）での数値で、その点の param\_card でしか使えない。その点では3過程とも相対 $1.1\times10^{-13}$ 以内で一致し、$Z\gamma$ も $\mu_R$ によらなかった。$\gamma\gamma$、$gg$ には対抗項が入らないので、どちらの点でも一致する。UFO は正しいが、その点のほかでは対抗項の入る過程に使えない。

\paragraph{(d) 幅と入力。}\texttt{loopind\_widths.py} は、(b) で確かめた式~\eqref{eq:loop}、\eqref{eq:zg} で LO の幅を求める（表~\ref{tab:liwidths}）。$\alpha(0)$、$G_F$、極質量では、$\gamma\gamma$ の振幅の和は $-6.5763+0.0870i$（$W$ が $-8.3315$、トップが $+1.8355$、$b$、$c$、$\tau$ がそれぞれ約 $-0.03+0.03i$）で、$\Gamma(H\to\gamma\gamma)=9.3941\times10^{-3}$~MeV、$\Gamma(H\to Z\gamma)=6.3586\times10^{-3}$~MeV である。$W$ とトップの寄与が逆の符号で打ち消し合うので、電荷を持つ重い粒子がほかにあれば、その寄与は $H\to\gamma\gamma$ に敏感に現れる（重い極限で $A_{1/2}\to\frac43$、$A_1\to-7$ と質量によらないので、重くても消えない）。$gg$ の和 $\frac34\sum A_{1/2}=0.9539+0.1036i$ のうち、$b$ と $c$ の分が幅をトップだけのとき（$0.19533$~MeV）より $13.6\%$ 下げ（$M_H>2m_b,\,2m_c$ なのでループが複素になり、実部もトップと逆の符号）、$\Gamma(H\to gg)=0.16868$~MeV になる。LO で選び方の決まらない入力のうち、$\alpha(0)$ を $\MSbar$ の $\hat\alpha(M_H)=1/127.49$ にすると $\gamma\gamma$ が $+15.5\%$、$Z\gamma$ が $+7.5\%$、$\sqrt2m_f/v_G$ を $\MSbar$ の湯川結合 $y_f(M_H)$ にすると（トップで $0.957$ 倍）$+1.5\%$、$+0.3\%$、$-2.3\%$、$\alpha_s$ の $\mu$ を $M_H/2$、$2M_H$ にすると $gg$ が $+19.9\%$、$-15.3\%$ 変わる。$\alpha$ の差は、NLO で光子の場の定数が入れる軽いフェルミオンの $\ln m_f^2$ の分で、on-shell の光子には $\alpha(0)$ が自然である。$gg$ の $\mu$ の依存は手順 (6) の NLO の QCD の補正が減らすはずである。

\subsection{手順 (3)：質量0の $H\to q\bar q$ の QCD の補正}\label{sec:step3}

\paragraph{(a) $d$ 次元で厳密に。}\texttt{hqq\_massless\_feyncalc.wl} は、NLO ノートの手順 (2) の計算を、$Z$ のベクトルの流れからヒッグスのスカラーの流れ（湯川の頂点、単位行列）に替えて行う。放射するボソンは $eQ\gamma^\rho$ で結合し、グルーオンでは $\alpha C=\alpha_sC_F$、光子では $\alpha Q_f^2$ である。木の $\sum|\mathcal M_0|^2$（結合と色を除く）は $2M_H^2$ で、実の放射 $H\to q\bar qg$ の2個の図の2乗の和は $d$ 次元で
\begin{equation}
r=\frac{M_H^2\sum|\mathcal M_R|^2}{e^2Q^2\sum|\mathcal M_0|^2}=\frac{2[(1-\epsilon)(1+y_{12}^2)+2\epsilon y_{12}]}{y_{13}y_{23}},\qquad y_{ij}=\frac{s_{ij}}{M_H^2}
\label{eq:hqqr}
\end{equation}
になった（$d=4$ では $2(M_H^4+s_{12}^2)/(s_{13}s_{23})$）。4次元の値は本ノートの FeynArts の模型の $H\to u\bar ug$、$\mu^-\mu^+\gamma$（質量0、湯川結合は独立の記号）の2乗と記号として一致した。$d$ 次元の3体の位相空間を Dirichlet の積分で、頂点の補正を \texttt{TID} の $B_0(M_H^2,0,0)$、$C_0(0,0,M_H^2,0,0,0)$ で、$\epsilon$ について厳密に求めると、$N(\epsilon)=\frac{\alpha C}{4\pi}(\frac{4\pi\mu^2}{M_H^2})^\epsilon/\Gamma(1-\epsilon)$ を単位にして、実の放射は $\frac4{\epsilon^2}+\frac6\epsilon+21-2\pi^2$、頂点は $-\frac4{\epsilon^2}-4+2\pi^2$、$\MSbar$ の湯川結合の対抗項 $2\delta y/y$ は $-\frac6\epsilon+6\ln\frac{\mu^2}{M_H^2}$ になる（$O(\epsilon^0)$ まで。厳密な形は \ref{app:hqq}）。仮想の補正と実の放射は単独では赤外で発散するが、とても軟らかいグルーオンやクォークと同じ向きに出るグルーオンを出した崩壊は、出さない崩壊と区別できないので、意味を持つのは二つの和である。和は極を持たず、$17+6\ln\frac{\mu^2}{M_H^2}$（$\epsilon^0$ の項。$O(\epsilon)$ も求めた）で、式~\eqref{eq:hqq} の $C_F\frac{\alpha_s}\pi(\frac{17}4+\frac32\ln\frac{\mu^2}{M_H^2})$ に一致した。頂点の単極は0だが、これは紫外の $+\frac6\epsilon$ と赤外の $-\frac6\epsilon$ の和で（質量0の自己エネルギーは0なので区別できない。(b) で分かれる）、赤外の分が実の放射の $+\frac6\epsilon$ を、紫外の分が対抗項の $-\frac6\epsilon$ を打ち消す。$Z$ のベクトルの流れは保存するので紫外で有限だったが、スカラーの流れは繰り込みが要る点が違う。

\paragraph{(b) グルーオンの質量。}\texttt{hqq\_gluonmass.wl} は、独立の確かめとして、放射するボソンに質量 $\lambda$ を与え、赤外の発散（軟らかい領域と平行な領域）を4次元で $\lambda$ で切る（NLO ノートの手順 (2) の光子の質量の確かめと同じ）。紫外は次元正則化のままで、頂点と場の定数 $2\delta Z=2\Sigma_V(0)$ の紫外の極は $\frac{\alpha C}{2\pi}$ を単位に $+3$ になり、$\MSbar$ の対抗項 $-3/\epsilon$ がちょうど打ち消す。実の放射は Dalitz の領域で数値で積分した（30桁）。$w=\lambda^2/M_H^2=10^{-4}$、$10^{-6}$、$10^{-8}$、$10^{-10}$ で、仮想と実の和と $\frac{\alpha C}{2\pi}(\frac{17}2+3\ln\frac{\mu^2}{M_H^2})$ の差は $-6.0\times10^{-4}$、$-6\times10^{-6}$、$-6\times10^{-8}$、$-6\times10^{-10}$ で（$\mu^2/M_H^2=1$、$4$ とも）、$w$ に比例して0に近づく。二つは $\ln^2w$ で大きく打ち消し合い（$w=10^{-10}$ で $-455$ と $+464$）、和だけが正則化によらない。

\paragraph{(c) 幅と $\mu$ の依存。}\texttt{hqq\_widths.py} は、式~\eqref{eq:hqq} を NLO ノートの入力の $\mu=M_H/2$、$M_H$、$2M_H$ の $\MSbar$ の湯川結合と $\alpha_s$、$\hat\alpha$ で求める（表~\ref{tab:hqq}。質量0の極限、$\beta=1$）。$\mu=M_H$ の QCD の補正は $+20.28\%$ で、$b\bar b$ の幅の $\mu$ による幅（3点の最大と最小の差）は LO の $19.4\%$ から NLO の $5.5\%$ に、$c\bar c$ では $17.2\%$ から $3.3\%$ に減った。湯川結合の QCD の走りを、補正の $\ln\mu^2$ の項が打ち消すからである。残る数 \% は、本ノートで求めない高次の補正（と、手順 (5) で扱う電弱の走り）の大きさの目安である。極質量の湯川結合で書いた式~\eqref{eq:hqqpole} では、括弧が $b$ で $0.640$、$c$ で $0.490$ になり、$\Gamma(H\to b\bar b)$ は $3.60$~MeV と $\MSbar$ の $2.25$~MeV より $60\%$ 大きい。極質量の展開は大きな対数 $\ln(m_q^2/M_H^2)$ のために収束が悪い。$\mu=M_H$ の $\MSbar$ の湯川結合は、$m_q$ から $M_H$ までの走りを初めから含んでいるので、その対数を吸収し、補正が素直な大きさにとどまる。本ノートで $\MSbar$ の湯川結合を使う理由が、数値で確かめられたことになる。レプトンの QED の補正は $+1.06\%$ である。ただし $\tau$ の幅の $\mu$ の依存は QED を入れて $2.2\%$ から $3.3\%$ に増える。入力の湯川結合の走りは、トップの湯川結合と弱い相互作用の部分が QED の部分より大きく（$y_\tau$ は $\mu$ とともに増える）、QED の補正はその QED の部分しか打ち消さないからである。残りは手順 (5) の電弱の補正が打ち消すはずである。MadGraph の UFO は湯川結合を運動学の質量で決めるので、質量0で湯川結合のある比較はできない。ツールとの比較は質量を入れる手順 (4) で行う。

\section{議論と今後}\label{sec:discussion}

\paragraph{現在の状態。}手順 (1) を終えた。模型は NLO ノートのものと同一で、木の振幅は一般の $R_\xi$ ゲージで手計算と記号として一致し、MadGraph とは倍精度の丸めの範囲で一致した。分かったことは三つある。(i) $\MSbar$ の湯川結合は $H\to b\bar b$、$c\bar c$ の木の幅を極質量の値の $0.33$、$0.13$ 倍にし、木の $\mu$ の依存は $\pm10\%$ と大きい。(ii) FJ の $v$ で書いた木の $H\to WW^*$、$ZZ^*$ は $G_F$ で書いた木より $9\%$、$13\%$ 大きい。(iii) 幅0の式~\eqref{eq:vv} は、$V$ の幅を入れた4フェルミオンの幅より $WW$ で $6\%$、$ZZ$ で $21\%$ 小さい。手順 (2) も終えた。$H\to\gamma\gamma$、$Z\gamma$、$gg$ の1ループの振幅は、対抗項なしに紫外で有限で、一般の $R_\xi$ ゲージでゲージによらない（$Z\gamma$ は光子の脚の $\gamma$--$Z$ の混合の図を含めて）。ループごとに式~\eqref{eq:loop}、\eqref{eq:zg} と一致し、MadLoop とも一致した。LO の幅の入力の選び方では、$\alpha(0)$ と $\hat\alpha(M_H)$ の差（$\gamma\gamma$ で $15.5\%$）と $gg$ の $\alpha_s$ の $\mu$ の依存（$\pm17\%$）が大きい。手順 (3) も終えた。質量0の $H\to q\bar q$ の QCD の補正は、$d$ 次元で厳密に $C_F\frac{\alpha_s}\pi(\frac{17}4+\frac32\ln\frac{\mu^2}{M_H^2})$ で、グルーオンの質量の4次元の計算とも一致した。スカラーの流れは紫外で発散し、$\MSbar$ の湯川結合の対抗項が要る。$\MSbar$ の湯川結合では $b\bar b$ の幅の $\mu$ の依存が LO の $19\%$ から NLO の $5\%$ に減り、極質量で書くと大きな対数のために NLO でも $60\%$ 違う。手順 (4)〜(8) はこれから行う。

\section{木の崩壊幅の導出}\label{app:lo}

$H\to f\bar f$ の振幅 $-i\frac{y_f}{\sqrt2}\bar uv$ の2乗をスピンと色で和をとると、$\sum|\mathcal M|^2=N_c\frac{y_f^2}2\cdot2(M_H^2-4m_f^2)=N_cy_f^2M_H^2\beta_f^2$ になる。2体の位相空間 $\int\dd\Phi_2=\beta_f/(8\pi)$ と $1/(2M_H)$ を掛けると、式~\eqref{eq:lo} になる。$H\to VV^*$ では、$V^*\to f\bar f'$ の不変質量 $q^2$ について $\Gamma=\int\frac{\dd q^2}\pi\frac{\sqrt{q^2}\,\Gamma_{V\to f\bar f'}(q^2)}{(q^2-M_V^2)^2}\Gamma(H\to VV(q^2))$（$\Gamma_{V\to f\bar f'}(q^2)$、$\Gamma(H\to VV(q^2))$ は一方の $V$ の質量を $\sqrt{q^2}$ にした幅）と書き、$\Gamma_V\ll M_V$ の幅を落として $q^2$ と角度を積分すると、関数 $R_T$ になる~\cite{km84}。

$H\to V(p_1)f(p_2)\bar f'(p_3)$ の振幅は、質量0のフェルミオンでは $V^*$ の伝播関数の $q^\mu q^\nu$ の項と Goldstone の図と湯川結合の図が消えるので、$\mathcal M=g_{HVV}\varepsilon^*_\mu(p_1)\frac{-1}{s_{23}-M_V^2}\bar u(p_2)\gamma^\mu(c_LP_L+c_RP_R)v(p_3)$ である（$s_{ij}=(p_i+p_j)^2$。$W$ では $c_L=gV_{ij}/\sqrt2$、$c_R=0$、$Z$ では $c_L=g_Z(T_3-Qs^2)$、$c_R=-g_ZQs^2$）。偏極の和 $-g^{\mu\nu}+p_1^\mu p_1^\nu/M_V^2$ をフェルミオンの跡 $2(c_L^2+c_R^2)(p_2^\mu p_3^\nu+p_2^\nu p_3^\mu-g^{\mu\nu}p_2\cdot p_3)$ と縮約すると
\begin{equation}
\sum|\mathcal M|^2=N_cg_{HVV}^2(c_L^2+c_R^2)\frac{s_{23}+4(p_1\cdot p_2)(p_1\cdot p_3)/M_V^2}{(s_{23}-M_V^2)^2}
\label{eq:hvffhand}
\end{equation}
になる。これを Dalitz の領域で $\Gamma=\frac1{256\pi^3M_H^3}\int\dd s_{12}\,\dd s_{23}\sum|\mathcal M|^2$ と積分し、フェルミオンと電荷の割り当てで和をとると、式~\eqref{eq:vv} になる。

4体の $H\to f_1(p_1)\bar f_2(p_2)f_3(p_3)\bar f_4(p_4)$（$V_1\to f_1\bar f_2$、$V_2\to f_3\bar f_4$、質量0）では
\begin{equation}
\begin{gathered}
\sum|\mathcal M|^2=16N_{c1}N_{c3}g_{HVV}^2\frac{(c_{L1}^2c_{L3}^2+c_{R1}^2c_{R3}^2)(p_1\cdot p_3)(p_2\cdot p_4)+(c_{L1}^2c_{R3}^2+c_{R1}^2c_{L3}^2)(p_1\cdot p_4)(p_2\cdot p_3)}{|D(s_{12})D(s_{34})|^2},\\
D(s)=s-M_V^2+iM_V\Gamma_V
\end{gathered}
\label{eq:h4f}
\end{equation}
である。フェルミオンの角度を積分すると、伝播関数の $q^\mu q^\nu$ の項は流れの上で消え、$V$ の崩壊の部分は $\sqrt{q^2}$ の質量の $V$ の幅になるので、
\begin{equation}
\begin{gathered}
\Gamma=\int\frac{\dd q_1^2}\pi\int\frac{\dd q_2^2}\pi\frac{\sqrt{q_1^2}\,\Gamma_1(q_1^2)}{|D(q_1^2)|^2}\frac{\sqrt{q_2^2}\,\Gamma_2(q_2^2)}{|D(q_2^2)|^2}\Gamma(H\to V(q_1)V(q_2)),\\
\Gamma_i(q^2)=N_{ci}(c_{Li}^2+c_{Ri}^2)\frac{\sqrt{q^2}}{24\pi},\qquad
\Gamma(H\to V(q_1)V(q_2))=g_{HVV}^2\Bigl[2+\frac{(k_1\cdot k_2)^2}{q_1^2q_2^2}\Bigr]\frac{\lambda^{1/2}(M_H^2,q_1^2,q_2^2)}{16\pi M_H^3}
\end{gathered}
\label{eq:h4ffact}
\end{equation}
になる（$k_1\cdot k_2=(M_H^2-q_1^2-q_2^2)/2$。数値の積分では $q^2=M_V^2+M_V\Gamma_V\tan\theta$ と置く）。幅を0にすると、一方の $V$ の Breit--Wigner は $\pi\delta(q^2-M_V^2)/(M_V\Gamma_V)$ になり、分岐比を掛けた式~\eqref{eq:vv} に戻る。

\section{質量0の $H\to q\bar q$ の NLO}\label{app:hqq}

手順 (3) の $d$ 次元の厳密な形は、$N(\epsilon)=\frac{\alpha C}{4\pi}(\frac{4\pi\mu^2}{M_H^2})^\epsilon/\Gamma(1-\epsilon)$ を単位にして
\begin{equation}
\begin{gathered}
\frac{\Gamma_R}{\Gamma_0N}=4\Gamma(2-\epsilon)\Bigl[\frac{\Gamma(-\epsilon)^2}{\Gamma(2-3\epsilon)}+\frac{\Gamma(1-\epsilon)^2+\Gamma(2-\epsilon)\Gamma(-\epsilon)}{\Gamma(3-3\epsilon)}\Bigr],\\
\frac{\Gamma_V}{\Gamma_0N}=-\frac{4\pi\cot(\pi\epsilon)\,\Gamma(2-\epsilon)^2}{\epsilon\,\Gamma(2-2\epsilon)},\qquad
\frac{2\delta y/y}{N}=-\frac{6e^{-\gamma_E\epsilon}\Gamma(1-\epsilon)}{\epsilon}\Bigl(\frac{\mu^2}{M_H^2}\Bigr)^{-\epsilon}
\end{gathered}
\label{eq:hqqexact}
\end{equation}
である（実の放射は式~\eqref{eq:hqqr} の $y_{12}^{-\epsilon}y_{13}^{-1-\epsilon}y_{23}^{-1-\epsilon}$ などの Dirichlet の積分、頂点は $\mathrm{Re}$ をとったもの、対抗項は $\delta y/y=-3\frac{\alpha C}{4\pi}\frac{(4\pi)^\epsilon e^{-\gamma_E\epsilon}}\epsilon$）。和を展開すると $17+6\ln\frac{\mu^2}{M_H^2}+O(\epsilon)$ になる。

\section{$H\to Z\gamma$ の関数}\label{app:zg}

式~\eqref{eq:zg} の関数は、$\tau=4m^2/M_H^2$、$\lambda=4m^2/M_Z^2$ として~\cite{djouadi08}
\begin{equation}
\begin{gathered}
A^{Z\gamma}_{1/2}(\tau,\lambda)=I_1(\tau,\lambda)-I_2(\tau,\lambda),\qquad
A^{Z\gamma}_1(\tau,\lambda)=c_W\Bigl\{4\Bigl(3-\frac{s_W^2}{c_W^2}\Bigr)I_2(\tau,\lambda)+\Bigl[\Bigl(1+\frac2\tau\Bigr)\frac{s_W^2}{c_W^2}-\Bigl(5+\frac2\tau\Bigr)\Bigr]I_1(\tau,\lambda)\Bigr\},\\
I_1(\tau,\lambda)=\frac{\tau\lambda}{2(\tau-\lambda)}+\frac{\tau^2\lambda^2}{2(\tau-\lambda)^2}\bigl[f(\tau^{-1})-f(\lambda^{-1})\bigr]+\frac{\tau^2\lambda}{(\tau-\lambda)^2}\bigl[g(\tau^{-1})-g(\lambda^{-1})\bigr],\\
I_2(\tau,\lambda)=-\frac{\tau\lambda}{2(\tau-\lambda)}\bigl[f(\tau^{-1})-f(\lambda^{-1})\bigr]
\end{gathered}
\label{eq:zgfun}
\end{equation}
で、$f$ は式~\eqref{eq:loop} のもの、$g(t)=\sqrt{1/t-1}\arcsin\sqrt t$（$t\le1$）、$g(t)=\frac12\sqrt{1-1/t}\,[\ln\frac{1+\sqrt{1-1/t}}{1-\sqrt{1-1/t}}-i\pi]$（$t>1$）である。手順 (2) で、本ノートの模型の1ループの振幅とループごとに一致することを確かめた。
