\begin{abstract}
新しく組んだループ計算環境（FeynCalc、Package-X、LoopTools、FeynRules、MadGraph）を練習し検算するための玩具模型として、質量 $m$ を持つ実スカラー1つの $\phi^3$ 理論を定義し、時空次元 $d=4$ と $d=6$ の両方で扱う。ラグランジアンから Feynman 則と対称性因子を導き、べき数え上げと Feynman パラメータ表示によって、1ループのタドポール・自己エネルギー・頂点補正の紫外発散を両方の次元で求めた。繰り込みは $\overline{\mathrm{MS}}$ で行い、対抗項を $\Delta_{\mathrm{UV}}\equiv1/\epsilon-\gamma_E+\ln4\pi$ に比例させる。$d=4$ では発散するのはタドポールと、自己エネルギーのうち外運動量によらない部分だけで、対抗項は質量項 $\delta_m=g^2\Delta_{\mathrm{UV}}/(2(4\pi)^2)$ だけが残る（$\delta_Z=\delta_g=0$）。繰り込まれた自己エネルギーと頂点補正は、$\overline{\mathrm{MS}}$ の有限部分 $B_0$ と $C_0$ で書ける。$d=6$ では三つとも発散し、$\delta_Z=-g^2\Delta_{\mathrm{UV}}/(12(4\pi)^3)$、$\delta_m=-g^2m^2\Delta_{\mathrm{UV}}/(2(4\pi)^3)$、$\delta_g=-g^3\Delta_{\mathrm{UV}}/(2(4\pi)^3)$ となる。ここから $\beta(g)=-3g^3/(4(4\pi)^3)$ が出て、理論は漸近自由である。質量は $\mu\,\dd m^2/\dd\mu=-5g^2m^2/(6(4\pi)^3)$ で走り、場の異常次元は $g^2/(12(4\pi)^3)$ である。$d=4$ では結合定数は1ループで走らず、質量は $\mu\,\dd m^2/\dd\mu=g^2/(4\pi)^2$ で走る。最後に、これらの手計算を各ツールの出力と突き合わせる計画を定め（比べる量、方法、一致の基準、数値の基準点 $m=g=\mu=1$）、その十段階をすべて実行した。FeynRules の模型ファイルから書き出した FeynArts 模型で作った木の振幅は、式と記号として一致した。MadGraph の断面積は、$\sqrt{s}=2.5,\,5,\,10$ で式の数値積分と統計誤差の1.3倍以内で一致した。$d=4$ の1ループでは、FeynCalc の振幅、発散部分、対抗項が手計算と記号として一致した。有限部分は $\overline{\mathrm{MS}}$ で比べ、$B_0$ は Package-X・LoopTools・COLLIER の三つとも閉じた式と相対 $8\times10^{-15}$ 以内で一致し、虚部は光学定理 $\mathrm{Im}\,B_0=\pi\beta$ を満たした。一方、この環境の LoopTools は閾値より下の $C_0$ を誤って返すことが分かった。$d=6$ の1ループでは、FeynCalc の Feynman パラメータ表示から極・対抗項・$\beta(g)$ が記号として再現された。さらに、$D+2$ 次元のスカラー積分が $D$ 次元のテンソル積分の $g^{\mu\nu}$ の係数の $-2\pi$ 倍であることを使い、$D=4-2\epsilon$ 用の Package-X・LoopTools・COLLIER で $d=6$ の有限部分を計算した。Package-X と COLLIER の値は、閉じた式と Feynman パラメータ積分に相対 $4\times10^{-14}$ 以内で一致し、光学定理も満たした。LoopTools の $C_0$ の誤りは $d=6$ にも現れた。最後に、$d=4$ の1ループの $\phi\phi\to\phi\phi$ 振幅（12図）を、FeynCalc と FormCalc の独立な二つの経路で手計算の式と記号として一致させた。その数値は、物理的な散乱の6点で Package-X・LoopTools・COLLIER の間で相対 $2\times10^{-11}$ 以内で一致した。虚部は、木の振幅二つから作ったユニタリー性の積分と相対 $6\times10^{-14}$ 以内で一致した。さらに、$\overline{\mathrm{MS}}$ の振幅を S 行列要素に直す式（極質量と留数による変換）を導き、on-shell の処方で直接計算した結果と一致することを示した。最後に、FeynRules の NLOCT で対抗項を含む UFO を作り、MadGraph の1ループ計算（MadLoop）と比べた。NLOCT の対抗項は on-shell の処方の手計算と記号として一致した。MadLoop の値は、on-shell の対抗項では S 行列要素の式と、極だけの $\overline{\mathrm{MS}}$ の対抗項では $\overline{\mathrm{MS}}$ の振幅と、相対 $3\times10^{-13}$ 以内で一致した。最後に、$\phi\phi$ 散乱の全断面積を $g^6$ まで求めた。それには、$2\to2$ の1ループの補正と、同じ次数の $\phi\phi\to\phi\phi\phi$ の両方が要る。$g=m$ では、1ループの補正は木の断面積の $0.9$〜$2\%$、$2\to3$ は $\sqrt s=20m$ で $2\%$ である。1ループの補正の角度積分は MadLoop と相対 $10^{-14}$ 以内で一致し、$2\to3$ は自前の二つの積分と MadGraph が $\sqrt s=4m,\,5m$ で一致した。さらに $d=6$ の1ループの $\phi\phi\to\phi\phi$ を、次元をずらす関係で4点関数まで広げて計算した。極は $d=6$ の対抗項で消え、虚部はユニタリー性と一致した。S 行列要素が $\mu$ によらないことから三つのツールの数値で逆算した $\beta$ 関数は、$\beta(g)=-3g^3/(4(4\pi)^3)$ と相対 $10^{-15}$ で一致した。最後に、両方の次元で、S 行列要素が $\mu$ によらないことを使い、6点の数値から質量の走りと $\beta$ 関数を同時に読み取った。$d=4$ では、MadLoop を含む四つのツールで $\mu\,\dd m^2/\dd\mu=g^2/(4\pi)^2$ と $\beta=0$ が得られた。$d=6$ では、$\beta(g)$ と $\overline{\mathrm{MS}}$ の質量の走り $-5g^2m^2/(6(4\pi)^3)$ が得られた。極質量で書けば、質量の走りは0になった。いずれも相対 $10^{-15}$ の精度である。これらの係数で、無次元のパラメータの空間での繰り込み群の流れも描いた。$d=4$ の流れは、べき数え上げから $\overline{\mathrm{MS}}$ では全次数で正しい。最後に、S 行列要素には現れない $d=6$ の場の異常次元を、1PI の2点関数の $\mu$ 依存から三つのツールで読み取った。2点・3点関数からは質量の走りと $\beta$ も別の経路で再現され、三つの RG 関数はすべて相対 $10^{-15}$ で手計算と一致した。三つは5ループの文献の1ループの項とも符号まで一致し、これは $d=6$ の対抗項の文献による検算にもなっている。導出はすべて付録に省略なく載せる。
\end{abstract}

\section{目的と問い}\label{sec:intro}

本ノートの問いは次の一つである。\textbf{$\phi^3$ 理論の1ループの紫外発散と繰り込みの構造は、$d=4$ と $d=6$ でどう違うか。そして、どの量をどの手段で突き合わせれば、計算環境の各部品を独立に検算できるか。}この問いを立てる理由は、ループ計算の環境を組み直したばかりで、その各部品がこちらの意図どおりに動くことを、手計算で答えが分かる模型で確かめたいからである~\cite{env}。$\phi^3$ 理論は3点結合を持つ最も簡単な相互作用理論であり、1ループの量はすべて手で計算できる。しかも次元によって性格が大きく変わる。$d=4$ では結合定数が質量次元を持つ超繰り込み可能な理論で、Package-X と LoopTools がそのまま使える。$d=6$ では繰り込み可能で漸近自由な理論になり、場・質量・結合のすべてが繰り込まれる~\cite{srednicki}。$d=6$ の積分は Package-X と LoopTools の守備範囲（$D=4-2\epsilon$）の外にあるので、FeynCalc を $D\neq4$ で使う練習にもなる。ただし、次元をずらす関係を通せば、これらのツールも $d=6$ に使える（第~\ref{sec:checks} 節）。

求める量は四つである。(i) Feynman 則と対称性因子。(ii) 1ループのスカラー積分 $I_1,I_2,I_3$ の紫外発散部分。(iii) $\overline{\mathrm{MS}}$ の1ループ対抗項と、繰り込み群の係数（$d=6$ の $\beta$ 関数、質量の走り、場の異常次元と、$d=4$ の質量の走り）。両方の次元で、繰り込まれた1PI 関数も求める。(iv) $\phi\phi\to\phi\phi$ の木の振幅と、$d=4$ での1ループの振幅、およびその S 行列要素。手計算とツールの間で求める一致は、発散部分と対抗項では記号として完全な一致、有限部分では数値基準点での倍精度の一致である。

本ノートの構成は次の通りである。第~\ref{sec:setup} 節で模型と前提を定める。第~\ref{sec:results} 節で上の (i)〜(iv) の結果を述べる。第~\ref{sec:plan} 節で、これらを各ツールと突き合わせる計画を定める。第~\ref{sec:checks} 節で、その手順 (1)〜(10) の結果を示す。第~\ref{sec:discussion} 節で未決の点と今後の手順をまとめる。導出は\ref{app:rules}〜\ref{app:anom} にある。

\section{設定}\label{sec:setup}

模型は、質量 $m$ を持つ実スカラー場 $\phi$ が1つだけあり、3次の自己相互作用を持つ理論である。ラグランジアン密度は
\begin{equation}
\mathcal{L}=\frac12\,\partial_\mu\phi\,\partial^\mu\phi-\frac12 m^2\phi^2-\frac{g\mu^{\epsilon}}{3!}\,\phi^3+Y\phi
+\frac12\,\delta_Z\,\partial_\mu\phi\,\partial^\mu\phi-\frac12\,\delta_m\phi^2-\frac{\delta_g\mu^{\epsilon}}{3!}\,\phi^3
\label{eq:L}
\end{equation}
とする。最初の4項が繰り込まれた量で書いた模型、残り3項が対抗項である。線形項 $Y\phi$ は、ループが作る1点関数（タドポール）を各次数でちょうど打ち消し、$\langle\phi\rangle=0$ を保つために置く。以前に作った FeynRules の模型ファイル（\nolinkurl{models/backup_20261009/feynrules_Library_Models/Phi3/Phi3.fr}）は $\mathcal{L}\supset-(\lambda/6)\phi^3$ と書いていたが、これは本ノートの $g$ と同じもの（$\lambda\equiv g$）である。$\phi^4$ の結合定数と区別するため、本ノートでは $g$ と書く。

\paragraph{前提。}本ノートは次の前提に立つ。
\begin{enumerate}
\item 計量は $(+,-,-,-)$、$\hbar=c=1$ とする。
\item 場は質量 $m$ の実スカラー1つで、相互作用は $\phi^3$ だけとする。$\phi^4$ などの他の相互作用は入れない。
\item 時空次元は $d=4$ と $d=6$ の二つを扱う。ループ積分は次元正則化で行い、$D=d-2\epsilon$ とする。$\phi$ の質量次元は $(D-2)/2$、$g$ の質量次元は $3-d/2$ なので、どちらの次元でも結合定数を $g\mu^{\epsilon}$ と書く（\ref{app:counting}）。
\item 紫外発散は $\overline{\mathrm{MS}}$ で処理し、有限部分もこの規約で定める。すなわち、対抗項を $\Delta_{\mathrm{UV}}\equiv1/\epsilon-\gamma_E+\ln4\pi$ に比例させ、$1/\epsilon$ の極を、それに伴って現れる定数 $-\gamma_E+\ln4\pi$ ごと打ち消す。これは、極だけを引く最小引き算（MS）のスケール $\mu_{\mathrm{MS}}$ を $\mu^2=4\pi e^{-\gamma_E}\mu_{\mathrm{MS}}^2$ と取り直したものと同じである。1ループの $\beta$ 関数と質量の走りは MS と変わらない（\ref{app:ren}）。
\item タドポールは $Y$ で各次数ちょうど打ち消す。そのため、外線にタドポールが付いた図は計算に含めない。FeynArts では \texttt{ExcludeTopologies -> Tadpoles} に当たる。
\item $\phi^3$ のポテンシャルは下に有界でない。本模型は摂動論の範囲でだけ扱う玩具模型である。
\item 数値を比べるときの基準点は $m=1$、$g=1$、$\mu=m$ とする（$d=4$ では $g$ は $m$ を単位とする）。
\end{enumerate}

\begin{equation}
\omega=d-\frac{d-2}{2}\,E+\frac{d-6}{2}\,V
\label{eq:omega}
\end{equation}
である（\ref{app:counting}）。$d=4$ では $\omega=4-E-V$ となり、頂点が増えるほど収束がよくなる。発散する図は有限個に限られ、理論は超繰り込み可能である。$d=6$ では $\omega=6-2E$ で $V$ によらず、$E\le3$ の関数がすべての次数で発散する。これは繰り込み可能な理論の振る舞いである。1ループの1PI 図では $E=V$ なので、どちらの次元でも $\omega=d-2E$ となる。

\paragraph{1ループ積分の発散部分。}1ループのスカラー積分を
\begin{equation}
I_N(q_1,\dots,q_N)\equiv\int\frac{\dd^Dk}{(2\pi)^D}\prod_{j=1}^{N}\frac{1}{(k+q_j)^2-m^2+i0}
\label{eq:IN}
\end{equation}
と定義する。Feynman パラメータでまとめ、Wick 回転して積分すると、$N$ と $d$ によらない次の一般式が得られる（\ref{app:integrals}）。
\begin{equation}
I_N=\frac{i(-1)^N\,\Gamma(N-D/2)}{(4\pi)^{D/2}}\int\!\dd F\,\Delta^{D/2-N},\qquad
\Delta=m^2-\sum_j x_jq_j^2+\Bigl(\sum_j x_jq_j\Bigr)^2 .
\label{eq:IN-general}
\end{equation}
発散は $\Gamma(N-D/2)$ の極からだけ生じ、$k\equiv d/2-N$ が0以上の整数のとき現れる。その極の部分は
\begin{equation}
I_N\Big|_{\text{pole}}=\frac{i\,(-1)^{N+k}}{(4\pi)^{d/2}\,k!\,\epsilon}\int\!\dd F\,\Delta^{k}
\label{eq:poleN}
\end{equation}
である。$k<0$ なら $I_N$ は有限である。これを $N=1,2,3$ に当てはめた結果を、表面的な発散次数とあわせて表~\ref{tab:poles} に示す。$d=4$ では $I_2$ の極が外運動量によらず、$I_3$ は有限である。$d=6$ では三つとも発散し、$I_2$ の極は $p^2$ に依存する。この違いが、次に述べる繰り込みの構造の違いを生む。

\paragraph{1ループの1PI 関数。}図~\ref{fig:oneloop} の図を Feynman 則で書き、対抗項を加えると、1PI の1点・2点・3点関数は
\begin{equation}
V_1=iY+\frac{g\mu^\epsilon}{2}\,I_1,\qquad
V_2(p^2)=\frac{g^2\mu^{2\epsilon}}{2}\,I_2(p^2)+i\bigl(\delta_Zp^2-\delta_m\bigr),\qquad
V_3=g^3\mu^{3\epsilon}\,I_3-i\,\delta_g\mu^{\epsilon}
\label{eq:V}
\end{equation}
となる（\ref{app:ren}）。タドポールの条件 $V_1=0$ から $Y=(ig\mu^\epsilon/2)\,I_1$ と決まる。$I_1$ は純虚数なので、$Y$ は実数である。

\paragraph{$\overline{\mathrm{MS}}$ の対抗項。}対抗項を $\Delta_{\mathrm{UV}}$ に比例させ、その係数を $V_2$ と $V_3$ の $1/\epsilon$ の極が消えるように決める（\ref{app:ren}）。$d=4$ では、自己エネルギーの極が外運動量によらず、頂点補正は有限なので、
\begin{equation}
d=4:\qquad \delta_Z=0,\qquad \delta_m=\frac{g^2}{2(4\pi)^2}\,\Delta_{\mathrm{UV}},\qquad \delta_g=0 .
\label{eq:ct4}
\end{equation}
$d=6$ では三つとも必要で、
\begin{equation}
d=6:\qquad \delta_Z=-\frac{g^2}{12(4\pi)^3}\,\Delta_{\mathrm{UV}},\qquad \delta_m=-\frac{g^2m^2}{2(4\pi)^3}\,\Delta_{\mathrm{UV}},\qquad \delta_g=-\frac{g^3}{2(4\pi)^3}\,\Delta_{\mathrm{UV}}.
\label{eq:ct6}
\end{equation}
Srednicki は $d=6-\epsilon_{\mathrm S}$ と書くので、$1/\epsilon_{\mathrm S}=1/(2\epsilon)$ である。同書の $\overline{\mathrm{MS}}$ は、スケール $\tilde\mu^2=4\pi e^{-\gamma_E}\mu_{\mathrm{S}}^2$ で書いたときの極だけを引くもので、本ノートの $\Delta_{\mathrm{UV}}$ による引き算と同じである（同書の $\tilde\mu$ が本ノートの $\mu$ にあたる）。$\Delta_{\mathrm{UV}}$ を $2/\epsilon_{\mathrm S}$ と読み替え、$\alpha\equiv g^2/(4\pi)^3$ と置くと、式~\eqref{eq:ct6} は $Z_\phi=1-\alpha/(6\epsilon_{\mathrm S})$、$Z_m=1-\alpha/\epsilon_{\mathrm S}$、$Z_g=1-\alpha/\epsilon_{\mathrm S}$ と書き直せる。これは同書の値と一致する~\cite{srednicki}。

\paragraph{$d=4$ の繰り込まれた1PI 関数。}式~\eqref{eq:ct4} の対抗項を式~\eqref{eq:V} に入れると、$V_2$ と $V_3$ は有限になり、$\epsilon\to0$ で
\begin{equation}
V_2(p^2)=\frac{ig^2}{2(4\pi)^2}\,B_0(p^2;m,m),\qquad
V_3=\frac{ig^3}{(4\pi)^2}\,C_0\bigl(p_1^2,p_2^2,(p_1+p_2)^2;m,m,m\bigr)
\label{eq:VR4}
\end{equation}
となる（\ref{app:b0}）。$p_1$、$p_2$ は頂点の二つの外線の運動量である。ここで
\begin{equation}
B_0(p^2;m,m)=-\int_0^1\dd x\,\ln\frac{m^2-x(1-x)p^2-i0}{\mu^2},\qquad
C_0=-\int\!\dd F\,\frac{1}{\Delta}
\label{eq:B0C0}
\end{equation}
は、1ループ積分から $\Delta_{\mathrm{UV}}$ を除いた $\overline{\mathrm{MS}}$ の有限部分で、LoopTools の規約（$\Delta=0$）の $B_0$、$C_0$ と同じものである。$C_0$ の $\Delta$ は式~\eqref{eq:IN-general} で $N=3$ としたものである。$V_3$ はもともと有限なので、規約によらない。タドポールの積分の有限部分は $A_0(m^2)=m^2\bigl(1-\ln(m^2/\mu^2)\bigr)$ だが、$V_1$ は $Y$ で打ち消すので $0$ である。$B_0$ は $\mu$ に $\ln\mu^2$ で依存する。その結果、自己エネルギー $\Sigma\equiv iV_2=-g^2B_0/(2(4\pi)^2)$ の $\mu$ 依存は式~\eqref{eq:mrun4} の $m^2$ の走りとちょうど打ち消し合い、伝播関数の分母 $p^2-m^2-\Sigma$ は $\mu$ によらない。

\paragraph{$d=6$ の繰り込まれた1PI 関数。}$d=6$ でも、1ループ積分を $\mu^{2\epsilon}I_N=\frac{i}{(4\pi)^3}\bigl[c_N\Delta_{\mathrm{UV}}+X_N\bigr]+O(\epsilon)$ と、発散に比例する部分と有限部分 $X_N$ に分ける。表~\ref{tab:poles} の $d=6$ の列から、$c_1=-m^4/2$、$c_2=-(m^2-p^2/6)$、$c_3=-1/2$ である。式~\eqref{eq:ct6} の対抗項を式~\eqref{eq:V} に入れると、$V_2$ と $V_3$ は有限になり、
\begin{equation}
V_2(p^2)=\frac{ig^2}{2(4\pi)^3}\,B_0^{(6)}(p^2;m,m),\qquad
V_3=\frac{ig^3}{(4\pi)^3}\,C_0^{(6)}
\label{eq:VR6}
\end{equation}
となる（\ref{app:d6}）。有限部分は
\begin{equation}
A_0^{(6)}=-\frac{m^4}{2}\Bigl(\frac32-\ln\frac{m^2}{\mu^2}\Bigr),\qquad
B_0^{(6)}=-\Bigl(m^2-\frac{p^2}{6}\Bigr)+\int_0^1\dd x\,\Delta\ln\frac{\Delta-i0}{\mu^2},\qquad
C_0^{(6)}=\int\!\dd F\,\ln\frac{\Delta-i0}{\mu^2}
\label{eq:X6}
\end{equation}
である。$B_0^{(6)}$ の $\Delta$ は $m^2-x(1-x)p^2$、$C_0^{(6)}$ の $\Delta$ は式~\eqref{eq:IN-general} で $N=3$ としたものである。$B_0^{(6)}$ は、$d=4$ の $B_0$ を使って閉じた形に書ける。
\begin{equation}
B_0^{(6)}(p^2;m,m)=-m^2+\frac{p^2}{9}+\frac{m^2}{3}\ln\frac{m^2}{\mu^2}-\frac23\Bigl(m^2-\frac{p^2}{4}\Bigr)B_0(p^2;m,m) .
\label{eq:B06}
\end{equation}
閾値より上では $\mathrm{Im}\,B_0^{(6)}=\pi p^2\beta^3/6$ である。$d=4$ の $\mathrm{Im}\,B_0=\pi\beta$ と比べて閾値での立ち上がりが遅いのは、6次元の2体位相空間が終状態の運動量の3乗に比例するためである。$d=6$ でも光学定理 $\mathrm{Im}\,\Sigma=-\sqrt{p^2}\,\Gamma(\phi^*\to\phi\phi)$ が成り立つ（\ref{app:d6}）。

\paragraph{繰り込み群。}裸の量が $\mu$ によらないことから、繰り込まれた量の走り方が決まる（\ref{app:ren}）。$d=6$ では
\begin{equation}
\beta(g)=-\frac{3g^3}{4(4\pi)^3}
\label{eq:beta6}
\end{equation}
となり、結合定数は高エネルギーで小さくなる（漸近自由）。$d=6$ では質量も走り、$\mu\,\dd m^2/\dd\mu=-5g^2m^2/(6(4\pi)^3)$ となる。場の異常次元 $\gamma_\phi\equiv\frac12\mu\,\dd\ln Z/\dd\mu$ は $g^2/(12(4\pi)^3)$ である。$d=4$ では、1ループで $\delta_Z=\delta_g=0$ なので、結合定数は（次元の分 $-\epsilon g$ を除いて）走らない。一方、質量は
\begin{equation}
d=4:\qquad \mu\frac{\dd m^2}{\dd\mu}=\frac{g^2}{(4\pi)^2}
\label{eq:mrun4}
\end{equation}
で走る。$g$ が質量次元を持つので、$m^2$ の走りは $m$ によらない加法的なものになる。

\mathcal{M}=-g^2\left[\frac{1}{s-m^2}+\frac{1}{t-m^2}+\frac{1}{u-m^2}\right]
\label{eq:Mtree}
\end{equation}
である（図~\ref{fig:tree}、\ref{app:tree}）。各チャンネルの対称性因子は1である。

\paragraph{1ループの $\phi\phi\to\phi\phi$ 振幅（$d=4$）。}式~\eqref{eq:Mtree} の木の振幅を $\mathcal{M}^{(0)}$ と書く。その1ループの補正には、箱図3つ、頂点補正の三角形6つ（各チャンネルに2つ）、内線の自己エネルギー3つの計12個の図が寄与する（図~\ref{fig:scat}）。タドポールは $Y$ で打ち消し、外線の自己エネルギーは含めない（外線を切り離した振幅）。内線に式~\eqref{eq:ct4} の質量の対抗項を入れて $\overline{\mathrm{MS}}$ で繰り込むと、
\begin{equation}
\mathcal{M}^{(1)}=\frac{g^4}{(4\pi)^2}\Bigl[D_0(s,t)+D_0(s,u)+D_0(t,u)+\sum_{x=s,t,u}\Bigl(\frac{2\,C_0(x)}{x-m^2}+\frac{B_0(x)}{2(x-m^2)^2}\Bigr)\Bigr]
\label{eq:M1}
\end{equation}
となる（\ref{app:scat}）。ここで $C_0(x)\equiv C_0(m^2,m^2,x;m,m,m)$、$B_0(x)\equiv B_0(x;m,m)$ は式~\eqref{eq:B0C0} の有限部分である。$D_0(x,y)$ は、外線の $p_i^2$ と内線の質量がすべて $m$ で、二つの対角の不変量が $x$、$y$ の箱図の積分で、$D_0=\int\dd F\,\Delta^{-2}$ と書ける（$\Delta$ は式~\eqref{eq:IN-general} で $N=4$ としたもの）。$D_0$ と $C_0$ は有限で、発散は $B_0$ からだけ生じ、それは対抗項で消えている。

物理的な散乱（$s>4m^2$、$t,u<0$）では、虚部は $s$ チャンネルの $B_0(s)$、$C_0(s)$、$D_0(s,t)$、$D_0(s,u)$ からだけ生じる。ユニタリー性から、それは木の振幅二つの位相空間積分に等しい（\ref{app:scat}）。
\begin{equation}
\mathrm{Im}\,\mathcal{M}^{(1)}(s,t)=\frac{p}{64\pi^2\sqrt s}\int\!\dd\Omega_k\,\mathcal{M}^{(0)}(s,t_1)\,\mathcal{M}^{(0)}(s,t_2),\qquad
t_1=(p_1-k)^2,\quad t_2=(p_3-k)^2 .
\label{eq:unit}
\end{equation}
$p=\sqrt{s/4-m^2}$ は重心系の運動量の大きさ、$k$ は中間状態の $\phi$ の一方の運動量で、積分はその向きについて行う。前方（$t=0$）では、これは光学定理 $\mathrm{Im}\,\mathcal{M}^{(1)}(s,0)=2p\sqrt s\,\sigma(\phi\phi\to\phi\phi)$ になる。ただし、$\mathcal{M}^{(1)}$ はまだ S 行列要素ではない。それを次に述べる。

\paragraph{S 行列要素と繰り込みの処方（$d=4$）。}式~\eqref{eq:M1} の $\mathcal{M}^{(1)}$ は、外線の自己エネルギーを除き、外線を $\overline{\mathrm{MS}}$ の質量 $m$ の上に置いた振幅である。これを S 行列要素にするには二つの補正が要る。一つは外線の質量である。粒子の物理的な質量は、完全な伝播関数 $i/(p^2-m^2-\Sigma(p^2))$ の極の位置 $m_{\mathrm p}$ で、$\overline{\mathrm{MS}}$ の $m$ とは一致しない。もう一つは極での留数 $R$ で、これも1ではない。1ループでは、$\Sigma=-g^2B_0/(2(4\pi)^2)$（式~\eqref{eq:VR4}）から
\begin{equation}
m_{\mathrm p}^2=m^2+\Sigma(m_{\mathrm p}^2)=m^2-\frac{g^2}{2(4\pi)^2}\,B_0(m^2)+O(g^4),\qquad
R=\frac{1}{1-\Sigma'(m_{\mathrm p}^2)}=1-\frac{g^2}{2(4\pi)^2}\,B_0'(m^2)+O(g^4)
\label{eq:mpole}
\end{equation}
となる（\ref{app:lsz}）。$B_0(m^2)\equiv B_0(m^2;m,m)$ で、$B_0'$ は $p^2$ についての微分である。$m_{\mathrm p}$ と $R$ は $\mu$ によらない。$m^2$ の $\mu$ 依存（式~\eqref{eq:mrun4}）を、$B_0(m^2)$ の $\ln\mu^2$ がちょうど打ち消すからである。LSZ の簡約公式によれば、S 行列要素は、外線を切り離した振幅を $p_i^2=m_{\mathrm p}^2$ で評価し、外線1本ごとに $\sqrt R$ を掛けたものである~\cite{peskin}。そこで $R^2$ を掛け、木の振幅の内線の質量 $m$ も $m_{\mathrm p}$ で書き直して1ループまで展開すると、
\begin{equation}
\mathcal{M}_{\mathrm{phys}}=\mathcal{M}^{(0)}\big|_{m\to m_{\mathrm p}}+\mathcal{M}^{(1)}\big|_{m\to m_{\mathrm p}}
+\frac{g^4}{2(4\pi)^2}\sum_{x=s,t,u}\Bigl[\frac{2B_0'(m_{\mathrm p}^2)}{x-m_{\mathrm p}^2}-\frac{B_0(m_{\mathrm p}^2)}{(x-m_{\mathrm p}^2)^2}\Bigr]+O(g^6)
\label{eq:Mphys}
\end{equation}
を得る。最後の項の $B_0'$ の部分は $R^2$ から、$B_0(m_{\mathrm p}^2)$ の部分は木の内線の質量の書き直しから来る。$\mathcal{M}^{(1)}$ の $B_0(x)$ の項とまとめると、各チャンネルの自己エネルギーの寄与は $\frac{g^4}{2(4\pi)^2}\bigl[B_0(x)-B_0(m_{\mathrm p}^2)+2(x-m_{\mathrm p}^2)B_0'(m_{\mathrm p}^2)\bigr]/(x-m_{\mathrm p}^2)^2$ となる。$B_0(x)-B_0(m_{\mathrm p}^2)$ と $B_0'$ は $\mu$ によらないので、$\mathcal{M}_{\mathrm{phys}}$ は $\mu$ によらない。一方、$\overline{\mathrm{MS}}$ で書いた $\mathcal{M}^{(0)}+\mathcal{M}^{(1)}$ の各項は $\mu$ に依存し、その依存は $m(\mu)$ の走りと打ち消し合う。

同じ $\mathcal{M}_{\mathrm{phys}}$ は、on-shell の処方で直接計算しても得られる（\ref{app:lsz}）。on-shell の処方では、極がちょうど $m_{\mathrm p}$ にあり、留数がちょうど1になるように、質量の対抗項と場の繰り込みを決める。$d=4$ でも、場の繰り込み $\delta_Z^{\mathrm{os}}=\Sigma'(m_{\mathrm p}^2)$ は有限の値として残る。外線の因子 $\sqrt R$ は不要になり、代わりに内線の自己エネルギーの引き算と、頂点の対抗項 $-\frac32ig\,\delta_Z^{\mathrm{os}}$ が加わる。それらを足すと式~\eqref{eq:Mphys} に一致する。つまり、繰り込みの処方の違いは、入力のパラメータの定義（ここでは $m$ か $m_{\mathrm p}$ か）と、物理に効かない場の規格化の違いにすぎない。同じ物理的な入力で書けば、どの処方でも S 行列要素は（その次数で）一致する。結合 $g$ は、$d=4$ の1ループでは繰り込まれない（$\delta_g=\delta_Z=0$、裸の結合は $g_0=\mu^\epsilon g$）。このように裸の結合で $g$ を定義する限り、どちらの処方でも $g$ は同じである。$g$ を別の物理的な条件で定義するなら、その分の変換が加わる。式~\eqref{eq:mpole} と式~\eqref{eq:Mphys}、二つの導出の一致、$\mu$ によらないことは、\texttt{Src/onshell4\_check.wl} で記号として確かめた。

大きさの目安として、$\mu=m$ では $B_0(m^2)=2-\pi/\sqrt3\approx0.186$、$m^2B_0'(m^2)=2\pi/(3\sqrt3)-1\approx0.209$ である。したがって $g=m$ では、$m_{\mathrm p}^2=m^2(1-5.9\times10^{-4})$、$R=1-6.6\times10^{-4}$ となる。どちらも小さいが、式~\eqref{eq:Mphys} の最後の項は $\mathcal{M}^{(1)}$ と同じ $g^4$ の次数である。例えば $\sqrt s=5m$、$\cos\theta=0.3$、$m_{\mathrm p}=g=1$ では、式~\eqref{eq:Mphys} の自己エネルギーの寄与（3つのチャンネルの合計）の実部は $-2.6\times10^{-4}$ で、$\mathrm{Re}\,\mathcal{M}^{(1)}=7.4\times10^{-4}$（表~\ref{tab:scat4}）と比べて無視できない。

\paragraph{全断面積（$d=4$、$g^6$ まで）。}$\phi\phi$ 散乱の全断面積を、木の次数（$g^4$）の次まで求める。$|\mathcal{M}|^2$ を展開すると、1ループの補正 $2\,\mathrm{Re}(\mathcal{M}^{(0)*}\mathcal{M}^{(1)}_{\mathrm{phys}})$ は $g^6$ の次数である。同じ $g^6$ の次数で、終状態が三つの $\phi$ になる $\phi\phi\to\phi\phi\phi$ も寄与する（振幅は $g^3$）。よって、終状態を問わない全断面積は
\begin{equation}
\sigma_{\mathrm{tot}}=\sigma^{(0)}+\sigma^{(1)}+\sigma_{2\to3}+O(g^8),\qquad
\sigma^{(1)}=\int\!\dd\Omega\,\frac{\mathcal{M}^{(0)}\,\mathrm{Re}\,\mathcal{M}^{(1)}_{\mathrm{phys}}}{64\pi^2s}
\label{eq:sigmatot}
\end{equation}
となる（\ref{app:sigma}）。$\sigma^{(0)}$ は式~\eqref{eq:sigma}、$\sigma^{(1)}$ には同種粒子の因子 $\frac12$ と $2\,\mathrm{Re}$ の $2$ が打ち消し合って入っている。入力は極質量 $m_{\mathrm p}$ と $g$ である。粒子はすべて質量を持つので赤外発散はなく、三つの項はそれぞれ有限である。$2\to3$ は $\sqrt s>3m$ で開く。$\phi\phi\to\phi\phi\phi$ の振幅は、外線5本の3次の木の図15個の和で、各図は二つの伝播関数の積に比例する。

\paragraph{$d=6$ の1ループの $\phi\phi\to\phi\phi$ 振幅と繰り込み群。}$d=6$ でも図は図~\ref{fig:scat} の12個で、$\overline{\mathrm{MS}}$ で繰り込んだ振幅は式~\eqref{eq:M1} と同じ形になる（\ref{app:scat6}）。
\begin{equation}
\mathcal{M}^{(1)}_{d=6}=\frac{g^4}{(4\pi)^3}\Bigl[D_0^{(6)}(s,t)+D_0^{(6)}(s,u)+D_0^{(6)}(t,u)+\sum_{x=s,t,u}\Bigl(\frac{2\,C_0^{(6)}(x)}{x-m^2}+\frac{B_0^{(6)}(x)}{2(x-m^2)^2}\Bigr)\Bigr]
\label{eq:M6}
\end{equation}
ここで $C_0^{(6)}(x)$ と $B_0^{(6)}(x)$ は式~\eqref{eq:X6} の有限部分（外線は $p_i^2=m^2$）で、$D_0^{(6)}=\int\dd F\,\Delta^{-1}$ は有限な箱図の積分である。$d=4$ と違い、三角形と内線の自己エネルギーは発散する。その極は、内線の2点の対抗項 $i(\delta_Zp^2-\delta_m)$ と、木の図の頂点の対抗項 $-i\delta_g$（各チャンネルに2つ）で消える。S 行列要素は式~\eqref{eq:Mphys} と同じ手順で作れて、$(4\pi)^2$ を $(4\pi)^3$ に、$B_0$ を $B_0^{(6)}$ に替えた形になる。必要な値は
\begin{equation}
B_0^{(6)}(m^2)=m^2\Bigl(-\frac{17}{9}+\frac{\pi}{2\sqrt3}+\frac56L\Bigr),\qquad
B_0^{(6)\prime}(m^2)=\frac{17}{18}-\frac{\pi}{2\sqrt3}-\frac L6,\qquad L\equiv\ln\frac{m^2}{\mu^2}
\label{eq:B06m}
\end{equation}
である。$d=6$ では $g$ が $\overline{\mathrm{MS}}$ で走るので、S 行列要素 $\mathcal{M}_{\mathrm{phys}}$ が $\mu$ によらないためには、1ループの部分の $\mu$ 依存が、木の振幅に入る $g(\mu)$ の走りと打ち消し合う必要がある。各チャンネルで
\begin{equation}
\mu\frac{\partial\mathcal{M}^{(1)}_{\mathrm{phys}}}{\partial\mu}=-\frac{3g^4}{2(4\pi)^3}\sum_x\frac{1}{x-m_{\mathrm p}^2},\qquad
\frac{\partial\mathcal{M}^{(0)}}{\partial g}\,\beta(g)=-2g\,\beta(g)\sum_x\frac{1}{x-m_{\mathrm p}^2}
\label{eq:rg6}
\end{equation}
なので、和が0になる条件は $\beta(g)=-3g^3/(4(4\pi)^3)$、すなわち式~\eqref{eq:beta6} である（\ref{app:scat6}）。逆に、1ループの振幅の $\mu$ 依存から $\beta$ 関数を読み取れる。虚部には $d=6$ のユニタリー性の関係（式~\eqref{eq:unit} の位相空間を $d=6$ のものに替えたもの）が成り立つ。

\paragraph{一致の基準。}発散部分と対抗項は、$1/\epsilon$ の係数が記号として完全に一致することを求める。有限部分は、基準点 $m=g=\mu=1$ で、Package-X の解析式・LoopTools の数値・Feynman パラメータ積分の数値積分が、倍精度の丸め誤差の範囲（相対 $10^{-12}$ 程度）で一致することを求める。有限部分は規約に依存するので、すべて $\overline{\mathrm{MS}}$（第~\ref{sec:setup} 節の前提4）にそろえて比べる。LoopTools（$\Delta=0$）と COLLIER（$\Delta_{\mathrm{UV}}=0$）は、既定で $\overline{\mathrm{MS}}$ の値を返す。一方、FeynCalc の PaVe 関数は測度 $\dd^Dq/(i\pi^2)$ で規格化されているので、その $\epsilon^0$ の係数は $\overline{\mathrm{MS}}$ の値から $-(\gamma_E+\ln\pi)$ だけずれる~\cite{env}。そこで FeynCalc の振幅は、本ノートの $V_n$ に直し、$\overline{\mathrm{MS}}$ の対抗項を加えてから比べる。MadGraph の断面積は、式~\eqref{eq:Mtree} を自分で数値積分した値と、統計誤差の範囲で一致することを求める。

\paragraph{手順。}次の順に進める。(1) 模型ファイル \texttt{Phi3.fr} を \texttt{Src/} に作り、FeynRules で FeynArts の模型と UFO を書き出して、Feynman 則を確かめる。(2) 木の振幅を FeynCalc と MadGraph で確かめる。(3) $d=4$ の1ループ（極、対抗項、有限部分）を FeynCalc・Package-X・LoopTools で確かめる。(4) $d=6$ の1ループを FeynCalc で $D=6-2\epsilon$ として計算し、式~\eqref{eq:ct6} と式~\eqref{eq:beta6} を再現する。有限部分は Feynman パラメータ積分の数値と比べる。(5) $d=4$ の1ループの $\phi\phi\to\phi\phi$ を、FeynCalc と FormCalc の二つの経路で式~\eqref{eq:M1} と記号として比べ、Package-X・LoopTools・COLLIER の数値を互いに比べる。虚部は式~\eqref{eq:unit} で確かめる。(6) FeynRules の NLOCT で対抗項を含む UFO を作り、MadLoop の値を式~\eqref{eq:Mphys}（on-shell の対抗項）と式~\eqref{eq:M1}（$\overline{\mathrm{MS}}$ の対抗項）に比べる。(7) 式~\eqref{eq:sigmatot} の全断面積を求め、$\sigma^{(1)}$ を MadLoop の角度積分と、$\sigma_{2\to3}$ を MadGraph の木の計算と比べる。(8) $d=6$ の1ループの $\phi\phi\to\phi\phi$ を計算し、極が式~\eqref{eq:ct6} の対抗項で消えること、虚部がユニタリー性を満たすこと、S 行列要素の $\mu$ 依存から $\beta$ 関数が再現されることを確かめる。(9) 両方の次元で、$\phi\phi\to\phi\phi$ の S 行列要素が $\mu$ によらないことを使い、6点のツールの数値から質量の走りと $\beta$ 関数を同時に読み取って、式~\eqref{eq:beta6}、式~\eqref{eq:mrun4} などと比べる。その係数で、無次元のパラメータの空間での流れを描く。(10) $d=6$ の場の異常次元を1PI の2点・3点関数の $\mu$ 依存から読み取り、質量の走りと $\beta$ とともに文献の値と照合する。

\section{検算の結果}\label{sec:checks}

第~\ref{sec:plan} 節の手順 (1)〜(10)、すなわち模型ファイルの作成、木の振幅の検算、$d=4$ と $d=6$ の1ループの検算、$d=4$ の1ループの $\phi\phi\to\phi\phi$ の検算、MadLoop との比較、全断面積の計算、$d=6$ の1ループの $\phi\phi\to\phi\phi$ の検算、繰り込み群の検算、$d=6$ の場の異常次元の検算をすべて行った。使ったスクリプトはすべて \texttt{Src/} にある。模型ファイルからの書き出しは \texttt{generate\_Phi3.wl} で、木の検算は \texttt{run\_tree\_check.sh} で、1ループの検算は \texttt{run\_oneloop4\_check.sh} と \texttt{run\_oneloop6\_check.sh} で、$\phi\phi\to\phi\phi$ の検算は \texttt{run\_scat4\_check.sh} で、MadLoop との比較は \texttt{generate\_Phi3\_NLO.sh} と \texttt{run\_madloop\_check.sh} で、全断面積は \texttt{run\_xsec\_check.sh} で、$d=6$ の $\phi\phi\to\phi\phi$ は \texttt{run\_scat6\_check.sh} で、繰り込み群は \texttt{run\_rg4\_check.sh} で、場の異常次元は \texttt{run\_anom6\_check.sh} で再実行できる。

\paragraph{手順 (1)：模型ファイル。}FeynRules の模型ファイル \texttt{Src/Phi3.fr} を作った。ラグランジアンは式~\eqref{eq:L} から対抗項と線形項を除いた部分である。結合定数 $g$ はパラメータ \texttt{gphi}（TeX 表記は $g$）と書いた。\texttt{g} という名前にすると、FeynRules 2.3.49 の UFO 出力が \texttt{\$RecursionLimit} に達して止まるためである。名前だけを変えた比較で、原因がこの名前であることを確かめた。FeynRules のチェック（エルミート性、運動項の規格化、質量スペクトル）はすべて通り、頂点は $-i\,\texttt{gphi}$ となって図~\ref{fig:rules} の $-ig$ と一致した。FeynArts 模型（\texttt{C[S[1],S[1],S[1]] == -I gphi}）と UFO も \texttt{Src/generated/} に書き出せた。MadGraph 3.8.1 はその UFO から $\phi\phi\to\phi\phi$ の図を $s,t,u$ の3つ生成した。なお、旧模型ファイルは運動項を \texttt{D[phi, mu]} と書いていた。これは Mathematica の記号 \texttt{mu} による微分なので 0 になり、旧ファイルのラグランジアンには運動項がなかった。実際に読み込んで評価すると、$-\frac12m^2\phi^2-\frac{\lambda}{6}\phi^3$ だけが残る。頂点は3次の項だけで決まるので、旧ファイルから書き出した FeynArts の頂点には影響しなかったと考えられる。新しいファイルでは FeynRules の偏微分 \texttt{del} を使っている。

\paragraph{手順 (2)：木の振幅。}\texttt{Src/generated/Phi3\_FA} の FeynArts 模型から $\phi\phi\to\phi\phi$ の木の図を作ると、$s,t,u$ の3つが対称性因子 $1$ で現れた。FeynCalc で振幅を組み立てて Mandelstam 変数で書くと、式~\eqref{eq:Mtree} との差は記号として $0$ になった。数値でも、$\sqrt{s}=5$、$\cos\theta=0.3$、$m=g=1$ で $\mathcal{M}=0.1463531980$ となり、式~\eqref{eq:Mtree} を Python で評価した値と一致した。FeynArts の \texttt{CreateFeynAmp} は既定で因子 $-i$ を掛けるので、出力は図の和 $i\mathcal{M}$ ではなく $\mathcal{M}$ そのものになる。FeynRules の模型には、一時フォルダに置いたコピーに FeynCalc 用のパッチ（\texttt{FAPatch}）を当ててから読み込んだ。

続いて、UFO を MadGraph 3.8.1 に読み込ませ、$\phi$ どうしを固定エネルギーで衝突させて全断面積を求めた。カットはかけず、$m=g=1$（単位は GeV）とした。比べる相手は、式~\eqref{eq:Mtree} の $|\mathcal{M}|^2$ を角度について数値積分した
\begin{equation}
\sigma=\frac12\int\!\dd\Omega\,\frac{|\mathcal{M}|^2}{64\pi^2s},\qquad
t=-2p^2(1-\cos\theta),\quad u=-2p^2(1+\cos\theta),\quad p^2=\frac{s}{4}-m^2
\label{eq:sigma}
\end{equation}
である（\ref{app:xsec}）。因子 $1/2$ は、終状態の二つの $\phi$ が同種粒子であることから来る。表~\ref{tab:tree} に示すように、$\sqrt{s}=2.5,\,5,\,10$ のすべてで、MadGraph の値は式~\eqref{eq:sigma} と統計誤差の1.3倍以内で一致した。なお、MadGraph は読み込んだ UFO に残る Python 2 の構文をその場で Python 3 に書き換える。そこで \texttt{Src/work/} に置いたコピーを読ませ、\texttt{Src/generated/} は FeynRules の出力のまま保った。

\paragraph{手順 (3)：$d=4$ の1ループ。}三つの観点から確かめた。まず図と規格化である。\texttt{Src/generated/Phi3\_FA} から FeynArts でタドポール・自己エネルギー・三角形の1PI 図を作ると、それぞれ1つずつ現れた。自己エネルギーではタドポールの付いた図を、三角形ではそれに加えて外線の自己エネルギーを除いた。\texttt{PreFactor -> 1} としてテンソル積分を FeynCalc で PaVe 関数まで簡約すると、振幅は
\begin{equation}
A_1=\frac{i\pi^2g}{2}\,A_0(m^2),\qquad
A_2=\frac{i\pi^2g^2}{2}\,B_0(p^2;m^2,m^2),\qquad
A_3=i\pi^2g^3\,C_0
\label{eq:A123}
\end{equation}
となった。これは図~\ref{fig:rules} の Feynman 則と、対称性因子 $1/2,\ 1/2,\ 1$ から予想される形と記号として一致する。FeynCalc の PaVe 関数は $\int\dd^Dq\,(\cdots)=i\pi^2\times\mathrm{PaVe}$ で定義されている。$A_n$ は測度 $\dd^Dq$ で書いた値なので、本ノートの $V_n$（測度 $\dd^Dq/(2\pi)^D$）とは $V_n=A_n/(2\pi)^D$ の関係にある。

次に発散部分である。Package-X（FeynHelpers 経由）で $A_n$ を $\epsilon$ について展開し、$V_n$ の $1/\epsilon$ の係数を取り出した。その値は、$V_1$ が $igm^2/(2(4\pi)^2)$、$V_2$ が $ig^2/(2(4\pi)^2)$、$V_3$ が $0$ で、表~\ref{tab:poles} の $d=4$ の列に式~\eqref{eq:V} の係数を掛けたものと一致した。$V_2$ の極が式~\eqref{eq:V} の対抗項で消える条件から、$\overline{\mathrm{MS}}$ の対抗項 $\delta_Z=0$、$\delta_m=g^2\Delta_{\mathrm{UV}}/(2(4\pi)^2)$、$\delta_g=0$ を得た。これは式~\eqref{eq:ct4} の再現である。

最後に有限部分を $\overline{\mathrm{MS}}$ で比べた。基準点は $m=\mu=1$ である。FeynCalc の振幅 $A_n$ を $V_n=A_n/(2\pi)^D$ に直し、上の $\overline{\mathrm{MS}}$ の対抗項を加えて $\epsilon\to0$ とすると、繰り込まれた $V_n$ が得られる。その中の PaVe 関数を Package-X（\texttt{PaXEvaluate}）と LoopTools（\texttt{LToolsEvaluate}）のそれぞれで評価し、式~\eqref{eq:VR4} の係数で割って $\overline{\mathrm{MS}}$ の $B_0$ を取り出した。タドポールにも同じ引き算を施して $A_0$ を取り出した。記号のままでも、こうして得た値は $A_0=m^2(1-\ln(m^2/\mu^2))$ と $B_0(0;m,m)=-\ln(m^2/\mu^2)$ を再現し、$V_3$ は式~\eqref{eq:VR4} と記号として一致した。FeynCalc の PaVe 関数の $\epsilon^0$ の係数だけを読むと、$B_0^{\mathrm{FC}}=1/\epsilon-\gamma_E-\ln\pi+B_0$ のように $\overline{\mathrm{MS}}$ の値からずれる。このずれ $-\gamma_E-\ln\pi$ は、測度 $\dd^Dq/(2\pi)^D$ の $(2\pi)^{2\epsilon}$ が極と掛け合わさって出る $+\ln4\pi^2$ と、$\overline{\mathrm{MS}}$ の引き算から出る $-\ln4\pi+\gamma_E$ で打ち消される。COLLIER は既定（$\Delta_{\mathrm{UV}}=0$、$\mu=1$）で $\overline{\mathrm{MS}}$ の値を返すので、そのまま比べた。$C_0$ は有限なので、どのツールでもその値をそのまま比べた。$B_0$ の基準値は\ref{app:b0} で導く閉じた式で、これは30桁で計算した Feynman パラメータ積分とも相対 $10^{-17}$ 以下で一致する。$p^2/m^2=-10$ から $30$ までの15点で、Package-X・LoopTools・COLLIER の値は、いずれも閉じた式と相対 $7.3\times10^{-15}$ 以内で一致した（表~\ref{tab:oneloop4}、図~\ref{fig:b0}）。閾値より上の6点では、三つとも虚部が $\mathrm{Im}\,B_0=\pi\beta$（$\beta=\sqrt{1-4m^2/p^2}$）を相対 $2\times10^{-15}$ 以内で満たした。これは光学定理の表れで、繰り込まれた自己エネルギー $\Sigma\equiv iV_2$ について $\mathrm{Im}\,\Sigma=-\sqrt{p^2}\,\Gamma(\phi^*\to\phi\phi)$ と書ける（\ref{app:b0}）。$C_0$ の基準値は、閾値より下の点では Feynman パラメータの2重積分（30桁）、閾値より上の点では Package-X とした。

この比較で、ツールの不具合と制限が三つ見つかった。第一に、この Mac でビルドした LoopTools 2.16 は、閾値より下で外運動量がゼロでない $C_0$ を誤って返す。例えば $C_0(1,1,1)$ は $-0.671253$ であるべきところ、$6.872+34.19\,i$ となる。Fortran から直接呼ぶと計算が終わらない。この振る舞いは gfortran 14 と 15、最適化の有無のいずれでも変わらない。LoopTools の $A_0$、$B_0$ と、閾値より上の $C_0$ は正しい。第二に、COLLIER の $C_0$ は外運動量がすべて厳密にゼロの場合を扱わず（エラー出力は ``case not implemented''）、番兵値 $10^{50}$ を返す。運動量をわずかにずらせば正しい極限に近づく。第三に、FeynHelpers で Package-X の $C_0$ を展開した式（\texttt{PaXC0Expand -> True}）は、適用範囲付きの式（\texttt{ConditionalExpression}）で、閾値より下では値を持たない。Package-X 本体の数値関数 \texttt{ScalarC0} は全点で正しく評価できたので、それを使った。

\paragraph{手順 (4)：$d=6$ の1ループ。}図は $d=4$ と同じで、FeynCalc の振幅も式~\eqref{eq:A123} の形のままである。ただし、その PaVe 関数を $D=6-2\epsilon$ 次元の積分として読む。ここでも三つの観点から確かめた。

まず極と対抗項である。FeynCalc の \texttt{FCFeynmanParametrize} で、スカラー積分 $I_1,I_2,I_3$ を $D=6-2\epsilon$ の Feynman パラメータ表示に直した。被積分関数と前因子は、ランダムに選んだ3点（$\epsilon=1/7$）で式~\eqref{eq:IN-general} と30桁で一致した。極の部分を Feynman パラメータで積分すると、表~\ref{tab:poles} の $d=6$ の列が記号として再現された。$V_2$ と $V_3$ の極を消す条件から決めた $\overline{\mathrm{MS}}$ の対抗項は式~\eqref{eq:ct6} と一致し、それから計算した $\beta(g)$ は式~\eqref{eq:beta6} と一致した。

次に、Package-X・LoopTools・COLLIER を $d=6$ に使う方法である。これらは $D=4-2\epsilon$ の積分しか扱わない。しかし、$D+2$ 次元のスカラー積分は、$D$ 次元のテンソル積分の $g^{\mu\nu}$ の係数に比例する（\ref{app:d6}）。FeynCalc の規格化では $\mathrm{PaVe}^{(D+2)}=-2\pi\,\mathrm{PaVe}_{00}^{(D)}$、すなわち $6-2\epsilon$ 次元の $A_0$、$B_0$、$C_0$ は、$4-2\epsilon$ 次元の $A_{00}$、$B_{00}$、$C_{00}$ の $-2\pi$ 倍である。$A_n$ の PaVe 関数をこの関係で置き換えて Package-X で評価すると、$V_1$、$V_2$、$V_3$ の極は上の結果と記号として一致し、有限部分も式~\eqref{eq:X6} の $A_0^{(6)}$ と式~\eqref{eq:B06} を記号として再現した。LoopTools と COLLIER では、$\overline{\mathrm{MS}}$ の有限部分が $X_N=-2\,T_{00}$（$T_{00}$ は $\Delta=0$ での $A_{00}$、$B_{00}$、$C_{00}$）として直接得られる。

\paragraph{手順 (5)：$d=4$ の1ループの $\phi\phi\to\phi\phi$。}二つの独立な経路で振幅を作った。一つは、これまでと同じく、FeynCalc 用にパッチを当てた FeynArts と FeynCalc である。もう一つは、パッチを当てない FeynArts 3.12 と FormCalc 9.10 で、FeynRules が書き出した模型をそのまま読み込める。どちらでも図は12個（箱図3、三角形6、内線の自己エネルギー3）で、対称性因子は図~\ref{fig:scat} のとおりだった。振幅は、どちらの経路でも式~\eqref{eq:M1} と記号として一致した。FeynCalc の出力では4本目の外線の $p^2$ が $s+t+u-3m^2$ の形で残るので、$s+t+u=4m^2$ を使って $m^2$ に直した。FormCalc の出力は、LoopTools の規格化の $B_0$、$C_0$、$D_0$ で書かれた式~\eqref{eq:M1} の形そのものである。発散は内線の $B_0$ からだけ生じ、式~\eqref{eq:ct4} の対抗項で消えた。FeynCalc では Package-X で極を取り出して、FormCalc では LoopTools の $\Delta$ を $0$ と $1$ にして、それぞれ確かめた。

数値は、物理的な散乱の6点（$\sqrt s=2.5m,\,5m,\,10m$ と $\cos\theta=0.3,\,0.9$）で比べた（表~\ref{tab:scat4}、図~\ref{fig:scat4}）。FeynCalc の振幅は、Package-X（$B_0$ は解析式、$C_0$ と $D_0$ は数値関数）と LoopTools で評価した。FormCalc の振幅は LoopTools で評価した。さらに COLLIER の積分から式~\eqref{eq:M1} を組み立てた。実部は、LoopTools（二つの経路とも）と COLLIER が相対 $2\times10^{-15}$ 以内で一致し、Package-X とは相対 $2.2\times10^{-11}$ 以内で一致した。Package-X の $D_0$ の数値関数は、内部のコンパイル済み関数で数値誤差を起こしてコンパイルしない計算に切り替わる（警告が出る）ので、精度がやや落ちたと考えられる。虚部は、四つの経路すべてが式~\eqref{eq:unit} の2重積分（20桁）と相対 $6\times10^{-14}$ 以内で一致した。式~\eqref{eq:unit} の積分は、前方では手順 (2) の断面積の式~\eqref{eq:sigma} から計算した $2p\sqrt s\,\sigma$ とも相対 $10^{-15}$ 以下で一致した。$g=m=1$ では、$|\mathcal{M}^{(1)}|$ は $|\mathcal{M}^{(0)}|$ の $0.3$〜$1.1\%$ である。

この手順では、4点関数 $D_0$ を扱える範囲がライブラリごとに違うことも分かった。外線と内線の質量がすべて等しい今回の運動学で、LoopTools は前方 $t=0$ で値を返さなかった（FF の実装がこの場合を「閾値上の退化した場合」として扱えない）。COLLIER も $t=0$ では番兵値 $10^{50}$ を返した。$s,t,u$ がすべて $4m^2$ より小さい非物理的な点（例えば $s=2m^2$、$t=-m^2$）では、Package-X の数値関数が不定（\texttt{Indeterminate}）になり、COLLIER は致命的エラーで停止した。そのため、比較はどのライブラリも値を返す物理的な点に限り、前方の光学定理の代わりに、任意の角度で使える式~\eqref{eq:unit} で虚部を確かめた。手順 (3) で見つかった LoopTools の $C_0$ の誤りは、この振幅に現れる $C_0(m^2,m^2,x)$（$x<0$ または $x>4m^2$）では起きなかった。なお、FeynHelpers の \texttt{LToolsEvaluate} は、倍精度の数を係数に持つ $B_0$ をテンソル積分と誤認して警告を出す（値は正しい）。そこで、運動学は有理数のまま渡した。

\paragraph{手順 (6)：MadLoop との比較。}MadLoop 自身は繰り込みの処方を持たない。紫外発散を消す対抗項は、UFO の対抗項の頂点から来る。そこで、FeynRules に付属する NLOCT 1.02 で、対抗項を含む UFO を三つの段階で作った。(i) FeynRules で \texttt{OnShellRenormalization} を使い、$\phi\to(1+\frac12\delta Z)\phi$、$m\to m+\delta m$、$g\to g+\delta g$ と置いたラグランジアンを FeynArts の模型として書き出す。(ii) FeynRules を読み込まない別のカーネルで、パッチなしの FeynArts と NLOCT の \texttt{WriteCT} で対抗項を求める。NLOCT の既定では、質量と場は on-shell、結合は $\overline{\mathrm{MS}}$ で繰り込まれる。(iii) FeynRules に戻って、対抗項を含む UFO を書き出す。NLOCT の質量の対抗項は $m$ のずれ $\delta m$ で書かれるので、2点の対抗項は $i[\delta Z(p^2-m^2)-2m\,\delta m]$ である。\ref{app:lsz} の記号との関係は $\delta Z=\delta_Z^{\mathrm{os}}$、$2m\,\delta m=\delta_m^{\mathrm{os}}-\delta_Z^{\mathrm{os}}m^2=-\Sigma_0(m^2)$ である。NLOCT が求めた値は、$\delta Z=-\frac{g^2}{2(4\pi)^2}B_0'(m^2)$、$2m\,\delta m=\frac{g^2}{2(4\pi)^2}\bigl[\frac1\epsilon+B_0(m^2)\bigr]$、頂点の対抗項 $-\frac32ig\,\delta Z$ で、いずれも\ref{app:lsz} と記号として一致した。$g$ は発散を持たないので、$\overline{\mathrm{MS}}$ の $\delta g$ は0になる。つまり NLOCT の処方は、\ref{app:lsz} で $g$ を裸の結合で定義した on-shell の処方そのものである。この on-shell の UFO に加えて、2点の対抗項の極だけを残した UFO も作った。これは式~\eqref{eq:ct4} の $\overline{\mathrm{MS}}$ の対抗項（$\delta_Z=\delta_g=0$）にあたる。

この過程で、ツールの不具合と制限が七つ見つかり、次のように回避した。(1) NLOCT の関数 \texttt{OnShell\allowbreak Renormalization} は、場の混合を一つも持たない模型では、混合を扱う段階で項の和でなく積を分解してしまい、途中で止まる。FeynRules の \texttt{Core/Loop.m} に局所パッチを当て、混合の項がないときはこの段階を飛ばした（元のファイルは \texttt{Loop.m.orig}）。(2) FeynRules は、flavor を展開しないと FeynArts の模型の場の対応表 \texttt{FR\$ClassesTranslation} を空にする。すると NLOCT は \texttt{S[1]} が \texttt{phi} だと分からず、$\phi$ の $\delta Z$ を0と置いてしまい、$\delta Z$ が決まらない。FeynArts の模型を \texttt{FlavorExpand -> True} で書き出して避けた。(3) R2 の頂点がない（スカラー理論）とき、NLOCT は不正な \texttt{R2\$vertlist = \{Last[\{\}]\}} を書く。読み込んだ後で空のリストに直した。(4) NLOCT の \texttt{MSbar -> True} は、この模型では2点の対抗項から因子 $-i$ が抜け、MadLoop で極が消えない。そこで $\overline{\mathrm{MS}}$ の対抗項は、on-shell の対抗項の極の部分を取り出して作った。(5) FeynRules の UFO は既定で \texttt{gauge = [0]}（ユニタリーゲージだけ）と書き、MadGraph はそのような模型では QCD 以外のループを生成しない。ゲージ場のない模型なので、\texttt{FeynmanGauge = True} として \texttt{gauge = [0, 1]} と書かせた。(6) MadGraph 3.8.1 の1ループ用インターフェースは、摂動の次数として QCD と QED しか受け付けない。作業用の UFO のコピーで、結合の次数の名前 \texttt{PHI} を \texttt{QCD} に変えた。色を持つ粒子はないので、これは名前だけの変更である。(7) MadLoop の単体の検査プログラムは、位相空間の点ごとに $\mu_R=\sqrt s$ と置き直す。生成されたプログラムを書き換え、$\mu_R$ をファイルから読むようにした。

MadGraph は、Born の図3つ、ループの図12個、対抗項の図（on-shell で12個、$\overline{\mathrm{MS}}$ で3つ）を生成した。ループの図は手順 (5) の12個と同じで、タドポールと外線の自己エネルギーは MadGraph が既定で除く。MadLoop の行列要素は終状態の同種粒子の因子 $\frac12$ を含み、Born は $|\mathcal{M}^{(0)}|^2/2$、1ループの有限部分は $2\,\mathrm{Re}(\mathcal{M}^{(0)*}\mathcal{M}^{(1)})/2=\mathcal{M}^{(0)}\,\mathrm{Re}\,\mathcal{M}^{(1)}$ である。手順 (5) と同じ6点（$m=g=1$）で比べると、Born は相対 $10^{-15}$ 以下で一致し、$1/\epsilon$ と $1/\epsilon^2$ の係数は $4\times10^{-19}$ 以下で消えた（表~\ref{tab:madloop}）。有限部分は、on-shell の対抗項では式~\eqref{eq:Mphys} から作った $\mathcal{M}^{(0)}\,\mathrm{Re}\,\mathcal{M}^{(1)}_{\mathrm{phys}}$ と、$\overline{\mathrm{MS}}$ の対抗項では式~\eqref{eq:M1} から作った値と、どちらも相対 $3.1\times10^{-13}$ 以内で一致した。最大のずれは、有限部分が相殺で小さくなる $\sqrt s=10m$、$\cos\theta=0.3$ で生じる。$\sqrt s=5m$、$\cos\theta=0.3$ で $\mu_R$ を $m/2$ から $5m$ まで変えると、on-shell の値は全桁で変わらず、$\overline{\mathrm{MS}}$ の値は $B_0$ の $\ln\mu_R^2$ から予想されるとおりに変わった。on-shell と $\overline{\mathrm{MS}}$（$\mu_R=m$）の値の比はこの点で $1.39$ で、式~\eqref{eq:Mphys} の処方の変換の項が、MadLoop の結果でも同じ大きさで現れている。

\paragraph{手順 (7)：全断面積。}$m_{\mathrm p}=g=1$ として、式~\eqref{eq:sigmatot} の三つの項を $\sqrt s=2.2m$ から $20m$ まで求めた（表~\ref{tab:xsec}、図~\ref{fig:xsec}）。$\sigma^{(1)}$ の角度積分では、COLLIER で $\overline{\mathrm{MS}}$ の $\mathcal{M}^{(1)}$（$\mu=m$）を求め、式~\eqref{eq:Mphys} の処方の変換を足した。被積分関数は $\cos\theta\to-\cos\theta$ で対称なので、$0\le\cos\theta\le1$ で積分して2倍した。$\sqrt s$ が大きいと、$t$ チャンネルの伝播関数のために被積分関数は前方の幅 $\sim m^2/(2p^2)$ に集中する。そこで変数を $y=\ln((m^2-t)/m^2)$ に替えて Gauss--Legendre の求積を使った（\ref{app:sigma}）。分点を32から64に増やしても、$\sigma^{(1)}$ は相対 $10^{-14}$ 以下しか変わらなかった。$\sqrt s=2.5m,\,5m,\,10m$ では同じ分点で MadLoop を走らせて積分し、$\sigma^{(0)}$ と $\sigma^{(1)}$ がどちらも相対 $7\times10^{-15}$ 以内で一致した。$\sigma^{(1)}/\sigma^{(0)}$ は閾値の近くで $2\%$ と大きく、高いエネルギーでは $0.94\%$ に近づく。

$\sigma_{2\to3}$ は、3体の位相空間 $\dd\Phi_3=\dd\Phi_2(P;k_1,Q)\,\frac{\dd Q^2}{2\pi}\,\dd\Phi_2(Q;k_2,k_3)$ をモンテカルロ積分して求めた（\ref{app:sigma}）。最初に一様なサンプリングで計算すると、$\sqrt s=10m$ では乱数の種を変えた結果が表示された誤差の2倍ほどばらつき、点数を増やすと値が上がっていった。$\sqrt s$ が大きいと、断面積の大部分を、二つの粒子がほぼビームの向きに出て二つの $t$ チャンネル型の伝播関数がともに小さくなる狭い領域が担うためである。そこで、格子を被積分関数に合わせる VEGAS 型の重点サンプリング（Lepage の方法）を numpy で書いて使った。さらに検算として、$\vec k_1$ と $\vec k_2$ の向きを変数にとり、$|\vec k_2|$ をエネルギー保存から解く別の変数の取り方でも積分した。二つの結果は、$\sqrt s=4m,\,5m,\,10m$ で統計誤差の1.1倍以内で一致した。MadGraph の行列要素は、自前の $|\mathcal{M}|^2/3!$ と同じ点で相対 $10^{-15}$ まで一致した。MadGraph の断面積は、$\sqrt s=4m$ と $5m$ では自前の値と統計誤差の0.5倍以内で一致した。ところが $\sqrt s=10m$ では、乱数の種と積分の設定（\texttt{sde\_strategy}、\texttt{hard\_survey}）を変えた5回の結果が $9.165$〜$9.260$~pb とばらついた。このばらつき（標準偏差 $0.036$~pb）は表示された誤差（約 $0.01$~pb）より大きく、平均 $9.220$~pb は自前の二つの値（$9.295\pm0.005$、$9.305\pm0.008$~pb）より $0.8\%$ 低い。行列要素は一致しているので、この差は MadGraph の位相空間の積分から来ていると考えられるが、原因は突き止めていない。自前の値は、異なる二つの変数の取り方で一致することを根拠に採った。

$g=m$ では、$\sigma_{2\to3}/\sigma^{(0)}$ は閾値 $\sqrt s=3m$ から増え、$\sqrt s=20m$ で $2\%$ になる。$\sigma^{(0)}$ が $1/s^2$ のように速く減るのに対し、$2\to3$ はゆっくりとしか減らないからである。表の値を内挿すると、$\sqrt s$ が約 $8.6m$ を超えると $2\to3$ が1ループの補正より大きくなる。すべての比は $g^2/m^2$ に比例し、ループの因子 $g^2/(16\pi^2m^2)\approx6\times10^{-3}$ の程度である。

\paragraph{手順 (8)：$d=6$ の1ループの $\phi\phi\to\phi\phi$。}FeynArts と FeynCalc で作った振幅は $d=4$ と同じ式で、その PaVe 関数を $D=6-2\epsilon$ 次元の積分と読む。手順 (4) の次元をずらす関係を4点関数まで使い、$D_0$、$C_0$、$B_0$ を $4-2\epsilon$ 次元の $D_{00}$、$C_{00}$、$B_{00}$ の $-2\pi$ 倍に置き換えて Package-X で評価した。Package-X は $D_{00}$ を FeynCalc の簡約で $D_0$ と $C_0$ に直してから評価する。振幅の極は、内線の2点の対抗項と頂点の対抗項（式~\eqref{eq:ct6}）を加えると記号として消え、$\overline{\mathrm{MS}}$ の振幅は式~\eqref{eq:M6} と記号として一致した。FormCalc は4次元の積分しか評価しないので、今回は使わなかった。MadLoop も4次元専用である。

数値は、手順 (5) と同じ6点で $\mu=m/2,\,m,\,2m$ として求めた（表~\ref{tab:scat6}、図~\ref{fig:scat6}）。LoopTools の $D_{00}$ と COLLIER の $D_{00}$、$C_{00}$、$B_{00}$ からも式~\eqref{eq:M6} を作った。実部は、LoopTools と COLLIER が相対 $10^{-13}$ 以内で一致した。Package-X とは最大 $1.4\times10^{-10}$ ずれたが、これは $\sqrt s=2.5m$、$\cos\theta=0.9$ で $\mathrm{Re}\,\mathcal{M}^{(1)}$ が大きな項の相殺で小さくなる点での値で、絶対的なずれは $2\times10^{-14}$ である。$d=4$ でも見た、Package-X の $D_0$ の数値関数の精度の限界と考えられる。虚部は、三つのツールすべてが $d=6$ のユニタリー性の2重積分（20桁）と相対 $1.5\times10^{-11}$ 以内で一致した。このユニタリー性の積分は、前方では $d=6$ の木の断面積から計算した $2p\sqrt s\,\sigma_{\mathrm{tree}}$ と相対 $10^{-14}$ 以下で一致し、6次元の角度の測度の検算にもなっている。

\paragraph{手順 (9)：繰り込み群。}S 行列要素は物理量なので、それをどのパラメータで書いても $\mu$ によらない。そこで、手順 (5) と (8) の6点で、ツールが返す $\mathcal{M}^{(1)}$ の $\mu$ 依存から、質量の走りと $\beta$ 関数を同時に読み取った。質量のパラメータ $m$（$\overline{\mathrm{MS}}$ の $m(\mu)$ または極質量 $m_{\mathrm p}$）と $\overline{\mathrm{MS}}$ の結合 $g(\mu)$ で書いた S 行列要素を $\mathcal{M}^{(0)}(m,g)+Y(\mu)+O(g^6)$ とする。$Y$ は、$\mathcal{M}^{(1)}$ に S 行列要素への変換を足した1ループの部分である。式~\eqref{eq:Mtree} の $\mathcal{M}^{(0)}$ を $m^2$ と $g$ で微分すると、$-g^2A$ と $-2gB$ になる。ここで $A\equiv\sum_x(x-m^2)^{-2}$、$B\equiv\sum_x(x-m^2)^{-1}$ である。よって、$\mu$ によらない条件は
\begin{equation}
\mu\frac{\partial Y}{\partial\mu}=g^2A\,\gamma+2gB\,\beta,\qquad\gamma\equiv\mu\frac{\dd m^2}{\dd\mu}
\label{eq:rgfit}
\end{equation}
となる（\ref{app:rg}）。$A$ と $B$ の比は点ごとに違うので、6点の左辺から $\gamma$ と $\beta$ が最小二乗で決まる。左辺は $\mu=m/2$ と $2m$ の値の差から求めた。$Y$ は $\ln\mu$ の1次式なので、この差は微分を正確に与える。次の四つの場合を調べた。(i) $d=4$、$\overline{\mathrm{MS}}$ の $m$。$Y$ は $\mathcal{M}^{(1)}$ に留数の項 $\frac{g^4}{(4\pi)^2}\sum_xB_0'(m^2)/(x-m^2)$ を足したもので、予想は式~\eqref{eq:mrun4} の $\gamma=g^2/(4\pi)^2$ と $\beta=0$ である。(ii) $d=4$、極質量。$Y=\mathcal{M}^{(1)}_{\mathrm{phys}}$（式~\eqref{eq:Mphys}）で、$m_{\mathrm p}$ も $g$ も走らないので、予想は $\gamma=\beta=0$ である。(iii) $d=6$、極質量。$Y=\mathcal{M}^{(1)}_{\mathrm{phys}}$（\ref{app:scat6}）で、予想は $\gamma=0$ と式~\eqref{eq:beta6} の $\beta$ である。手順 (8) では $\gamma=0$ を仮定して $\beta$ を求めたが、ここでは $\gamma=0$ も確かめる。(iv) $d=6$、$\overline{\mathrm{MS}}$ の $m$。$Y$ は $\mathcal{M}^{(1)}_{d=6}$ に $\frac{g^4}{(4\pi)^3}\sum_xB_0^{(6)\prime}(m^2)/(x-m^2)$ を足したもので、予想は第~\ref{sec:results} 節の $\gamma=-5g^2m^2/(6(4\pi)^3)$ と式~\eqref{eq:beta6} の $\beta$ である。

$d=4$ の値は次のように求めた。手順 (5) と同じ FeynCalc の振幅を Package-X と LoopTools で評価し、COLLIER の積分からも式~\eqref{eq:M1} を組み立てた。どちらも $\mu=m/2,\,m,\,2m$ で求めた。さらに、手順 (6) の極だけの $\overline{\mathrm{MS}}$ の対抗項を使った MadLoop を $\mu_R=\mu$ として走らせ、有限部分を $\mathcal{M}^{(0)}$ で割って $\mathrm{Re}\,\mathcal{M}^{(1)}$ とした。MadLoop の質量のパラメータは、スケール $\mu_R$ での $\overline{\mathrm{MS}}$ の質量にあたる。18個の値の実部は、COLLIER との相対的なずれが LoopTools で $3\times10^{-15}$、MadLoop で $1.7\times10^{-13}$、Package-X で $3.9\times10^{-11}$ 以内だった。虚部は $\mu$ によらず、三つのツールで全桁が同じだった。$d=6$ の値は手順 (8) のものを使った。

結果を表~\ref{tab:rg} に示す。四つの場合のすべてのツールで、$\gamma$ と $\beta$ は予想と相対 $1.3\times10^{-15}$ 以内で一致した。0になるべき量は、ループの因子 $(4\pi)^{-d/2}$ を単位として $1.7\times10^{-15}$ 以下だった。6点を式~\eqref{eq:rgfit} で表したときの残差も、1ループの傾きの大きさの $5\times10^{-16}$ 以下である。$\mu=m$ の $Y$ が両端の平均と相対 $10^{-14}$ 以下で一致することから、$Y$ が $\ln\mu$ の1次式であることも確かめた。手順 (8) と同じく、この一致は数値の精度というより、対抗項、振幅、S 行列要素への変換、各ツールの $\mu$ の約束が整合していることの検算である。(i) では、$\mu_R$ を変えたときの MadLoop の値が $\overline{\mathrm{MS}}$ の質量の走りを正しく含むことも確かめられた。(iv) の質量の走りは、裸の質量が $\mu$ によらない条件（\ref{app:ren}）からも、極質量が $\mu$ によらない条件（\ref{app:rg}）からも導ける。

図~\ref{fig:rg4} は、$d=4$、$\sqrt s=5m$、$\cos\theta=0.3$ で、$\overline{\mathrm{MS}}$ の $m$ で書いた S 行列要素の $\mu$ を $m/4$ から $4m$ まで変えたものである。図~\ref{fig:scat6rg} と同じ形式で、$d=6$ の $g$ の代わりに $m$ を走らせる。$m$ を固定すると、$\mu=m/4$ から $4m$ までで相対 $2.5\times10^{-3}$ 変わる。$m(\mu)$ を式~\eqref{eq:mrun4} で走らせると、$\mu=m$ からのずれは最大 $1.0\times10^{-6}$（$g^6$ の残り）に縮む。この残りは木の振幅を $m^2$ について2次まで展開した項で、$\ln\mu$ の偶関数なので、両端の値はほぼ等しい（\ref{app:rg}）。

確かめた係数を使い、無次元のパラメータの空間での繰り込み群の流れを描いた（図~\ref{fig:rgflow}）。$\hat m^2\equiv m^2/\mu^2$ と、ループの展開のパラメータ $\hat\alpha$（$d=4$ では $g^2/((4\pi)^2\mu^2)$、$d=6$ では $g^2/(4\pi)^3$）を使い、$t\equiv\ln\mu$ と書くと
\begin{equation*}
d=4:\ \ \frac{\dd\hat\alpha}{\dd t}=-2\hat\alpha,\quad\frac{\dd\hat m^2}{\dd t}=\hat\alpha-2\hat m^2;\qquad
d=6:\ \ \frac{\dd\hat\alpha}{\dd t}=-\frac32\hat\alpha^2,\quad\frac{\dd\hat m^2}{\dd t}=-\Bigl(2+\frac56\hat\alpha\Bigr)\hat m^2
\end{equation*}
である（\ref{app:rg}）。図の軌道は、表~\ref{tab:rg} の COLLIER の $\gamma$ と $\beta$ から作った係数で描いた。その係数は、上の式の $1$、$-3/2$、$-5/6$ と相対 $6\times10^{-16}$ 以内で一致する。どちらの次元でも、固定点は原点（自由な理論）だけで、紫外（$\mu\to\infty$）ではすべての軌道が原点に向かう。違いは近づき方にある。$d=4$ では、$\hat\alpha$ と $\hat m^2$ がどちらも $\mu^{-2}$ の程度で小さくなる。二つの質量次元が等しいので、1ループの混合は固有値が重なった線形の流れ（Jordan 標準形）になり、解に $t\,e^{-2t}$ の項、すなわち質量の走りの $\ln\mu$ が現れる。$\hat m^2/\hat\alpha$ は $t$ とともに増え続けるので、軌道は $\hat m^2$ 軸に接して原点に入る。$d=6$ では、$\hat\alpha$ は $1/\ln\mu$ のようにしか小さくならない（漸近自由）。$\hat m^2$ は $\mu^{-2}$ で小さくなるので、軌道は $\hat\alpha$ 軸に接して原点に入る。$\hat m^2=0$ の直線は、$d=6$ では流れで保たれる（質量が掛け算の形で繰り込まれる）が、$d=4$ では保たれない（質量の走りが $g^2$ に比例する加法的なもの）。赤外では、$d=6$ の $\hat\alpha$ は有限の $\mu$ で発散する（1ループの Landau 極）。$d=6$ の流れは1ループのもので、$\hat\alpha\ll1$ でだけ信頼できる。一方、$d=4$ の流れは、べき数え上げから $\overline{\mathrm{MS}}$ では全次数で正しい（\ref{app:rg}）。基準点（$\mu=m$ で $m=g=1$）は $\hat m^2=1$、$\hat\alpha=6.3\times10^{-3}$（$d=4$）または $5.0\times10^{-4}$（$d=6$）で、どちらの次元でも $\hat m^2$ 軸のすぐ近くにある。

\paragraph{手順 (10)：$d=6$ の場の異常次元と文献との照合。}場の異常次元 $\gamma_\phi$ は S 行列要素には現れないので、手順 (9) の方法では読み取れない。そこで、繰り込まれた1PI 関数の $\mu$ 依存を使った。$\phi_0=Z^{1/2}\phi$ なので、$n$ 点の1PI 関数は $\Gamma^{(n)}=Z^{n/2}\Gamma^{(n)}_0$ で、裸の $\Gamma^{(n)}_0$ が $\mu$ によらないことから $\mu\,\dd\Gamma^{(n)}/\dd\mu=n\gamma_\phi\Gamma^{(n)}$ となる。1ループでは、$\Gamma^{(2)}=p^2-m^2-\Sigma$ と $\Gamma^{(3)}=-g+g^3C_0^{(6)}/(4\pi)^3$ について
\begin{equation}
-\mu\frac{\partial\Sigma}{\partial\mu}=\gamma+2\gamma_\phi\,(p^2-m^2),\qquad
\beta=\frac{g^3}{(4\pi)^3}\,\mu\frac{\partial C_0^{(6)}}{\partial\mu}+3g\,\gamma_\phi
\label{eq:anom}
\end{equation}
が成り立つ（\ref{app:anom}）。第1式の左辺は $p^2$ の1次式で、その傾きが $\gamma_\phi$ を、$p^2=m^2$ での値が質量の走り $\gamma$ を与える。第2式は、3点関数から $\beta$ を与える。

数値は、手順 (4) と同じく次元をずらす関係を使って求めた。$\Sigma=-\frac{g^2}{2(4\pi)^3}B_0^{(6)}$ の有限部分は、$p^2=-5m^2$ から $8m^2$ までの8点（閾値の上の2点を含む）で求めた。$C_0^{(6)}$ は4点で求めた。どちらも Package-X・LoopTools・COLLIER で、$\mu=m/2,\,m,\,2m$ について計算した。$B_0^{(6)}$ は、三つのツールと式~\eqref{eq:B06} が相対 $2.2\times10^{-14}$ 以内で一致した。$C_0^{(6)}$ は、Package-X と COLLIER が $2.2\times10^{-12}$ 以内で一致した。LoopTools の $C_0^{(6)}$ は閾値より下で値が誤っている（手順 (3)、(4)）が、その $\mu$ 依存は正しかった。$C_{00}$ の $\mu$ 依存は、紫外の発散と同じく $B_0$ からだけ来て、誤りのある $C_0$ は $\mu$ によらないからである。

式~\eqref{eq:anom} の第1式を8点の傾きに最小二乗で当てはめた。三つのツールで $\gamma_\phi=4.1994185460\times10^{-5}$、$\gamma=-4.1994185460\times10^{-4}$（$m=g=1$）となり、予想 $g^2/(12(4\pi)^3)$、$-5g^2m^2/(6(4\pi)^3)$ と相対 $2\times10^{-16}$ 以内で一致した（表~\ref{tab:anom6}、図~\ref{fig:anom6}）。$\mu\,\partial C_0^{(6)}/\partial\mu$ はどの点でも $-1$ だった（点ごとのばらつきは $10^{-15}$ 以下）。第2式からは $\beta=-3.7794766914\times10^{-4}$ が相対 $6\times10^{-16}$ で得られた。虚部は $\mu$ によらなかった。手順 (9) で S 行列要素から読み取った質量の走りと $\beta$ は、1PI 関数という別の経路でも相対 $10^{-15}$ で再現された。

最後に、三つの RG 関数を文献と照合した。Borinsky、Gracey、Kompaniets、Schnetz~\cite{bgks} は、$d=6-\epsilon$ の次元正則化と $\overline{\mathrm{MS}}$ で、$\phi^3$ 理論の RG 関数を5ループまで求めている。定義は $\beta=\mu\,\partial g/\partial\mu$、$\gamma_\phi=\mu\,\partial\ln Z_\phi/\partial\mu$（$\phi_0=Z_\phi\phi$）、$\gamma_{m^2}=\mu\,\partial\ln Z_{m^2}/\partial\mu$（$m_0^2=m^2Z_{m^2}$）である。$Z_\phi=Z^{1/2}$ なので $\gamma_\phi$ の定義は本ノートと同じで、$\mu\,\dd\ln m^2/\dd\mu=-\gamma_{m^2}$ である。同論文は結果を、結合を純虚数にした Lee--Yang 型の理論（$g_0\to ig_0$）について書いており、1ループの項は $\beta=\frac34g^3$、$\gamma_\phi=-\frac1{12}g^2$、$\gamma_{m^2}=-\frac56g^2$ である。$g\to ig$ を戻すと $g^2$ の符号が変わり、$\beta=-\frac34g^3$、$\gamma_\phi=\frac1{12}g^2$、$\gamma_{m^2}=\frac56g^2$ となる（\ref{app:anom}）。同論文の $g^2$ を本ノートの $g^2/(4\pi)^3$ に対応させると、これらは式~\eqref{eq:beta6}、上の $\gamma_\phi$、質量の走り $-5g^2m^2/(6(4\pi)^3)$ と符号まで一致する。三つの比 $\frac34:\frac1{12}:\frac56$ は結合の規格化によらないので、この一致は規格化の選び方による偶然ではない。三つの RG 関数は式~\eqref{eq:ct6} の三つの係数 $\delta_Z$、$\delta_m$、$\delta_g$ を決める（\ref{app:anom}）。したがって、この一致は式~\eqref{eq:ct6} の文献による検算にもなっている。

\section{議論と今後}\label{sec:discussion}

\paragraph{決まっていないこと。}有限部分の規約は $\overline{\mathrm{MS}}$ とした。物理的な質量や留数を直接与える on-shell 条件で繰り込む場合は、$\overline{\mathrm{MS}}$ との差が有限の対抗項になり、$d=4$ でも $\delta_Z$ に有限の寄与が生じる。$\phi\phi\to\phi\phi$ については、on-shell の処方との関係を式~\eqref{eq:Mphys} と\ref{app:lsz} で求めた。$d=6$ の有限部分は、次元をずらす関係を通して Package-X と COLLIER でも検算できた。ただし、この関係で扱えるのは1ループの PaVe 関数である。2ループ以上の $d=6$ の積分を数値で確かめるには、2ループ用に推奨された pySecDec などが要る~\cite{review}。

\paragraph{タドポールの扱い。}本ノートでは、$Y$ でタドポールを打ち消す方法をとった。これは1ループでは、FeynArts でタドポールの位相（\texttt{Tadpoles}）を除くことと同じである。2ループ以上では、ループの内側にタドポールが付いた図も $Y$ の高次の項で消えるので、同じ除き方で済むかどうかを確かめる必要がある。

\paragraph{LoopTools の $C_0$。}手順 (3) で見つかった LoopTools の $C_0$ の誤りは、コンパイラの版や最適化によらない。そのため、この Mac（Apple M3）上での LoopTools 2.16 の問題である可能性が高いが、原因は突き止めていない。この誤りは $C_{00}$ を通して $d=6$ の $C_0^{(6)}$ にも現れた。当面、$C_0$ と $C_{00}$ には Package-X と COLLIER を使い、LoopTools は $A_0$、$B_0$ と、それから作る $A_{00}$、$B_{00}$ にだけ使う。ただし、手順 (5) に現れた $C_0(m^2,m^2,x)$（$x<0$ または $x>4m^2$）と $D_0$（物理的な点）は、LoopTools でも正しかった。Fortran から \texttt{C0(1D0,1D0,1D0,1D0,1D0,1D0)} を呼ぶと止まるという最小の再現例があるので、開発者に報告できる。

\paragraph{今後。}第~\ref{sec:plan} 節の手順 (1)〜(10) はすべて終わった。次の候補は三つある。一つ目は、$d=4$ の2ループの自己エネルギーを計算し、1ループの対抗項の挿入だけで有限になることを確かめることである。これは、$d=4$ の繰り込み群の流れが全次数で正しいという\ref{app:rg} の主張を直接確かめる。二つ目は、手順 (7) で見つかった、$\sqrt s=10m$ の $2\to3$ での MadGraph の $0.8\%$ のずれの原因を調べることである。三つ目は2ループで、環境の記録で保留したツール（Kira、FIRE、pySecDec など）を入れる必要がある。

\section{Feynman 則と対称性因子の導出}\label{app:rules}

\paragraph{伝播関数。}自由部分の作用は、部分積分して $S_0=\int\dd^dx\,\tfrac12\phi(-\partial^2-m^2)\phi$ と書ける。2点関数 $\langle0|T\phi(x)\phi(y)|0\rangle$ は演算子 $(-\partial^2-m^2)$ の逆に $i$ を掛けたもので、Fourier 変換 $\phi(x)=\int\dd^dp/(2\pi)^d\,e^{-ip\cdot x}\tilde\phi(p)$ のもとで $-\partial^2\to p^2$ となる。よって運動量空間の伝播関数は $i/(p^2-m^2+i0)$ である。$+i0$ は時間順序積を与える Feynman の処方である。

\paragraph{頂点。}相互作用の部分 $\mathcal{L}_{\text{int}}=-(g\mu^\epsilon/3!)\phi^3+Y\phi$ から、頂点の因子は「$i\times$（$\mathcal{L}_{\text{int}}$ の係数）$\times$（同じ場の線の付け方の数）」で決まる。3点頂点では、区別できる3本の線を3つの $\phi$ に付ける方法が $3!$ 通りあるので、因子は $i\cdot(-g\mu^\epsilon/3!)\cdot3!=-ig\mu^\epsilon$ となる。線形項は $1$ 通りで $iY$ である。対抗項も同じ規則に従う。$\tfrac12\delta_Z\partial_\mu\phi\partial^\mu\phi-\tfrac12\delta_m\phi^2$ は2本の線の付け方が $2$ 通りあり、運動量 $p$ が流れ込むと $\partial_\mu\to\mp ip_\mu$ が2つ掛かって $\partial\phi\cdot\partial\phi\to p^2$ となる。よって因子は $i\cdot2\cdot(\tfrac12\delta_Zp^2-\tfrac12\delta_m)=i(\delta_Zp^2-\delta_m)$ である。3点の対抗項は3点頂点と同じ計算で $-i\delta_g\mu^\epsilon$ となる。

\paragraph{対称性因子。}$n$ 次の摂動項は $\frac{1}{n!}\bigl(i\int\mathcal{L}_{\text{int}}\bigr)^n$ で、各頂点に $1/3!$ が付く。Feynman 則の頂点因子にはすでに $3!$ を含めたので、図の値は「Feynman 則による値 $\times$ $N_c/(n!\,(3!)^n)$」となる。ここで $N_c$ は、その図を与える Wick の縮約の数である。この比が $1/S$（$S$ が対称性因子）に当たる。
\begin{itemize}
\item \textbf{タドポール}（$n=1$）：外の $\phi(x)$ と縮約する頂点の場の選び方が $3$ 通り、残る2つの場どうしの縮約が $1$ 通りで、$N_c=3$。よって $1/S=3/(1!\cdot3!)=1/2$。
\item \textbf{自己エネルギー}（$n=2$）：$\phi(x)$ が付く頂点の選び方が $2$、その頂点の場の選び方が $3$、$\phi(y)$ が他方の頂点のどの場に付くかが $3$、残る2本ずつの場の対の付け方が $2$ で、$N_c=2\cdot3\cdot3\cdot2=36$。よって $1/S=36/(2!\,(3!)^2)=36/72=1/2$。
\item \textbf{頂点補正の三角形}（$n=3$）：3つの外線を3つの頂点に割り当てる方法が $3!$、各頂点で外線に付ける場の選び方が $3^3$ である。各頂点に残る2本の場を、他の二つの頂点のどちらへ向けるかの選び方が $2^3$ で、それで三角形の辺の縮約は一意に決まる。よって $N_c=6\cdot27\cdot8=1296$、$1/S=1296/(3!\,(3!)^3)=1296/1296=1$。
\item \textbf{木の各チャンネル}（$n=2$、外線4本）：外線1,2が付く頂点の選び方が $2$、その頂点で1と2に付ける場の選び方が $3\cdot2$、他方の頂点で3と4に付ける場の選び方が $3\cdot2$、残る1本ずつの場の縮約が $1$ で、$N_c=2\cdot6\cdot6=72$。よって $1/S=72/(2!\,(3!)^2)=1$。
\end{itemize}

\section{次元とべき数え上げ}\label{app:counting}

\paragraph{次元。}作用 $\int\dd^Dx\,\mathcal{L}$ は無次元なので、$\mathcal{L}$ の質量次元は $D$ である。運動項 $\partial\phi\partial\phi$ から $[\phi]=(D-2)/2$ となる。$g_0\phi^3$ の次元が $D$ であることから $[g_0]=D-3(D-2)/2=3-D/2$ となり、$D=d-2\epsilon$ では $[g_0]=3-d/2+\epsilon$ である。そこで $g_0=\mu^\epsilon(g+\delta_g)Z^{-3/2}$ と書けば、$g$ の次元は $3-d/2$ になる。すなわち $d=4$ で1、$d=6$ で0である。

\paragraph{発散次数。}外線 $E$、頂点 $V$、内線 $I$、ループ $L$ の図では、ループ積分 $\dd^dk$ ごとに $d$、伝播関数ごとに $-2$ のべきが付くので、$\omega=dL-2I$ である。各頂点から3本の線が出るので $3V=E+2I$、すなわち $I=(3V-E)/2$。連結な図では $L=I-V+1$ である。これらを代入すると
\begin{equation*}
\omega=(d-2)I-dV+d=(d-2)\frac{3V-E}{2}-dV+d=d-\frac{d-2}{2}E+\frac{d-6}{2}V
\end{equation*}
となり、式~\eqref{eq:omega} を得る（線形項の頂点は $Y$ で打ち消したので数えない）。1ループ（$L=1$）では $I=V$ なので、$3V=E+2V$ から $E=V$ となり、$\omega=d-2E$ である。

\section{1ループ積分の一般式と発散部分}\label{app:integrals}

\paragraph{Feynman パラメータ。}$\mathrm{Im}\,A_j>0$ の量に対して $1/A_j=-i\int_0^\infty\dd t_j\,e^{it_jA_j}$ が成り立つ。$N$ 個の積をとり、$1=\int_0^\infty\dd\lambda\,\delta(\lambda-\sum_jt_j)$ を挿入して $t_j=\lambda x_j$ と変数変換すると、$\prod_j\dd t_j=\lambda^{N-1}\dd\lambda\prod_j\dd x_j$ かつ $\delta(\lambda-\lambda\sum x_j)=\lambda^{-1}\delta(1-\sum x_j)$ なので、
\begin{equation*}
\prod_{j=1}^N\frac{1}{A_j}=(-i)^N\int\!\dd F\int_0^\infty\dd\lambda\,\lambda^{N-1}e^{i\lambda B}
=(-i)^N\int\!\dd F\,\frac{\Gamma(N)}{(-iB)^N}=\Gamma(N)\int\!\dd F\,\frac{1}{B^N},
\qquad B=\sum_jx_jA_j .
\end{equation*}
ここで $\int\dd F\equiv\int_0^1\prod_j\dd x_j\,\delta(1-\sum_jx_j)$ であり、$\mathrm{Im}\,B>0$ のもとで $\int_0^\infty\dd\lambda\,\lambda^{N-1}e^{i\lambda B}=\Gamma(N)/(-iB)^N$ を使った。$A_j=(k+q_j)^2-m^2+i0$ は $\mathrm{Im}\,A_j>0$ を満たす。

\paragraph{運動量のずらし。}$\sum_jx_j=1$ を使うと
\begin{equation*}
B=\sum_jx_j\bigl[(k+q_j)^2-m^2\bigr]=k^2+2k\cdot Q+\sum_jx_jq_j^2-m^2=(k+Q)^2-\Delta,\qquad Q\equiv\sum_jx_jq_j,
\end{equation*}
\begin{equation*}
\Delta=m^2-\sum_jx_jq_j^2+Q^2 .
\end{equation*}
次元正則化では積分変数をずらせるので、$\ell=k+Q$ とする。

\paragraph{Wick 回転と $D$ 次元の積分。}$\Delta>0$ のとき、$\ell^0=i\ell_E^0$ と積分路を回転できる（$+i0$ の極の位置と整合する）。このとき $\dd^D\ell=i\,\dd^D\ell_E$、$\ell^2=-\ell_E^2$ なので、
\begin{equation*}
J_n(\Delta)\equiv\int\frac{\dd^D\ell}{(2\pi)^D}\frac{1}{(\ell^2-\Delta+i0)^n}=i(-1)^n\int\frac{\dd^D\ell_E}{(2\pi)^D}\frac{1}{(\ell_E^2+\Delta)^n}.
\end{equation*}
$D$ 次元の単位球面の面積は $2\pi^{D/2}/\Gamma(D/2)$ で、$t=\ell_E^2$ とすると $\ell_E^{D-1}\dd\ell_E=\tfrac12t^{D/2-1}\dd t$ なので、$\int\dd^D\ell_E\,f(\ell_E^2)=\frac{\pi^{D/2}}{\Gamma(D/2)}\int_0^\infty\dd t\,t^{D/2-1}f(t)$ となる。さらに $t=\Delta u/(1-u)$ と置くと、ベータ関数の積分
\begin{equation*}
\int_0^\infty\dd t\,\frac{t^{a-1}}{(t+\Delta)^n}=\Delta^{a-n}\int_0^1\dd u\,u^{a-1}(1-u)^{n-a-1}=\Delta^{a-n}\frac{\Gamma(a)\Gamma(n-a)}{\Gamma(n)}
\end{equation*}
を得る。$a=D/2$ とし、$\pi^{D/2}/(2\pi)^D=1/(4\pi)^{D/2}$ を使うと、
\begin{equation*}
J_n(\Delta)=\frac{i(-1)^n}{(4\pi)^{D/2}}\frac{\Gamma(n-D/2)}{\Gamma(n)}\,\Delta^{D/2-n}.
\end{equation*}

\paragraph{一般式。}以上をまとめると $I_N=\Gamma(N)\int\dd F\,J_N(\Delta)$ となり、$\Gamma(N)$ が約分されて式~\eqref{eq:IN-general} を得る。$\Delta\le0$ となる運動学では、$m^2\to m^2-i0$ による解析接続で同じ式を使う。

\paragraph{極の取り出し。}$D=d-2\epsilon$、$k=d/2-N$ とすると、$\Gamma(N-D/2)=\Gamma(-k+\epsilon)$ である。$k<0$ なら、これは $\epsilon\to0$ で有限である。$k\ge0$ の整数なら、$\Gamma(z+1)=z\Gamma(z)$ を $k+1$ 回使って
\begin{equation*}
\Gamma(-k+\epsilon)=\frac{\Gamma(1+\epsilon)}{\epsilon(\epsilon-1)(\epsilon-2)\cdots(\epsilon-k)}
=\frac{1}{\epsilon}\cdot\frac{1}{(-1)^k\,k!}\bigl(1+O(\epsilon)\bigr)
\end{equation*}
となる。残りの因子は $(4\pi)^{-D/2}=(4\pi)^{-d/2}(1+O(\epsilon))$、$\Delta^{D/2-N}=\Delta^{k}(1+O(\epsilon))$ で、有限部分にしか寄与しない。よって極の部分は式~\eqref{eq:poleN} になる。

\paragraph{$N=1,2,3$ への適用。}$N=1$（$q_1=0$）では $\int\dd F=1$、$\Delta=m^2$ である。$N=2$（$q_1=0$、$q_2=p$、$x_2=x$）では $\Delta=m^2-xp^2+x^2p^2=m^2-x(1-x)p^2$ で、$\int_0^1x(1-x)\dd x=1/6$ より $\int\dd F\,\Delta=m^2-p^2/6$ である。$N=3$ では $\int\dd F=\int_0^1\dd x\int_0^{1-x}\dd y=1/2$ である。これらを式~\eqref{eq:poleN} に入れる。
\begin{itemize}
\item $d=4$：$I_1$ は $N=1,k=1$ で $\dfrac{i(-1)^2}{(4\pi)^2\,1!\,\epsilon}m^2=\dfrac{im^2}{(4\pi)^2\epsilon}$。$I_2$ は $N=2,k=0$ で $\dfrac{i(-1)^2}{(4\pi)^2\epsilon}=\dfrac{i}{(4\pi)^2\epsilon}$。$I_3$ は $k=-1<0$ で有限。
\item $d=6$：$I_1$ は $N=1,k=2$ で $\dfrac{i(-1)^3}{(4\pi)^3\,2!\,\epsilon}m^4=-\dfrac{im^4}{2(4\pi)^3\epsilon}$。$I_2$ は $N=2,k=1$ で $\dfrac{i(-1)^3}{(4\pi)^3\epsilon}\Bigl(m^2-\dfrac{p^2}{6}\Bigr)$。$I_3$ は $N=3,k=0$ で $\dfrac{i(-1)^3}{(4\pi)^3\epsilon}\cdot\dfrac12=-\dfrac{i}{2(4\pi)^3\epsilon}$。
\end{itemize}
これが表~\ref{tab:poles} である。

\section{1PI 関数、対抗項、繰り込み群の導出}\label{app:ren}

\paragraph{1PI 関数。}Feynman 則（\ref{app:rules}）で、ループの伝播関数1本ごとに $i$ が1つ出る。それをまとめて積分 $I_N$ の外に出すと、次のようになる。タドポールは頂点1つ、伝播関数1本、対称性因子 $1/2$ なので $\frac12(-ig\mu^\epsilon)(i\,I_1)=\frac{g\mu^\epsilon}{2}I_1$。自己エネルギーは $\frac12(-ig\mu^\epsilon)^2\,i^2\,I_2=\frac12(-1)(-1)g^2\mu^{2\epsilon}I_2=\frac{g^2\mu^{2\epsilon}}{2}I_2$。三角形は $(-ig\mu^\epsilon)^3\,i^3\,I_3=\bigl((-i)\cdot i\bigr)^3g^3\mu^{3\epsilon}I_3=g^3\mu^{3\epsilon}I_3$。これに線形項 $iY$ と対抗項 $i(\delta_Zp^2-\delta_m)$、$-i\delta_g\mu^\epsilon$ を加えたものが式~\eqref{eq:V} である。$V_1=0$ から $Y=(ig\mu^\epsilon/2)I_1$。その極の部分は、$d=4$ で $Y=-gm^2/(2(4\pi)^2\epsilon)$、$d=6$ で $Y=gm^4/(4(4\pi)^3\epsilon)$ である。

\paragraph{$\overline{\mathrm{MS}}$ の対抗項。}対抗項を $\delta_i=c_i\Delta_{\mathrm{UV}}$（$i=Z,m,g$）と置き、係数 $c_i$ を $V_2$ と $V_3$ の $1/\epsilon$ の極が消えるように決める。$\Delta_{\mathrm{UV}}$ の極は $1/\epsilon$ なので、$\delta_i$ の極は $c_i/\epsilon$ である。$\mu^{n\epsilon}=1+O(\epsilon)$ は有限部分にしか効かないので、極の条件では $1$ と置いてよい。
\begin{itemize}
\item $d=4$：$V_2$ の極は $\frac{g^2}{2}\cdot\frac{i}{(4\pi)^2\epsilon}+\frac{i}{\epsilon}(c_Zp^2-c_m)$。これが $p^2$ によらず $0$ になるには、$p^2$ の係数から $c_Z=0$、定数部分から $c_m=g^2/(2(4\pi)^2)$。$V_3$ は有限なので $c_g=0$。
\item $d=6$：$V_2$ の極は $\frac{g^2}{2}\cdot\Bigl(-\frac{i}{(4\pi)^3\epsilon}\Bigr)\Bigl(m^2-\frac{p^2}{6}\Bigr)+\frac{i}{\epsilon}(c_Zp^2-c_m)$。$p^2$ の係数から $\frac{ig^2}{12(4\pi)^3}+ic_Z=0$、すなわち $c_Z=-\frac{g^2}{12(4\pi)^3}$。定数部分から $-\frac{ig^2m^2}{2(4\pi)^3}-ic_m=0$、すなわち $c_m=-\frac{g^2m^2}{2(4\pi)^3}$。$V_3$ の極は $g^3\cdot\Bigl(-\frac{i}{2(4\pi)^3\epsilon}\Bigr)-\frac{i}{\epsilon}c_g$ で、これを $0$ として $c_g=-\frac{g^3}{2(4\pi)^3}$。
\end{itemize}
$\delta_i=c_i\Delta_{\mathrm{UV}}$ とすれば式~\eqref{eq:ct4} と式~\eqref{eq:ct6} になる。

\paragraph{裸の量との関係。}裸のラグランジアン $\frac12(\partial\phi_0)^2-\frac12m_0^2\phi_0^2-\frac{g_0}{3!}\phi_0^3$ に $\phi_0=Z^{1/2}\phi$ を代入すると、$\frac12Z(\partial\phi)^2-\frac12Zm_0^2\phi^2-\frac{g_0Z^{3/2}}{3!}\phi^3$ となる。これを式~\eqref{eq:L} の $Y$ 以外の部分と比べると、
\begin{equation*}
Z=1+\delta_Z,\qquad Zm_0^2=m^2+\delta_m,\qquad g_0Z^{3/2}=\mu^\epsilon(g+\delta_g)
\end{equation*}
を得る。

\paragraph{$d=6$ の $\beta$ 関数。}$K\equiv(4\pi)^3$ と書く。1ループの精度で
\begin{equation*}
g_0=\mu^\epsilon(g+\delta_g)(1+\delta_Z)^{-3/2}=\mu^\epsilon\Bigl(g+\delta_g-\frac32g\,\delta_Z\Bigr)
=\mu^\epsilon\Bigl(g-\frac{g^3\Delta_{\mathrm{UV}}}{2K}+\frac{g^3\Delta_{\mathrm{UV}}}{8K}\Bigr)=\mu^\epsilon f(g),\qquad f(g)\equiv g-\frac{3g^3\Delta_{\mathrm{UV}}}{8K}.
\end{equation*}
$g_0$ は $\mu$ によらないので、$0=\dd g_0/\dd\ln\mu=\mu^\epsilon\bigl[\epsilon f(g)+f'(g)\,\beta_\epsilon\bigr]$ である。ここで $\beta_\epsilon\equiv\dd g/\dd\ln\mu$（$D$ 次元での値）とした。よって
\begin{equation*}
\beta_\epsilon=-\frac{\epsilon f(g)}{f'(g)}=-\epsilon\,\frac{g-\frac{3g^3\Delta_{\mathrm{UV}}}{8K}}{1-\frac{9g^2\Delta_{\mathrm{UV}}}{8K}}
=-\epsilon\Bigl(g-\frac{3g^3\Delta_{\mathrm{UV}}}{8K}\Bigr)\Bigl(1+\frac{9g^2\Delta_{\mathrm{UV}}}{8K}\Bigr)+O(g^5)
=-\epsilon g-\frac{6g^3}{8K}\,\epsilon\Delta_{\mathrm{UV}}+O(g^5).
\end{equation*}
$\epsilon\Delta_{\mathrm{UV}}=1+\epsilon(\ln4\pi-\gamma_E)\to1$ なので、$\epsilon\to0$ として $\beta(g)=-\frac{3g^3}{4K}=-\frac{3g^3}{4(4\pi)^3}$ を得る。$\Delta_{\mathrm{UV}}$ の定数部分は $\epsilon\to0$ で落ちるので、1ループの $\beta$ 関数は MS と同じである。これが式~\eqref{eq:beta6} である。$\alpha=g^2/K$ で書けば $\dd\alpha/\dd\ln\mu=2g\beta/K=-\frac32\alpha^2$ となる。

\paragraph{$d=6$ の質量の走り。}$Zm_0^2=m^2+\delta_m$ と $Z=1+\delta_Z$ から、1ループの精度で
\begin{equation*}
m_0^2=(m^2+\delta_m)(1-\delta_Z)=m^2+\delta_m-m^2\delta_Z=m^2-\frac{g^2m^2\Delta_{\mathrm{UV}}}{2K}+\frac{g^2m^2\Delta_{\mathrm{UV}}}{12K}=m^2-\frac{5g^2m^2\Delta_{\mathrm{UV}}}{12K}
\end{equation*}
である。$m_0^2$ が $\mu$ によらないことから
\begin{equation*}
0=\frac{\dd m^2}{\dd\ln\mu}\Bigl(1-\frac{5g^2\Delta_{\mathrm{UV}}}{12K}\Bigr)-\frac{5m^2\Delta_{\mathrm{UV}}}{12K}\cdot2g\,\beta_\epsilon .
\end{equation*}
$\beta_\epsilon=-\epsilon g+O(g^3)$ を入れると、$\dd m^2/\dd\ln\mu=-\frac{5g^2m^2}{6K}\,\epsilon\Delta_{\mathrm{UV}}+O(g^4)\to-\frac{5g^2m^2}{6(4\pi)^3}$ を得る。$m^2$ に比例するのは、$d=6$ では $g$ が無次元で、質量の次元を持つパラメータが $m$ しかないからである。

\paragraph{$d=6$ の場の異常次元。}$\gamma_\phi\equiv\frac12\mu\,\dd\ln Z/\dd\mu$ とする。$Z=1+\delta_Z=1-\frac{g^2\Delta_{\mathrm{UV}}}{12K}$ から、1ループの精度で
\begin{equation*}
\gamma_\phi=\frac12\,\frac{\dd\delta_Z}{\dd\ln\mu}=\frac12\Bigl(-\frac{\Delta_{\mathrm{UV}}}{12K}\Bigr)\cdot2g\,\beta_\epsilon=\frac12\Bigl(-\frac{\Delta_{\mathrm{UV}}}{12K}\Bigr)(-2\epsilon g^2)+O(g^4)=\frac{g^2}{12K}\,\epsilon\Delta_{\mathrm{UV}}\to\frac{g^2}{12(4\pi)^3}
\end{equation*}
を得る。$\gamma_\phi>0$ であり、$d=4$ では $\delta_Z=0$ なので $\gamma_\phi=0$ である。

\paragraph{$d=4$ の走り。}1ループで $\delta_Z=\delta_g=0$ なので、$g_0=\mu^\epsilon g$、すなわち $\beta_\epsilon=-\epsilon g$ である。$\epsilon\to0$ で、$g$ は1ループでは走らない。質量は $Z=1$ より $m_0^2=m^2+\delta_m=m^2+\frac{g^2\Delta_{\mathrm{UV}}}{2(4\pi)^2}$ である。$m_0^2$ が $\mu$ によらないことから
\begin{equation*}
\frac{\dd m^2}{\dd\ln\mu}=-\frac{\Delta_{\mathrm{UV}}}{2(4\pi)^2}\frac{\dd g^2}{\dd\ln\mu}=-\frac{\Delta_{\mathrm{UV}}}{2(4\pi)^2}\cdot2g\beta_\epsilon=-\frac{\Delta_{\mathrm{UV}}}{2(4\pi)^2}\cdot(-2\epsilon g^2)=\frac{g^2}{(4\pi)^2}\,\epsilon\Delta_{\mathrm{UV}}\to\frac{g^2}{(4\pi)^2}
\end{equation*}
となる。これが式~\eqref{eq:mrun4} である。

\section{木レベルの振幅の導出}\label{app:tree}

$s$ チャンネルの図は、頂点2つ（$-ig$ ずつ）と、運動量 $p_1+p_2$ の伝播関数1本からなり、対称性因子は $1$ である（\ref{app:rules}）。よってその値は $(-ig)^2\,\frac{i}{s-m^2}=-\frac{ig^2}{s-m^2}$ である。$t$、$u$ チャンネルも、伝播関数の運動量が $p_1-p_3$、$p_1-p_4$ に変わるだけである。三つの和が $i\mathcal{M}$ なので、
\begin{equation*}
i\mathcal{M}=-ig^2\left[\frac{1}{s-m^2}+\frac{1}{t-m^2}+\frac{1}{u-m^2}\right]
\end{equation*}
となり、式~\eqref{eq:Mtree} を得る。木のレベルでは $\mu^\epsilon\to1$ とした。

\section{断面積の式の導出}\label{app:xsec}

\paragraph{出発点。}$2\to2$ 散乱 $p_1+p_2\to k_1+k_2$ の断面積は、流束因子と2体の位相空間を使って
\begin{equation*}
\sigma=\frac{S}{4E_1E_2|\vec v_1-\vec v_2|}\int|\mathcal{M}|^2\,\dd\Phi_2,\qquad
\dd\Phi_2=\frac{\dd^3k_1}{(2\pi)^32E_1'}\,\frac{\dd^3k_2}{(2\pi)^32E_2'}\,(2\pi)^4\delta^4(p_1+p_2-k_1-k_2)
\end{equation*}
と書ける。$E_{1,2}$ は始状態、$E'_{1,2}$ は終状態のエネルギーである。$S$ は終状態の同種粒子による因子で、終状態の角度を全立体角で積分するとき、二つの $\phi$ を二重に数えないために $S=1/2$ とする。

\paragraph{2体位相空間。}重心系では $\vec k_2=-\vec k_1$ で、$\dd^3k_2$ を $\delta^3$ で積分すると、$(2\pi)^4/(2\pi)^6=1/(4\pi^2)$ より
\begin{equation*}
\dd\Phi_2=\frac{1}{4\pi^2}\,\frac{k^2\,\dd k\,\dd\Omega}{4E_1'E_2'}\,\delta\bigl(\sqrt{s}-E_1'-E_2'\bigr),\qquad k\equiv|\vec k_1| .
\end{equation*}
$E_i'=\sqrt{k^2+m^2}$ だから、$\dd(E_1'+E_2')/\dd k=k/E_1'+k/E_2'=k(E_1'+E_2')/(E_1'E_2')$ で、根 $E_1'+E_2'=\sqrt{s}$ ではこれが $k\sqrt{s}/(E_1'E_2')$ になる。よって $\delta(\sqrt s-E_1'-E_2')=\frac{E_1'E_2'}{k_f\sqrt s}\delta(k-k_f)$ であり、
\begin{equation*}
\dd\Phi_2=\frac{1}{16\pi^2}\,\frac{k_f^2}{E_1'E_2'}\,\frac{E_1'E_2'}{k_f\sqrt s}\,\dd\Omega=\frac{k_f}{16\pi^2\sqrt s}\,\dd\Omega .
\end{equation*}

\paragraph{流束因子。}重心系では二つの速度は逆向きで、大きさは $k_i/E_1$、$k_i/E_2$ である（$k_i$ は始状態の運動量の大きさ）。よって $4E_1E_2|\vec v_1-\vec v_2|=4E_1E_2(k_i/E_1+k_i/E_2)=4k_i(E_1+E_2)=4k_i\sqrt s$ となる。

\paragraph{まとめ。}以上から
\begin{equation*}
\frac{\dd\sigma}{\dd\Omega}=S\,\frac{|\mathcal{M}|^2}{4k_i\sqrt s}\,\frac{k_f}{16\pi^2\sqrt s}=S\,\frac{|\mathcal{M}|^2}{64\pi^2s}\,\frac{k_f}{k_i}
\end{equation*}
を得る。四つの粒子の質量がすべて $m$ なら $k_f=k_i=p$、$p^2=s/4-m^2$ で $k_f/k_i=1$ となり、$S=1/2$ とともに式~\eqref{eq:sigma} になる。$|\mathcal{M}|^2$ は方位角によらないので、$\dd\Omega=2\pi\,\dd\!\cos\theta$ とした。

\paragraph{$t$ と $u$。}$\theta$ を $\vec p_1$ と $\vec k_1$ のなす角とする。$E_1=E_1'=E=\sqrt{p^2+m^2}$ なので、
\begin{equation*}
t=(p_1-k_1)^2=2m^2-2(EE-p^2\cos\theta)=2m^2-2(p^2+m^2)+2p^2\cos\theta=-2p^2(1-\cos\theta).
\end{equation*}
$u=(p_1-k_2)^2$ は $\vec k_2=-\vec k_1$ なので $\cos\theta\to-\cos\theta$ として $u=-2p^2(1+\cos\theta)$ である。確かに $s+t+u=4p^2+4m^2-4p^2=4m^2$ を満たす。

\section{$\overline{\mathrm{MS}}$ の有限部分、$B_0$ の閉じた式、虚部の導出}\label{app:b0}

\paragraph{出発点。}式~\eqref{eq:IN-general} で $N=2$、$q_1=0$、$q_2=p$ とすると $\Delta=m^2-x(1-x)p^2$ であり、
\begin{equation*}
I_2=\frac{i\,\Gamma(\epsilon)}{(4\pi)^{2-\epsilon}}\int_0^1\dd x\,\Delta^{-\epsilon}=\frac{i}{(4\pi)^2}\,\Gamma(\epsilon)(4\pi)^{\epsilon}\int_0^1\dd x\,\Delta^{-\epsilon}
\end{equation*}
となる。$\Delta\le0$ となる運動学では $m^2\to m^2-i0$ なので、$\Delta\to\Delta-i0$ と読む。$\Gamma(\epsilon)=\Gamma(1+\epsilon)/\epsilon=1/\epsilon-\gamma_E+O(\epsilon)$（$\Gamma'(1)=-\gamma_E$）、$(4\pi)^\epsilon=1+\epsilon\ln4\pi+O(\epsilon^2)$、$\Delta^{-\epsilon}=1-\epsilon\ln\Delta+O(\epsilon^2)$ より、
\begin{equation*}
\Gamma(\epsilon)(4\pi)^\epsilon\Delta^{-\epsilon}=\frac1\epsilon-\gamma_E+\ln4\pi-\ln\Delta+O(\epsilon).
\end{equation*}
結合定数から来る $\mu^{2\epsilon}=1+2\epsilon\ln\mu+O(\epsilon^2)$ を掛けると $\ln\Delta\to\ln(\Delta/\mu^2)$ となるので、
\begin{gather*}
\mu^{2\epsilon}I_2=\frac{i}{(4\pi)^2}\Bigl[\Delta_{\mathrm{UV}}+B_0(p^2;m,m)\Bigr]+O(\epsilon),\\
\Delta_{\mathrm{UV}}\equiv\frac1\epsilon-\gamma_E+\ln4\pi,\qquad
B_0(p^2;m,m)\equiv-\int_0^1\dd x\,\ln\frac{m^2-x(1-x)p^2-i0}{\mu^2}
\end{gather*}
を得る。$\overline{\mathrm{MS}}$ の対抗項は $\Delta_{\mathrm{UV}}$ を引くので、この $B_0$ が有限部分として残る。LoopTools の $\Delta$ は本ノートの $\Delta_{\mathrm{UV}}$ と同じ $2/(4-D)-\gamma_E+\ln4\pi$ なので~\cite{env}、$\Delta=0$ の LoopTools の値はこの $B_0$ に等しい。

\paragraph{$A_0$ と $C_0$。}$N=1$ では $\Delta=m^2$ で、式~\eqref{eq:IN-general} は $I_1=-i\,\Gamma(-1+\epsilon)(4\pi)^{\epsilon-2}(m^2)^{1-\epsilon}$ となる。$\Gamma(-1+\epsilon)=\Gamma(1+\epsilon)/\bigl(\epsilon(\epsilon-1)\bigr)=-1/\epsilon-1+\gamma_E+O(\epsilon)$ と、上と同じ $(4\pi)^\epsilon$、$(m^2)^{-\epsilon}$、$\mu^{2\epsilon}$ の展開から
\begin{gather*}
\mu^{2\epsilon}I_1=\frac{i\,m^2}{(4\pi)^2}\Bigl(\frac1\epsilon+1-\gamma_E\Bigr)\Bigl(1+\epsilon\ln4\pi-\epsilon\ln\frac{m^2}{\mu^2}\Bigr)+O(\epsilon)
=\frac{i}{(4\pi)^2}\Bigl[m^2\Delta_{\mathrm{UV}}+A_0(m^2)\Bigr]+O(\epsilon),\\
A_0(m^2)=m^2\Bigl(1-\ln\frac{m^2}{\mu^2}\Bigr)
\end{gather*}
を得る。$N=3$ では $k=-1<0$ で $I_3$ は有限なので、$\epsilon=0$ として
\begin{equation*}
I_3=\frac{i(-1)^3\,\Gamma(1)}{(4\pi)^2}\int\!\dd F\,\Delta^{-1}=\frac{i}{(4\pi)^2}\,C_0,\qquad C_0\equiv-\int\!\dd F\,\frac1\Delta
\end{equation*}
である。

\paragraph{繰り込まれた1PI 関数。}式~\eqref{eq:V} に $d=4$ の対抗項（式~\eqref{eq:ct4}）を入れると、
\begin{gather*}
V_2=\frac{g^2}{2}\,\mu^{2\epsilon}I_2-i\delta_m=\frac{ig^2}{2(4\pi)^2}\bigl(\Delta_{\mathrm{UV}}+B_0\bigr)-\frac{ig^2}{2(4\pi)^2}\Delta_{\mathrm{UV}}+O(\epsilon)=\frac{ig^2}{2(4\pi)^2}\,B_0+O(\epsilon),\\
V_3=g^3\mu^{3\epsilon}I_3=\frac{ig^3}{(4\pi)^2}\,C_0+O(\epsilon)
\end{gather*}
となり、式~\eqref{eq:VR4} を得る。$V_3$ では $I_3$ が有限なので、$\mu^{3\epsilon}\to1$ とした。$\delta_Z=0$ なので $V_2$ に $p^2$ の対抗項はない。

\paragraph{$B_0$ の閉じた式。}$a\equiv p^2/m^2$、$D(x)\equiv1-ax(1-x)$ と置くと、$m^2>0$ より
\begin{equation*}
B_0=-\ln\frac{m^2}{\mu^2}-I(a),\qquad I(a)\equiv\int_0^1\dd x\,\ln\bigl(D(x)-i0\bigr).
\end{equation*}

\paragraph{補助積分。}実数 $c$ に対して
\begin{equation*}
\int_0^1\dd x\,\ln|x-c|=(1-c)\ln|1-c|+c\ln|c|-1
\end{equation*}
が成り立つ。実際、$x\ne c$ で $\frac{\dd}{\dd x}\bigl[(x-c)\ln|x-c|-x\bigr]=\ln|x-c|$ であり、この原始関数は $t\ln|t|\to0$（$t\to0$）より $x=c$ でも連続なので、両端の値の差が上式になる。

\paragraph{根。}$a\ne0$ のとき $D(x)=ax^2-ax+1=a(x-x_+)(x-x_-)$、$x_\pm=(1\pm\beta)/2$、$\beta\equiv\sqrt{1-4/a}$ と因数分解できる。根と係数の関係から $x_++x_-=1$、$x_+x_-=1/a$ であり、$x_+-x_-=\beta$、$1-x_\pm=x_\mp$、$2x_\pm-1=\pm\beta$ が成り立つ。$\beta$ は $a<0$ で $\beta>1$、$a>4$ で $0<\beta<1$ の実数である。

\paragraph{$a<0$。}$x_-=(1-\beta)/2<0$、$x_+>1$ なので、$[0,1]$ 上で $(x-x_+)(x-x_-)<0$ であり、$a<0$ と合わせて $D>0$ となる（$i0$ は効かない）。よって $\ln D=\ln(-a)+\ln|x-x_+|+\ln|x-x_-|$ である。補助積分と $1-x_\pm=x_\mp$ から
\begin{equation*}
\int_0^1\ln|x-x_+|\,\dd x=x_-\ln|x_-|+x_+\ln x_+-1,\qquad
\int_0^1\ln|x-x_-|\,\dd x=x_+\ln x_++x_-\ln|x_-|-1 .
\end{equation*}
また $|x_+x_-|=-1/a$ から $\ln(-a)=-\ln x_+-\ln|x_-|$ である。これらを足すと、$|x_-|=(\beta-1)/2$ を使って
\begin{equation*}
I(a)=-2+(2x_+-1)\ln x_++(2x_--1)\ln|x_-|=-2+\beta\ln\frac{x_+}{|x_-|}=-2+\beta\ln\frac{\beta+1}{\beta-1}
\end{equation*}
となり、$B_0=-\ln(m^2/\mu^2)+2+\beta\ln\dfrac{\beta-1}{\beta+1}$ を得る。

\paragraph{$a>4$。}$0<x_-<x_+<1$ で、$x_-<x<x_+$ では $D<0$ である。$D-i0$ の偏角は $-\pi$ なので、そこでは $\ln(D-i0)=\ln|D|-i\pi$ となる。$\ln|D|=\ln a+\ln|x-x_+|+\ln|x-x_-|$ に、上と同じ補助積分（今度は $x_\pm>0$）と $\ln a=-\ln x_+-\ln x_-$ を使うと、
\begin{gather*}
\mathrm{Re}\,I(a)=-2+(2x_+-1)\ln x_++(2x_--1)\ln x_-=-2+\beta\ln\frac{x_+}{x_-}=-2+\beta\ln\frac{1+\beta}{1-\beta},\\
\mathrm{Im}\,I(a)=-\pi(x_+-x_-)=-\pi\beta
\end{gather*}
となる。よって $B_0=-\ln(m^2/\mu^2)+2+\beta\ln\dfrac{1-\beta}{1+\beta}+i\pi\beta$ である。

\paragraph{$a=0$ と $a=4$。}$a=0$ では $D=1$ で $I=0$、$B_0=-\ln(m^2/\mu^2)$ である。$a=4$ では $D=(1-2x)^2\ge0$ で、$u=1-2x$ と置くと $I=2\int_0^1\ln|1-2x|\,\dd x=\int_{-1}^{1}\ln|u|\,\dd u=2\int_0^1\ln u\,\dd u=-2$ となり、$B_0=-\ln(m^2/\mu^2)+2$ である。

\paragraph{$0<a<4$。}$D>0$ で実根を持たない。部分積分すると、$D(1)=1$ より境界項が消えて
\begin{equation*}
I(a)=\bigl[x\ln D\bigr]_0^1-\int_0^1\dd x\,\frac{xD'(x)}{D(x)}=-\int_0^1\dd x\,\frac{2ax^2-ax}{D(x)}
\end{equation*}
となる（$D'(x)=2ax-a$）。分子を $2ax^2-ax=2D(x)+(ax-2)$、さらに $ax-2=\tfrac12D'(x)+\tfrac{a-4}{2}$ と分け、$\int_0^1D'/D\,\dd x=[\ln D]_0^1=0$ を使うと、
\begin{equation*}
I(a)=-2-\frac{a-4}{2}\int_0^1\frac{\dd x}{D(x)} .
\end{equation*}
$D(x)=a\bigl[(x-\tfrac12)^2+b^2\bigr]$、$b^2=(4-a)/(4a)>0$ と平方完成すると、
\begin{equation*}
\int_0^1\frac{\dd x}{D(x)}=\frac{1}{ab}\Bigl[\arctan\frac{x-1/2}{b}\Bigr]_0^1=\frac{2}{ab}\arctan\frac{1}{2b}.
\end{equation*}
$\tilde\beta\equiv\sqrt{4/a-1}$ と置くと $(4-a)/(ab)=2\tilde\beta$、$1/(2b)=1/\tilde\beta$ なので、$I(a)=-2+2\tilde\beta\arctan(1/\tilde\beta)$、すなわち $B_0=-\ln(m^2/\mu^2)+2-2\tilde\beta\arctan(1/\tilde\beta)$ である。以上の五つの場合が、\texttt{oneloop4\_numeric.py} の閉じた式である。

\paragraph{虚部と光学定理。}以上から $\mathrm{Im}\,B_0=\pi\beta\,\theta(p^2-4m^2)$ である。虚部は、二つの $\phi$ を実際に生成できる閾値 $p^2=4m^2$ から現れる。これを崩壊幅と結びつける。1PI の2点関数 $V_2$ を伝播関数 $D=i/(p^2-m^2)$ に繰り返し挿入すると、$D+DV_2D+\cdots=D/(1-V_2D)=i/(p^2-m^2-iV_2)$ となる。そこで自己エネルギーを $\Sigma\equiv iV_2$ と定義すると、完全な伝播関数は $i/(p^2-m^2-\Sigma)$ である。繰り込まれた $V_2$（式~\eqref{eq:VR4}）から
\begin{equation*}
\Sigma=i\cdot\frac{ig^2}{2(4\pi)^2}\,B_0=-\frac{g^2}{2(4\pi)^2}\,B_0,\qquad
\mathrm{Im}\,\Sigma=-\frac{g^2\pi\beta}{2(4\pi)^2}=-\frac{g^2\beta}{32\pi}
\end{equation*}
となる。対抗項は実数なので、虚部は繰り込みの規約によらない。一方、質量 $M\equiv\sqrt{p^2}>2m$ の $\phi^*$ が二つの $\phi$ に崩壊する幅を求める。木の振幅の大きさは頂点 $-ig$ から $|\mathcal{M}|=g$ である。\ref{app:xsec} の2体位相空間は、$k_f=M\beta/2$ を使って $\int\dd\Phi_2=4\pi k_f/(16\pi^2M)=\beta/(8\pi)$ となる。同種粒子の因子 $1/2$ も含めて
\begin{equation*}
\Gamma(\phi^*\to\phi\phi)=\frac{1}{2M}\cdot\frac12\cdot g^2\cdot\frac{\beta}{8\pi}=\frac{g^2\beta}{32\pi M}.
\end{equation*}
よって $\mathrm{Im}\,\Sigma=-M\,\Gamma(\phi^*\to\phi\phi)$ が成り立つ。これは自己エネルギーに対する光学定理（ユニタリー性）であり、完全な伝播関数が $i/(p^2-m^2-\mathrm{Re}\,\Sigma+iM\Gamma)$ という Breit--Wigner 形になることと整合する。

\section{$d=6$ の有限部分と次元をずらす関係の導出}\label{app:d6}

\paragraph{有限部分。}$K\equiv(4\pi)^3$ と書く。式~\eqref{eq:IN-general} で $D=6-2\epsilon$ とし、$(4\pi)^{\epsilon}=1+\epsilon\ln4\pi$、$\mu^{2\epsilon}\Delta^{-\epsilon}=1-\epsilon\ln(\Delta/\mu^2)$（いずれも $O(\epsilon^2)$ を除く）を使う。$N=1$ では $\Gamma(-2+\epsilon)=\Gamma(1+\epsilon)/\bigl(\epsilon(\epsilon-1)(\epsilon-2)\bigr)$ で、$1/\bigl((\epsilon-1)(\epsilon-2)\bigr)=\tfrac12\bigl(1+\tfrac32\epsilon\bigr)+O(\epsilon^2)$ より $\Gamma(-2+\epsilon)=\tfrac12\bigl(1/\epsilon+\tfrac32-\gamma_E\bigr)+O(\epsilon)$ である。よって
\begin{equation*}
\mu^{2\epsilon}I_1=-i\,\Gamma(-2+\epsilon)\,\frac{(4\pi)^\epsilon}{K}\,(m^2)^2\Bigl(\frac{m^2}{\mu^2}\Bigr)^{-\epsilon}
=\frac{i}{K}\Bigl[-\frac{m^4}{2}\Delta_{\mathrm{UV}}-\frac{m^4}{2}\Bigl(\frac32-\ln\frac{m^2}{\mu^2}\Bigr)\Bigr]+O(\epsilon).
\end{equation*}
$N=2$ では \ref{app:b0} の $\Gamma(-1+\epsilon)=-1/\epsilon-1+\gamma_E+O(\epsilon)$ を使い、$\int_0^1\Delta\,\dd x=m^2-p^2/6$ より
\begin{equation*}
\mu^{2\epsilon}I_2=i\,\Gamma(-1+\epsilon)\,\frac{(4\pi)^\epsilon}{K}\int_0^1\dd x\,\Delta\Bigl(\frac{\Delta}{\mu^2}\Bigr)^{-\epsilon}
=\frac{i}{K}\Bigl[-\Bigl(m^2-\frac{p^2}{6}\Bigr)(\Delta_{\mathrm{UV}}+1)+\int_0^1\dd x\,\Delta\ln\frac{\Delta}{\mu^2}\Bigr]+O(\epsilon).
\end{equation*}
$N=3$ では $\Gamma(\epsilon)=1/\epsilon-\gamma_E+O(\epsilon)$ と $\int\dd F=1/2$ より
\begin{equation*}
\mu^{2\epsilon}I_3=-i\,\Gamma(\epsilon)\,\frac{(4\pi)^\epsilon}{K}\int\!\dd F\Bigl(\frac{\Delta}{\mu^2}\Bigr)^{-\epsilon}
=\frac{i}{K}\Bigl[-\frac12\Delta_{\mathrm{UV}}+\int\!\dd F\,\ln\frac{\Delta}{\mu^2}\Bigr]+O(\epsilon).
\end{equation*}
$\Delta\le0$ となる運動学では、\ref{app:b0} と同じく $\Delta\to\Delta-i0$ と読む。これらが $c_N$ と式~\eqref{eq:X6} の $X_N$ である。

\paragraph{繰り込まれた1PI 関数。}式~\eqref{eq:ct6} から $i(\delta_Zp^2-\delta_m)=\frac{ig^2}{2K}\bigl(m^2-\frac{p^2}{6}\bigr)\Delta_{\mathrm{UV}}$、$-i\delta_g=\frac{ig^3}{2K}\Delta_{\mathrm{UV}}$ である。式~\eqref{eq:V} に入れると
\begin{gather*}
V_2=\frac{g^2}{2}\,\mu^{2\epsilon}I_2+i(\delta_Zp^2-\delta_m)=\frac{ig^2}{2K}\Bigl[c_2\Delta_{\mathrm{UV}}+B_0^{(6)}\Bigr]+\frac{ig^2}{2K}\Bigl(m^2-\frac{p^2}{6}\Bigr)\Delta_{\mathrm{UV}}=\frac{ig^2}{2K}\,B_0^{(6)},\\
V_3=\mu^{\epsilon}\bigl(g^3\mu^{2\epsilon}I_3-i\delta_g\bigr)=\mu^\epsilon\,\frac{ig^3}{K}\Bigl[-\frac12\Delta_{\mathrm{UV}}+C_0^{(6)}+\frac12\Delta_{\mathrm{UV}}\Bigr]\to\frac{ig^3}{K}\,C_0^{(6)}
\end{gather*}
となり（いずれも $O(\epsilon)$ を除く）、式~\eqref{eq:VR6} を得る。

\paragraph{$B_0^{(6)}$ の閉じた式。}\ref{app:b0} と同じく $a\equiv p^2/m^2$、$D(x)\equiv1-ax(1-x)$、$I(a)\equiv\int_0^1\ln(D-i0)\,\dd x$ とし、$J(a)\equiv\int_0^1D\ln(D-i0)\,\dd x$ と置く。$y\equiv x-\tfrac12$ とすると $D=c+ay^2$、$c\equiv1-a/4$ である。$y$ について部分積分すると、$y=\pm\tfrac12$ で $D=1$、$\ln D=0$ なので境界項は消え、
\begin{equation*}
J=\Bigl[y\,D\ln D\Bigr]_{-1/2}^{1/2}-\int_{-1/2}^{1/2}\dd y\,y\,\frac{\dd}{\dd y}(D\ln D)=-\int_{-1/2}^{1/2}\dd y\,2ay^2(\ln D+1)
\end{equation*}
となる（$\dd D/\dd y=2ay$）。$ay^2=D-c$ を使うと、右辺は $-2J-2\int D\,\dd y+2cI+2c$ である。$\int_{-1/2}^{1/2}D\,\dd y=c+a/12=1-a/6$ を入れて $J$ について解くと
\begin{equation*}
3J=2c(I+1)-2\Bigl(1-\frac a6\Bigr)=2cI-\frac a6,\qquad J(a)=\frac23\Bigl(1-\frac a4\Bigr)I(a)-\frac{a}{18}
\end{equation*}
を得る。$a=4$ では $D=(1-2x)^2$ で、$J=\int_0^1(1-2x)^2\ln(1-2x)^2\,\dd x=2\int_0^1u^2\ln u\,\dd u=-2/9$ となり、確かに上式（$I(4)=-2$）と一致する。$L\equiv\ln(m^2/\mu^2)$ と置くと、$\int_0^1\Delta\ln(\Delta/\mu^2)\,\dd x=m^2\bigl[J+(1-a/6)L\bigr]$ であり、\ref{app:b0} の $B_0=-L-I$ から $I=-B_0-L$ である。これらを式~\eqref{eq:X6} の $B_0^{(6)}$ に入れると
\begin{equation*}
B_0^{(6)}=-m^2\Bigl(1-\frac a6\Bigr)+m^2\Bigl[-\frac23\Bigl(1-\frac a4\Bigr)(B_0+L)-\frac a{18}+\Bigl(1-\frac a6\Bigr)L\Bigr]
=m^2\Bigl[-1+\frac a9+\frac L3-\frac23\Bigl(1-\frac a4\Bigr)B_0\Bigr]
\end{equation*}
となり、式~\eqref{eq:B06} を得る。$L$ の係数は $1-a/6-\tfrac23(1-a/4)=\tfrac13$ である。虚部は $\mathrm{Im}\,B_0=\pi\beta$（$p^2>4m^2$）から $\mathrm{Im}\,B_0^{(6)}=\tfrac23\bigl(\tfrac{p^2}{4}-m^2\bigr)\pi\beta=\pi p^2\beta^3/6$ である。最後の等号には $p^2/4-m^2=p^2\beta^2/4$ を使った。

\paragraph{光学定理。}式~\eqref{eq:VR6} から $\Sigma\equiv iV_2=-\frac{g^2}{2K}B_0^{(6)}$、$\mathrm{Im}\,\Sigma=-\frac{g^2}{2K}\cdot\frac{\pi p^2\beta^3}{6}=-\frac{g^2p^2\beta^3}{768\pi^2}$ である。一方、$d$ 次元の2体位相空間は、\ref{app:xsec} の計算で $\dd^3k\to\dd^{d-1}k=k^{d-2}\dd k\,\dd\Omega$、$(2\pi)^4/(2\pi)^6\to(2\pi)^d/(2\pi)^{2(d-1)}$ と置き換えれば、$\int\dd\Phi_2=(2\pi)^{2-d}k_f^{d-3}\,\Omega_{d-2}/(4\sqrt s)$ となる。ここで $\Omega_{d-2}=2\pi^{(d-1)/2}/\Gamma\bigl((d-1)/2\bigr)$ は $d-1$ 次元空間の単位球面の面積で、$d=4$ では $4\pi$、$d=6$ では $8\pi^2/3$ である（$\Gamma(5/2)=3\sqrt\pi/4$）。$d=4$ では \ref{app:b0} の $\beta/(8\pi)$ に戻る。$d=6$、$\sqrt s=M\equiv\sqrt{p^2}$、$k_f=M\beta/2$ では $\int\dd\Phi_2=\frac{1}{16\pi^4}\cdot\frac{M^3\beta^3}{8}\cdot\frac{8\pi^2}{3}\cdot\frac{1}{4M}=\frac{M^2\beta^3}{192\pi^2}$ である。$d=6$ では $g$ は無次元で、木の振幅は $|\mathcal{M}|=g$ のままなので、同種粒子の因子 $1/2$ を含めて
\begin{equation*}
\Gamma(\phi^*\to\phi\phi)=\frac{1}{2M}\cdot\frac12\cdot g^2\cdot\frac{M^2\beta^3}{192\pi^2}=\frac{g^2M\beta^3}{768\pi^2}
\end{equation*}
となる。よって $d=6$ でも $\mathrm{Im}\,\Sigma=-M\,\Gamma(\phi^*\to\phi\phi)$ が成り立つ。

\paragraph{次元をずらす関係。}テンソル積分 $I_N^{\mu\nu}\equiv\int\frac{\dd^Dk}{(2\pi)^D}\,k^\mu k^\nu\prod_j\bigl[(k+q_j)^2-m^2\bigr]^{-1}$ の $g^{\mu\nu}$ の係数を $I_{N,00}^{(D)}$ と書く。\ref{app:integrals} と同じく Feynman パラメータでまとめて $\ell=k+Q$ とずらすと、$k^\mu k^\nu=\ell^\mu\ell^\nu-\ell^\mu Q^\nu-Q^\mu\ell^\nu+Q^\mu Q^\nu$ である。$\ell$ の1次の項は積分で消え、$Q^\mu Q^\nu$ は外運動量の積なので $g^{\mu\nu}$ に寄与しない。$\ell^\mu\ell^\nu$ は対称性から $g^{\mu\nu}\ell^2/D$ に置き換えられる。$\ell^2=(\ell^2-\Delta)+\Delta$ と分けて \ref{app:integrals} の $J_n$ を使うと
\begin{align*}
\int\frac{\dd^D\ell}{(2\pi)^D}\frac{\ell^2}{(\ell^2-\Delta)^n}=J_{n-1}+\Delta J_n
&=\frac{i(-1)^{n-1}\Delta^{D/2+1-n}}{(4\pi)^{D/2}}\Bigl[\frac{\Gamma(n-1-D/2)}{\Gamma(n-1)}-\frac{\Gamma(n-D/2)}{\Gamma(n)}\Bigr]\\
&=\frac{i(-1)^{n-1}}{(4\pi)^{D/2}}\,\frac{D}{2}\,\frac{\Gamma(n-1-D/2)}{\Gamma(n)}\,\Delta^{D/2+1-n}
\end{align*}
となる。最後の等号では $\Gamma(n-D/2)=(n-1-D/2)\Gamma(n-1-D/2)$、$\Gamma(n)=(n-1)\Gamma(n-1)$ を使った。これを $D$ で割ったものは、$D+2$ 次元の $J_n^{(D+2)}(\Delta)=\frac{i(-1)^n}{(4\pi)^{D/2+1}}\frac{\Gamma(n-1-D/2)}{\Gamma(n)}\Delta^{D/2+1-n}$ の $-4\pi/2=-2\pi$ 倍である。Feynman パラメータの積分 $\Gamma(N)\int\dd F$ は両辺で共通なので、
\begin{equation*}
I_{N,00}^{(D)}=-2\pi\,I_N^{(D+2)}
\end{equation*}
を得る。FeynCalc の規格化（$\int\dd^Dq=i\pi^2\,\mathrm{PaVe}$）に直すと、$I_N^{(D)}=i\pi^2\mathrm{PaVe}^{(D)}/(2\pi)^D$ などから $\mathrm{PaVe}^{(D+2)}=-2\pi\,\mathrm{PaVe}_{00}^{(D)}$ である。$D=4-2\epsilon$ とすれば $D+2=6-2\epsilon$ で、$\epsilon$ も $\mu^{2\epsilon}$ も両辺で共通である。LoopTools と COLLIER の規格化では、$\mu^{2\epsilon}I_{N,00}^{(4-2\epsilon)}=\frac{i}{(4\pi)^2}\bigl[c_{N,00}\Delta_{\mathrm{UV}}+T_{N,00}\bigr]$（$T_{N,00}$ は $\Delta=0$ の値）となる。\ref{app:b0} で $B_0$ について見たのと同じである。よって
\begin{equation*}
\mu^{2\epsilon}I_N^{(6-2\epsilon)}=-\frac{1}{2\pi}\cdot\frac{i}{(4\pi)^2}\bigl[c_{N,00}\Delta_{\mathrm{UV}}+T_{N,00}\bigr]=\frac{i}{(4\pi)^3}\bigl[-2c_{N,00}\Delta_{\mathrm{UV}}-2T_{N,00}\bigr]
\end{equation*}
であり、$c_N=-2c_{N,00}$、$X_N=-2T_{N,00}$ となる。例えば $A_{00}=\frac{m^2}{4}\bigl(A_0+\frac{m^2}{2}\bigr)$ の $\Delta=0$ の値は $\frac{m^4}{4}\bigl(\frac32-\ln\frac{m^2}{\mu^2}\bigr)$ で、$-2$ 倍すると式~\eqref{eq:X6} の $A_0^{(6)}$ になる。

\section{1ループの $\phi\phi\to\phi\phi$ 振幅とユニタリー性の導出}\label{app:scat}

\paragraph{図と対称性因子。}外線が4本で、タドポールと外線の自己エネルギーを含まない1ループの図は、頂点の数と、ループに外線がどう付くかで3つの型に分かれる。(i) 箱図：4つの頂点がループをなし、各頂点に外線が1本ずつ付く。外線をループの周りに並べる順は、回転と裏返しを除いて $3!/2=3$ 通りある。(ii) 三角形：3つの頂点がループをなし、そのうち2つに外線が1本ずつ付き、残る1つが内線を通して木の頂点につながる。木の頂点には残りの外線2本が付く。外線の組の分け方（チャンネル）が3通り、ループがどちら側にあるかが2通りで、計6つ。(iii) 内線の自己エネルギー：木の図の内線に図~\ref{fig:oneloop} の自己エネルギーを挟んだもので、チャンネルごとに1つ、計3つ。対称性因子は\ref{app:rules} と同じ数え方で求まる。箱図では、外線を頂点に割り当てる方法が $4!$、各頂点で外線に付ける場の選び方が $3^4$、各頂点に残る2本の場をループの両隣のどちらへ向けるかが $2^4$ で、$N_c=4!\cdot3^4\cdot2^4$、$1/S=N_c/(4!\,(3!)^4)=1$ である。三角形も同様に $1/S=1$ である。内線の自己エネルギーでは、ループの2本の内線を入れ替えても図が変わらないので $1/S=1/2$ である（\ref{app:rules} の自己エネルギーと同じ）。

\paragraph{各図の値。}運動量 $p_1,p_2$ が入り $p_3,p_4$ が出る。\ref{app:ren} と同じく、ループの伝播関数1本ごとの $i$ をまとめる。箱図は、頂点4つと伝播関数4本から
\begin{equation*}
i\mathcal{M}_{\text{box}}=(-ig)^4\int\frac{\dd^Dk}{(2\pi)^D}\prod_{j=1}^{4}\frac{i}{(k+q_j)^2-m^2}=g^4I_4
\end{equation*}
である。$I_4$ は $N=4$、$k=d/2-N=-2<0$ なので有限で、式~\eqref{eq:IN-general} から $I_4=\frac{i}{(4\pi)^2}\int\dd F\,\Delta^{-2}\equiv\frac{i}{(4\pi)^2}D_0$ となる。$\sum_jx_j=1$ を使うと $\Delta=m^2-\sum_{i<j}x_ix_j(q_i-q_j)^2$ と書ける。ループを回って隣り合う $q_i$ の差は外線の運動量なので $(q_i-q_j)^2=m^2$、対角の2つの差の2乗は外線を並べる順に応じて $s,t,u$ のうちの2つになる。例えば外線の順が $p_1,p_2,p_3,p_4$ なら $q=(0,\,p_1,\,p_1+p_2,\,p_1+p_2-p_3)$ で、対角は $(q_3-q_1)^2=s$、$(q_4-q_2)^2=(p_2-p_3)^2=u$ である。よって3つの箱図は $\mathcal{M}=g^4D_0(x,y)/(4\pi)^2$ の形で、$(x,y)=(s,t),(s,u),(t,u)$ を与える。

$s$ チャンネルの三角形は、1PI の3点関数 $V_3$（外線 $p_1$、$p_2$、内線 $p_1+p_2$）、伝播関数、木の頂点の積で、式~\eqref{eq:VR4} から
\begin{equation*}
i\mathcal{M}=V_3\cdot\frac{i}{s-m^2}\cdot(-ig)=\frac{ig^3C_0(s)}{(4\pi)^2}\cdot\frac{i}{s-m^2}\cdot(-ig)=\frac{ig^4}{(4\pi)^2}\frac{C_0(s)}{s-m^2}
\end{equation*}
である。$V_3$ の二つの外線は $p_i^2=m^2$ なので、$C_0(s)=C_0(m^2,m^2,s;m,m,m)$ である。ループが $p_3,p_4$ の側にある図も同じ値を持つので、$s$ チャンネルで $2g^4C_0(s)/((4\pi)^2(s-m^2))$ となる。$s$ チャンネルの内線の自己エネルギーは、対抗項の挿入も含めた繰り込まれた $V_2$（式~\eqref{eq:VR4}）を使って
\begin{equation*}
i\mathcal{M}=(-ig)\,\frac{i}{s-m^2}\,V_2(s)\,\frac{i}{s-m^2}\,(-ig)=\frac{g^2V_2(s)}{(s-m^2)^2}=\frac{ig^4}{2(4\pi)^2}\frac{B_0(s)}{(s-m^2)^2}
\end{equation*}
である。これは完全な伝播関数 $i/(s-m^2-\Sigma)$ を $\Sigma\equiv iV_2$ について1次まで展開したもの（$-g^2\Sigma/(s-m^2)^2$）と同じである。$t$、$u$ チャンネルも同様で、すべてを足すと式~\eqref{eq:M1} を得る。$d=4$ では $\delta_Z=\delta_g=0$ なので、対抗項は内線の質量の対抗項だけである。$B_0$ の極 $\Delta_{\mathrm{UV}}$ は、各チャンネルの $-g^2\delta_m/(x-m^2)^2=-\frac{g^4\Delta_{\mathrm{UV}}}{2(4\pi)^2(x-m^2)^2}$ でちょうど消える。

\paragraph{ユニタリー性。}S 行列を $S=1+iT$ と書くと、$S^\dagger S=1$ から $-i(T-T^\dagger)=T^\dagger T$ である。$\langle f|T|i\rangle=(2\pi)^4\delta^4(p_f-p_i)\,\mathcal{M}(i\to f)$ とし、中間状態の完全系を挟むと、$\mathcal{M}(i\to f)=\mathcal{M}(f\to i)$ のもとで
\begin{equation*}
2\,\mathrm{Im}\,\mathcal{M}(i\to f)=\sum_n\int\dd\Phi_n\,\mathcal{M}(i\to n)\,\mathcal{M}(f\to n)^*
\end{equation*}
となる。中間状態に同種粒子が二つあれば因子 $1/2$ が付く。$g^4$ の次数で寄与する中間状態は二つの $\phi$ だけである（一つの $\phi$ は $s\ne m^2$ では運動学的に許されず、三つの $\phi$ は $g^6$ 以上になる）。木の振幅は実数なので、
\begin{equation*}
\mathrm{Im}\,\mathcal{M}^{(1)}(p_1p_2\to p_3p_4)=\frac12\cdot\frac12\int\dd\Phi_2(k,k')\,\mathcal{M}^{(0)}(p_1p_2\to kk')\,\mathcal{M}^{(0)}(p_3p_4\to kk')
\end{equation*}
である。\ref{app:xsec} より $\dd\Phi_2=p\,\dd\Omega_k/(16\pi^2\sqrt s)$ で、$\mathcal{M}^{(0)}(p_1p_2\to kk')$ は $s$ と $t_1=(p_1-k)^2$ だけで決まる（$u_1=4m^2-s-t_1$）。同じく $\mathcal{M}^{(0)}(p_3p_4\to kk')$ は $s$ と $t_2=(p_3-k)^2$ で決まる。よって式~\eqref{eq:unit} を得る。数値計算では $\vec p_1$ を $z$ 軸、$\vec p_3$ を $xz$ 面内で $z$ 軸から角 $\theta$ の向きに取り、$\vec k$ の極角 $\alpha$ と方位角 $\varphi$ で $t_1=-2p^2(1-\cos\alpha)$、$t_2=-2p^2\bigl(1-\sin\theta\sin\alpha\cos\varphi-\cos\theta\cos\alpha\bigr)$ とした。前方（$p_3=p_1$、$t=0$）では $t_1=t_2$ で、式~\eqref{eq:sigma} の $\int\dd\Omega\,|\mathcal{M}^{(0)}|^2=128\pi^2s\,\sigma$ から $\mathrm{Im}\,\mathcal{M}^{(1)}(s,0)=\frac{p}{64\pi^2\sqrt s}\cdot128\pi^2s\,\sigma=2p\sqrt s\,\sigma$ となる。これが光学定理である。

$\mathcal{M}^{(1)}$ のどの項が虚部を持つかも確かめておく。$s>4m^2$ では $B_0(s)$ が虚部 $\pi\beta$ を持ち（\ref{app:b0}）、$C_0(s)$ と、対角の一方が $s$ の $D_0(s,t)$、$D_0(s,u)$ も、二つの内線が同時に質量殻に乗れるので虚部を持つ。一方、$t,u<0$ では $B_0(t)$、$C_0(t)$、$D_0(t,u)$ などは実数である（どの切断でも内線が質量殻に乗れない）。木の伝播関数 $1/(x-m^2)$ も実数である。したがって式~\eqref{eq:unit} は、3つの型の図の $s$ チャンネルの部分をまとめて確かめる。

\section{S 行列要素と繰り込みの処方の導出}\label{app:lsz}

\paragraph{極と留数。}\ref{app:b0} で見たように、1PI の2点関数を繰り返し挿入した完全な伝播関数は $i/(p^2-m^2-\Sigma(p^2))$ である（$\Sigma\equiv iV_2$）。$\Sigma$ は $\overline{\mathrm{MS}}$ で繰り込んだもので、1ループでは $\Sigma=-\frac{g^2}{2(4\pi)^2}B_0(p^2;m,m)$ である（式~\eqref{eq:VR4}）。閾値 $4m^2$ より下では $B_0$ は実数なので、$\Sigma$ も実数である。極の位置 $m_{\mathrm p}^2$ は $m_{\mathrm p}^2-m^2-\Sigma(m_{\mathrm p}^2)=0$ で決まる。$\Sigma=O(g^2)$ なので $m_{\mathrm p}^2-m^2=O(g^2)$ であり、$\Sigma(m_{\mathrm p}^2)-\Sigma(m^2)=\Sigma'\cdot(m_{\mathrm p}^2-m^2)+\cdots=O(g^4)$ である。よって $m_{\mathrm p}^2=m^2+\Sigma(m^2)+O(g^4)$ となる。また、極の近くで分母を展開すると
\begin{equation*}
p^2-m^2-\Sigma(p^2)=(p^2-m_{\mathrm p}^2)-\bigl[\Sigma(p^2)-\Sigma(m_{\mathrm p}^2)\bigr]=(p^2-m_{\mathrm p}^2)\bigl[1-\Sigma'(m_{\mathrm p}^2)\bigr]+O\bigl((p^2-m_{\mathrm p}^2)^2\bigr)
\end{equation*}
なので、完全な伝播関数は極の近くで $iR/(p^2-m_{\mathrm p}^2)$、$R=1/(1-\Sigma'(m_{\mathrm p}^2))=1+\Sigma'(m^2)+O(g^4)$ となる。$\Sigma$ を代入すると式~\eqref{eq:mpole} である。ここで $B_0(m_{\mathrm p}^2;m,m)$ と $B_0(m^2;m,m)$ の差も $O(g^2)$ なので、$O(g^2)$ の項ではどちらを使ってもよい。

\paragraph{$B_0(m^2)$ と $B_0'(m^2)$。}\ref{app:b0} の $0<a<4$ の場合の式 $I(a)=-2+2\tilde\beta\arctan(1/\tilde\beta)$、$\tilde\beta=\sqrt{4/a-1}$ を使う（$a=p^2/m^2$、$B_0=-L-I(a)$、$L\equiv\ln(m^2/\mu^2)$）。$a=1$ では $\tilde\beta=\sqrt3$、$\arctan(1/\sqrt3)=\pi/6$ なので、$B_0(m^2)=-L+2-\pi/\sqrt3$ である。微分は、$\tilde\beta^2=4/a-1$ より $\dd\tilde\beta/\dd a=-2/(a^2\tilde\beta)$、$\frac{\dd}{\dd\tilde\beta}\arctan(1/\tilde\beta)=-1/(1+\tilde\beta^2)=-a/4$ を使って
\begin{equation*}
\frac{\dd I}{\dd a}=2\,\frac{\dd\tilde\beta}{\dd a}\Bigl[\arctan\frac1{\tilde\beta}-\frac{a\tilde\beta}{4}\Bigr]=-\frac{4}{a^2\tilde\beta}\arctan\frac1{\tilde\beta}+\frac1a
\end{equation*}
となる。$B_0'=\dd B_0/\dd p^2=-\frac1{m^2}\frac{\dd I}{\dd a}$ に $a=1$ を入れると、$m^2B_0'(m^2)=\frac{4}{\sqrt3}\cdot\frac\pi6-1=\frac{2\pi}{3\sqrt3}-1$ を得る。$L$ は $p^2$ によらないので、$B_0'$ は $\mu$ によらない。

\paragraph{$\mu$ によらないこと。}$B_0(p^2;m,m)=-\int_0^1\dd x\,\ln[(m^2-x(1-x)p^2)/\mu^2]$ は $\mu$ に $+\ln\mu^2$ の形でだけ依存するので、$\mu\,\partial B_0/\partial\mu=2$ である。式~\eqref{eq:mrun4} の $\mu\,\dd m^2/\dd\mu=g^2/(4\pi)^2$ と合わせると、
\begin{equation*}
\mu\frac{\dd m_{\mathrm p}^2}{\dd\mu}=\frac{g^2}{(4\pi)^2}-\frac{g^2}{2(4\pi)^2}\cdot2+O(g^4)=O(g^4)
\end{equation*}
となる（$B_0(m^2)$ の中の $m^2$ の走りは $O(g^4)$ にしか効かない）。$B_0'$ は $\mu$ によらないので、$R$ も $O(g^2)$ で $\mu$ によらない。

\paragraph{LSZ の簡約公式。}繰り込まれた場 $\phi$ の4点グリーン関数を考える。外線の運動量を質量殻に近づけると、各外線は完全な伝播関数 $iR/(p_i^2-m_{\mathrm p}^2)$ の極を持つ。一方、正しく規格化した1粒子状態に対しては $\langle0|\phi(0)|p\rangle=\sqrt R$ である。LSZ の簡約公式は、S 行列要素が、外線の完全な伝播関数を取り除いたグリーン関数（外線を切り離した振幅）を $p_i^2=m_{\mathrm p}^2$ で評価し、外線1本ごとに $\sqrt R$ を掛けたものであることを示す~\cite{peskin}。外線を切り離した振幅とは、外線に自己エネルギーが挿入されていない図の和で、手順 (5) で計算した振幅（FeynArts の \texttt{WFCorrections} を除いたもの）がちょうどそれである。よって
\begin{equation*}
\mathcal{M}_{\mathrm{phys}}=R^2\,\mathcal{G}(p_i^2=m_{\mathrm p}^2),\qquad
\mathcal{G}=\mathcal{M}^{(0)}+\mathcal{M}^{(1)}+O(g^6)
\end{equation*}
である。木の振幅 $\mathcal{M}^{(0)}=-g^2\sum_x1/(x-m^2)$ は外線の $p_i^2$ によらない。$\mathcal{M}^{(1)}$ はすでに $O(g^4)$ なので、外線を $m^2$ に置いても $m_{\mathrm p}^2$ に置いても、違いは $O(g^6)$ である。$s,t,u$ は $s+t+u=4m_{\mathrm p}^2$ を満たす物理的な運動学の値とする。

\paragraph{$\overline{\mathrm{MS}}$ からの変換。}極質量の式から $m^2=m_{\mathrm p}^2-\Sigma(m_{\mathrm p}^2)+O(g^4)=m_{\mathrm p}^2+\frac{g^2}{2(4\pi)^2}B_0(m_{\mathrm p}^2)+O(g^4)$ である（右辺の $B_0$ は質量 $m_{\mathrm p}$ で評価してよい）。木の振幅の伝播関数を展開すると
\begin{equation*}
\frac{1}{x-m^2}=\frac{1}{x-m_{\mathrm p}^2}+\frac{m^2-m_{\mathrm p}^2}{(x-m_{\mathrm p}^2)^2}+O(g^4),\qquad
\mathcal{M}^{(0)}=\mathcal{M}^{(0)}\big|_{m\to m_{\mathrm p}}-\frac{g^4}{2(4\pi)^2}\sum_x\frac{B_0(m_{\mathrm p}^2)}{(x-m_{\mathrm p}^2)^2}+O(g^6)
\end{equation*}
となる。留数の因子は $R^2=1+2\Sigma'(m_{\mathrm p}^2)+O(g^4)=1-\frac{g^2}{(4\pi)^2}B_0'(m_{\mathrm p}^2)+O(g^4)$ で、これを木の振幅に掛けると
\begin{equation*}
\bigl(R^2-1\bigr)\,\mathcal{M}^{(0)}=-\frac{g^2}{(4\pi)^2}B_0'(m_{\mathrm p}^2)\cdot\Bigl(-g^2\sum_x\frac{1}{x-m_{\mathrm p}^2}\Bigr)+O(g^6)=\frac{g^4}{2(4\pi)^2}\sum_x\frac{2B_0'(m_{\mathrm p}^2)}{x-m_{\mathrm p}^2}+O(g^6)
\end{equation*}
である。$R^2$ を $\mathcal{M}^{(1)}$ に掛けた分と、$\mathcal{M}^{(1)}$ の中の $m$ を $m_{\mathrm p}$ に変えた分は $O(g^6)$ である。以上を足すと式~\eqref{eq:Mphys} を得る。

\paragraph{on-shell の処方での直接の計算。}裸のラグランジアン $\frac12(\partial\phi_0)^2-\frac12m_0^2\phi_0^2-\frac{g_0}{3!}\phi_0^3$ に $\phi_0=Z^{1/2}\phi$ を代入し、$Z=1+\delta_Z^{\mathrm{os}}$、$Zm_0^2=m_{\mathrm p}^2+\delta_m^{\mathrm{os}}$ と置く。結合は $\overline{\mathrm{MS}}$ と同じく $g_0=\mu^\epsilon g$ とする（$d=4$ の1ループでは $g$ は発散を持たないので、これで有限である）。すると $g_0Z^{3/2}=\mu^\epsilon g(1+\frac32\delta_Z^{\mathrm{os}})+\cdots$ なので、対抗項は
\begin{equation*}
\frac12\,\delta_Z^{\mathrm{os}}\,\partial_\mu\phi\,\partial^\mu\phi-\frac12\,\delta_m^{\mathrm{os}}\,\phi^2-\frac{\frac32\delta_Z^{\mathrm{os}}\,g\mu^\epsilon}{3!}\,\phi^3
\end{equation*}
となる。\ref{app:rules} と同じ規則で、2点の挿入は $i(\delta_Z^{\mathrm{os}}p^2-\delta_m^{\mathrm{os}})$、3点の挿入は $-\frac32ig\mu^\epsilon\delta_Z^{\mathrm{os}}$ である。2点の挿入は $\Sigma=iV_2$ に $-(\delta_Z^{\mathrm{os}}p^2-\delta_m^{\mathrm{os}})$ を加えるので、繰り込まれた自己エネルギーは $\Sigma^{\mathrm{os}}(p^2)=\Sigma_0(p^2)-\delta_Z^{\mathrm{os}}p^2+\delta_m^{\mathrm{os}}$ である。ここで $\Sigma_0=-\frac{g^2}{2(4\pi)^2}(\Delta_{\mathrm{UV}}+B_0)$ は対抗項を含まないループの値である（\ref{app:b0}）。極が $m_{\mathrm p}$ にあり留数が1である条件 $\Sigma^{\mathrm{os}}(m_{\mathrm p}^2)=0$、$\Sigma^{\mathrm{os}\prime}(m_{\mathrm p}^2)=0$ から、
\begin{equation*}
\delta_Z^{\mathrm{os}}=\Sigma_0'(m_{\mathrm p}^2)=-\frac{g^2}{2(4\pi)^2}B_0'(m_{\mathrm p}^2),\qquad
\delta_m^{\mathrm{os}}=-\Sigma_0(m_{\mathrm p}^2)+\delta_Z^{\mathrm{os}}m_{\mathrm p}^2,
\end{equation*}
\begin{equation*}
\Sigma^{\mathrm{os}}(p^2)=\Sigma_0(p^2)-\Sigma_0(m_{\mathrm p}^2)-(p^2-m_{\mathrm p}^2)\,\Sigma_0'(m_{\mathrm p}^2)=-\frac{g^2}{2(4\pi)^2}\Bigl[B_0(p^2)-B_0(m_{\mathrm p}^2)-(p^2-m_{\mathrm p}^2)B_0'(m_{\mathrm p}^2)\Bigr]
\end{equation*}
を得る。$\Delta_{\mathrm{UV}}$ は $\delta_m^{\mathrm{os}}$ にだけ入り、$\Sigma^{\mathrm{os}}$ からは消えている。この処方では $R=1$、極は $m_{\mathrm p}$ なので、S 行列要素は外線を切り離した振幅そのものである。箱図と三角形は $\overline{\mathrm{MS}}$ と同じである（ループの中の対抗項は $O(g^6)$）。内線の自己エネルギーは、\ref{app:scat} と同じ計算で $-g^2\Sigma^{\mathrm{os}}(x)/(x-m_{\mathrm p}^2)^2$ を与える。木の図の頂点の一方を3点の挿入に替えた図は、頂点が2つあるので、各チャンネルで $2\cdot\frac32\delta_Z^{\mathrm{os}}\cdot\bigl(-g^2/(x-m_{\mathrm p}^2)\bigr)$ を与える。各チャンネルで足すと
\begin{equation*}
\frac{g^4}{2(4\pi)^2}\,\frac{B_0(x)-B_0(m_{\mathrm p}^2)-(x-m_{\mathrm p}^2)B_0'(m_{\mathrm p}^2)}{(x-m_{\mathrm p}^2)^2}+\frac{g^4}{2(4\pi)^2}\,\frac{3B_0'(m_{\mathrm p}^2)}{x-m_{\mathrm p}^2}
=\frac{g^4}{2(4\pi)^2}\,\frac{B_0(x)-B_0(m_{\mathrm p}^2)+2(x-m_{\mathrm p}^2)B_0'(m_{\mathrm p}^2)}{(x-m_{\mathrm p}^2)^2}
\end{equation*}
となり、$\overline{\mathrm{MS}}$ から変換した式~\eqref{eq:Mphys} と一致する。場の繰り込み $\delta_Z^{\mathrm{os}}$ は、外線4本の $\frac12\delta_Z^{\mathrm{os}}$ ずつ（$\overline{\mathrm{MS}}$ の側の $R^2$ にあたる）を、頂点2つの $\frac32\delta_Z^{\mathrm{os}}$ ずつと内線1本の $-\delta_Z^{\mathrm{os}}$ に移しただけで、合計の $2\delta_Z^{\mathrm{os}}=3\delta_Z^{\mathrm{os}}-\delta_Z^{\mathrm{os}}$ は変わらない。

\paragraph{結合の定義と $\mu$ によらないこと。}上の二つの計算は、どちらも $g$ を裸の結合 $g_0=\mu^\epsilon g$ で定義している。$g$ を例えば質量殻上の3点関数で定義し直せば、$g=g'(1+c)$（$c=O(g^2)$）の変換で $\mathcal{M}^{(0)}\propto g^2$ から $2c\,\mathcal{M}^{(0)}$ が加わる。MadLoop と比べるときは、NLOCT の作る対抗項でこの点を確かめる必要がある。最後に、$\mathcal{M}_{\mathrm{phys}}$ に現れる $B_0(x)-B_0(m_{\mathrm p}^2)$ と $B_0'(m_{\mathrm p}^2)$ は $\ln\mu^2$ を含まず、$C_0$、$D_0$ も $\mu$ によらないので、$\mathcal{M}_{\mathrm{phys}}$ は $\mu$ によらない。$\overline{\mathrm{MS}}$ の側では、$\mathcal{M}^{(1)}$ の $B_0(x)$ の項が $\mu\,\partial/\partial\mu$ で $\frac{g^4}{(4\pi)^2}\sum_x(x-m^2)^{-2}$ を与え、$\mathcal{M}^{(0)}$ の $m^2$ の走りが $\frac{\partial\mathcal{M}^{(0)}}{\partial m^2}\cdot\frac{g^2}{(4\pi)^2}=-\frac{g^4}{(4\pi)^2}\sum_x(x-m^2)^{-2}$ を与えて打ち消し合う。

\section{全断面積の式の導出}\label{app:sigma}

\paragraph{次数の数え方。}終状態を問わない全断面積は、すべての終状態 $f$ についての $\sigma(\phi\phi\to f)$ の和である。$\phi\phi\to\phi\phi$ の振幅は $\mathcal{M}^{(0)}=O(g^2)$、$\mathcal{M}^{(1)}=O(g^4)$ なので、$|\mathcal{M}|^2=|\mathcal{M}^{(0)}|^2+2\,\mathrm{Re}(\mathcal{M}^{(0)*}\mathcal{M}^{(1)})+O(g^8)$ の第2項が $g^6$ の補正である。$\phi\phi\to\phi\phi\phi$ の木の振幅は頂点3つで $O(g^3)$、その2乗は $O(g^6)$ で、同じ次数になる。一つの $\phi$ だけの終状態は $s\ne m^2$ では運動学的に許されず、四つ以上の $\phi$ は $O(g^8)$ 以上である。よって式~\eqref{eq:sigmatot} を得る。どの項にも赤外発散はない（質量のない粒子がない）ので、$2\to2$ と $2\to3$ を別々に計算してよい。

\paragraph{$\sigma^{(1)}$。}\ref{app:xsec} の式で $|\mathcal{M}|^2$ を $2\,\mathrm{Re}(\mathcal{M}^{(0)*}\mathcal{M}^{(1)}_{\mathrm{phys}})$ に替えると、$\sigma^{(1)}=\frac12\int\dd\Omega\,2\,\mathrm{Re}(\mathcal{M}^{(0)*}\mathcal{M}^{(1)}_{\mathrm{phys}})/(64\pi^2s)$ である。$\frac12$ は終状態の同種粒子の因子である。$\mathcal{M}^{(0)}$ は実数なので、これは式~\eqref{eq:sigmatot} の形になる。被積分関数は方位角によらず、$t\leftrightarrow u$ すなわち $\cos\theta\to-\cos\theta$ で対称なので、$\sigma^{(1)}=\frac{2\pi}{64\pi^2s}\cdot2\int_0^1\dd c\,\mathcal{M}^{(0)}\mathrm{Re}\,\mathcal{M}^{(1)}_{\mathrm{phys}}$（$c=\cos\theta$）である。$t=-2p^2(1-c)$ なので $c\in[0,1]$ は $t\in[-2p^2,0]$ にあたる。$y=\ln((m^2-t)/m^2)\in[0,\ln(1+2p^2/m^2)]$ と置くと $\dd c=e^ym^2\dd y/(2p^2)$ で、$t$ チャンネルの $1/(t-m^2)^2$ は $e^{-y}$、他のチャンネルとの干渉は定数の程度になり、被積分関数は滑らかになる。この $y$ で Gauss--Legendre の求積を行った。MadLoop の有限部分は $\mathcal{M}^{(0)}\mathrm{Re}\,\mathcal{M}^{(1)}$（同種粒子の因子 $\frac12$ を含む）なので、同じ分点で $\frac{2\pi}{64\pi^2s}\cdot2\sum_iw_i\times(\text{有限部分})$ とすれば $\sigma^{(1)}$ になる。

\paragraph{$\phi\phi\to\phi\phi\phi$ の振幅。}すべての運動量を外向きにとり、$q_1=-p_1$、$q_2=-p_2$、$q_3=k_1$、$q_4=k_2$、$q_5=k_3$ とする。外線5本の3次の木の図は、真ん中の頂点に付く外線 $e$ を選び（5通り）、残る4本を二つの組 $\{a,b\}$、$\{c,d\}$ に分ける（3通り）ことで尽くされ、計15個である。各図は頂点3つ（$(-ig)^3=ig^3$）と伝播関数2本（$i^2=-1$）からなるので
\begin{equation*}
i\mathcal{M}_{2\to3}=-ig^3\sum_{15}\frac{1}{\bigl[(q_a+q_b)^2-m^2\bigr]\bigl[(q_c+q_d)^2-m^2\bigr]}
\end{equation*}
である。伝播関数の分母は、二つの始状態の和なら $s-m^2$、始状態と終状態の差なら $t$ 型で $\le-m^2$、二つの終状態の和なら $\ge3m^2$ で、どれも0にならない。よって被積分関数は有界である。終状態の三つの同種粒子の因子は $1/3!$ で、
\begin{equation*}
\sigma_{2\to3}=\frac{1}{3!}\,\frac{1}{4p\sqrt s}\int|\mathcal{M}_{2\to3}|^2\,\dd\Phi_3
\end{equation*}
となる（$4p\sqrt s$ は\ref{app:xsec} の流束因子）。

\paragraph{3体の位相空間。}\ref{app:xsec} の規格化（$(2\pi)^4\delta^4$ と各粒子の $\dd^3k/((2\pi)^32E)$）では、中間の質量 $Q^2=(k_2+k_3)^2$ を挿入して $\dd\Phi_3=\dd\Phi_2(P;k_1,Q)\,\frac{\dd Q^2}{2\pi}\,\dd\Phi_2(Q;k_2,k_3)$ と分けられる。$\delta^4(P-k_1-k_2-k_3)=\int\dd^4Q\,\delta^4(P-k_1-Q)\delta^4(Q-k_2-k_3)$ と $\int\dd^4Q=\int\dd Q^2\,\dd^3Q/(2Q^0)$ を使えば、$(2\pi)$ の因子が $\frac{1}{2\pi}$ だけ残ることが分かる。\ref{app:xsec} の2体位相空間 $\dd\Phi_2(P;a,b)=|\vec p^{\,*}|\,\dd\Omega^*/(16\pi^2\sqrt{P^2})$（$\vec p^{\,*}$ は $P$ の静止系での運動量）を使い、$Q^2\in[4m^2,(\sqrt s-m)^2]$、二つの立体角を一様にとり、$Q$ の静止系の $k_2,k_3$ を重心系に Lorentz 変換した。$|\vec k_1|=\lambda^{1/2}(s,m^2,Q^2)/(2\sqrt s)$、$Q$ の静止系での $|\vec k_2|=\sqrt{Q^2/4-m^2}$ である。検算に使ったもう一つの変数の取り方では、$\dd\Phi_3=(2\pi)^{-5}\frac{\dd^3k_1}{2E_1}\frac{\dd^3k_2}{2E_2}\frac{1}{2E_3}\delta(\sqrt s-E_1-E_2-E_3)$（$\vec k_3=-\vec k_1-\vec k_2$）とし、$\vec k_2$ の向きを決めて $|\vec k_2|$ についての $\delta$ 関数を解いた。エネルギー保存の式は2乗を2回とると $|\vec k_2|$ の2次方程式になり、解は0、1、2個ある。各解に $|\partial(E_1+E_2+E_3)/\partial|\vec k_2||^{-1}$ を掛けて足した。

\paragraph{重点サンプリング。}$\sqrt s$ が大きいと、二つの $t$ 型の伝播関数がともに $O(m^2)$ になる狭い領域（二つの終状態の粒子がそれぞれ始状態の粒子とほぼ同じ運動量を持つ配置）が積分の大部分を担う。一様なサンプリングではこの領域に落ちる点が少なく、誤差の見積もりも小さく出る。VEGAS 型の方法では、5つの積分変数それぞれの区間を、被積分関数の2乗の重みに比例するように反復して分割し直す。この格子で点を発生させ、ヤコビアンを掛けて平均する。適応の8回の後の8回の結果を誤差で重み付けして平均し、三つの乱数の種の結果のばらつきと内部の誤差の大きい方を誤差とした。

\section{$d=6$ の1ループの $\phi\phi\to\phi\phi$ と繰り込み群の導出}\label{app:scat6}

\paragraph{各図の値と対抗項。}図とその対称性因子は $d=4$（\ref{app:scat}）と同じである。$K\equiv(4\pi)^3$ と書く。箱図は $i\mathcal{M}=g^4\mu^{2\epsilon}I_4$ で、$N=4$、$k=d/2-N=-1<0$ なので $I_4$ は有限で、式~\eqref{eq:IN-general} から $I_4=\frac{i}{K}\int\dd F\,\Delta^{-1}\equiv\frac iKD_0^{(6)}$ となる（$\Gamma(4-3)=1$）。よって $\mathcal{M}=g^4D_0^{(6)}/K$ である。三角形と内線の自己エネルギーは、\ref{app:scat} の計算で $(4\pi)^2$ を $K$ に、$\mu^{2\epsilon}I_N$ の有限部分を $X_N$ に替えればよい。ただし $d=6$ では極が残る。\ref{app:d6} の $\mu^{2\epsilon}I_3=\frac iK[-\frac12\Delta_{\mathrm{UV}}+C_0^{(6)}]$、$\mu^{2\epsilon}I_2=\frac iK[-(m^2-\frac{x}{6})\Delta_{\mathrm{UV}}+B_0^{(6)}]$ から、各チャンネルのループの極は
\begin{equation*}
2\cdot\frac{g^4}{K}\cdot\frac{-\frac12\Delta_{\mathrm{UV}}}{x-m^2}=-\frac{g^4\Delta_{\mathrm{UV}}}{K(x-m^2)},\qquad
\frac{g^4}{2K}\cdot\frac{-(m^2-\frac x6)\Delta_{\mathrm{UV}}}{(x-m^2)^2}
\end{equation*}
である（前が三角形、後が自己エネルギー）。一方、木の図に対抗項を入れた図は、内線の2点の挿入が $i\mathcal{M}=(-ig)\frac{i}{x-m^2}\,i(\delta_Zx-\delta_m)\,\frac{i}{x-m^2}(-ig)$、すなわち $\mathcal{M}=g^2(\delta_Zx-\delta_m)/(x-m^2)^2$ を、頂点の一方の挿入が2つで $i\mathcal{M}=2(-i\delta_g)\frac{i}{x-m^2}(-ig)$、すなわち $\mathcal{M}=-2g\delta_g/(x-m^2)$ を与える。式~\eqref{eq:ct6} を入れると、前者は $\frac{g^4}{2K}(m^2-\frac x6)\Delta_{\mathrm{UV}}/(x-m^2)^2$、後者は $g^4\Delta_{\mathrm{UV}}/(K(x-m^2))$ で、ループの極をちょうど打ち消す。残る有限部分が式~\eqref{eq:M6} である。これは、\ref{app:d6} の繰り込まれた $V_2$、$V_3$（式~\eqref{eq:VR6}）を使って \ref{app:scat} と同じ計算をしたものと同じである。箱図の有限部分にも次元をずらす関係が使えて、$D_0^{(6)}=-2D_{00}$（$D_{00}$ は $4-2\epsilon$ 次元の $g^{\mu\nu}$ の係数の $\Delta=0$ の値）である。

\paragraph{S 行列要素。}\ref{app:lsz} の議論は次元によらない。$d=6$ の自己エネルギーは $\Sigma=iV_2=-\frac{g^2}{2K}B_0^{(6)}$（式~\eqref{eq:VR6}）なので、極質量と留数は $m_{\mathrm p}^2=m^2-\frac{g^2}{2K}B_0^{(6)}(m^2)$、$R=1-\frac{g^2}{2K}B_0^{(6)\prime}(m^2)$ である。式~\eqref{eq:Mphys} の導出をそのままたどると、$\mathcal{M}_{\mathrm{phys}}=\mathcal{M}^{(0)}|_{m\to m_{\mathrm p}}+\mathcal{M}^{(1)}_{\mathrm{phys}}$、
\begin{equation*}
\mathcal{M}^{(1)}_{\mathrm{phys}}=\mathcal{M}^{(1)}_{d=6}\big|_{m\to m_{\mathrm p}}+\frac{g^4}{2K}\sum_x\Bigl[\frac{2B_0^{(6)\prime}(m_{\mathrm p}^2)}{x-m_{\mathrm p}^2}-\frac{B_0^{(6)}(m_{\mathrm p}^2)}{(x-m_{\mathrm p}^2)^2}\Bigr]
\end{equation*}
を得る。$g$ は $\overline{\mathrm{MS}}$ の結合 $g(\mu)$ のままである。式~\eqref{eq:B06m} は、式~\eqref{eq:B06} に $p^2=m^2$ を入れて得られる。$B_0(m^2)=2-\pi/\sqrt3-L$（\ref{app:lsz}）から $B_0^{(6)}(m^2)=-m^2+\frac{m^2}9+\frac{m^2}3L-\frac23\cdot\frac34m^2B_0(m^2)=m^2\bigl(-\frac{17}9+\frac{\pi}{2\sqrt3}+\frac56L\bigr)$ である。式~\eqref{eq:B06} を $p^2$ で微分すると $\frac19+\frac16B_0(p^2)-\frac23(m^2-\frac{p^2}4)B_0'(p^2)$ で、$p^2=m^2$ と $m^2B_0'(m^2)=\frac{2\pi}{3\sqrt3}-1$ を入れると $B_0^{(6)\prime}(m^2)=\frac{17}{18}-\frac{\pi}{2\sqrt3}-\frac L6$ となる。

\paragraph{繰り込み群。}$m_{\mathrm p}$ は物理量で $\mu$ によらない。$g$ を固定して $\mathcal{M}^{(1)}_{\mathrm{phys}}$ を $\ln\mu$ で微分する。$\mu$ は有限部分の中の $\ln\mu^2$ にだけ入るので（$L=\ln(m^2/\mu^2)$ を含めて）、$\mu\,\partial/\partial\mu$ は $\ln\mu^2$ の係数の2倍を取り出す。$D_0^{(6)}$ は $\mu$ によらない。式~\eqref{eq:X6} から $\mu\partial C_0^{(6)}/\partial\mu=-2\int\dd F=-1$、$\mu\partial B_0^{(6)}(x)/\partial\mu=-2\int_0^1\Delta\,\dd x=-2(m^2-\frac x6)$ である。式~\eqref{eq:B06m} から $\mu\partial B_0^{(6)}(m^2)/\partial\mu=-\frac53m^2$、$\mu\partial B_0^{(6)\prime}(m^2)/\partial\mu=\frac13$ である。これらを各チャンネルで足すと
\begin{align*}
&\frac{g^4}{K}\Bigl[\frac{-2}{x-m^2}-\frac{m^2-\frac x6}{(x-m^2)^2}\Bigr]+\frac{g^4}{2K}\Bigl[\frac{2/3}{x-m^2}+\frac{\frac53m^2}{(x-m^2)^2}\Bigr]\\
&\qquad=\frac{g^4}{K}\Bigl[-\frac{2}{x-m^2}+\frac{1}{3(x-m^2)}+\frac{-m^2+\frac x6+\frac56m^2}{(x-m^2)^2}\Bigr]=-\frac{3g^4}{2K}\,\frac{1}{x-m^2}
\end{align*}
となる（$-m^2+\frac x6+\frac56m^2=\frac16(x-m^2)$ を使った。$m$ は $m_{\mathrm p}$ と読む）。これが式~\eqref{eq:rg6} の第1式である。$\mathcal{M}^{(0)}=-g^2\sum_x1/(x-m_{\mathrm p}^2)$ の $g$ の走りによる変化は第2式で、$\mu\,\dd\mathcal{M}_{\mathrm{phys}}/\dd\mu=0$ から $\beta=-\frac{3g^3}{4K}$ を得る。これは\ref{app:ren} で対抗項から求めた式~\eqref{eq:beta6} と同じである。

\paragraph{$d=6$ のユニタリー性。}\ref{app:scat} の議論は次元によらず、$\mathrm{Im}\,\mathcal{M}^{(1)}=\frac14\int\dd\Phi_2\,\mathcal{M}^{(0)}(s,t_1)\mathcal{M}^{(0)}(s,t_2)$ である。\ref{app:d6} の $d$ 次元の2体位相空間から、$d=6$ では $\dd\Phi_2=(2\pi)^{-4}p^3\,\dd\Omega_4/(4\sqrt s)$（$p$ は重心系の運動量）である。5次元空間の単位球面 $S^4$ を、$\hat p_1$ からの角 $\alpha$、$\hat p_1$ と $\hat p_3$ の張る面の中での角 $\beta$ と、残り2つの角で表すと、$\dd\Omega_4=\sin^3\alpha\,\sin^2\beta\,\sin\gamma\,\dd\alpha\,\dd\beta\,\dd\gamma\,\dd\varphi$ である。被積分関数は $\alpha$、$\beta$ にしかよらないので、$\gamma$ と $\varphi$ の積分は $4\pi$ を与える（$\int\dd\Omega_4=4\pi\cdot\frac43\cdot\frac\pi2=\frac{8\pi^2}3$ と一致する）。$t_1=-2p^2(1-\cos\alpha)$、$t_2=-2p^2(1-\cos\theta\cos\alpha-\sin\theta\sin\alpha\cos\beta)$ として、この2重積分を数値で求めた。前方（$\theta=0$）では $t_2=t_1$ で $\beta$ の積分は $\pi/2$ を与え、$\mathrm{Im}\,\mathcal{M}^{(1)}(s,0)=\frac14(2\pi)^{-4}\frac{p^3}{4\sqrt s}\cdot2\pi^2\int_0^\pi\sin^3\alpha\,|\mathcal{M}^{(0)}|^2\dd\alpha$ となる。これは、$d=6$ の木の断面積 $\sigma_{\mathrm{tree}}=\frac{1}{4p\sqrt s}\cdot\frac12\int\dd\Phi_2|\mathcal{M}^{(0)}|^2$（$\int\dd\Omega_4=2\pi^2\int_0^\pi\sin^3\alpha\,\dd\alpha$、$2\pi^2$ は $S^3$ の面積）を使った光学定理 $2p\sqrt s\,\sigma_{\mathrm{tree}}$ と一致する。

\section{S 行列要素の $\mu$ 依存と繰り込み群の導出}\label{app:rg}

\paragraph{関係式。}S 行列要素を、質量のパラメータ $m$ と $\overline{\mathrm{MS}}$ の結合 $g$ で $\mathcal{M}=\mathcal{M}^{(0)}(m,g)+Y(\mu;m,g)+O(g^6)$ と書く。$Y=O(g^4)$ は1ループの部分である。$s,t,u$ は物理的な運動学の値に固定する。外線の質量は $\mathcal{M}^{(1)}$ にしか入らないので、それを $m$ と $m_{\mathrm p}$ のどちらに置いても違いは $O(g^6)$ である（\ref{app:lsz}）。$m$ と $g$ が $\mu$ とともに $\gamma=\mu\,\dd m^2/\dd\mu$、$\beta=\mu\,\dd g/\dd\mu$ で動くとすると
\begin{equation*}
\mu\frac{\dd\mathcal{M}}{\dd\mu}=\frac{\partial\mathcal{M}^{(0)}}{\partial m^2}\,\gamma+\frac{\partial\mathcal{M}^{(0)}}{\partial g}\,\beta+\mu\frac{\partial Y}{\partial\mu}+O(g^6)
\end{equation*}
である。$\gamma=O(g^2)$、$\beta=O(g^3)$ なので、$Y$ の中の $m$ と $g$ を通した $\mu$ 依存は $O(g^6)$ で、落としてよい。$\mathcal{M}^{(0)}=-g^2\sum_x(x-m^2)^{-1}$ から $\partial\mathcal{M}^{(0)}/\partial m^2=-g^2\sum_x(x-m^2)^{-2}=-g^2A$、$\partial\mathcal{M}^{(0)}/\partial g=-2g\sum_x(x-m^2)^{-1}=-2gB$ である。$\mu\,\dd\mathcal{M}/\dd\mu=0$ とおくと式~\eqref{eq:rgfit} を得る。$A/B$ は点ごとに違うので、多くの点で式~\eqref{eq:rgfit} が成り立つなら、$\mu\,\partial Y/\partial\mu$ の $A$ と $B$ の係数をそれぞれ $g^2\gamma$、$2g\beta$ と等しいとおいてよい。

\paragraph{$Y$ の形。}\ref{app:lsz} より、S 行列要素は $R^2\,\mathcal{G}(p_i^2=m_{\mathrm p}^2)$ である。$\overline{\mathrm{MS}}$ の $m$ で書くときは木の振幅の内線の質量を書き直さないので、加わるのは留数の因子の分 $(R^2-1)\mathcal{M}^{(0)}$ だけである。$R^2-1=2\Sigma'(m^2)+O(g^4)=-\frac{g^2}{(4\pi)^{d/2}}B_0'(m^2)$（$d=6$ では $B_0^{(6)\prime}$）なので
\begin{equation*}
Y=\mathcal{M}^{(1)}+(R^2-1)\,\mathcal{M}^{(0)}=\mathcal{M}^{(1)}+\frac{g^4}{(4\pi)^{d/2}}\sum_x\frac{B_0'(m^2)}{x-m^2}
\end{equation*}
となる。極質量で書くときは、木の内線の質量の書き直しも加わり、$Y=\mathcal{M}^{(1)}_{\mathrm{phys}}$（式~\eqref{eq:Mphys}、\ref{app:scat6}）である。

\paragraph{$d=4$ の予想。}$\mu$ は有限部分の $\ln\mu^2$ にだけ入るので、$\mu\,\partial/\partial\mu$ はその係数の2倍を取り出す。$d=4$ では $\mu\,\partial B_0(p^2)/\partial\mu=2$ で、$B_0'$、$C_0$、$D_0$ は $\mu$ によらない（\ref{app:lsz}）。よって $\mu\,\partial\mathcal{M}^{(1)}/\partial\mu=\frac{g^4}{(4\pi)^2}\sum_x\frac{2}{2(x-m^2)^2}=\frac{g^4}{(4\pi)^2}A$ である。(i) 留数の項は $\mu$ によらないので、$\mu\,\partial Y/\partial\mu=\frac{g^4}{(4\pi)^2}A$ となる。$A$ と $B$ の係数を比べて $\gamma=g^2/(4\pi)^2$、$\beta=0$ を得る。これは式~\eqref{eq:mrun4} と、$\delta_Z=\delta_g=0$ から $g$ が走らないこと（\ref{app:ren}）に一致する。(ii) 式~\eqref{eq:Mphys} の変換の項の $\mu$ 依存は $B_0(m_{\mathrm p}^2)$ からだけ来て、$-\frac{g^4}{2(4\pi)^2}\sum_x\frac{2}{(x-m^2)^2}=-\frac{g^4}{(4\pi)^2}A$ を与える。これが $\mathcal{M}^{(1)}$ の分と打ち消し合うので $\mu\,\partial Y/\partial\mu=0$、すなわち $\gamma=\beta=0$ である。

\paragraph{$d=6$ の予想。}(iii) 式~\eqref{eq:rg6} の第1式から $\mu\,\partial Y/\partial\mu=-\frac{3g^4}{2K}B$（$K\equiv(4\pi)^3$）なので、$\gamma=0$、$\beta=-\frac{3g^3}{4K}$ である。(iv) (iii) の $Y$ との違いは、木の内線の質量の書き直しの項 $-\frac{g^4}{2K}\sum_xB_0^{(6)}(m^2)/(x-m^2)^2$ を含まないことだけである。すなわち $Y=\mathcal{M}^{(1)}_{\mathrm{phys}}+\frac{g^4}{2K}\sum_x\frac{B_0^{(6)}(m^2)}{(x-m^2)^2}$ である。\ref{app:scat6} の $\mu\,\partial B_0^{(6)}(m^2)/\partial\mu=-\frac53m^2$ を使うと
\begin{equation*}
\mu\frac{\partial Y}{\partial\mu}=-\frac{3g^4}{2K}B+\frac{g^4}{2K}\Bigl(-\frac53m^2\Bigr)A=-\frac{5g^4m^2}{6K}A-\frac{3g^4}{2K}B
\end{equation*}
となり、$\gamma=-\frac{5g^2m^2}{6K}$、$\beta=-\frac{3g^3}{4K}$ を得る。この $\gamma$ は、\ref{app:ren} で裸の質量から求めた値と一致する。極質量 $m_{\mathrm p}^2=m^2-\frac{g^2}{2K}B_0^{(6)}(m^2)$（\ref{app:scat6}）が $\mu$ によらない条件 $0=\gamma-\frac{g^2}{2K}\bigl(-\frac53m^2\bigr)$ からも同じ値が出る。

\paragraph{数値の手順。}6点 $k$ で $S_k\equiv[Y(\mu=2m)-Y(\mu=m/2)]/(2\ln2)$ を求めた。ツールでは $m$ と $g$ を固定して $\mu$ だけを変えるので、$Y$ は $\ln\mu$ の1次式で、$S_k$ は $\mu\,\partial Y/\partial\mu$ そのものである。$m=g=1$ として $S_k=A_k\gamma+2B_k\beta$ を最小二乗で解いた。各点の式は $\sqrt{A_k^2+4B_k^2}$ で割って重みをそろえた。残差は、各点の1ループの傾きの大きさ $\sqrt{A_k^2+4B_k^2}/(4\pi)^{d/2}$ を単位として測った。

\paragraph{図~\ref{fig:rg4} の曲線。}$d=4$ では $\beta=0$ なので、式~\eqref{eq:mrun4} はそのまま積分できる。$\mu=m$ での値を $m$ と書くと $m^2(\mu)=m^2+\frac{g^2}{(4\pi)^2}\ln\frac{\mu}{m}$ である。実線は、$\mathcal{M}^{(0)}$ をこの $m(\mu)$ で、$Y$ を $m$ で評価した。$\delta\equiv m^2(\mu)-m^2$ とすると
\begin{equation*}
\mathcal{M}^{(0)}\big|_{m^2\to m^2+\delta}=-g^2\sum_x\frac{1}{x-m^2-\delta}=\mathcal{M}^{(0)}-g^2A\,\delta-g^2\delta^2\sum_x\frac{1}{(x-m^2)^3}+O(\delta^3)
\end{equation*}
である。第2項は $Y$ の $\mu$ 依存と打ち消し合い、第3項が $O(g^6\ln^2\mu)$ の残りとして残る。これは $\ln\mu$ の偶関数である。$Y$ を $m(\mu)$ で評価しても、違いは $O(g^6)$ である。$\sqrt s=5m$、$\cos\theta=0.3$、$\mu=4m$ では $\delta=8.78\times10^{-3}$、$\sum_x(x-m^2)^{-3}=-1.96\times10^{-3}$ で、第3項は S 行列要素の相対 $1.0\times10^{-6}$ にあたり、数値の結果と一致する。

\paragraph{無次元のパラメータの流れ。}$t\equiv\ln\mu$ とする。$d=4$ では、$\hat\alpha=g^2/((4\pi)^2\mu^2)$、$\hat m^2=m^2/\mu^2$ と $\beta=0$、$\gamma=g^2/(4\pi)^2$ から
\begin{equation*}
\frac{\dd\hat\alpha}{\dd t}=\frac{2g\beta}{(4\pi)^2\mu^2}-2\hat\alpha=-2\hat\alpha,\qquad
\frac{\dd\hat m^2}{\dd t}=\frac{\gamma}{\mu^2}-2\hat m^2=\hat\alpha-2\hat m^2
\end{equation*}
である。行列で書くと $\frac{\dd}{\dd t}(\hat\alpha,\hat m^2)^{\mathrm T}=M(\hat\alpha,\hat m^2)^{\mathrm T}$、$M=\bigl(\begin{smallmatrix}-2&0\\1&-2\end{smallmatrix}\bigr)$ で、固有値 $-2$ が重なり、固有ベクトルは $(0,1)$ の一つだけである（Jordan 標準形）。解は $\hat\alpha=\hat\alpha_0e^{-2t}$、$\hat m^2=(\hat m_0^2+\hat\alpha_0t)\,e^{-2t}$ で、$\hat m^2/\hat\alpha=\hat m_0^2/\hat\alpha_0+t$ は $t\to\infty$ で発散する。よって紫外では、軌道は $\hat m^2$ 軸に接して原点に入る。$d=6$ では、$\hat\alpha=g^2/K$ と $\beta=-\frac{3g^3}{4K}$、$\gamma=-\frac{5g^2m^2}{6K}$ から
\begin{equation*}
\frac{\dd\hat\alpha}{\dd t}=\frac{2g\beta}{K}=-\frac32\hat\alpha^2,\qquad
\frac{\dd\hat m^2}{\dd t}=\frac{\gamma}{\mu^2}-2\hat m^2=-\Bigl(2+\frac56\hat\alpha\Bigr)\hat m^2
\end{equation*}
である。第1式から $\hat\alpha=\hat\alpha_0/(1+\frac32\hat\alpha_0t)$ で、これを第2式に入れると $\int-\frac56\hat\alpha\,\dd t=-\frac59\ln(1+\frac32\hat\alpha_0t)$ より $\hat m^2=\hat m_0^2\,e^{-2t}(1+\frac32\hat\alpha_0t)^{-5/9}$ を得る。$\hat m^2/\hat\alpha\propto e^{-2t}(1+\frac32\hat\alpha_0t)^{4/9}\to0$ なので、紫外では軌道は $\hat\alpha$ 軸に接して原点に入る。赤外では、$t\to-2/(3\hat\alpha_0)$ で $\hat\alpha$ が発散する。図~\ref{fig:rgflow} の灰色の線はこれらの解である。

\paragraph{$d=4$ の流れが全次数で正しいこと。}式~\eqref{eq:omega} の $d=4$ の形 $\omega=4-E-V$ を使う。$\phi^3$ の図では $3V=E+2I$ なので、$E$ と $V$ の偶奇は等しい。真空の図（$E=0$）を除くと、表面的に発散する（$\omega\ge0$ の）1PI 関数は、1点関数（$V=1,3$）と $E=V=2$ の2点関数（$\omega=0$）だけである。1点関数は $Y$ で打ち消す。2点関数の発散は $\omega=0$ なので外運動量によらない定数で、$\delta_m$ にだけ入り、$\delta_Z$ には入らない。$E\ge3$ の関数と $V\ge4$ の2点関数は $\omega<0$ である。高次の図の部分発散は低次の対抗項の挿入で消え、$\omega<0$ の図には全体の発散が残らない。したがって、すべての次数で $\delta_Z=\delta_g=0$ で、$\delta_m=g^2\Delta_{\mathrm{UV}}/(2(4\pi)^2)$ は1ループの値のままである。\ref{app:ren} の $d=4$ の計算は $g_0=\mu^\epsilon g$ と $m_0^2=m^2+\delta_m$ だけを使っているので、$\beta=0$ と式~\eqref{eq:mrun4} は全次数で成り立つ。上の $d=4$ の流れも全次数で正しい。$d=6$ では $\omega=6-2E$ が $V$ によらないので、高次の項が $\beta$ と質量の走りに加わる。

\section{1PI 関数の $\mu$ 依存と文献との対応の導出}\label{app:anom}

\paragraph{1PI 関数の繰り込み群の方程式。}裸の場の完全な伝播関数は $\langle\phi_0\phi_0\rangle=Z\langle\phi\phi\rangle$ なので、その逆である2点の1PI 関数は $\Gamma^{(2)}=Z\,\Gamma_0^{(2)}$ となる。外線を切り離した $n$ 点の1PI 関数は、外線1本ごとに $Z^{1/2}$ を受けて $\Gamma^{(n)}=Z^{n/2}\Gamma^{(n)}_0$ となる。$\Gamma^{(n)}_0$ は裸の量だけで決まり $\mu$ によらないので、外運動量を固定して
\begin{equation*}
\mu\frac{\dd\Gamma^{(n)}}{\dd\mu}=\frac n2\,\mu\frac{\dd\ln Z}{\dd\mu}\,\Gamma^{(n)}=n\gamma_\phi\,\Gamma^{(n)}
\end{equation*}
である。左辺の $\dd/\dd\mu$ は、陽な $\mu$ 依存と、$m^2(\mu)$、$g(\mu)$ を通した依存の和である。

\paragraph{2点関数。}完全な伝播関数は $i/(p^2-m^2-\Sigma)$ なので $\Gamma^{(2)}=p^2-m^2-\Sigma$ である。$\Sigma=O(g^2)$ の中の $m$ と $g$ の走りは $O(g^4)$ にしか効かないので、1ループでは $\mu\,\dd\Gamma^{(2)}/\dd\mu=-\gamma-\mu\,\partial\Sigma/\partial\mu+O(g^4)$ である。右辺は $2\gamma_\phi(p^2-m^2)+O(g^4)$ なので、式~\eqref{eq:anom} の第1式を得る。手計算の値と比べると、$\Sigma=-\frac{g^2}{2K}B_0^{(6)}$ と\ref{app:scat6} の $\mu\,\partial B_0^{(6)}(p^2)/\partial\mu=-2(m^2-\frac{p^2}6)$ から
\begin{equation*}
-\mu\frac{\partial\Sigma}{\partial\mu}=\frac{g^2}{2K}\cdot\Bigl(-2m^2+\frac{p^2}3\Bigr)=-\frac{5g^2m^2}{6K}+\frac{g^2}{6K}\,(p^2-m^2)
\end{equation*}
となる。これは $\gamma=-\frac{5g^2m^2}{6K}$、$\gamma_\phi=\frac{g^2}{12K}$ にあたり、\ref{app:ren} で裸の量から求めた値と一致する。

\paragraph{3点関数。}1PI の3点関数を $i\Gamma^{(3)}$ と書くと、木の頂点 $-ig$ と式~\eqref{eq:VR6} の $V_3$ から $\Gamma^{(3)}=-g+\frac{g^3}{K}C_0^{(6)}$ である。1ループでは $\mu\,\dd\Gamma^{(3)}/\dd\mu=-\beta+\frac{g^3}{K}\mu\,\partial C_0^{(6)}/\partial\mu+O(g^5)$ で、右辺は $3\gamma_\phi\cdot(-g)+O(g^5)$ なので、式~\eqref{eq:anom} の第2式を得る。\ref{app:scat6} の $\mu\,\partial C_0^{(6)}/\partial\mu=-1$（外運動量によらない）を入れると、$\beta=-\frac{g^3}{K}+\frac{3g^3}{12K}=-\frac{3g^3}{4K}$ となり、式~\eqref{eq:beta6} に一致する。

\paragraph{RG 関数と対抗項。}$\delta_i=c_i\Delta_{\mathrm{UV}}$ と書く。$c_Z$、$c_m$ は $g^2$ に、$c_g$ は $g^3$ に比例するので、$\beta_\epsilon=-\epsilon g$ を使うと $\dd c_Z/\dd\ln\mu=-2\epsilon c_Z$ などとなる。\ref{app:ren} と同じ計算を一般の係数で行うと、1ループで次の関係を得る（$\epsilon\Delta_{\mathrm{UV}}\to1$）。まず $\gamma_\phi=\frac12\,\dd\delta_Z/\dd\ln\mu=-c_Z$ である。次に $m_0^2=(m^2+\delta_m)(1-\delta_Z)=m^2+(c_m-m^2c_Z)\Delta_{\mathrm{UV}}$ が $\mu$ によらないことから $\gamma=2(c_m-m^2c_Z)$ である。最後に $g_0\mu^{-\epsilon}=g+(c_g-\frac32gc_Z)\Delta_{\mathrm{UV}}$ から $\beta=2(c_g-\frac32gc_Z)$ である。式~\eqref{eq:ct6} では $c_Z=-\frac{g^2}{12K}$、$c_m-m^2c_Z=-\frac{5g^2m^2}{12K}$、$c_g-\frac32gc_Z=-\frac{3g^3}{8K}$ なので、上の三つの値が出る。この関係は線形で逆に解けるので、三つの RG 関数が分かれば $c_Z$、$c_m$、$c_g$ は一意に決まる。

\paragraph{文献との対応。}文献~\cite{bgks} は $d=6-\epsilon_{\mathrm B}$ で $g_0=g\mu^{\epsilon_{\mathrm B}/2}Z_g$ と書くので、$\epsilon_{\mathrm B}=2\epsilon$ で、同論文の $\beta=-\frac{\epsilon_{\mathrm B}}2g+\cdots$ の第1項は本ノートの $\beta_\epsilon=-\epsilon g$ と同じである。同論文の $\phi_0=Z_\phi\phi$ は本ノートの $Z_\phi=Z^{1/2}$ にあたるので、$\gamma_\phi$ の定義は同じである。$m_0^2=m^2Z_{m^2}$ と $m_0$ が $\mu$ によらないことから、$\mu\,\dd\ln m^2/\dd\mu=-\gamma_{m^2}$ である。Lee--Yang 型の理論は $g_0\to ig_0$（繰り込まれた結合も $g_{\mathrm{LY}}=ig$）で得られる。実の結合の理論で $\beta=b\,g^3$、$\gamma=c\,g^2$ とすると、$\mu\,\dd g_{\mathrm{LY}}/\dd\mu=i\beta=ib(-ig_{\mathrm{LY}})^3=-b\,g_{\mathrm{LY}}^3$、$c\,g^2=c(-ig_{\mathrm{LY}})^2=-c\,g_{\mathrm{LY}}^2$ である。同論文の Lee--Yang 型の値 $-b=\frac34$、$-c_\phi=-\frac1{12}$、$-c_{m^2}=-\frac56$ から、実の結合では $b=-\frac34$、$c_\phi=\frac1{12}$、$c_{m^2}=\frac56$ となる。同論文の $g$ を $g/(4\pi)^{3/2}$ と読むと、$\beta=-\frac{3g^3}{4K}$、$\gamma_\phi=\frac{g^2}{12K}$、$\mu\,\dd m^2/\dd\mu=-\frac{5g^2m^2}{6K}$ を得る。
