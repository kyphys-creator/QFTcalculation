\title{標準模型：$\MSbar$ の電弱の1ループの繰り込みと検算\\（$V_{\mathrm{CKM}}=1$、FJ のタドポール、一般の $R_\xi$ ゲージ、$d=4$）}

\begin{abstract}
$\phi^3$ 理論から QCD までのノート~\cite{phi3note,phi34note,yukawanote,qednote,qcdnote} に続き、標準模型の電弱相互作用の1ループの繰り込みを $d=4$ で調べる。これまでのノートと同じく、紫外発散を次元正則化と $\MSbar$ で処理する。模型は標準模型の CKM 行列を単位行列に置いたもの（標準模型の18個のパラメータのうち CKM の4個を0にした点）で、3世代のフェルミオン（ニュートリノは質量0）、$SU(3)_C\times SU(2)_L\times U(1)_Y$ のゲージ場、Higgs 二重項からなり、一般の $R_\xi$ ゲージ（$\xi_A,\xi_Z,\xi_W$）で Goldstone ボソンとゴーストを残す。$\MSbar$ のパラメータは、破れていないラグランジアンの $g_s,g,g',\lambda,\mu^2,y_f$ で、真空期待値は $v\equiv\sqrt{\mu^2/\lambda}$ とする。タドポールは打ち消さず図として含める（Fleischer--Jegerlehner の処方~\cite{fj81}）。このとき $v$ と $\MSbar$ の質量 $M_W=gv/2$ などはゲージによらず、その対抗項は $\frac{\DUV}2\,\dd M^2/\dd\ln\mu$ と1ループの $\beta$ 関数だけで決まる。共変微分の符号と電荷の割り当ては QED と QCD のノートと同じで、すべての場が $D_\mu=\partial_\mu-ieQA_\mu$ で光子と結合する（$e>0$、$Q_e=-1$）。本ノートではまず、Feynman 則（93個の頂点のクラス、ゴーストとスカラーの結合は反ゴーストのゲージ場の $\xi$ に比例する）、木のレベルの関係と崩壊幅、$\MSbar$ の対抗項と1ループの $\beta$ 関数、$\MSbar$ の質量と $v$ の走り、一般の $R_\xi$ ゲージのタドポール $T$ を手で求めた。$T$ の $\xi$ 依存は Goldstone ボソンのループだけに残り（ベクトル場のループの $\xi$ の部分はゴーストのループが打ち消す）、タドポールを各次数で打ち消す処方の真空期待値 $v+T/M_H^2$ は、その分だけゲージに依存して走る。$\phi^3$ のノートの線形項と違い、標準模型にはタドポールを独立に打ち消すパラメータがない。検算と応用の十の手順を定め、手順 (1)〜(9) を行った。模型ファイル \texttt{SM.fr} は FeynRules に付属のものを使わずに一から書き、ゴーストとスカラーの結合は二重項の BRST 変換から模型ファイルの中で生成した。FeynRules 2.3.49 が出力した93個の頂点のクラスは、すべて手計算の表と記号として一致した（わざと3か所を誤らせた表では3個の差が出た）。MadGraph 3.8.1 が作った21個の過程の木の図の数は、ユニタリーゲージと Feynman ゲージの両方で手で数えた数と一致した。この過程で、自分の模型ファイルの誤り（湯川の項で世代の添字が3回現れ、FeynRules が警告なしに余分な添字を残した）と、ツールの問題を二つ見つけた。FeynRules を読み込んだカーネルでは置き換えの規則の左辺 \texttt{ProjM[\_,\_]} が射影演算子のトレース2に評価され、MadGraph は Feynman ゲージを許さない模型（UFO の \texttt{gauge = [0]}）で、続くコマンドを警告なしに組み込みの標準模型で実行する。手順 (2) では、$W$、$Z$、$H$、$t$ の11個の2体の崩壊と $e^+e^-\to\mu^+\mu^-$ の振幅の2乗が FeynCalc で手計算の式と記号として一致し、$e^+e^-\to\mu^+\mu^-$、$W^+W^-$ はゲージパラメータ $\xi_A$、$\xi_Z$ によらなかった。明示的な行列で組んだ $e^+e^-\to W^+W^-$ は FeynCalc と相対 $2.3\times10^{-14}$ で一致し、縦波の $W$ 対の各図の $s/M_W^2$ に比例する部分は、手で求めた比 $\frac1{2\sw^2}:Q_e:\frac{\cw}{\sw}g_L^e$ で現れて和で打ち消した（30~TeV \section{目的と問い}\label{sec:intro}

本ノートの問いは二つである。\textbf{第一に、自発的に破れたゲージ理論である標準模型の電弱部分で、$\MSbar$ の1ループの繰り込みの構造はどうなるか。とくに、Goldstone ボソンとゴースト、タドポール、光子と $Z$ の混合が、ゲージによらない $\MSbar$ のパラメータにどう組み込まれるかを、これまでのノートと同じ手順でツールと突き合わせられるか。第二に、測定された物理量から $\MSbar$ のパラメータを決め、高いスケールまで走らせたとき、何が分かるか。}具体的には、極質量と $G_F$、$\alpha(0)$ の $\MSbar$ のパラメータへの換算、結合の走り、Higgs のポテンシャルの安定性を調べる。

第一の問いを立てる理由は、QCD のノート~\cite{qcdnote} までの模型ではゲージ対称性が破れておらず、ゲージ場の質量、Goldstone ボソン、スカラーとゴーストの結合、タドポール、異なるゲージ場の混合を扱っていないからである。これまでのノートはすべて $\MSbar$ で繰り込み、$\MSbar$ のパラメータ（QED の $e(\mu)$、$m(\mu)$、QCD の $g(\mu)$、$m(\mu)$）はゲージによらず、物理量が $\xi$ によらないことを手順ごとに確かめてきた。標準模型でもこの処方を保つには、タドポールの扱いを選ぶ必要がある。$\phi^3$ と $\phi^3+\phi^4$ のノート~\cite{phi3note,phi34note} では、タドポールを線形項 $Y\phi$ で各次数打ち消した。$Y$ は対称性で禁じられない独立なパラメータなので、この条件で決めても何も失わない。標準模型ではゲージ対称性が線形項を禁じるので、タドポールを打ち消すには展開の点 $v$ を木のポテンシャルの最小点からずらすしかなく、そのずらしがゲージに依存する。そこで本ノートでは、タドポールを打ち消さずに図として含める Fleischer と Jegerlehner の処方~\cite{fj81}（以下 FJ）をとり、すべての $\MSbar$ のパラメータをゲージによらないものにする。打ち消す処方との関係（どの量がどれだけゲージに依存するか）も結果として求める。第二の問いを立てる理由は、Higgs の4点結合 $\lambda$ が高いスケールで負になるかどうかという問いが、トップの湯川結合とゲージ結合の $\MSbar$ の値、とくに極質量からの換算に敏感で、その換算に上の構造がすべて入るからである~\cite{degrassi12,buttazzo13}。

以前に本リポジトリにあった標準模型のノート（2026年10月16日に削除、最後の版はコミット 201985b）は、on-shell の処方で、FeynRules に付属の模型ファイルをそのまま使っていた。本ノートはそれを使わずに作り直したものである。模型ファイルは一から書き、FeynRules に付属の \texttt{SM.fr} と \nolinkurl{models/backup_20261009} の模型ファイルは書式を見るためだけに読んだ。頂点はすべて手計算の表と照合する（手順 (1)）。以前のノートで分かったツールの問題（計算環境の記録~\cite{env} の表 10、11、13、14）は参考にする。

求める量は六つである。(i) Feynman 則（一般の $R_\xi$ ゲージ）。(ii) 木のレベルの関係と、$W$、$Z$、$H$、$t$ の崩壊幅、$e^+e^-\to f\bar f$。(iii) $\MSbar$ の対抗項、1ループの $\beta$ 関数、$\MSbar$ の質量と $v$ の走り。(iv) 1ループのタドポールと自己エネルギー、FJ とタドポールを打ち消す処方の関係。(v) 極質量、$G_F$、$\alpha(0)$ と $\MSbar$ のパラメータの換算。(vi) 応用として、測定値から決めた $\MSbar$ のパラメータ、結合の走りと真空の安定性。手計算とツールの間で求める一致は、これまでのノートと同じく、発散部分と対抗項では記号として完全な一致、有限部分では数値基準点での倍精度の一致である。

本ノートの構成は次の通りである。第~\ref{sec:setup} 節で模型と前提を定める。第~\ref{sec:results} 節で (i)〜(iv) の手計算の結果と、(v) の $G_F$、$\alpha(0)$ の換算の式、(vi) の $\MSbar$ のパラメータを決める式と走りを述べる（(iv) の自己エネルギーの有限部分と、(vi) の真空の安定性は、それぞれの手順を行うときに加える）。第~\ref{sec:plan} 節で、それらをツールと突き合わせる計画を定める。第~\ref{sec:checks} 節で検算の結果を示す（現時点では手順 (1)〜(9)）。第~\ref{sec:discussion} 節で次の手順をまとめる。導出は\ref{app:rules}〜\ref{app:tadpole} に、検算の細部は\ref{app:details} にある。

\section{設定}\label{sec:setup}

模型は、$SU(3)_C\times SU(2)_L\times U(1)_Y$ のゲージ場 $G^a_\mu$、$W^a_\mu$、$B_\mu$、Higgs 二重項 $\Phi$、3世代のフェルミオンからなる。ゲージ固定とゴーストの項を除いたラグランジアン密度は
\begin{equation}
\begin{aligned}
\mathcal L_0={}&-\frac14B_{\mu\nu}B^{\mu\nu}-\frac14W^a_{\mu\nu}W^{a\mu\nu}-\frac14G^a_{\mu\nu}G^{a\mu\nu}
+\sum_{\psi}\bar\psi\,i\slashed D\psi
+(D_\mu\Phi)^\dagger(D^\mu\Phi)+\mu^2\Phi^\dagger\Phi-\lambda(\Phi^\dagger\Phi)^2\\
&-\sum_{i=1}^3\Bigl(y_{d_i}\,\bar Q_{Li}\Phi\,d_{Ri}+y_{\ell_i}\,\bar L_{Li}\Phi\,\ell_{Ri}+y_{u_i}\,\bar Q_{Li}\tilde\Phi\,u_{Ri}+\mathrm{h.c.}\Bigr),\\
D_\mu={}&\partial_\mu-ig'YB_\mu-igT^aW^a_\mu-ig_sT^aG^a_\mu,\qquad
W^a_{\mu\nu}=\partial_\mu W^a_\nu-\partial_\nu W^a_\mu+g\epsilon^{abc}W^b_\mu W^c_\nu
\end{aligned}
\label{eq:L}
\end{equation}
である（$G^a_{\mu\nu}$ は QCD のノート~\cite{qcdnote} と同じ）。$\psi$ は左巻きの二重項 $Q_L=(u_L,d_L)$、$L_L=(\nu_L,\ell_L)$ と右巻きの一重項 $u_R$、$d_R$、$\ell_R$ を走る。$SU(2)_L$ の生成子は $T^a=\sigma^a/2$ で左巻きの二重項と $\Phi$ にだけ働き、$Q=T^3+Y$ で、$Y$ は $Q_L$、$L_L$、$u_R$、$d_R$、$\ell_R$、$\Phi$ に対して $\frac16$、$-\frac12$、$\frac23$、$-\frac13$、$-1$、$\frac12$ である。$\tilde\Phi_i=\epsilon_{ij}\Phi_j^*$（$\epsilon_{12}=1$）である。湯川結合は世代について対角で、CKM 行列は単位行列である。Higgs 二重項を
\begin{equation}
\Phi=\begin{pmatrix}-iG^+\\[2pt] \dfrac{v+H+iG^0}{\sqrt2}\end{pmatrix},\qquad v\equiv\sqrt{\mu^2/\lambda}
\label{eq:Phi}
\end{equation}
と書き（$G^+$ の位相は Peskin--Schroeder~\cite{peskin} と FeynRules の標準模型と同じ）、ゲージ場を
\begin{equation}
W^\pm_\mu=\frac{W^1_\mu\mp iW^2_\mu}{\sqrt2},\qquad
Z_\mu=\cw W^3_\mu-\sw B_\mu,\qquad A_\mu=\sw W^3_\mu+\cw B_\mu,\qquad
\cw=\frac{g}{\sqrt{g^2+g'^2}}
\label{eq:fields}
\end{equation}
と組み替える（$\sw=g'/\sqrt{g^2+g'^2}$）。$v$ は木のポテンシャル $-\mu^2|\Phi|^2+\lambda|\Phi|^4$ の最小点である。ここで
\begin{equation}
e=g\sw=g'\cw,\quad M_W=\frac{gv}{2}=\frac{ev}{2\sw},\quad M_Z=\frac{\sqrt{g^2+g'^2}\,v}{2}=\frac{M_W}{\cw},\quad M_H^2=2\lambda v^2=2\mu^2,\quad m_f=\frac{y_fv}{\sqrt2}
\label{eq:masses}
\end{equation}
で、すべての場が共変微分の $-ieQA_\mu$ で光子と結合する（\ref{app:rules}）。$Z$ との結合は $-i\frac{e}{\sw\cw}(T^3-\sw^2Q)Z_\mu$ である。

\paragraph{ゲージ固定とゴースト。}ゲージ固定には $R_\xi$ ゲージ~\cite{fls72} を使い、
\begin{equation}
\begin{gathered}
\mathcal L_{\mathrm{gf}}=-\frac{(F^A)^2}{2\xi_A}-\frac{(F^Z)^2}{2\xi_Z}-\frac{F^+F^-}{\xi_W}-\frac{(\partial^\mu G^a_\mu)^2}{2\xi_G},\\
F^A=\partial^\mu A_\mu,\qquad F^Z=\partial^\mu Z_\mu-\xi_ZM_ZG^0,\qquad F^\pm=\partial^\mu W^\pm_\mu-\xi_WM_WG^\pm
\end{gathered}
\label{eq:gf}
\end{equation}
とする。この符号で、$(D_\mu\Phi)^\dagger D^\mu\Phi$ に現れるゲージ場と Goldstone ボソンの2次の混合 $M_W(W^{+\mu}\partial_\mu G^-+W^{-\mu}\partial_\mu G^+)+M_ZZ^\mu\partial_\mu G^0$ が部分積分の後に打ち消し、Goldstone ボソンは質量 $\sqrt{\xi_Z}M_Z$、$\sqrt{\xi_W}M_W$ を持つ（\ref{app:rules}）。Faddeev--Popov の項は
\begin{equation}
\begin{gathered}
\mathcal L_{\mathrm{FP}}=-\sum_{k=A,Z,+,-}\bar u^k\,sF^k-\bar u^a_G\,\partial^\mu(D_\mu u_G)^a,\\
s\Phi=i\Bigl(gT^au^a+\frac{g'}2u^B\Bigr)\Phi,\qquad sW^a_\mu=\partial_\mu u^a+g\epsilon^{abc}W^b_\mu u^c,\qquad sB_\mu=\partial_\mu u^B
\end{gathered}
\label{eq:fp}
\end{equation}
で、$s$ はゲージ変換のパラメータをゴーストで置き換えた BRST 変換である。ゴーストは場と同じ行列で $u^A,u^Z,u^\pm$ に組み替え、$\bar u^\pm$ は $u^\pm$ と対になる反ゴーストである。$sF^k$ の Goldstone ボソンの部分から、ゴーストの質量 $\xi_ZM_Z^2$、$\xi_WM_W^2$ と、反ゴーストのゲージ場の $\xi$ に比例するゴーストとスカラーの結合が生じる。

\paragraph{伝播関数。}光子、$Z$、$W$ の伝播関数は
\begin{equation}
\frac{-i}{k^2-M_V^2}\Bigl[g_{\mu\nu}-(1-\xi_V)\frac{k_\mu k_\nu}{k^2-\xi_VM_V^2}\Bigr]
\qquad(V=A,Z,W;\ M_A=0)
\label{eq:propV}
\end{equation}
で、$G^0$ と $u^Z$ は $i/(k^2-\xi_ZM_Z^2)$、$G^\pm$ と $u^\pm$ は $i/(k^2-\xi_WM_W^2)$、$u^A$ は $i/k^2$、$H$ は $i/(k^2-M_H^2)$、フェルミオンは $i(\slashed p+m_f)/(p^2-m_f^2)$、グルーオンとそのゴーストは QCD のノートと同じである。$\xi_V=1$ が 't~Hooft--Feynman ゲージ（以下 Feynman ゲージ）、$\xi_V\to0$ が Landau ゲージである。

\paragraph{繰り込み。}裸の量と繰り込まれた量を
\begin{equation}
\begin{gathered}
g_0=\mu^\epsilon Z_gg,\quad g'_0=\mu^\epsilon Z_{g'}g',\quad g_{s0}=\mu^\epsilon Z_{g_s}g_s,\quad
\lambda_0=\mu^{2\epsilon}Z_\lambda\lambda,\quad \mu_0^2=Z_{\mu^2}\mu^2,\quad y_{f0}=\mu^\epsilon Z_{y_f}y_f,\\
W^a_0=Z_W^{1/2}W^a,\quad B_0=Z_B^{1/2}B,\quad G_0=Z_G^{1/2}G,\quad \Phi_0=Z_\Phi^{1/2}\Phi,\quad \psi_0=Z_\psi^{1/2}\psi
\end{gathered}
\label{eq:bare}
\end{equation}
で結ぶ（$\psi$ はカイラルな多重項ごと）。パラメータの繰り込み定数 $Z_X$ はすべて $\MSbar$ で、$Z_X-1$ は $\DUV$ に比例する。それらはゲージによらない（第~\ref{sec:rg} 節）。場の繰り込み定数もこのノートでは $\MSbar$ とするが、ゲージに依存し、物理量には入らない。$\mathcal L_{\mathrm{gf}}$ は繰り込まれた場と $\MSbar$ の $M_Z$、$M_W$ で書き、対抗項を付けない（QED と QCD のノートの $\xi_0=Z_3\xi$ と同じ扱い）。ゴーストの項の対抗項は1ループの物理量に入らないので書かない。

\paragraph{タドポール（FJ の処方）。}裸の場 $\Phi_0$ を、裸のパラメータで書いた木のポテンシャルの最小点 $v_0=\sqrt{\mu_0^2/\lambda_0}$ のまわりで展開する。すると $H$ の1次の項は裸のラグランジアンにも対抗項にも現れず、タドポールの図（1ループの $H$ の1点関数 $iT$ を $H$ の運動量0の伝播関数で他の線につないだ図）はすべての計算に含める。裸の質量 $M_{W,0}=g_0v_0/2$ などは $\MSbar$ のパラメータの組み合わせで、その対抗項はゲージによらない（第~\ref{sec:rg} 節）。$v$ の代わりに、ループで補正したポテンシャルの最小点 $v+T/M_H^2$ のまわりで展開し、タドポールを各次数で打ち消す処方もある（以下 $\beta_t$ の処方）。両者の関係は第~\ref{sec:tadpole} 節で求める。

\paragraph{前提。}本ノートは次の前提に立つ。
\begin{enumerate}
\item 計量は $(+,-,-,-)$、$\hbar=c=1$ とする。共変微分の符号は FeynRules の規約 $D_\mu=\partial_\mu-igT^aW^a_\mu-ig'YB_\mu$ に合わせる（Peskin--Schroeder~\cite{peskin} と同じ）。QED と QCD のノートと同じく $e>0$ で、光子との結合は $D_\mu\supset-ieQA_\mu$、電子は $Q_e=-1$ である。FeynArts の \texttt{SM.mod} と FormCalc は Denner の規約~\cite{denner93} で、光子の場の符号と $G^\pm$ の位相が違う（$A^{\mathrm{Denner}}=-A$、$\phi^+=-iG^+$。計算環境の記録~\cite{env} の表 10）。規約の対応は Romão--Silva~\cite{romao12} にまとめられている。二つの規約の頂点や対抗項を一つの計算で混ぜない。
\item フェルミオンは3世代で、CKM 行列は単位行列とする（次の段落）。ニュートリノは質量0の左巻きだけの場である。クォークの色の数を $N_c=3$ とし、レプトンでは $N_c=1$ とする。$T^3_f$ と $Q_f$ はフェルミオン $f$ の左巻きの成分の弱アイソスピンの第3成分と電荷である。
\item ゲージは $R_\xi$ ゲージ \eqref{eq:gf} で、$\xi_A,\xi_Z,\xi_W,\xi_G$ を独立に残す。物理量は $\xi$ によらないはずで、それを確かめる。手計算の有限部分は、とくに断らなければ Feynman ゲージ（すべての $\xi=1$）でとる。
\item 時空次元は $d=4$ とし、ループ積分は次元正則化で $D=4-2\epsilon$ とする。$\gamma$ 行列は $D$ 次元で反可換とし（NDR）、$\tr1=4$ とする。1ループの2点関数とタドポールには、$\gamma_5$ を含むトレースの曖昧さは現れない。
\item 紫外発散は $\MSbar$ で処理し、対抗項を $\DUV\equiv1/\epsilon-\gamma_E+\ln4\pi$ に比例させる。$\MSbar$ のパラメータは破れていないラグランジアンの $g_s,g,g',\lambda,\mu^2,y_f$ で、$v=\sqrt{\mu^2/\lambda}$ と式~\eqref{eq:masses} の $e$、$\sw$、$M_W$、$M_Z$、$M_H$、$m_f$ はそれらの関数である（以下、これらを $\MSbar$ の質量などと呼び、物理量と区別するときは $\hat M_W$ などと書く）。タドポールは FJ の処方で扱う。
\item 1ループの積分は LoopTools の規約~\cite{looptools} の $A_0$、$B_0$ で書き、$\DUV$ をそれらに含める。$\MSbar$ の有限部分は $\DUV=0$ の値である。$\alpha=e^2/4\pi$、$K\equiv(4\pi)^2$ と書く。
\item 数値を比べるときの基準点は、$\MSbar$ のパラメータで $\alpha^{-1}=128$、$M_W=80$~GeV、$M_Z=91$~GeV（$\sw^2=1881/8281$）、$M_H=125$~GeV、$\alpha_s=0.118$、フェルミオンの質量 $m_t=165$、$m_b=2.86$、$m_c=0.619$、$m_s=0.0546$、$m_d=0.00271$、$m_u=0.00127$、$m_\tau=1.746$、$m_\mu=0.1027$、$m_e=0.000487$~GeV、$\mu=M_Z$ とし、ゲージの検算では $\xi=0,1,3$ を使う（$M_Z$ のスケールでの走る質量に近い値を選んだが、文献の値ではない）。応用の手順では、PDG~2024~\cite{pdg24} の値 $\alpha^{-1}(0)=137.035999177$、$G_F=1.1663788\times10^{-5}$~GeV$^{-2}$、$M_Z=91.1880$~GeV、$M_W=80.3692$~GeV、$M_H=125.20$~GeV、$m_t=172.57$~GeV、$\alpha_s(M_Z)=0.1180$、$\Delta\alpha^{(5)}_{\mathrm{had}}(M_Z^2)=0.02783$、$\Gamma_Z=2.4955$~GeV、$\Gamma_W=2.085$~GeV と3ループの $\Delta\alpha_{\mathrm{lep}}(M_Z^2)=0.03149769$~\cite{steinhauser98} を使う。PDG の $M_Z$、$M_W$ はエネルギーに依存する幅の Breit--Wigner の質量なので、極の質量 $M/\sqrt{1+\Gamma^2/M^2}$（$Z$ で 34~MeV、$W$ で 27~MeV 小さい~\cite{mr19}）に直して使う。
\end{enumerate}

\paragraph{CKM 行列を単位行列にすること。}本ノートの模型は、現実の標準模型そのものではなく、その CKM 行列を単位行列に置いた点である。標準模型の18個のパラメータ（$g_s,g,g',\lambda,\mu^2$、クォーク6個とレプトン3個の質量、CKM の角度3個と位相1個）のうち、CKM の4個を0にしている。式~\eqref{eq:L} の湯川結合を世代の行列で $\bar Q_{Li}(Y_d)_{ij}\Phi d_{Rj}$ などと書くと、一般には $Y_u=U^u_L\hat Y_uU^{u\dagger}_R$、$Y_d=U^d_L\hat Y_dU^{d\dagger}_R$（$\hat Y$ は対角）と対角化できる。質量の基底では $M=Yv/\sqrt2$ と湯川行列が比例するので、$H$、$G^0$ の結合は対角になる。CKM 行列 $V=U^{u\dagger}_LU^d_L$ は、$\bar u_id_jW^+$、$\bar u_id_jG^+$ の結合の $V_{ij}$ にだけ現れる（レプトンでは右巻きのニュートリノがないので残らない）。$V=1$ では、世代ごとのクォーク数を別々に回す $U(1)$ の対称性ができる。ゲージ相互作用はこれを保つので、ループの補正は非対角の湯川結合を作らず、$V=1$ は繰り込み群で保たれる。したがってこの模型はそれ自体でくりこみ可能なゲージ理論で、本ノートで確かめる Slavnov--Taylor 恒等式や物理量のゲージ不変性は、この理論の中で成り立つ。この模型にないのは、世代を変える過程（$K$、$B$ 中間子の混合、$b\to s\gamma$、$t\to sW$ など）とクォークの CP の破れ（Jarlskog 不変量 $J=3.12\times10^{-5}$~\cite{pdg24}）である。

本ノートで求める量への CKM 行列の効果は小さい。$V$ は1ループでは $|V_{ij}|^2$ としてだけ入り、タドポールと $Z$、光子、$H$ の自己エネルギーには入らない（中性の結合は質量の基底で対角で、$V$ を含まない）。$\mu$ 崩壊はレプトンの過程なので、$W$ の自己エネルギーを通してしか入らない。$W$ の自己エネルギーのクォークのループは $\sum_{ij}|V_{ij}|^2F(m_{u_i},m_{d_j})$ になり、その紫外の極はユニタリー性で変わらない（$\dd M_W^2/\dd\ln\mu$ は湯川結合のトレースだけによる）。トップの自己エネルギーでは内線の $d$ 型のクォークが $|V_{tj}|^2$ の重みで変わり、紫外の極は、$\beta_{y_t}$ の $y_b^2$ の項が $\sum_j|V_{tj}|^2y_{d_j}^2$ になる分だけ変わる。手順 (3) の式に PDG~2024 の CKM 行列~\cite{pdg24}（$\sin\theta_{12}=0.22501$、$\sin\theta_{13}=0.003732$、$\sin\theta_{23}=0.04183$、$\delta=1.147$）を入れると、基準点で $\hat\Delta$（式~\eqref{eq:GF1}）は $-7.4\times10^{-8}$、$M_W$ の極質量は $2.2\times10^{-7}$~GeV、$m_t$ の極質量は $-4.3\times10^{-8}$~GeV、$\beta_{y_t}$ は相対 $-8.2\times10^{-8}$ 変わる（\texttt{ckm\_estimate.wl}）。どれも本ノートの精度（2ループの項、入力の誤差）よりはるかに小さい。このとき $W$ の紫外の極の変化は0になり、トップの紫外の極の変化は上の $\beta_{y_t}$ の変化と一致し、トップの極質量の変化は $\xi_W$ によらなかった。2ループの $\beta$ 関数には $\mathrm{tr}(Y_uY_u^\dagger Y_dY_d^\dagger)=\sum_{ij}|V_{ij}|^2y_{u_i}^2y_{d_j}^2$ などが入るが、その変化も $|V_{ts}|^2y_t^2y_b^2\approx4\times10^{-7}$ の程度である。なお FeynArts の模型は湯川結合を行列の要素の記号として持ち、非対角の要素が0であることを知らないので、世代を変える図を挿入する。それらは \texttt{FCFAConvert} の後で0になる（図~\ref{fig:se}）。CKM 行列を入れるには、湯川結合を質量の基底で対角のまま、$V$ を $W$ と $G^\pm$ の頂点に入れればよい。

\section{結果}\label{sec:results}

\subsection{Feynman 則}\label{sec:rules}

式~\eqref{eq:L}〜\eqref{eq:fp} から読み取れる頂点を、表~\ref{tab:rules-f}〜\ref{tab:rules-gh} に示す（\ref{app:rules}）。運動量はすべて頂点に入る向きにとり、$p_i$ は $i$ 番目の脚の運動量、$\mu_i$ はそのローレンツの添字である。場の並びは FeynRules の出力と同じで、$\{\phi_1,\phi_2,\dots\}$ の頂点はラグランジアンのその場の積の項に対応する。場 $W$ は $W^+$ を消し $W^-$ を作る場、$\bar W$ はその共役で、$G^\pm$、$u^\pm$ も同様である。ゲージ場の頂点の Lorentz 構造を
\begin{equation}
\begin{gathered}
\Gamma^{\mu_1\mu_2\mu_3}(p_1,p_2,p_3)=g^{\mu_1\mu_2}(p_1-p_2)^{\mu_3}+g^{\mu_2\mu_3}(p_2-p_3)^{\mu_1}+g^{\mu_3\mu_1}(p_3-p_1)^{\mu_2},\\
S^{ij,kl}=2g^{\mu_i\mu_j}g^{\mu_k\mu_l}-g^{\mu_i\mu_k}g^{\mu_j\mu_l}-g^{\mu_i\mu_l}g^{\mu_j\mu_k}
\end{gathered}
\label{eq:GammaS}
\end{equation}
と書く。頂点のクラスは93個で、フェルミオン23、スカラーの自己結合9、ゲージ場の自己結合8、ゲージ場とスカラー29、ゴーストとゲージ場13、ゴーストとスカラー11である。ゴーストとスカラーの結合は、反ゴーストのゲージ場の $\xi$（$\bar u^\pm$ なら $\xi_W$、$\bar u^Z$ なら $\xi_Z$）に比例し、$\bar u^A$ の結合はない。伝播関数と頂点の型を図~\ref{fig:rulesfig} に示す。

\paragraph{べき数え上げ。}外線のボソン $E_B$ 本とフェルミオン $E_F$ 本の1PI 図の表面的な発散次数は、くりこみ可能な理論の一般の式 $\omega=4-E_B-\frac32E_F$ である（ゴーストはボソンと同じに数える）。$R_\xi$ ゲージの伝播関数 \eqref{eq:propV} は $k\to\infty$ で $1/k^2$ になるので、ユニタリーゲージと違ってこの数え上げが使える。タドポール（$E_B=1$）は $\omega=3$ だが、次元正則化では $A_0$ の $m^2\DUV$ だけが残る。

\subsection{木のレベルの関係と崩壊幅}\label{sec:tree}

$\MSbar$ のパラメータで書いた木のレベルの関係は、物理的な入力で書いたものと同じ形である。$\mu$ 崩壊の4フェルミの振幅を運動量0で比べると、木のレベルでは
\begin{equation}
\frac{G_F}{\sqrt2}=\frac{g^2}{8M_W^2}=\frac1{2v^2}
\label{eq:GF}
\end{equation}
である（1ループの補正は式~\eqref{eq:GF1}）。2体の崩壊幅は、終状態の質量を残して（\ref{app:tree}）
\begin{equation}
\begin{aligned}
\Gamma(W^+\to f\bar f')&=N_c\frac{e^2M_W}{48\pi\sw^2}\,\lambda^{1/2}(1,x_f,x_{f'})\Bigl[1-\frac{x_f+x_{f'}}2-\frac{(x_f-x_{f'})^2}2\Bigr],\qquad x=\frac{m^2}{M_W^2},\\
\Gamma(Z\to f\bar f)&=N_c\frac{e^2M_Z}{24\pi}\beta_f\bigl[(g_L^{f2}+g_R^{f2})(1-x_f)+6g_L^fg_R^fx_f\bigr],\qquad x_f=\frac{m_f^2}{M_Z^2},\ \beta_f=\sqrt{1-4x_f},\\
\Gamma(H\to f\bar f)&=N_c\frac{m_f^2M_H}{8\pi v^2}\beta_f^3,\qquad \beta_f=\sqrt{1-4m_f^2/M_H^2},\\
\Gamma(t\to bW^+)&=\frac{e^2m_t^3}{64\pi\sw^2M_W^2}\,\lambda^{1/2}(1,x_b,x_W)\bigl[(1-x_b)^2+x_W(1+x_b)-2x_W^2\bigr],\qquad x=\frac{m^2}{m_t^2}
\end{aligned}
\label{eq:widths}
\end{equation}
で、$\lambda(a,b,c)=a^2+b^2+c^2-2ab-2bc-2ca$ である。質量0では $\Gamma(W\to\ell\nu)=e^2M_W/(48\pi\sw^2)$、$\Gamma(Z\to\nu\bar\nu)=e^2M_Z/(96\pi\sw^2\cw^2)$ になり、式~\eqref{eq:GF} で $G_FM_W^3/(6\sqrt2\pi)$、$G_FM_Z^3/(12\sqrt2\pi)$ と書ける。$H\to WW$、$ZZ$ は基準点でも物理の値でも2体では開かない。

質量0のフェルミオンの $e^+e^-\to f\bar f$（$f\ne e$）は、光子と $Z$ の $s$ チャンネルの交換で（\ref{app:tree}）
\begin{equation}
\sum|\mathcal M|^2=4e^4N_c\Bigl[u^2\bigl(|A_{LL}|^2+|A_{RR}|^2\bigr)+t^2\bigl(|A_{LR}|^2+|A_{RL}|^2\bigr)\Bigr],\qquad
A_{ij}=\frac{Q_eQ_f}{s}+\frac{g_i^eg_j^f}{s-M_Z^2+iM_Z\Gamma_Z}
\label{eq:eeff}
\end{equation}
である（$i,j=L,R$、$t=(p_{e^-}-p_f)^2$）。光子だけなら $8e^4N_cQ_f^2(t^2+u^2)/s^2$ になる。

$e^-(p_1)e^+(p_2)\to W^-(k_1)W^+(k_2)$（電子の質量0）は、$s$ チャンネルの光子と $Z$、$t$ チャンネルの $\nu_e$ の三つの図からなる。縦波の $W$ 対では、偏極ベクトルが $\epsilon_L(k)=k/M_W+O(M_W/E)$ なので、各図が $s/M_W^2$ に比例して増える。高エネルギーで、三つの図の主要な部分は（\ref{app:tree}）
\begin{equation}
\mathcal M_\nu+\mathcal M_\gamma+\mathcal M_Z\simeq\frac{e^2}{M_W^2}\,\bar v(p_2)\slashed k_2\Bigl[\Bigl(\frac1{2\sw^2}+Q_e+\frac{\cw}{\sw}g_L^e\Bigr)P_L+\Bigl(Q_e+\frac{\cw}{\sw}g_R^e\Bigr)P_R\Bigr]u(p_1)
\label{eq:eeww}
\end{equation}

\subsection{$\MSbar$ の対抗項と繰り込み群}\label{sec:rg}

\paragraph{1ループの $\beta$ 関数。}式~\eqref{eq:bare} の裸の量が $\mu$ によらないことから、1ループでは
\begin{equation}
Z_X=1+\frac{\beta_X}{2X}\DUV\qquad(X=g,g',g_s,\lambda,y_f,\mu^2;\ \beta_{\mu^2}\equiv\gamma_{\mu^2})
\label{eq:zrule}
\end{equation}
で、$\beta_X$ は4次元の1ループの $\beta$ 関数である（\ref{app:rg}）。標準模型では
\begin{equation}
\begin{aligned}
K\beta_{g_s}&=-7g_s^3,\qquad K\beta_g=-\frac{19}6g^3,\qquad K\beta_{g'}=\frac{41}6g'^3,\\
K\beta_{y_u}&=y_u\Bigl[\frac32(y_u^2-y_d^2)+\mathcal T-8g_s^2-\frac94g^2-\frac{17}{12}g'^2\Bigr],\\
K\beta_{y_d}&=y_d\Bigl[\frac32(y_d^2-y_u^2)+\mathcal T-8g_s^2-\frac94g^2-\frac5{12}g'^2\Bigr],\\
K\beta_{y_\ell}&=y_\ell\Bigl[\frac32y_\ell^2+\mathcal T-\frac94g^2-\frac{15}4g'^2\Bigr],\\
K\beta_\lambda&=24\lambda^2+4\lambda\mathcal T-2\sum_i\bigl(3y_{u_i}^4+3y_{d_i}^4+y_{\ell_i}^4\bigr)-3\lambda(3g^2+g'^2)+\frac38\bigl[2g^4+(g^2+g'^2)^2\bigr],\\
K\gamma_{\mu^2}&=\mu^2\Bigl[12\lambda+2\mathcal T-\frac92g^2-\frac32g'^2\Bigr]
\end{aligned}
\label{eq:beta}
\end{equation}
である（$y_u$ と $y_d$ は同じ世代の組、$\mathcal T=\sum_i(3y_{u_i}^2+3y_{d_i}^2+y_{\ell_i}^2)$）。トップだけを残すと、よく知られた $K\beta_{y_t}=y_t(\frac92y_t^2-8g_s^2-\frac94g^2-\frac{17}{12}g'^2)$、$K\beta_\lambda=24\lambda^2+12\lambda y_t^2-6y_t^4-3\lambda(3g^2+g'^2)+\frac38[2g^4+(g^2+g'^2)^2]$ になる~\cite{mv1,mv2,mv3,arason92}。ゲージ結合の係数は $-\frac{11}3C_2(G)+\frac23S_2(F)+\frac13S_2(S)$（$F$ は Weyl フェルミオン、$S$ は複素スカラー）で、$SU(2)$ では $-\frac{22}3+4+\frac16$、$U(1)$ では $\frac{20}3+\frac16$、$SU(3)$ では $-11+4$ である。$\beta_\lambda$ と $\gamma_{\mu^2}$ は、Landau ゲージの1ループの有効ポテンシャルが $\mu$ によらないことと、Landau ゲージの $K\gamma_\Phi=\mathcal T-\frac94g^2-\frac34g'^2$ から導いた（\ref{app:rg}）。

\paragraph{$e$、$\sw^2$ と $\MSbar$ の質量の走り。}式~\eqref{eq:masses} から
\begin{equation}
\frac{\dd e}{\dd\ln\mu}=\frac{11}3\frac{e^3}K,\qquad
\frac{\dd\sw^2}{\dd\ln\mu}=\frac{2e^2}K\Bigl(\frac{41}6\sw^2+\frac{19}6\cw^2\Bigr)
\label{eq:erun}
\end{equation}
である。$\frac{11}3=\frac43\sum_fN_cQ_f^2-7$ は、3世代のフェルミオン（$\frac43\cdot8$）と $W$ のループ（$-7$）の和で、$W$ を脱結合させていない $\MSbar$ の電荷の走りである。$v^2=\mu^2/\lambda$ と質量の走りは
\begin{equation}
\begin{aligned}
K\frac{\dd\ln v^2}{\dd\ln\mu}&=K\Bigl(\frac{\gamma_{\mu^2}}{\mu^2}-\frac{\beta_\lambda}\lambda\Bigr)
=-12\lambda-2\mathcal T+\frac92g^2+\frac32g'^2+\frac2\lambda\sum_fN_cy_f^4-\frac3{8\lambda}\bigl[2g^4+(g^2+g'^2)^2\bigr],\\
\frac{\dd\ln M_W^2}{\dd\ln\mu}&=\frac{\dd\ln v^2}{\dd\ln\mu}+\frac{2\beta_g}g,\qquad
\frac{\dd\ln M_Z^2}{\dd\ln\mu}=\frac{\dd\ln v^2}{\dd\ln\mu}+\frac{2(g\beta_g+g'\beta_{g'})}{g^2+g'^2},\\
\frac{\dd\ln M_H^2}{\dd\ln\mu}&=\frac{\gamma_{\mu^2}}{\mu^2},\qquad
\frac{\dd\ln m_f^2}{\dd\ln\mu}=\frac{\dd\ln v^2}{\dd\ln\mu}+\frac{2\beta_{y_f}}{y_f}
\end{aligned}
\label{eq:vrun}
\end{equation}
である（$\sum_f$ は9個の質量のあるフェルミオンについての和）。$v^2$ の走りの $1/\lambda$ の項はタドポールから来る（第~\ref{sec:tadpole} 節）。物理の値の付近（$\mu\approx m_t$）では $\frac2\lambda\sum N_cy_f^4\approx6y_t^4/\lambda\approx37$ で、残りの項の和（約 $-7$）の5倍ほどあり、FJ の処方の $v^2$ と $\MSbar$ の質量は $\mu$ が $e$ 倍になるごとに2割ほど変わる。

\paragraph{質量の対抗項。}FJ の処方では、裸の質量は $\MSbar$ のパラメータの組み合わせで（$M_{W,0}^2=g_0^2\mu_0^2/(4\lambda_0)$ など）、式~\eqref{eq:zrule} から
\begin{equation}
\delta M^2\equiv M_0^2-M^2=\frac{\DUV}2\,\frac{\dd M^2}{\dd\ln\mu}\qquad(M=M_W,M_Z,M_H,m_f\ \text{の2乗})
\label{eq:dM2}
\end{equation}
である。これらは $\MSbar$ のパラメータの $\beta$ 関数だけで決まるので、ゲージによらない。フェルミオンでは $m_0=m+\delta m$、$\delta m/m=\frac{\DUV}4\dd\ln m^2/\dd\ln\mu$ である。

\paragraph{場の繰り込み。}場の繰り込み定数はゲージに依存し、物理量には入らないが、2点関数の紫外の極の $k^2$ の形を決める。共通の $\xi$（$\xi_A=\xi_Z=\xi_W=\xi$）では、$R_\xi$ のゲージ固定は $W^a$、$B$ の対称な共変ゲージに質量に比例する項を加えたものなので、$k^2$ の係数は対称な相の共変ゲージの値で決まり（\ref{app:rg}）
\begin{equation}
\delta Z_W=\frac{g^2}K\Bigl(\frac16-\xi\Bigr)\DUV,\qquad \delta Z_B=-\frac{41}6\frac{g'^2}K\DUV=-2(Z_{g'}-1)
\label{eq:dZWB}
\end{equation}
である（$\delta Z_X\equiv Z_X-1$）。$\delta Z_W$ は $(\frac{13}6-\frac\xi2)C_2(G)-\frac23S_2(F)-\frac13S_2(S)$ の $SU(2)$ の値、$\delta Z_B$ は可換の Ward 恒等式 $Z_{g'}Z_B^{1/2}=1$ による。質量の基底では、裸の場 $A_0=\sin\theta_0W^3_0+\cos\theta_0B_0$、$Z_0=\cos\theta_0W^3_0-\sin\theta_0B_0$ を繰り込まれた場で書き（$\tan\theta=g'/g$）、$Z_0=(1+\frac12\delta Z_{ZZ})Z+\frac12\delta Z_{ZA}A$、$A_0=\frac12\delta Z_{AZ}Z+(1+\frac12\delta Z_{AA})A$ とすると
\begin{equation}
\begin{gathered}
\delta Z_{AA}=\sw^2\delta Z_W+\cw^2\delta Z_B,\qquad \delta Z_{ZZ}=\cw^2\delta Z_W+\sw^2\delta Z_B,\\
\delta Z_{ZA}=2\sw\cw\Bigl(\delta Z_g+\frac{\delta Z_W}2\Bigr),\qquad \delta Z_{AZ}=\sw\cw\bigl(4\delta Z_{g'}+\delta Z_W-2\delta Z_g\bigr)
\end{gathered}
\label{eq:dZmix}
\end{equation}
で、自己エネルギーの紫外の極は
\begin{equation}
\Sigma^{AA}_T\big|_{\mathrm{UV}}=-\delta Z_{AA}k^2,\qquad
\Sigma^{AZ}_T\big|_{\mathrm{UV}}=-\frac{\delta Z_{AZ}}2k^2-\frac{\delta Z_{ZA}}2\bigl(k^2-M_Z^2\bigr),\qquad
\Sigma^{VV}_T\big|_{\mathrm{UV}}=-\delta Z_{VV}\bigl(k^2-M_V^2\bigr)+\delta M_V^2
\label{eq:uvk2}
\end{equation}
になるはずである（$V=W,Z$、$\delta Z_{WW}\equiv\delta Z_W$）。光子の自己エネルギーは $W$ のループを通じてだけ $\xi$ によるので、$\Sigma^{AA}_T$ の極は、$\xi_A,\xi_Z,\xi_W$ が違っても $\xi=\xi_W$ の式で決まる：$K\Sigma^{AA}_T|_{\mathrm{UV}}=e^2(\frac{20}3+\xi_W)k^2\DUV$（$\frac{20}3=\frac43\sum N_cQ_f^2+\frac13-\frac{13}3$）。$k^2=0$ では $\Sigma^{AZ}_T(0)|_{\mathrm{UV}}=\frac{M_Z^2}2\delta Z_{ZA}=-\frac{e^2M_W^2}{2K\sw\cw}(3+\xi)\DUV$ で、0でない。電荷の繰り込み定数は、$e=gg'/\sqrt{g^2+g'^2}$ と式~\eqref{eq:dZmix} から
\begin{equation}
Z_e-1=\sw^2\delta Z_g+\cw^2\delta Z_{g'}=-\frac12\delta Z_{AA}+\frac{\sw}{2\cw}\delta Z_{ZA}=\frac{11}6\frac{e^2}K\DUV
\label{eq:dZe}
\end{equation}
で、光子と $\gamma Z$ の2点関数の極だけで書ける。$\delta Z_{AA}$ と $\delta Z_{ZA}$ はそれぞれ $\xi_W$ に依存するが、この組み合わせでは打ち消す。混合の項の符号は Denner の式~\cite{denner93} と逆で、光子の場の符号の違い（$A^{\mathrm{Denner}}=-A$）から来る。

\subsection{タドポールと2点関数}\label{sec:tadpole}

\paragraph{タドポール。}1ループの $H$ の1点の1PI 関数 $iT$ は、図~\ref{fig:tadpole} の図の和で、一般の $R_\xi$ ゲージで（\ref{app:tadpole}）
\begin{equation}
\begin{aligned}
T=\frac1{Kv}\Bigl[&2M_W^2\bigl(3A_0(M_W)-2M_W^2\bigr)+M_Z^2\bigl(3A_0(M_Z)-2M_Z^2\bigr)+\frac32M_H^2A_0(M_H)\\
&+\frac{M_H^2}2\Bigl(A_0\bigl(\sqrt{\xi_Z}M_Z\bigr)+2A_0\bigl(\sqrt{\xi_W}M_W\bigr)\Bigr)-4\sum_fN_cm_f^2A_0(m_f)\Bigr]
\end{aligned}
\label{eq:T}
\end{equation}
である。$-2M_V^2$ は $(D-1)A_0(M_V)$ の $(D-4)A_0$ から来る有理数の項である。$W$ と $Z$ のループの $\xi$ に比例する部分 $\xi_VA_0(\sqrt{\xi_V}M_V)$ は、ゴーストのループがちょうど打ち消し、$\xi$ 依存は Goldstone ボソンのループの質量 $\sqrt{\xi_V}M_V$ だけに残る。

\paragraph{2点関数とタドポールの寄与。}1PI の2点関数の1ループの部分を、Denner~\cite{denner93} と同じ形で
\begin{equation}
\Gamma^{VV'}_{\mu\nu}\supset-ig_{\mu\nu}\Sigma^{VV'}_T(k^2)+(k_\mu k_\nu\ \text{の項}),\qquad
\Gamma^H\supset i\Sigma^H(k^2),\qquad
\Gamma^f\supset i\bigl[\slashed pP_L\Sigma^L_f+\slashed pP_R\Sigma^R_f+m_f\Sigma^S_f\bigr]
\label{eq:Gamma2}
\end{equation}
と書く。FJ の処方では、これにタドポールの付いた図（図~\ref{fig:tadpole} の右）を加えたものを2点関数とする。その寄与は
\begin{equation}
\Sigma^{WW}_T\supset-2M_W^2\frac{\Delta v}v,\qquad \Sigma^{ZZ}_T\supset-2M_Z^2\frac{\Delta v}v,\qquad
\Sigma^H\supset-6\lambda v\,\Delta v=-\frac{3T}v,\qquad \Sigma^S_f\supset-\frac{\Delta v}v
\label{eq:tadins}
\end{equation}

\paragraph{極質量の紫外の極。}極は $k^2-M_0^2+\Sigma_T(k^2)=0$（$H$ では $\Sigma^H$、フェルミオンでは $m_{\mathrm p}=m(1-\Sigma^V-\Sigma^S)$、$\Sigma^V=(\Sigma^L+\Sigma^R)/2$）にあるので、1ループの極質量は
\begin{equation}
M_{\mathrm p}^2=M^2-\re\Sigma_T(M^2)\big|_{\MSbar}
\label{eq:pole}
\end{equation}
で、それが有限であることは、タドポールを含めた $\Sigma_T(M^2)$ の $\DUV$ の係数が式~\eqref{eq:dM2} の $\frac12\dd M^2/\dd\ln\mu$ に等しいことと同じである。フェルミオンでは、$\Sigma^V_f(m_f^2)+\Sigma^S_f(m_f^2)$ の $\DUV$ の係数が $\delta m_f/m_f$ の係数 $\frac14\dd\ln m_f^2/\dd\ln\mu$ に等しい。右辺はゲージによらないので、$\Sigma_T(M^2)$ の紫外の極は、タドポールを含めると $\xi$ によらないはずである。同じことが有限部分にも言え、1ループの極質量はタドポールを含めると $\xi$ によらない（手順 (3)、(5) で確かめる）。

\paragraph{Slavnov--Taylor 恒等式。}ゲージ固定の関数の2点関数は、BRST 不変性によって木の値から変わらない（$\langle F^+F^-\rangle=-i\xi_W$、$\langle F^AF^Z\rangle=0$ など、\ref{app:tadpole}）。1PI の関数を、Feynman 則の積で縦の部分 $-i\frac{k_\mu k_\nu}{k^2}\Sigma^{VV'}_L$、$W^+$ が入り $G^+$ が出る混合 $ik_\mu\Sigma^{WG}$（$G^+$ が入り $W^+$ が出るものは $\Sigma^{GW}$）、Goldstone ボソン $i\Sigma^{G}$ と書くと、1ループでは
\begin{equation}
\begin{gathered}
k^2\Sigma^{WW}_L+iM_Wk^2\bigl(\Sigma^{GW}-\Sigma^{WG}\bigr)-M_W^2\Sigma^{G^\pm}=0,\qquad
k^2\Sigma^{ZZ}_L+iM_Zk^2\bigl(\Sigma^{G^0Z}-\Sigma^{ZG^0}\bigr)-M_Z^2\Sigma^{G^0}=0,\\
\Sigma^{AA}_L=0,\qquad \Sigma^{AZ}_L+iM_Z\Sigma^{G^0A}=0
\end{gathered}
\label{eq:st}
\end{equation}
が、くりこまない2点関数（タドポールの付いた図を含める）で一般の $R_\xi$ ゲージで成り立つ。$\langle W^+_\mu G^-\rangle$ は $G^+\to W^+$ の遷移なので $\Sigma^{GW}$ が、$\langle G^+W^-_\nu\rangle$ には $\Sigma^{WG}$ が入る。各 $\xi$ の因子は、木の伝播関数の縦の部分 $-i\xi/(k^2-\xi M^2)$ と Goldstone ボソンの $i/(k^2-\xi M^2)$ の積から共通に括り出される。

\paragraph{$\beta_t$ の処方との関係。}ループで補正したポテンシャルの最小点は $v+\Delta v$ である（\ref{app:tadpole}）。$\beta_t$ の処方はこの点のまわりで展開してタドポールの図を除き、その代わりに $v_\beta=v+\Delta v|_{\MSbar}$ を真空期待値とする。1ループでは、FJ のタドポールの付いた図（式~\eqref{eq:tadins}）が、$\beta_t$ の処方の木の質量の $v_\beta$ と $v$ の差にちょうど置き換わり、物理量はどちらでも同じである。違いは $v_\beta$（と $g v_\beta/2$ などの「$\MSbar$ の質量」）がゲージに依存することである。式~\eqref{eq:T} の $A_0$ の $\ln\mu^2$ と式~\eqref{eq:vrun} から
\begin{equation}
\frac{\dd\ln v_\beta}{\dd\ln\mu}=\frac12\frac{\dd\ln v^2}{\dd\ln\mu}+\frac{\dd}{\dd\ln\mu}\frac{\Delta v}v
=-\gamma_\Phi^{\mathrm L}+\frac1{4K}\bigl[\xi_Z(g^2+g'^2)+2\xi_Wg^2\bigr],\qquad
K\gamma_\Phi^{\mathrm L}=\mathcal T-\frac94g^2-\frac34g'^2
\label{eq:vbeta}
\end{equation}
である（$\gamma_\Phi^{\mathrm L}$ は Landau ゲージの $\Phi$ の異常次元）。$v$ の走りの $1/\lambda$ の項は $\Delta v$ の走りと打ち消し、$v_\beta$ は Landau ゲージでは場の異常次元で走り、一般の $R_\xi$ ゲージでは Goldstone ボソンの質量を通じて $\xi$ に依存して走る。$\phi^3$ のノートの線形項 $Y$ と違い、この依存を吸収する独立なパラメータはない。

\subsection{$G_F$ と $\alpha(0)$ の換算}\label{sec:matching}

\paragraph{$\mu$ 崩壊。}$\mu^-\to\nu_\mu e^-\bar\nu_e$ の振幅を、外線の運動量を0、$e$ と $\mu$ の質量を0にして比べる。1ループの振幅を木の振幅の $1+\hat\Delta$ 倍と書くと、式~\eqref{eq:GF} は
\begin{equation}
\frac{G_F}{\sqrt2}=\frac{1+\hat\Delta}{2v^2},\qquad
\hat\Delta=\Bigl[\frac{\Sigma^{WW}_T(0)}{M_W^2}+\delta_V+\delta_B-\frac12\sum_{f=\mu,\nu_\mu,e,\nu_e}\Sigma^L_f(0)\Bigr]_{\MSbar}
\label{eq:GF1}
\end{equation}
になる。$\Sigma^{WW}_T(0)$ はタドポールの付いた図を含み（式~\eqref{eq:tadins}）、$\delta_V$、$\delta_B$ は頂点と箱の図の振幅の木に対する比、最後の項は外線の場の繰り込みである。$\mu$ の寿命から決める $G_F$ は Fermi 理論の4フェルミの結合で、比べるのは標準模型の振幅から Fermi 理論の光子のループを引いたものである。運動量0では後者は0になる（Fierz 変換した $\bar e\gamma^\alpha P_L\mu$ の流れについての Ward 恒等式で、頂点と外線の補正が打ち消す~\cite{sirlin80}）。光子に赤外の質量 $M_A$ を与えると、箱と外線の補正は別々に $\ln M_A$ を含むが、和は含まない。$v_0^2=v^2(1+\frac{\DUV}2\dd\ln v^2/\dd\ln\mu)$ なので、式~\eqref{eq:GF1} の括弧の $\DUV$ の係数は $\frac12\dd\ln v^2/\dd\ln\mu$（式~\eqref{eq:vrun}）でなければならない。これは1ループで $G_F$ が $\mu$ によらないことと同じである。Feynman ゲージでは
\begin{equation}
K\Bigl[\delta_V+\delta_B-\frac12\sum_f\Sigma^L_f(0)\Bigr]=\frac{e^2}{\sw^2}\Bigl[4B_0(0,M_W,M_W)+6+\frac{7-4\sw^2}{2\sw^2}\ln\cw^2\Bigr]
\label{eq:dVB}
\end{equation}
で、$\mu=M_W$ での $\MSbar$ の有限部分は Sirlin の $\delta_{VB}$~\cite{sirlin80,denner93} である。各項は $\xi$ に依存するが、和の $\hat\Delta$ はゲージによらない（手順 (6)）。$\hat\Delta$ で最も大きい項は $\Sigma^{WW}_T(0)$ のタドポールの部分 $-2\Delta v/v$（基準点で $-0.028$〜$-0.031$、ゲージによる）で、その大部分をトップのループが占める。$\hat\Delta$ は $\mu$ とともに $\dd\ln v^2/\dd\ln\mu$ の割合で変わり、$\mu\approx m_t$ では $\mu$ が $e$ 倍になるごとに約 $0.2$ 変わる。図の型を図~\ref{fig:mudecay} に示す。

\paragraph{電荷。}Thomson 極限の電荷を $e_{\mathrm{OS}}$（$\alpha(0)=e_{\mathrm{OS}}^2/(4\pi)$）とすると、$\MSbar$ の $e(\mu)$ との関係は、on-shell の電荷の繰り込み定数の有限部分で
\begin{equation}
\frac{e(\mu)}{e_{\mathrm{OS}}}=1+\delta_e,\qquad
\delta_e=\Bigl[\frac12\Pi^{AA}(0)+\frac\sw\cw\frac{\Sigma^{AZ}_T(0)}{M_Z^2}\Bigr]_{\MSbar},\qquad
\Pi^{AA}(0)=\frac{\dd\Sigma^{AA}_T}{\dd k^2}\Big|_{k^2=0}
\label{eq:deltae}
\end{equation}
である（$A=-A_{\mathrm{Denner}}$ なので、混合の項の符号は Denner~\cite{denner93} の式と逆）。$\DUV$ の係数は式~\eqref{eq:dZe} の $\frac{11}6\frac{e^2}K$ である。$\Pi^{AA}(0)$ と $\Sigma^{AZ}_T(0)$ は別々には $\xi_W$ に依存するが、$\delta_e$ はよらない。トップ以外のフェルミオン（軽いフェルミオン）の $\Pi_f(0)$ は、ハドロンでは摂動で求まらない。そこで、on-shell の $\alpha(M_Z^2)=\alpha(0)/[1-\Delta\alpha(M_Z^2)]$ の $\Delta\alpha=\sum_f[\Pi_f(0)-\re\Pi_f(M_Z^2)]$ を使い、$\Pi_f(0)$ を $\re\Pi_f(M_Z^2)+\Delta\alpha_f$ で置き換える。質量0の $\re\Pi_f(M_Z^2)$ を使うと、1ループで
\begin{equation}
\frac1{\hat\alpha(\mu)}=\frac{1-\Delta\hat\alpha(\mu)}{\alpha(0)},\qquad
\Delta\hat\alpha(\mu)=\Delta\alpha_{\mathrm{lep}}+\Delta\alpha^{(5)}_{\mathrm{had}}+\frac\alpha\pi\Bigl[\frac{100}{27}-\frac16-\frac{20}9\ln\frac{M_Z^2}{\mu^2}-\frac74\ln\frac{\mu^2}{M_W^2}-\frac49\ln\frac{m_t^2}{\mu^2}\Bigr]
\label{eq:alphahat}
\end{equation}
である（$\hat\alpha=e(\mu)^2/(4\pi)$、$\Delta\hat\alpha=2\delta_e$。1ループの $1/\alpha$ の走りが線形なので、PDG と同じく $1/\hat\alpha$ を線形に書く）。括弧の $\frac{100}{27}-\frac{20}9\ln$ は8個の軽いフェルミオン（$\sum N_cQ_f^2=\frac{20}3$）、$-\frac16-\frac74\ln$ は $W$ とその Goldstone ボソン、ゴーストのループ、最後の項はトップの寄与である。トップを除いて $\mu=M_Z$ に置くと、PDG の電弱のレビューの $\Delta\hat\alpha(M_Z)-\Delta\alpha(M_Z)$ の式~\cite{pdg24} の1ループの部分になる。$\mu$ への依存は $\dd(1/\hat\alpha)/\dd\ln\mu=-\frac{11}{6\pi}$ で、式~\eqref{eq:erun} と合う。

\subsection{測定値から決める $\MSbar$ のパラメータ}\label{sec:fit}

\paragraph{1ループの換算。}式~\eqref{eq:pole}、\eqref{eq:GF1} を $\MSbar$ のパラメータについて解く。1ループの関数を on-shell の入力から作った木の値で評価し、補正について1次で打ち切る（Buttazzo らの $\theta=\theta^{(0)}+\theta^{(1)}$~\cite{buttazzo13} と同じ打ち切り）。$v_G^2=1/(\sqrt2G_F)$ として
\begin{equation}
\begin{gathered}
g=\frac{2M_W}{v_G}\Bigl[1+\frac12(\delta_W-\hat\Delta)\Bigr],\qquad
g^2+g'^2=\frac{4M_Z^2}{v_G^2}\bigl(1+\delta_Z-\hat\Delta\bigr),\qquad
y_t=\frac{\sqrt2M_t}{v_G}\Bigl(1+\delta_t-\frac12\hat\Delta\Bigr),\\
\lambda=\frac{M_h^2}{2v_G^2}\bigl(1+\delta_H-\hat\Delta\bigr),\qquad
m^2\equiv2\mu^2=M_h^2(1+\delta_H),\qquad
v=v_G\Bigl(1+\frac12\hat\Delta\Bigr)
\end{gathered}
\label{eq:fit}
\end{equation}
である。ここで $\delta_V=\re\Sigma^{VV}_T(M_V^2)/M_V^2$、$\delta_H=\re\Sigma^H(M_h^2)/M_h^2$、$\delta_t=\re(\Sigma^V+\Sigma^S)(M_t^2)$ はタドポールの付いた図を含む $\MSbar$ の有限部分で、$M$ はすべて極の質量である。$g'$ は2番目の式から $g$ を引いて1次で求める。$m$ は Buttazzo らの $V=-\frac12m^2|H|^2+\lambda|H|^4$ の質量で、$\MSbar$ の Lagrangian のパラメータ $m^2$ を1次で展開する。タドポールの部分は $\delta_W-\hat\Delta$、$\delta_Z-\hat\Delta$、$\delta_t-\frac12\hat\Delta$ で打ち消す（式~\eqref{eq:tadins} から $-2\Delta v/v$、$-\Delta v/v$ が両方に入る）。一方 $\lambda$ と $m^2$ には残る（$\Sigma^H$ の $-3\Delta v/v$ と $\hat\Delta$ の $-2\Delta v/v$）。

$M_W$ の代わりに $\alpha(0)$ を入力にすると（Martin--Robertson の入力の組~\cite{mr19}）、$M_W$ を予言できる。$\delta_W$、$\delta_Z$、$\hat\Delta$ のタドポールの部分（$\mu=M_t$ でそれぞれ約 $0.12$）は $\hat\Delta-\delta_Z$ と $\delta_Z-\delta_W$ でだけ打ち消すので、これらについて1次で
\begin{equation}
s_W^2c_W^2=\frac{e(\mu)^2}{4\sqrt2G_FM_Z^2}\bigl(1+\hat\Delta-\delta_Z\bigr),\qquad
M_W=M_Zc_W\Bigl[1+\frac12(\delta_Z-\delta_W)\Bigr]
\label{eq:fitalpha}
\end{equation}
と書き、$e(\mu)$ を式~\eqref{eq:alphahat} からとる。1ループの関数は予言した $M_W$ で評価し、自己無撞着になるまで繰り返す。その $M_W$ を式~\eqref{eq:fit} に入れると、$g$ と $g'$ が決まる。

\paragraph{トップの QCD の高次。}$\mu=M_t$ での純 QCD の換算は、$a=\alpha_s^{(6)}(M_t)/\pi$ で
\begin{equation}
\frac{m_t(M_t)}{M_t}=1-\frac43a-9.125\,a^2-(80.42\pm0.02)\,a^3+O(a^4)
\label{eq:mtqcd}
\end{equation}
である。これは Marquard らの $m_t(m_t)/M_t$~\cite{marquard16} を、6フレーバーの $\gamma_m$（2ループの係数 $\gamma_1=\frac{27}8$）で $\mu=m_t(m_t)$ から $M_t$ まで走らせて求めた（$\pm0.02$ は Marquard らの3ループの係数 $1.944$ の丸めによる。$y_t$ への影響は $10^{-6}$ 以下である）。1ループの $-\frac43a$ は手順 (5) で確かめた $\delta_t$ の QCD の部分である。本ノートの1ループの結果は1ループの $\delta_t$ だけで出し、文献と比べるときだけ $a^2$、$a^3$ の項を加える（表~\ref{tab:fit} の $y_t^{\mathrm{QCD3}}$）。$\alpha_s^{(6)}(\mu)$ は $\alpha_s^{(5)}(M_Z)$ から1ループの走り（$n_f=5$）と1ループの脱結合 $\alpha_s^{(6)}=\alpha_s^{(5)}[1+\frac{\alpha_s}{6\pi}\ln(\mu^2/M_t^2)]$ で求める。

\subsection{繰り込み群の走りと $\lambda$ の零点}\label{sec:running}

\paragraph{2ループの $\beta$ 関数。}2ループの $\beta$ 関数のうち、ゲージ結合を $g=g'=0$ とした極限（$y_b=y_\tau=0$）の部分を、本ノートの模型の2ループの図から求める（手順 (8)）。$\beta$ 関数は質量によらないので、破れていない相（$v=0$、すべての質量0）で求めればよい。$\beta_x=\dd x/\dd\ln\mu$ として
\begin{align}
K^2\beta^{(2)}_{y_t}&=y_t\bigl(-12y_t^4-12\lambda y_t^2+6\lambda^2+36g_s^2y_t^2-108g_s^4\bigr),\notag\\
K^2\beta^{(2)}_{g_s}&=-26g_s^5-2g_s^3y_t^2,\label{eq:beta2}\\
K^2\beta^{(2)}_\lambda&=-312\lambda^3-144\lambda^2y_t^2-3\lambda y_t^4+30y_t^6+80g_s^2\lambda y_t^2-32g_s^2y_t^4\notag
\end{align}
である（$-26$ は6フレーバーの QCD の $102-\frac{38}3n_f$）。Higgs 二重項の場の異常次元は、Landau ゲージで $K^2\gamma_\Phi^{\mathrm L(2)}=6\lambda^2+20g_s^2y_t^2-\frac{27}4y_t^4$ になる。式~\eqref{eq:beta2} は Buttazzo らの付録 B の式~\cite{buttazzo13} の同じ極限と一致する（第~\ref{sec:checks} 節）。走りには、1ループの式~\eqref{eq:beta} に式~\eqref{eq:beta2} を加えた方程式（以下「本ノートの方程式」）を使う。$g,g'$ を含む2ループの項、$m^2$ の2ループの項、3ループ以上の項は求めていない。それらの大きさは、文献の2ループと3ループの式（Buttazzo らの付録 B）で走らせた値との差で見積もる。文献の式はこの比較だけに使う。その2ループの部分は、Luo--Wang--Xiao の一般の公式~\cite{luo03}（Machacek--Vaughn~\cite{mv1,mv2,mv3} を複素の Weyl フェルミオンについて直したもの）を標準模型の場で陽に組んだ実装でも確かめた。3ループの項と $g_3$ の4ループの純 QCD の項は確かめていない。

\paragraph{$\lambda$ の零点と $\MSbar$ の質量。}$\lambda(\mu)=0$ となるスケールを $\Lambda_\lambda$ と書く。$\Lambda_\lambda$ は $\MSbar$ の $\lambda$ の性質で、ゲージにはよらないがスキームによる。物理的な不安定のスケールは有効ポテンシャルで定義し~\cite{buttazzo13}、手順 (10) で扱う。FJ の処方の $v^2=\mu^2/\lambda=m^2/(2\lambda)$ は、$\mu^2$ と $\lambda$ がどちらも滑らかに走るのに対して $\lambda\to0$ で発散し、$\Lambda_\lambda$ より上では負になる。したがって FJ の $\MSbar$ の質量 $M_W=gv/2$ などは、$\Lambda_\lambda$ に近づくと意味を失う。$\beta_t$ の処方の $v_\beta$ は、Landau ゲージでは場の異常次元で走り（式~\eqref{eq:vbeta}）、$\lambda$ の零点で特別なことは起きない。ただし $v_\beta$ はゲージに依存する。

\paragraph{一致の基準。}発散部分と対抗項は、$1/\epsilon$ の係数が記号として完全に一致することを求める。有限部分は、基準点で、ツールどうしと手計算の数値が倍精度の丸め誤差の範囲（相対 $10^{-12}$ 程度）で一致することを求める。FeynCalc の PaVe 関数の $\epsilon^0$ の係数は、これまでのノートと同じく $\MSbar$ の値に直してから比べる。MadGraph の断面積は、自分で数値積分した値と統計誤差の範囲で一致することを求める。$\xi$ によらないはずの量は、記号として $\xi$ を含まないこと、または $\xi=0,1,3$ で同じ値になることを求める。応用の手順では、比べる値の精度（文献の値の桁数、統計誤差）の範囲で一致することを求め、その精度を各手順に示す。

\paragraph{手順。}次の順に進める。(1) 模型ファイル \texttt{SM.fr} を一から書き、FeynArts の模型と UFO を書き出して、Feynman 則と MadGraph の図を確かめる。(2) 木の振幅の2乗と崩壊幅を FeynCalc で記号として確かめ、MadGraph の幅と断面積と比べる。$e^+e^-\to W^+W^-$ の縦波の $W$ 対で、三つの図の $s/M_W^2$ に比例して増える部分が打ち消すことを確かめる。(3) タドポールと自己エネルギーを一般の $R_\xi$ ゲージで $D$ 次元で求め、式~\eqref{eq:T} と、タドポールを含めた $\Sigma(M^2)$ の紫外の極が式~\eqref{eq:dM2} に等しく $\xi$ によらないこと、紫外の極の $k^2$ の形が式~\eqref{eq:uvk2} になること、有限部分の極質量が $\xi$ によらないことを確かめる。有限部分を LoopTools、Package-X、COLLIER で比べ、FeynArts の \texttt{SMQCD.mod} の図とも比べる。(4) 2点関数の Slavnov--Taylor 恒等式 \eqref{eq:st} を確かめる。$\beta$ 関数 \eqref{eq:beta} を、2点関数の極（手順 (3) の質量の極と、式~\eqref{eq:dZe} の電荷）と、一般の公式~\cite{mv1,mv2,mv3,luo03} を標準模型の場で陽に組んだ実装の二つで確かめる。式~\eqref{eq:vbeta} の $v_\beta$ の走りを確かめる。(5) $W$、$Z$、$H$、$t$ の1ループの極質量を $\MSbar$ のパラメータで求め、$\xi$ によらないこと、$\mu$ を変えた変化が式~\eqref{eq:vrun} と打ち消すことを確かめる（トップには $O(\alpha_s)$ を含める）。(6) $\mu$ 崩壊の1ループ（頂点と箱の図）から $G_F$ と $\MSbar$ の $v$ の関係を、光子の真空偏極から $\alpha(0)$ と $e(\mu)$ の関係を求め、$\xi$ によらないことを確かめる。(7) 測定値（$G_F$、$M_Z$、$M_W$、$M_H$、$m_t$、$\alpha(0)$ と $\Delta\alpha_{\mathrm{had}}$、$\alpha_s$）から1ループの換算で $\MSbar$ のパラメータを決め、高次の文献の値~\cite{buttazzo13,mr19} と比べる。(8) 2ループの $\beta$ 関数のうちゲージ結合を0にした部分を、本ノートの模型の2ループの図から求めて文献の式と比べる。それを1ループの式に加えた方程式で結合を走らせ、$\lambda$ が0になるスケールを求めて文献~\cite{degrassi12,buttazzo13} と比べる。$\MSbar$ の質量の走りを FJ と $\beta_t$ の処方で比べる。(9) 1ループの電弱の振幅を本ノートの模型で FeynCalc と FormCalc で求め、二つの形で MadLoop と比べる。(a) MadGraph の電弱 NLO の模型（on-shell）の振幅と、パラメータを手順 (5)〜(7) と同じ有限の関係で on-shell の値に直して比べる。(b) $\MSbar$ の対抗項（FJ を対抗項の形にしたもの）を本ノートの模型の UFO に入れ、MadLoop の $\MSbar$ の振幅を直接比べる。その対抗項をすべての頂点に広げ、外線が質量0の過程で (a) の模型と換算を通して比べる。(10) 繰り込み群で改良した有効ポテンシャルで、真空の崩壊の bounce と寿命を、$\phi^3+\phi^4$ と湯川のノート~\cite{phi34note,yukawanote} の道具で求める。

\section{検算}\label{sec:checks}

第~\ref{sec:plan} 節の手順を順に行う。スクリプトはすべて \texttt{Src/} にあり、各手順は \texttt{run\_*.sh} でまとめて再実行できる（手順 (1)〜(5) は \texttt{run\_model\_check.sh}、\texttt{run\_tree\_check.sh}、\texttt{run\_oneloop\_check.sh}、\texttt{run\_rg\_check.sh}、\texttt{run\_pole\_check.sh}）。

\paragraph{手順 (1)：模型ファイル。}FeynRules の模型ファイル \texttt{Src/SM.fr} を一から書いた。ラグランジアンは式~\eqref{eq:L} とゴーストの項 \eqref{eq:fp} で、ゲージ固定の項 \eqref{eq:gf} は頂点を持たないので含めない。ゲージ群、共変微分、場の強さは FeynRules の記法（\texttt{DC}、\texttt{FS}）で書き、湯川結合は世代について対角な行列にした。ゴーストとスカラーの結合は、手で展開した式を使わず、模型ファイルの中で $s\Phi=i(gT^au^a+\frac{g'}2u^B)\Phi$ を2行2列の行列で計算し、そこから $sG^\pm$、$sG^0$ を取り出して $\xi_ZM_Z\bar u^ZsG^0+\xi_WM_W(\bar u^+sG^++\bar u^-sG^-)$ を作った。こうすると、表~\ref{tab:rules-gh} との比較は自分の手計算の写しどうしの比較にならない。外部パラメータは $\MSbar$ の $\alpha^{-1}$、$M_W$、$M_Z$、$M_H$、フェルミオンの質量、$\alpha_s$、$\xi_A,\xi_Z,\xi_W,\xi_G$ で、$v$、$\lambda$、$\mu^2$、湯川結合は式~\eqref{eq:masses} の内部パラメータである（\ref{app:details}）。

FeynRules のチェックでは、エルミート性が通り（$\mathcal L-\mathcal L^\dagger$ の頂点は0個）、警告は予想した二つだけだった。左巻きだけのニュートリノの運動項の規格化と、Goldstone ボソンの質量項の符号（質量はゲージ固定の項から来るが、それを含めていない）である。質量のスペクトルは模型ファイルの値と一致し、ゴーストの質量は $\xi_WM_W^2$、$\xi_ZM_Z^2$ になった。頂点のクラスは93個で、内訳は第~\ref{sec:rules} 節の数と同じである。スクリプト \texttt{generate\_SM.wl} は、それぞれの頂点を表~\ref{tab:rules-f}〜\ref{tab:rules-gh} の式と比べた。フェルミオンの頂点は世代ごとに分けて比べ、世代の非対角の成分が0であることも確かめた。$v$、$\lambda$、$y_f$ を式~\eqref{eq:masses} で $M_W$、$M_H$、$m_f$ に直し、3点の頂点では運動量の保存を使うと、93個すべての差が記号として0になった。比べ方が誤りを見逃さないことを確かめるため、わざと3か所を誤らせた表（$AW\bar W$ の符号、$G^0G^0H$ の2倍、$\bar u^Zu^ZH$ の $\xi_Z$ の欠落）とも比べ、ちょうど3個の差が出た。FeynArts の模型では、ゴーストとスカラーの11個の結合の $\xi_Z$、$\xi_W$ を FeynArts の \texttt{GaugeXi[Z]}、\texttt{GaugeXi[W]} に置き換え、伝播関数の \texttt{GaugeXi} と同じ記号にした。クラスは \texttt{F[1]}〜\texttt{F[4]}（$\nu,\ell,u,d$、世代の添字付き）、\texttt{S[1]}〜\texttt{S[3]}（$H,G^0,G^+$）、\texttt{V[1]}〜\texttt{V[4]}（$A,Z,W^+,G$）、\texttt{U[1]}〜\texttt{U[5]}（$u^A,u^Z,u^+,u^-,u_G$）である。

この過程で三つのことが分かった。一つ目は自分の模型ファイルの誤りで、湯川の項を最初 $y_f\bar Q_{Lf}\Phi d_{Rf}$ のように一つの世代の添字を3回使って書いたところ、FeynRules は警告を出さずに、頂点に縮約されない世代の添字を残した（$\bar udG^+$ の頂点に \texttt{IndexDelta[Index[Generation, Ext[2]], Index[Generation, a]]} が現れた）。湯川結合を対角の行列 $y_{f_1f_2}$ にして、どの添字も2回だけ現れるように直した。二つ目は比べる側の問題で、FeynRules を読み込んだカーネルでは、置き換えの規則の左辺 \texttt{ProjM[\_, \_]} が射影演算子のトレース2に評価され、規則が式の中の整数2をすべて $P_L$ に置き換えた（$e^2$ が $e^{P_L}$ になった）。左辺を \texttt{HoldPattern} で包み、パターンの変数に別の名前を付けて直した。三つ目は MadGraph の問題で、次の段落に書く。

UFO は制限なしで書き、MadGraph の制限カード \texttt{restrict\_massless.dat}（トップ以外のフェルミオンを質量0にする）をスクリプト \texttt{make\_restrict.py} で作った。MadGraph 3.8.1 は、その UFO から表~\ref{tab:diagrams} の数の木の図を、ユニタリーゲージと Feynman ゲージの両方で生成し、すべて手で数えた数と一致した。Feynman ゲージで図が増えるのは、$\gamma\gamma\to W^+W^-$（$t$、$u$ チャンネルの $G^\pm$）、$W^+W^-\to ZZ$、$W^+W^-\to HH$（$G^\pm$）、$ZZ\to HH$（$G^0$）である。最初の実行では、Feynman ゲージの数がユニタリーゲージと同じになった。MadGraph は UFO の \texttt{gauge = [0]}（Feynman ゲージを許さない）を見て「Feynman gauge is not allowed for your current model」と表示してユニタリーゲージに戻り、模型の読み込みに失敗したまま、続く \texttt{generate} を警告なしに組み込みの標準模型で実行していた。FeynRules は大域変数 \texttt{FeynmanGauge} が \texttt{True} のときだけ \texttt{gauge = [0, 1]} と書く。本ノートの模型は Goldstone ボソンとゴーストをいつも含むので、\texttt{SM.fr} でこの変数を \texttt{True} にし、スクリプトはログにこの表示があれば止まるようにした。スクリプトは \texttt{generate\_SM.wl}（FeynRules）、\texttt{make\_restrict.py}、\texttt{model\_mg5.mg5}（MadGraph）である。手順 (1) で分かったツールの問題は計算環境の記録~\cite{env} の表 15 にまとめた。

\paragraph{手順 (2)：木のレベル。}木の振幅の2乗を、本ノートの FeynArts の模型と FeynCalc で記号として求めた（\texttt{tree\_feyncalc.wl}。図~\ref{fig:treeproc}）。比べたのは、$W^+\to t\bar b$、$c\bar s$、$\nu_\tau\tau^+$（式~\eqref{eq:widths} は質量の代数式なので、開いていない $t\bar b$ も質量への依存の検算になる）、$Z\to b\bar b$、$t\bar t$、$\tau^+\tau^-$、$\nu\bar\nu$、$H\to b\bar b$、$t\bar t$、$\tau^+\tau^-$、$t\to bW^+$ の11個の2体の崩壊と、質量0の $e^+e^-\to\mu^+\mu^-$ の $\sum|\mathcal M|^2$（式~\eqref{eq:eeff}、$\Gamma_Z=0$）で、12個すべての差が記号として0になった。外の $W$、$Z$ の偏極の和は $-g_{\mu\nu}+k_\mu k_\nu/M^2$ である。\texttt{CreateFeynAmp} で \texttt{GaugeRules -> \{\}} として伝播関数の \texttt{GaugeXi} を残すと、$e^+e^-\to\mu^+\mu^-$ と $e^+e^-\to W^+W^-$ の振幅は $\xi_A$ と $\xi_Z$ を含み（$\xi_W$ は木の図に現れない）、$\sum|\mathcal M|^2$ をそれらで微分すると0になり、ゲージによらなかった。

明示的な行列（カイラル表示の Dirac 行列、スピノル、ヘリシティの偏極ベクトル）で表~\ref{tab:rules-f}〜\ref{tab:rules-sv} の頂点から $e^+e^-\to W^+W^-$ の三つの図を組むと（\texttt{tree\_numeric.py}）、$\sum|\mathcal M|^2$ は FeynCalc の値と9点（$\sqrt s=200$、500、3000~GeV、$\cos\theta=-0.9$、0、0.7）で相対 $2.3\times10^{-14}$ 以内で一致した。縦波の $W$ 対の振幅は、$\sqrt s=200$~GeV から 30~TeV まで、各図が $s/M_W^2$ に比例して増える一方、和はほぼ一定（$|\mathcal M|\approx0.13$、右巻きの電子では $0.06$）にとどまった。30~TeV での三つの図の比は、左巻きの電子で $2.201223:-0.999986:-1.201217$、右巻きで $0:-1:1.000009$ で、式~\eqref{eq:eeww} の $\frac1{2\sw^2}:Q_e:\frac{\cw}{\sw}g_L^e=2.201223:-1:-1.201223$ と $-1:1$ に $O(M_W^2/s)$ の差で一致した。

MadGraph の \texttt{compute\_widths} が本ノートの UFO（すべてのフェルミオンの質量を残す）から求めた25個の部分幅（$W$ が5、$Z$ が11、$H$ が8、$t$ が1）は、式~\eqref{eq:widths} の値と相対 $9\times10^{-16}$ 以内で一致した（MadGraph の出力カードの注釈の17桁の値。幅の合計は7桁で書かれ、その桁まで一致した）。基準点での合計は $\Gamma_W=2.063420$、$\Gamma_Z=2.472961$、$\Gamma_H=2.407885\times10^{-3}$、$\Gamma_t=1.296442$~GeV である。断面積（質量0の電子と $\mu$、カットなし、$\Gamma_Z$ はパラメータのカードの 2.4955~GeV）は、$e^+e^-\to\mu^+\mu^-$（$\sqrt s=200$~GeV）が MadGraph で $3.01486\pm0.00189$~pb、式~\eqref{eq:eeff} の積分で $3.017487$~pb（差は誤差の $-1.4$ 倍）、$e^+e^-\to W^+W^-$ が $200$~GeV で $20.188\pm0.041$ と $20.150$~pb（$+0.9$ 倍）、$500$~GeV で $7.416\pm0.014$ と $7.412$~pb（$+0.3$ 倍）で、統計誤差の範囲で一致した。

この手順では二つのことに注意が要った。一つ目に、FeynRules が書き出した FeynArts の模型は湯川結合の行列が対角であることを知らず（\texttt{SM.fr} の \texttt{Definitions} は FeynArts に渡らない）、$e^+e^-\to\mu^+\mu^-$ に世代を変える $t$ チャンネルの $H$、$G^0$ の交換を挿入する。模型ファイルに非対角を0にする定義を加えても挿入は減らなかったので、\texttt{FCFAConvert} の後で非対角の湯川結合を0にし、消える振幅の数を表示した（$e^+e^-\to\mu^+\mu^-$ の6個のうち、その2個と質量0の電子の $H$、$G^0$ の2個が0になった）。二つ目に、FeynCalc 10 の \texttt{DoPolarizationSums[x, k, 0]} は質量0のベクトルの和 $-g_{\mu\nu}$ で（警告 \texttt{PolarizationSum::notmassless} が出る）、質量のある和 $-g_{\mu\nu}+k_\mu k_\nu/M^2$ は2引数の \texttt{DoPolarizationSums[x, k]} である。最初は前者を使い、$Z\to f\bar f$ の差が $k_\mu k_\nu$ の項の分（$N_ce^2m_f^2/(2\sw^2\cw^2)$）だけ残った。また、FeynArts の \texttt{CreateFeynAmp} は既定で \texttt{GaugeRules -> \{\_GaugeXi -> 1\}} を使い Feynman ゲージにする（計算環境の記録~\cite{env} の表 6 とスピノル QED のノート~\cite{qednote}）。最初の版のスクリプトはこれを指定し忘れ、上の $\xi$ についての微分は振幅に $\xi$ がないまま0になっていた。手順 (3) でタドポールの Goldstone ボソンの質量に $\sqrt\xi$ が現れないことから気付き、\texttt{GaugeRules -> \{\}} にして確かめ直した。$t\to bW^+$ の $\sum|\mathcal M|^2$ は、色についても和をとると式~\eqref{eq:widths} から作った値の $N_c=3$ 倍になる（幅は初期状態の色とスピンで平均する）。スクリプトは \texttt{tree\_feyncalc.wl}、\texttt{tree\_numeric.py}、\texttt{tree\_mg5.mg5}、\texttt{compare\_tree\_mg5.py} で、\texttt{run\_tree\_check.sh} でまとめて実行できる。

\paragraph{手順 (3)：タドポールと自己エネルギー。}本ノートの FeynArts の模型で、タドポールの17個の図と、$W$、$Z$、光子、$\gamma Z$、$H$、トップの1PI の自己エネルギー（23、24、17、17、43、13個の図）、タドポールを $H$ の線でつないだ図（それぞれ17個）を、一般の $R_\xi$ ゲージ（$\xi_A,\xi_Z,\xi_W,\xi_G$ を独立に残す）で $D$ 次元で求めた（\texttt{oneloop\_feyncalc.wl}。図~\ref{fig:tadpole}、\ref{fig:se}）。TID と \texttt{PaVeReduce} で $A_0$、$B_0$ と $D$ の有理式にし、光子とそのゴーストには赤外を分けるための質量 $M_A$ を与え、紫外の極をとった後で $M_A\to0$ とした。タドポールの付いた図のうち、$W$ の自己エネルギーに $Z$ と光子の線でつながる29個は、ベクトル場の1点のループが Lorentz 不変性で0なので除いた（光子の線は運動量0で $1/0$ になる）。

結果は次の通りである。(a) $T$ は式~\eqref{eq:T} と $D$ 次元で記号として一致した。(b) $W$、$Z$、$H$ の $\Sigma_T(M^2)$ にタドポールの部分を加えたものの紫外の極は、$\frac12\dd M^2/\dd\ln\mu$（式~\eqref{eq:vrun}）と記号として一致し、$\xi_A,\xi_Z,\xi_W$ によらなかった。トップの $\Sigma^V+\Sigma^S$ の極も $\frac14\dd\ln m_t^2/\dd\ln\mu$（$O(\alpha_s)$ を含む）と一致した。1PI の部分だけでは、どの極も $\xi$ に依存する。(c) 極の $k^2$ の形は式~\eqref{eq:uvk2} の通りだった（\texttt{oneloop\_numeric.wl}）。$\Sigma^{AA}_T$ は $\xi_A,\xi_Z,\xi_W$ が独立でも $K\Sigma^{AA}_T|_{\mathrm{UV}}=e^2(\frac{20}3+\xi_W)k^2$ で、$\Sigma^{AZ}_T$、$\Sigma^{ZZ}_T$、$\Sigma^{WW}_T$ の $k^2$ の係数は共通の $\xi$ で式~\eqref{eq:dZWB}、\eqref{eq:dZmix} に一致した。$\xi$ が独立なときは、$K\,\partial_{k^2}\Sigma^{WW}_T|_{\mathrm{UV}}=\frac{e^2}{6\sw^2}[3\xi_W+3\xi_Z+3\sw^2(\xi_A-\xi_Z)-1]$ のように $\xi$ が混ざり、対称な基底の場の繰り込みでは書けないが、$\delta M^2$ は変わらない。$\Sigma^{AZ}_T(0)$ の極は独立な $\xi$ でも $-\frac{e^2M_W^2}{2K\sw\cw}(3+\xi_W)$ だった。

(d) $\MSbar$ の有限部分を基準点（$\mu=M_Z$）で、$(\xi_Z,\xi_W)=(\frac13,\frac13)$、$(1,1)$、$(2,2)$、$(3,3)$、$(\frac13,3)$、$(3,\frac13)$ の六つのゲージで求めた（$\xi_A=1$。Feynman ゲージの点は、簡約した式が $1/(1-\xi)$ を含むので $\xi=1+10^{-20}$ を40桁で評価した）。表~\ref{tab:oneloopfin} のように、$\Sigma_T(M^2)$ にタドポールの部分を加えたものは六つのゲージで27桁以上一致し、1PI の部分だけでは $W$、$Z$、$H$ でそれぞれ 14、18、52~GeV$^2$、トップで $1.1\times10^{-3}$ だけ変わった。式~\eqref{eq:pole} の1ループの極質量は $M_{W,\mathrm p}=80.6469$、$M_{Z,\mathrm p}=91.2249$、$M_{H,\mathrm p}=120.017$、$m_{t,\mathrm p}=168.548$~GeV である（基準点の値は物理の値に合わせたものではない）。現れる46個の $B_0$ の値は、LoopTools と COLLIER（\texttt{oneloop\_collier.f90}）が Package-X の40桁の閉じた形とそれぞれ相対 $1.1\times10^{-14}$、$9.6\times10^{-15}$ 以内で一致し、極質量は三つで倍精度の全桁が同じだった。タドポールの部分は大きく、$W$、$Z$ では $-195$、$-253$~GeV$^2$（Feynman ゲージ）で1PI の部分（$+91$、$+212$~GeV$^2$）を上回る。その約4分の3がトップのループのタドポール（$\propto N_cm_t^4/M_H^2$）である。

(e) 独立な模型との比較として、FeynArts に付属の \texttt{SMQCD.mod}（Denner の規約で、本ノートと無関係に書かれたもの）から同じ $T$ と1PI の自己エネルギーを求め、本ノートの模型の値と比べた（\texttt{oneloop\_smmod.wl}）。\texttt{SM.mod} の写しで光子とそのゴーストに同じ質量 $M_A$ を与え、$\xi_A,\xi_Z,\xi_W,\xi_G$ を一般に残すと、$T$、$\Sigma^{WW}_T$、$\Sigma^{ZZ}_T$、$\Sigma^{AA}_T$、$\Sigma^{AZ}_T$、$\Sigma^H$、トップの $\Sigma^V$、$\Sigma^S$ の8個がすべて $D$ 次元で記号として一致した（$\Sigma^{AZ}_T$ は $A^{\mathrm{Denner}}=-A$ で符号が逆）。図の数が \texttt{SMQCD.mod} で少ない（$H$ で25、トップで7）のは、本ノートの模型では世代を変える湯川結合の図が挿入されて0になるからである。

この手順では、ツールの扱いで四つのことに注意が要った。一つ目に、FeynArts の \texttt{CreateFeynAmp} の値は Feynman 則の積を $i$ で割ったもの（振幅 $\mathcal M$ であり $i\mathcal M$ ではない）で、タドポールの図の和はそのまま $T$ である。二つ目に、タドポールの付いた図の運動量0の $H$ の伝播関数 $1/(0-M_H^2)$ をループの式の中に残すと、FeynCalc の TID が \texttt{FCLoopSplit::failmsg} で止まる。\texttt{FCFAConvert} の直後に数 $-1/M_H^2$ に置き換えた。三つ目に、トップの自己エネルギーで Dirac の鎖の外に残った $P_L+P_R$ は FeynCalc が1にまとめず、射影演算子を含むトレースで $\Sigma^L$、$\Sigma^R$ を取り出すと $(P_L+P_R-1)$ に比例する見かけの差が残った。極質量に要る $\Sigma^V=\tr[\slashed k\Sigma]/(4k^2)$ と $\Sigma^S=\tr[\Sigma]/(4m)$ を射影演算子なしで取り出した。四つ目に、グルーオンのループの一般の $\xi_G$ の部分は、質量0の伝播関数の2乗から赤外で発散する $C_0(0,k^2,k^2;0,0,m_t^2)$ を $(m_t^2-k^2)^2$ 倍で含む。QCD のノートと同じ部分積分の関係で $A_0$、$B_0$ に直してから殻の上に置いた（$D$ 次元でちょうど0になる）。スクリプトは \texttt{run\_oneloop\_check.sh} でまとめて実行できる（約2分）。

\paragraph{手順 (4)：Slavnov--Taylor 恒等式と $\beta$ 関数。}式~\eqref{eq:st} の4つの恒等式を、手順 (3) と同じ方法で求めた縦の部分、混合、Goldstone ボソンの自己エネルギー（1PI とタドポールの付いた図。$W$ の側の図は 23、15、15、33 個、$Z$ の側は 24、15、15、38 個）で確かめた（\texttt{st\_feyncalc.wl}）。$Z$、$\Sigma^{AA}_L$、$\Sigma^{AZ}_L$ の恒等式は、一般の $\xi_A,\xi_Z,\xi_W$ で $D$ 次元で記号として成り立った。$W$ の恒等式は、光子の赤外の質量 $M_A$ を残すと $M_A^2$ と $A_0(M_A^2)$ に比例する項だけが残り（光子の質量は $W$ と光子のループで BRST 不変性を破る）、$M_A\to0$ で成り立った。混合は $\Sigma^{GW}=-\Sigma^{WG}$、$\Sigma^{G^0Z}=-\Sigma^{ZG^0}$、$\Sigma^{G^0A}=-\Sigma^{AG^0}$ を満たした。タドポールの付いた図を除くと、$W$ と $Z$ の恒等式は成り立たない。

$\beta$ 関数は二つの方法で確かめた。一つ目に、Machacek--Vaughn と Luo--Wang--Xiao の一般の1ループの公式~\cite{mv1,mv2,mv3,luo03} を、標準模型の45個の Weyl フェルミオン、4個の実スカラー、$SU(3)\times SU(2)\times U(1)$ の生成子を陽な行列で組んで計算した（\texttt{rg\_general.py}。湯川の行列は $\Phi^*Qd^c$ などの項から作り、9個の湯川結合をすべて違う値にした）。3つのゲージ結合の係数、9個の湯川結合の $\beta$ 関数、$\lambda_{abcd}$ の2つの独立な成分、$\gamma_{\mu^2}$、Landau ゲージの $\gamma_\Phi$ が、式~\eqref{eq:beta} と相対 $8\times10^{-16}$ 以内で一致した。二つ目に、2点関数の紫外の極から確かめた。手順 (3) の $W$、$Z$、$H$、$t$ の質量の極は、すべてのフェルミオンの質量を記号のまま残して式~\eqref{eq:vrun} の $\frac12\dd M^2/\dd\ln\mu$ と恒等的に一致したので、それぞれ $2\beta_g/g+\gamma_{\mu^2}/\mu^2-\beta_\lambda/\lambda$ などの組み合わせを結合の多項式として確かめている。電荷の極（式~\eqref{eq:dZe}）は $\Sigma^{AA}_T$ の $k^2$ の係数と $\Sigma^{AZ}_T(0)$ から求めると $K(Z_e-1)=\frac{11}6e^2\DUV$ で、$\xi_A,\xi_Z,\xi_W$ が独立でもゲージによらなかった（混合の項を Denner の符号にすると $\frac16(29+6\xi_W)e^2$ になり、ゲージに依存する）。$e$ の極は $s_W^2\beta_g/g+c_W^2\beta_{g'}/g'$ を与え、$W$ と $Z$ の極の差と合わせると $\beta_g$ と $\beta_{g'}$ が別々に決まる。$H$ は $\gamma_{\mu^2}$ を、$W$ は残りの $\beta_\lambda$ を、$t$ は $\beta_{y_t}$ を与える。こうして2点関数だけで $\beta_g,\beta_{g'},\beta_\lambda,\gamma_{\mu^2},\beta_{y_t}$ が一つに決まり、式~\eqref{eq:beta} と一致した。最後に、手順 (3) の $T$ の $\ln\mu^2$ への依存から求めた $\dd\ln v_\beta/\dd\ln\mu$ は、一般の $\xi_Z$、$\xi_W$ で式~\eqref{eq:vbeta} と記号として一致し、Landau ゲージで $-\gamma_\Phi^{\mathrm L}$ になった（\texttt{rg\_feyncalc\_check.wl}）。スクリプトは \texttt{run\_rg\_check.sh} でまとめて実行できる。

\paragraph{手順 (5)：極質量。}手順 (3) の式から、1ループの極質量を三つの点で調べた（\texttt{pole\_numeric.wl}）。(a) トップの QCD の部分は、$D$ 次元の式で $k^2=m_t^2$ に置くと $\xi_G$ が $\Sigma^V$ と $\Sigma^S$ の間で打ち消し、$K(\Sigma^V+\Sigma^S)_{\mathrm{QCD}}=-C_Fg_s^2(4+3\ln\frac{\mu^2}{m_t^2})$、すなわちよく知られた $m_{t,\mathrm p}=m_t(\mu)[1+\frac{\alpha_s}{\pi}(\frac43+\ln\frac{\mu^2}{m_t^2})]$ に記号として一致した。(b) $\beta_t$ の処方の「$\MSbar$ の質量」$gv_\beta/2$、$\sqrt{g^2+g'^2}v_\beta/2$、$\sqrt{2\lambda}v_\beta$、$y_tv_\beta/\sqrt2$ を、$\Delta v/v$（$W$ の自己エネルギーのタドポールの部分から）で基準点の六つのゲージで求めると、$\Delta v/v$ は $1.41$〜$1.53\%$ で、$W$、$Z$、$H$、$t$ の質量はゲージによってそれぞれ $0.089$、$0.101$、$0.138$、$0.183$~GeV 変わった。これらは物理量ではない。$\beta_t$ の処方でも、$v_\beta$ のゲージ依存は1ループの補正 $-\Sigma^{\mathrm{1PI}}(\xi)$ のゲージ依存と打ち消し、極質量はゲージによらない（表~\ref{tab:oneloopfin} の和）。そのため、$\beta_t$ の処方の $\MSbar$ の値は、ゲージ（たとえば Landau ゲージ~\cite{mr19}）を決めて初めて意味を持つ。FJ の処方の $\MSbar$ の質量と極質量はゲージによらない。なお、1ループでは $M^2-\re\Sigma(M^2)$ がゲージによらないが、不安定な粒子で2ループ以上を扱うときにゲージによらないのは複素数の極 $M_{\mathrm p}^2-iM_{\mathrm p}\Gamma$ である。(c) 基準点のパラメータ（$\mu_0=M_Z$）を式~\eqref{eq:beta} の1ループの方程式で $\mu=M_Z/2$、$2M_Z$、$165$~GeV に走らせ、その $\mu$ で1ループの極質量を求めた（表~\ref{tab:polerg}）。FJ の処方の $\MSbar$ の質量は $\mu$ が2倍になると $W$、$Z$、$t$ で $+5$~GeV ほど変わるが（式~\eqref{eq:vrun} の $1/\lambda$ の項）、極質量の変化は $2M_Z$ で $0.01$〜$0.12$~GeV と2ループの大きさにとどまり、1ループの $\mu$ 依存が打ち消すことを確かめた。$M_Z/2$ への変化は $0.05$〜$0.5$~GeV と大きく、$\ln^2(\mu/\mu_0)$ と大きな走りの2乗が効く。

\paragraph{手順 (6)：$G_F$ と $\alpha(0)$ の換算。}(a) $\mu$ 崩壊の木（1個）、頂点（8個）、箱（5個）の図（図~\ref{fig:mudecay}）を、本ノートの FeynArts の模型で、一般の $\xi_A,\xi_Z,\xi_W$ と光子の質量 $M_A$ で求めた（\texttt{mudecay\_feyncalc.wl}。$e$、$\mu$ の質量を0にして残った図の数）。外線の運動量を0にし、二つの Dirac の鎖 $[\bar\nu_\mu\cdots\mu]$、$[\bar e\cdots\nu_e]$ を、$\gamma_\beta$ を挟んだトレースの積で木の構造に射影した（紫外で発散する頂点は $D$ 次元で、有限な箱は4次元で）。外線の $\Sigma^L_f(0)$ は質量0のフェルミオンの自己エネルギーから、$\Sigma^{WW}_T(0)$ は1PI とタドポールの付いた図から求めた。現れるループの関数は運動量0の $A_0$、$B_0$、$\partial B_0/\partial k^2$ だけなので、閉じた形を入れて記号として調べた（\texttt{mudecay\_check.wl}）。式~\eqref{eq:GF1} の括弧の $\DUV$ の係数は、$e$、$\mu$ 以外のフェルミオンの質量を記号のまま残して、一般の $\xi$ で式~\eqref{eq:vrun} の $\frac12\dd\ln v^2/\dd\ln\mu$ と一致した（光子の質量を残すと $M_A^2/M_W^2$ に比例する項が残り、$M_A\to0$ で消える）。有限部分の $\ln M_A$ は箱と外線の補正の間で打ち消し、$M_A\to0$ の $\hat\Delta$ は $\xi_A,\xi_Z,\xi_W$ によらなかった（四つの項はそれぞれ $\xi_W$ に依存する）。Feynman ゲージの頂点、箱、外線の和は式~\eqref{eq:dVB} と記号として一致した。基準点（$\mu=M_Z$）では $\hat\Delta=-0.01077$ で、Feynman ゲージの内訳は $\Sigma^{WW}_T(0)/M_W^2=-0.02056$、$\delta_V=0.00400$、箱と外線の和 $0.00578$ である。

(b) 手順 (3) の $\Sigma^{AA}_T$、$\Sigma^{AZ}_T$ を $k^2$ で展開した（\texttt{alpha\_matching.wl}。$B_0(k^2,a,b)$ の $k^2$ の係数は Feynman のパラメータの積分の閉じた形で）。射影の $1/k^2$ の項は $A_0(a)-A_0(b)=(a-b)B_0(0,a,b)$ で消え、$\Sigma^{AA}_T(0)=0$ だった。$\Pi^{AA}(0)$ のフェルミオンの部分は、9個のフェルミオンについて手で求めた $\frac{e^2}K\frac43N_cQ_f^2[B_0(0,m_f,m_f)+2m_f^2\partial B_0/\partial k^2-\frac13]$ と一致し、$\Sigma^{AZ}_T(0)$ にはフェルミオンが寄与しなかった。式~\eqref{eq:deltae} の $\delta_e$ は、紫外の極が $\frac{11}6\frac{e^2}K$ で、有限部分が $\xi_A,\xi_Z,\xi_W$ によらなかった（$\Pi^{AA}(0)$ と $\Sigma^{AZ}_T(0)$ は別々には $\xi_W$ による）。ボソンの部分は $\mu=M_Z$ で $\frac\alpha\pi[-\frac16-\frac74\ln(M_Z^2/M_W^2)]$ に記号として一致した。PDG~2024 の入力（第~\ref{sec:setup} 節）と3ループの $\Delta\alpha_{\mathrm{lep}}=0.03149769$~\cite{steinhauser98} を使うと、トップを除いた $\Delta\hat\alpha(M_Z)-\Delta\alpha(M_Z)$ の1ループの値は $0.0071892$ で、$1/\hat\alpha^{(5)}(M_Z)=127.921$ になる。PDG の値は、クォークのループの QCD の補正を含めた $0.007122$ から $127.930\pm0.008$ で~\cite{pdg24}、差の $0.009$ はこの QCD の補正の分である（同じ入力で $0.007122$ を使うと 127.930 になる）。本ノートの $\MSbar$ のパラメータはトップを脱結合させないもので、トップのループ（$m_t=172.57$~GeV）を加えると $1/\hat\alpha(M_Z)=128.101$ である（トップの質量を $\MSbar$ の値にすると約 $0.02$ 変わるが、これは2ループの大きさである）。$1/\hat\alpha$ を数値で微分した $\mu$ への依存は $-11/(6\pi)$ と相対 $10^{-10}$ で一致した。スクリプトは \texttt{run\_gf\_check.sh} でまとめて実行できる。

\paragraph{手順 (7)：測定値から決める $\MSbar$ のパラメータ。}式~\eqref{eq:fit}、\eqref{eq:fitalpha} の $\delta_V$、$\delta_H$、$\delta_t$ を手順 (3) の式から LoopTools で、$\hat\Delta$ を手順 (6) の式から求めた（\texttt{msbar\_fit.wl}。表~\ref{tab:fit}）。オンシェルの $W$ の自己エネルギーでは、赤外の対数 $\ln M_A^2$ が $k^2-M_W^2=0$ の係数を持ち、$1/M_A^2$ の項の分子が $M_A^2$ の次数なので、$M_A\to0$ を項ごとにはとれない。そこで光子に $M_A=10^{-3}$~GeV を残し、40桁の数で通分してから有限部分をとった（$M_A=10^{-2}$~GeV との差は $10^{-7}$ 以下）。ゲージは $\xi_Z=\xi_W=\xi_G=2$ と $3$（$\xi_A=1$）で、結果の差は $10^{-13}$ 以下だった（$\xi=1$ では閉じた形が $0/0$ になるので使わない）。軽いフェルミオンの質量は $\mu\approx M_t$ の走る質量~\cite{mr19} にとり、それを半分にしたときの変化は $\lambda$ で $3\times10^{-6}$ である。

(a) Buttazzo らの入力（彼らの表~2）では、木の値が彼らの LO と、1ループの値が NLO と、5つの量すべてで彼らの示した桁まで一致した（差は $\lambda$、$y_t$、$g_2$、$g_Y$ で $10^{-5}$ 以下、$m$ で $10^{-3}$~GeV。$y_t$ には彼らの $g_3(M_t)=1.1666$ を使った。本ノートの1ループの走りの $g_3=1.1668$ では $y_t$ が $2\times10^{-5}$ 小さい）。式~\eqref{eq:mtqcd} の $a^2$、$a^3$ を加えた $y_t$ は $0.93706$ で、彼らの3ループの純 QCD を含む値 $0.93690$ との差 $1.6\times10^{-4}$ は、彼らの NNLO に入っている2ループの電弱と混合の補正の大きさである（$a^3$ の項だけの差 $-0.00328$ は、彼らの NNLO と3ループの QCD を含む値の差と一致した）。(b) $\mu=M_Z$ で合わせて1ループの繰り込み群で $M_t$ まで走らせた値と、$M_t$ で合わせた値の差は、$\lambda$ で $0.0029$、$y_t$ で $-0.0020$、$g_2$、$g_Y$ で $10^{-4}$、$m$ で $0.08$~GeV で、1ループの換算の2ループの不定性の目安になる。Buttazzo らの NNLO と NLO の差（$\lambda$ で $-0.0017$、$y_t$ で $-0.011$、$m$ で $-0.82$~GeV）もこの大きさで、$y_t$ では2ループの QCD（$-9.125a^2$ で $-0.0108$）がほとんどを占める。(c) Martin--Robertson の入力（$\alpha(0)$ を使い、$M_W$ を使わない）では、本ノートの1ループの値と彼らの値（2ループ以上を含む）の差は、$\lambda$ で $0.0016$、$m$ で $0.93$~GeV、$y_t^{\mathrm{QCD3}}$ で $0.0011$（彼らは4ループの QCD も含む）、$g_2$、$g'$ で $10^{-4}$ だった。これは (b) の高次の大きさと合う。予言した $M_W$ は極の質量で $80.388$~GeV（Breit--Wigner の質量で $80.415$~GeV）である。(d) PDG~2024 の入力では、$\mu=M_t=172.57$~GeV で $\lambda=0.12785$、$y_t=0.94693$（QCD を3ループまで入れると $0.93298$）、$g_2=0.64724$、$g_Y=0.35936$、$m=132.27$~GeV、FJ の $v=261.89$~GeV である（$M_W$ を入力にした場合）。$\alpha(0)$ を入力にすると $g_2$、$g_Y$ は $3\times10^{-4}$、$-6\times10^{-4}$ 変わり、予言した $M_W$ は Breit--Wigner の質量で $80.409$~GeV で、測定値 $80.369$~GeV より 40~MeV 大きい（PDG の高次の予言は $80.356$~GeV~\cite{pdg24}。差の 50~MeV は2ループの補正の大きさ）。FJ の $v$ は $v_G=246.22$~GeV より 6\% 大きい。$\mu=M_t$ では $\hat\Delta=+0.127$（$\mu=M_Z$ の基準点では $-0.011$）で、そのほとんどがトップのタドポールだからである。$\lambda$、$g$、$g'$、$y_t$ と $m^2$ は Lagrangian の結合なので、タドポールの処方によらず Buttazzo らや Martin--Robertson の値とそのまま比べられる。$v$ は処方による（Martin--Robertson の $v$ は Landau ゲージの有効ポテンシャルの最小点で $246.60$~GeV）。スクリプトは \texttt{run\_fit\_check.sh} で実行できる。

\paragraph{手順 (8)：2ループの $\beta$ 関数と繰り込み群の走り。}(a) 2点関数と頂点。本ノートの FeynArts の模型（手順 (1)）で $v\to0$、すべての質量を0、$e\to0$（$g=g'=0$）とし、$\lambda$、$y_t$（湯川の行列の $(3,3)$ 成分。ほかの成分は0）、$g_s$ を残した（\texttt{twoloop\_sym\_setup.wl}）。光子、$Z$、$W$ とそのゴースト、レプトンは挿入から除き、グルーオンは Landau ゲージにとった。$H$、$t$、$b$、グルーオン、ゴーストの自己エネルギーと、$H$ の運動量を0にした $\bar ttH$ の頂点の図（1ループで 4、4、2、9、1、3個、2ループで 26、49、23、70、12、101個。図~\ref{fig:twoloop} の (a)〜(e)）を FeynCalc で求め、$-q^2=\mu^2$ の質量0の伝播関数型の積分（QCD のノートの手順 (7) と同じ族）にした。844個の積分を Kira~3.1~\cite{kira3} で、バブルの2乗と sunset の2個のマスター積分に還元した（\texttt{twoloop\_sym\_feyncalc.wl}）。射影と規格化は、1ループで式~\eqref{eq:beta} を再現するように決めた（\texttt{twoloop\_sym\_oneloop.wl}）。$Z_X(1+\Pi_X)$（$X=\Phi$、$t_L$、$t_R$、$b_L$、ゴースト）、$Z_3(1-\Pi_A)$、$Z_{y_t}Z_\Phi^{1/2}Z_{t_L}^{1/2}Z_{t_R}^{1/2}(1+\Lambda)$ が有限になるように $\MSbar$ の $Z$ を決め、Landau ゲージの $Z_{g_s}=1/(\tilde Z_3Z_3^{1/2})$ を使った（\texttt{twoloop\_sym\_eval.wl}）。$\beta_x=(\sum_l\rho_lx_l\partial_l-\rho_x)a_x^{(1)}$（$a_x^{(1)}$ は $xZ_x$ の $1/\epsilon$ の留数。$\rho=1$ は $y_t$、$g_s$、$\rho=2$ は $\lambda$）で求めた $\beta^{(2)}_{y_t}$、$\beta^{(2)}_{g_s}$ は、Buttazzo らの式と記号として一致した。$1/\epsilon^2$ の極は1ループの $\beta$ 関数から決まる値と一致し、2ループでもグルーオンの自己エネルギーは横波で、左右の頂点 $\Lambda_L=\Lambda_R$ と同じ二重項の $Z_{b_L}=Z_{t_L}$ が成り立った。

(b) 4点関数。$\Gamma_{HHHH}$ は外線の運動量をどう流しても運動量0の外線を含むので、質量0の線では赤外で発散しうる。そこで外線の運動量を0にし、すべての伝播関数の分母に共通の補助の質量 $M$（$=\mu$）を入れた（Chetyrkin--Misiak--Münz の赤外の組み替え~\cite{cmm98}。分子のクォークの質量は入れない）。対数発散する図の全体の紫外の対抗項は質量によらず、2次発散する部分図（$\Sigma_H$）の $M^2$ の極は補助のスカラーの質量の対抗項で除く。1ループの $\Sigma_H(0)$（4個）と $\Gamma_{HHHH}$（15個）は $D$ 次元で厳密に求めた。2ループの363個の図（図~\ref{fig:twoloop} の (f)〜(l)。対抗項は (m)〜(o)）は55個の真空積分にして、Kira で tadpole の2乗と等質量の sunset に還元した（\texttt{twoloop\_lambda\_feyncalc.wl}）。sunset は AMFlow~2.0~\cite{amflow,amflow2} で30桁で求めた（\texttt{twoloop\_lambda\_masters.wl}。同じ方法で求めた tadpole の2乗は $\Gamma(-1+\epsilon)^2$ と各次数で29桁以上一致し、sunset の極は1ループあたり $e^{\epsilon\gamma_E}\int\dd^Dl/(i\pi^{D/2})$ の規格化で $\frac3{2\epsilon^2}+\frac9{2\epsilon}$ になった）。$Z_\Phi^2\Gamma_{HHHH}/(-6i)$ が有限になるように $\lambda$ の対抗項を決めると、最初は $y_t^6$ の係数が文献の30でなく21になり、ほかの係数はすべて一致した。原因は、内線のクォークの場の繰り込みが裸の場で打ち消すとした扱いにあった。分母だけに $M$ を入れたクォークの線 $S_M=i\slashed l/(l^2-M^2)$ に運動項の対抗項 $i\delta Z\slashed l$ を挟むと
\begin{equation}
S_M\,(i\delta Z\slashed l)\,S_M=-\delta Z\Bigl(1+M^2\frac{\partial}{\partial M^2}\Bigr)S_M
\label{eq:cmmq}
\end{equation}
で、質量0の線の $-\delta Z\,S$ と $M^2$ の項だけ違う。トップの線についての和 $-\bar z_tM^2\partial G_4^{(1)}/\partial M^2$（$\bar z_t=(z_{t_L}+z_{t_R})/2=-\frac34y_t^2/\epsilon$。トレースの $\gamma_5$ の部分は0）は $1/\epsilon$ の極 $-\frac94y_t^6$ を持ち、これを加えると $\beta_\lambda^{(2)}$ が文献の式と記号として一致した（\texttt{twoloop\_lambda\_eval.wl}。$1/\epsilon^2$ の極も RG と一致）。スカラーの線の同じ $M^2$ の項は補助の質量の対抗項に含めてある（$\delta M^2=\mathrm{pole}[\Sigma_H(0)]-z_\Phi M^2$）。Landau ゲージではグルーオンによるクォークの $Z_2$ の1ループの極が0なので、$g_s^2$ の項はこの影響を受けない。独立な確かめとして、$\lambda=0$ では外の $H$ がトップにしか付かず、運動量を $H_1$ から $H_3$ へ流した質量0の伝播関数型の積分が赤外で有限なので、補助の質量なしで $y_t^6$ と $g_s^2y_t^4$ の項を求めた（\texttt{twoloop\_lambda\_massless.wl}。2ループで204個の図、88個の積分）。結果は $30y_t^6-32g_s^2y_t^4$ で、文献の式と一致した。この場合は $S\slashed lS=S$ なので、裸の場の扱いがそのまま正しい。

(c) 本ノートの方程式での走り（\texttt{rg\_run.py}、表~\ref{tab:rgrun}、図~\ref{fig:rg}）。Buttazzo らの NNLO の値（$\mu=M_t=173.34$~GeV）から $M_{\mathrm{Pl}}=1.22\times10^{19}$~GeV まで走らせると、$\lambda(M_{\mathrm{Pl}})$ は1ループの方程式で $-0.0337$、本ノートの方程式で $-0.0148$ になる。文献の2ループの式では $-0.0151$ なので、2ループの走りの効果のほとんどは式~\eqref{eq:beta2} の $y_t$、$g_s$、$\lambda$ の項から来る。残りの $g,g'$ を含む2ループの項は $\lambda(M_{\mathrm{Pl}})$ を $-0.0003$、$y_t(M_{\mathrm{Pl}})$ を $+0.002$ 変え、$\Lambda_\lambda$ は $10^{9.69}$ と $10^{9.68}$~GeV でほとんど変わらない。文献の3ループの式では $\lambda(M_{\mathrm{Pl}})=-0.0144$、$\Lambda_\lambda=10^{9.79}$~GeV で、3ループの効果は $\Lambda_\lambda$ で 0.1 桁である。本ノートの方程式の $m^2$ は1ループで走るので、$m(M_{\mathrm{Pl}})$ は文献の2ループの式より約 0.9~GeV 小さい。PDG~2024 の入力（手順 (7)、$y_t$ は QCD を3ループまで）では、本ノートの方程式で $\lambda(M_{\mathrm{Pl}})=-0.0084$、$\Lambda_\lambda=10^{11.24}$~GeV（文献の2ループの式で $-0.0086$、$10^{11.21}$~GeV、3ループで $-0.0079$、$10^{11.41}$~GeV）である。$M_t=172.57$~GeV が Buttazzo らの 173.34~GeV より小さいぶん、安定に近い。

(d) 換算の次数。同じ入力から手順 (7) の1ループの換算で出発すると、本ノートの方程式での $\lambda(M_{\mathrm{Pl}})$ は、Buttazzo らの NNLO から走らせた値より $0.0023$、Martin--Robertson の値から走らせた値より $0.0019$ 大きく、$\Lambda_\lambda$ は 0.5 桁ほど高い。$\lambda(M_{\mathrm{Pl}})$ の $\lambda(M_t)$、$y_t(M_t)$、$g_3(M_t)$ への感度はそれぞれ $+1.44$、$-1.12$、$+0.43$ で、差は $\lambda(M_t)$ の2ループの換算（$-0.0017$）でほぼ説明できる。$y_t$ を1ループの換算のままにすると、$\Lambda_\lambda$ は約3桁下がる。$\Lambda_\lambda$ を桁の精度で見積もるには、$\lambda$ と $y_t$ の2ループの換算が要る。

(e) 比較に使った文献の式の確かめ。Luo--Wang--Xiao の2ループの一般の公式を、手順 (4) の陽な場（45個の Weyl フェルミオン、4個の実スカラー、群ごとの生成子）で組んだ（\texttt{rg\_twoloop.py}。半単純群への拡張は彼らの置き換えの規則、$m^2$ は伝播しないダミーのスカラーの方法）。$t$、$b$、$\tau$ の湯川結合だけを残した任意の2点（一つは $\lambda<0$）で、すべての結合の1ループと2ループの $\beta$ 関数が Buttazzo らの式と相対 $5\times10^{-14}$ 以内で一致した。これは Buttazzo らの付録の転記の検算になる。文献の3ループの式で Buttazzo らの NNLO の値を走らせると、彼らの $M_{\mathrm{Pl}}$ での値 $g_1=0.6154$、$g_2=0.5055$、$g_3=0.4873$、$y_t=0.3825$ を4桁で、$\lambda=-0.0143$ を $7\times10^{-5}$ の差で、$\Lambda_\lambda\approx2\Lambda_V=10^{9.8}$~GeV を再現した。$m(M_{\mathrm{Pl}})$ は 139.4~GeV で、彼らの式の 129.4~GeV と合わないが、彼らの図~2 では $m$ が $M_{\mathrm{Pl}}$ で約 0.14~TeV に上がっていて本ノートの値と合うので、式の数値の誤植と考えられる。

\paragraph{手順 (9)：1ループの電弱の振幅と MadLoop。}(a) MadGraph の電弱 NLO の模型との比較。過程は $\nu_e(p_1)\bar\nu_e(p_2)\to\nu_\mu(p_3)\bar\nu_\mu(p_4)$ で、外線に光子が付かないので赤外で有限である。木は $s$ チャンネルの $Z$ だけで、1ループでは $Z$ の自己エネルギーに FJ のタドポールが入る。トップ以外のフェルミオンの質量と幅を0とし、$1/\alpha(M_Z)=128$、$M_Z=91.1876$、$M_W=80.369$、$M_H=125.2$、$M_t=172.57$~GeV、$\sqrt s=500$~GeV、散乱角 $\pi/3$ の点で、木と1ループの干渉 $W=\sum_{\mathrm{spins}}\mathcal M_0^*\mathcal M_1$ を比べた（表~\ref{tab:nunu}）。本ノートの模型で、FeynCalc（一般の $R_\xi$。\texttt{nunu\_feyncalc.wl}）と、パッチのない FeynArts と FormCalc（Feynman ゲージ。\texttt{nunu\_formcalc.wl}）で独立に求めた。図は木1個、頂点22個と $s$ チャンネルの自己エネルギー24個（模型が湯川と同じく対角性を知らずに挿入する、世代を変える0の図を含む）、運動量0の $H$ の線で付くタドポール17個、箱25個である。外線のニュートリノには足ごとに LSZ の因子 $1-\Sigma^L_\nu(0)/2$ を掛けた。紫外で発散する部分は $D$ 次元で木の構造 $[\bar v_2\gamma^\mu P_Lu_1][\bar u_3\gamma_\mu P_Lv_4]$ に直し、有限な箱は4次元のスピン和で求めた。$\MSbar$ の振幅は裸の振幅で $\DUV\to0$ としたもので、その紫外の極は $\MSbar$ の対抗項（下の換算の極）と $10^{-18}$ まで打ち消した。比較の相手は MadGraph に付属の \texttt{loop\_qcd\_qed\_sm}~\cite{mg5ew}（\texttt{no\_widths}）で、on-shell の $M_W$、$M_Z$、$M_H$、$M_t$ と $\alpha(M_Z)$ のスキーム、Feynman ゲージ、MadGraph 側の R2 と対抗項による独立な実装である（トップの湯川結合の質量 \texttt{ymt} は $M_t$ にした）。MadLoop は1ループの図26個（ほかに7個）、R2 17個、UV 6個から値を求め、極は0、有限部分は $\mu_R=30$、$M_Z$、500~GeV で14桁同じだった。

換算は次のとおりである。同じ数値を on-shell の値と見て、本ノートのパラメータとの差を
\begin{equation}
M_V^2(\MSbar)=M_V^2(\mathrm{OS})+\re\Sigma_T^{VV}(M_V^2),\qquad
\frac{e(\mu)}{e_{\alpha(M_Z)}}-1=\frac12\bigl[\Pi_{\mathrm{heavy}}(0)+\re\Pi_{\mathrm{light}}(M_Z^2)\bigr]+\frac{s_W}{c_W}\frac{\Sigma_T^{AZ}(0)}{M_Z^2}
\label{eq:convOS}
\end{equation}
（$\Sigma_T^{VV}$ はタドポールを含む FJ の値、$\Pi_{\mathrm{light}}$ は質量0のフェルミオンのループ、heavy はトップとボソン。手順 (3)、(6) と同じ図）で求め、木の微分で $W_{\mathrm{OS}}=W+B_4\,\delta\ln\mathcal M_0$、$\delta\ln\mathcal M_0=2\delta e-\delta\ln(s_W^2c_W^2)+\delta M_Z^2/(s-M_Z^2)$（$B_4=\sum|\mathcal M_0|^2$）とした。$\delta e$ は MadGraph の模型の電荷の対抗項の有限部分と16桁一致した（$\mu=M_Z$ で $0.0031433258370745$）。木は三つの計算で16桁、$W(\MSbar)$ は FeynCalc と FormCalc で14桁一致した。$W(\MSbar)$ は $\mu=M_Z$ の $-2.347\times10^{-4}$ から 500~GeV の $+2.89\times10^{-5}$ へ大きく変わり（タドポールの図だけで $\mu=M_Z$ で $+7.9\times10^{-5}$）、$\delta M_W^2$、$\delta M_Z^2$ も $-199$、$-154$~GeV$^2$ から $+2303$、$+3157$~GeV$^2$ へ変わるが、それらは $W_{\mathrm{OS}}$ で打ち消し、$W_{\mathrm{OS}}/2$ は $\mu$ によらず MadLoop の値と相対 $10^{-14}$ で一致した。FeynCalc の $W(\MSbar)$ と $\delta\ln\mathcal M_0$ は、$(\xi_Z,\xi_W)=(1,1)$ と $(2,3)$ で15桁同じだった（$\MSbar$ の振幅も、FJ のタドポールを含む換算もゲージによらない）。なお、一般の $\xi$ では $s$ チャンネルの自己エネルギーを4点の図として射影すると非常に遅いので、それらは $\mathcal M_0\,(-\Sigma_T^{ZZ}(s)/(s-M_Z^2))$ として2点関数から組んだ（伝播関数の $k^\mu k^\nu$ の項は質量0の流れで消える。Feynman ゲージで図から求めた値と全桁同じ）。

途中で FeynCalc の問題を二つ見つけた（計算環境の記録~\cite{env}）。FeynArts の運動量の流し方で $u(p_1)$ の隣の運動量が $p_3+p_4-p_2-q$ になると、\texttt{DiracSimplify} は運動量の保存を知らないので $p_1$ の Dirac 方程式を使えず、入射の鎖の3個の頂点の図だけが、出射の鎖の鏡像の図と FormCalc の値から（有限な $B_0-B_0-M^2C_0$ の組み合わせで）ずれた。図ごとの比較で見つけ、ループのある鎖ごとに運動量をその鎖の外線で書き直して一致させた。また FeynCalc は $D$ 次元の $\gamma_5$ のトレースを評価しないので、$Z$ の自己エネルギーのフェルミオンのループの $\gamma_5$ の部分（$\epsilon(p_3,\mu,p_4,\rho)$ の対で打ち消す）は4次元で評価した。

(b) FJ を対抗項の形にした本ノートの UFO。MadLoop はタドポールの図と外線の自己エネルギーを作らないので、FJ の処方は対抗項の頂点として入れる必要がある。本ノートの模型（\texttt{SM.fr}、Feynman ゲージ）を NLOCT で繰り込んだ模型から \texttt{WriteCT} で R2 の頂点（163個）を求め（\texttt{nlo\_renormalize.wl}、\texttt{nlo\_writect.wl}。タドポールの定数の1点の頂点は FeynArts の一般の模型にないので0とした）、NLOCT の on-shell の UV の頂点は使わずに、UV の頂点を自分で書いた。この過程に要るのは次の頂点で、初めはこれだけを本ノートの自己エネルギー（\texttt{nlo\_fjct.wl}）から書いた UFO で確かめた：
\begin{equation}
ZZ:\ ig^{\mu\nu}\bigl(\delta M_Z^2-\Sigma_{\mathrm{tad}}^{ZZ}\bigr),\qquad
Z\nu\bar\nu:\ (\text{木の頂点})\times\Bigl[\frac{\delta e}{e}-\frac{\delta c_W^2}2\Bigl(\frac1{c_W^2}-\frac1{s_W^2}\Bigr)+\delta Z_\nu^L\Bigr].
\label{eq:fjct}
\end{equation}
$\delta M_Z^2$、$\delta e$、$\delta c_W^2=\delta M_W^2/M_Z^2-M_W^2\delta M_Z^2/M_Z^4$ は $\MSbar$ の極（$\delta M^2$ はタドポールを含む $\Sigma_T(M^2)$ の極）、$\Sigma^{ZZ}_{\mathrm{tad}}$ は運動量0の $H$ の線で付くタドポールの図（極と有限部分。MadLoop が作らない図をそのまま頂点にしたもの）、$\delta Z^L_\nu=-\Sigma^L_\nu(0)$ は外線のための on-shell の場の定数で、$Z$ の場は繰り込まない。$K\,\delta e/e=\frac{11}6e^2$ を再現した。式~\eqref{eq:fjct} は FJ の処方の UV の頂点の一般形（$\MSbar$ の極、タドポールの有限な頂点、外線の on-shell の場の定数）の、この過程に要る部分で、(d) ですべての頂点に広げた。その UFO で MadLoop に同じ数値を本ノートの $\MSbar$ のパラメータとして与えると（図は1ループ42個、R2 28個、UV 6個）、有限部分は $\mu=M_Z$ で $-1.1737308938221\times10^{-4}$、500~GeV で $+1.4427406016859\times10^{-5}$ になり、FeynCalc の $\re W(\MSbar)/2$ と相対 $2\times10^{-14}$、$1\times10^{-13}$ で一致した（極は0。式~\eqref{eq:fjct} の頂点だけの UFO とも相対 $3\times10^{-14}$ で同じ）。$\MSbar$ の振幅の $\mu$ による大きな変化も、FJ を対抗項の形にした UFO がそのまま再現する。

(c) 二つの UFO の違い（表~\ref{tab:ufo}）。MadGraph に付属の \texttt{loop\_qcd\_qed\_sm} は、Shao らが電弱の NLO の自動化のために作った模型~\cite{mg5ew}で、R2 と UV の頂点を閉じた形で手で書いてある。本ノートの UFO は、本ノートの \texttt{SM.fr} から FeynRules の \texttt{WriteUFO} で書き出し、R2 の頂点は NLOCT~\cite{nloct} で同じ模型から求め、UV の頂点は (d) の対抗項のラグランジアンとタドポールの頂点である。物理的な違いは繰り込みのスキームにある。公式の模型ではパラメータが on-shell の質量と $\alpha(M_Z)$ で、タドポールを対抗項 $\delta t$ で打ち消す（$\beta_t$ の処方に当たる。\texttt{HiggsTadpole\_UV\_EW} が頂点の対抗項に入る）。本ノートの UFO ではパラメータが FJ の $\MSbar$ の値で、タドポールの図をそのまま頂点に入れる。そのため、同じ param\_card の数値でも二つの模型の振幅は違う量であり、$\mu_R$ への依存も違う（$\nu_e\bar\nu_e\to\nu_\mu\bar\nu_\mu$ では、公式の模型では $\mu_R$ によらず、本ノートの UFO では $\MSbar$ の振幅と同じく $\mu_R$ による）。両者は式~\eqref{eq:convOS} の有限な換算だけでつながり、(a)、(b)、(d) の結果はその関係を数値で確かめたことになる。範囲の違いは、本ノートの UFO の対抗項が軽いフェルミオンの質量0の場合だけで正しいことである（公式の模型は軽い質量を残す制限カードにも使える）。MadLoop の図の数の違い（1ループ 26 (+7) と 42 (+2)）は、本ノートの UFO が軽いフェルミオンの質量をパラメータとして残し、質量に比例する $H$、$G^0$、$G^\pm$ とレプトンの結合（値は0）の図も作るためで、軽い質量と幅を0にする制限カードを与えると 26 (+7) になり、有限部分は14桁同じだった。R2 の数（17 と 18）の違いは、R2 の結合を内線の粒子ごとにどう分けるかの違い（対抗項の振幅の数 23 と 24）で、ループの図そのものは同じである。

(d) すべての頂点の FJ の対抗項。(b) の UV の頂点を、軽いフェルミオンが質量0のどの過程にも使える形に広げた（\texttt{nlo\_ctrules.wl}、\texttt{nlo\_dz.wl}、\texttt{nlo\_fjdelta.wl}、\texttt{nlo\_ctparams.wl}、\texttt{nlo\_ufo.wl}）。UV の頂点は二つの部分の和である。一つは、NLOCT の \texttt{OnShellRenormalization} で繰り込んだ本ノートのラグランジアン（Feynman ゲージ）の対抗項の部分の Feynman 則（181個の頂点。パラメータの定数 $\delta p$ と場の定数 $\delta Z$ について線形）である。もう一つは、$H\to H+\delta v_T$ の1次の項 $\delta v_T\,\partial\mathcal L/\partial H$ の Feynman 則（2点と3点の29個）である。後者は運動量0の $H$ の線でタドポールを線と頂点につないだ図で、$\delta v_T=T/M_H^2$（手順 (3) の $T$）とすると、MadLoop の作らないタドポールの図をすべて与える（1点の項、つまりタドポールそのものは入れない。$ZZ$ の頂点は式~\eqref{eq:fjct} の $-\Sigma^{ZZ}_{\mathrm{tad}}$ と、軽い質量を $10^{-12}$~GeV にした数値で $10^{-52}$~GeV$^2$ まで一致した）。定数は次のとおりである。
\begin{itemize}
\item パラメータの定数は FJ の $\MSbar$ の極 $\delta p=\frac{\DUV}2\,\dd p/\dd\ln\mu$ で、UFO の外部パラメータ $1/\alpha$、$\alpha_s$、$M_Z$、$M_W$、$M_H$、$m_f$ の走りを式~\eqref{eq:beta} から連鎖律で求めた（$v^2=\mu^2/\lambda$ の $1/\lambda$ の項を含む）。$K\,\delta e/e=\frac{11}6e^2$ を再現し、$\delta M_Z^2$、$\delta M_W^2$、$\delta e$ の極は (b) の FeynCalc の値と記号として一致した。
\item 場の定数は外線の LSZ の因子で、NLOCT の on-shell の値を使う。MadLoop は外線の自己エネルギーを作らないので外線の場の定数は on-shell でなければならず、内線の場の定数は振幅の中で打ち消す。NLOCT は定数を代入した UV の頂点しか書き出さないので、その2点の頂点（21個）と、対抗項のラグランジアンの記号の頂点の係数を比べて、31個の定数を取り出した。複数の頂点から出る定数は互いに一致し、$\delta Z^L_\nu$ は (b) の FeynCalc の $-\Sigma^L_\nu(0)$ と18桁、$u,d,e,\mu,\nu_e$ の定数は MadGraph の模型の独立な値（\texttt{Wcft\_UV\_EW}）と15桁一致した。Goldstone ボソンは内線にしか現れないので、その場の定数は0にした（NLOCT の $G^0G^0$、$G^+G^-$ の頂点には、対抗項のラグランジアンにない定数の項がある）。
\item 軽いフェルミオン（$u,d,s,c,b,e,\mu,\tau$）は質量0とする（MadGraph の既定の制限と同じ）。NLOCT の定数は、質量の等式と閾値の条件（273個）を \texttt{If} で含む。UFO はこのうち0との比較しか表せないので、軽い質量を0、重い質量を基準点の値として条件を決めた（$M_H<2M_W$、$M_t>M_W$ などの順序が保たれる範囲で正しい）。質量の特異性を持たない定数は、軽い質量を $10^{-7}$~GeV にした NLOCT の式と相対 $2\times10^{-16}$ 以下で一致した。$\delta v_T$ の軽い質量の $m^4\ln m^2$ の項は0とした。
\end{itemize}
定数は38個の CT パラメータ（電弱の部分と QCD の部分は別のパラメータにし、結合の次数は $\delta Z$、$\delta p$ が QED 2 または QCD 2、$\delta v_T$ が QED 1）として UFO の \texttt{CT\_parameters.py} に入れ、頂点の結合をそれらについて線形に書いた（MadGraph の \texttt{CTParameter}。FeynRules には外部パラメータとして渡し、書き出した後で移した）。UV の頂点は173個である。MadLoop は UV の頂点のうち、自己共役な場の2点の頂点（$AA$、$ZZ$、$HH$ など）を、R2 と同じく \texttt{loop\_particles} と同じ粒子の組のループを持つ図にだけ付ける。そこで、すべての UV の頂点の \texttt{loop\_particles} を空にし、その位置のループごとに1回ずつ付くようにした。

この UFO を、外線がすべて質量0の7個の過程で MadGraph の模型と比べた（表~\ref{tab:fjall}。\texttt{run\_fj\_check.sh}、\texttt{fj\_madloop.py}。点と入力は (a) と同じ）。二つの模型のループの図は同じ（数も同じ）で、違うのは対抗項だけであり、それは繰り込み定数について線形である。場の定数は同じなので、同じ数値 $p$ を on-shell と $\MSbar$ の値と見ると、$\MSbar$ のパラメータ $p$ は on-shell の $p-\delta p$（$\delta p=p(\MSbar)-p(\mathrm{OS})$、式~\eqref{eq:convOS} の有限部分）に当たる。したがって1ループで厳密に
\begin{equation}
\mathrm{finite}(\mathrm{MG})-\mathrm{finite}(\mathrm{FJ})=\sum_{p=1/\alpha,\,M_Z,\,M_W}\frac{\partial\,\mathrm{born}}{\partial p}\,\delta p,\qquad\delta(1/\alpha)=-\frac{2\,\delta e}{\alpha}
\label{eq:fjdiff}
\end{equation}
となる。born の微分は MadGraph の模型の数値の差分（5点の公式を刻み $2\times10^{-4}$ と $4\times10^{-4}$ で求め、Richardson で外挿）で求め、$\delta p$ は (a) の値を使った。式~\eqref{eq:fjdiff} の両辺の差は、七つの過程の二つの $\mu$ で born の $7\times10^{-13}$ 以下で、極は二つの模型で $10^{-18}$ まで同じだった。両辺の相対の差は最大 $4\times10^{-10}$ である（$\mu=500$~GeV では $M_Z$ と $M_W$ の項が和の約30倍の大きさで打ち消すので、差分の丸めが効く）。$\nu_e\bar\nu_e\to\nu_\mu\bar\nu_\mu$ では、解析的な微分を使うと両辺が相対 $5\times10^{-15}$ で一致した。$e^+e^-\to\gamma\gamma$ では外線の光子の定数 $\delta Z_{AA}$、$\delta Z_{ZA}$ を、$u\bar u$、$d\bar d$ では外線のクォークの定数を含めて確かめたことになる。途中で、MadGraph の param\_card の読み込みが値を20文字で切ることが分かった（有効数字16桁の \texttt{1.725700000000000e+02} は $1.7257$ と読まれ、警告は出ない）。

\section{議論と今後}\label{sec:discussion}

\paragraph{現時点で分かったこと。}$\MSbar$ のパラメータを破れていないラグランジアンのもの（$g_s,g,g',\lambda,\mu^2,y_f$）にとり、タドポールを FJ の処方で扱うと、標準模型の1ループの繰り込みは QED と QCD のノートの $\MSbar$ と同じ形になる。$\MSbar$ の質量の対抗項は $\frac{\DUV}2\dd M^2/\dd\ln\mu$ で、$\beta$ 関数だけから決まり、ゲージによらない。その代わり、タドポールが質量の走りに $1/\lambda$ の大きな項を持ち込む。タドポールを打ち消す $\beta_t$ の処方では、この項が消える代わりに真空期待値が $\xi$ に依存して走る（式~\eqref{eq:vbeta}）。$\phi^3$ のノートの線形項と違い、標準模型ではこの依存を吸収するパラメータがないので、ゲージによらない $\MSbar$ のパラメータの組を保つには FJ の処方が要る。模型ファイルは手計算の Feynman 則と93個すべてのクラスで記号として一致し、MadGraph の図の数も両方のゲージで手で数えた数と一致した。木のレベルでは、振幅の2乗、崩壊幅、断面積が手計算、FeynCalc、明示的な行列、MadGraph の四つで一致し、縦波の $W$ 対の増える部分は $T^3_e$ と $Q_e$ の関係で打ち消した。

\paragraph{FJ の処方の確かめ。}手順 (3) で、FJ の処方の構造がすべて具体的に確かめられた。タドポールを含めた $\Sigma(M^2)$ の紫外の極は $\beta$ 関数だけで決まり、一般の $R_\xi$ ゲージで $\xi$ によらず、有限部分の極質量も $\xi$ によらない。1PI の部分だけを使う（タドポールを捨てる）と、極も有限部分もゲージに依存する。タドポールの部分は $W$、$Z$ の質量の補正の主な部分で、トップのループが大部分を占める。$\beta_t$ の処方ではこれが $v_\beta$ に入り、$v_\beta$ がゲージに依存する（式~\eqref{eq:vbeta}）。

\paragraph{$G_F$ と $\alpha(0)$。}手順 (6) で、測定値と $\MSbar$ のパラメータをつなぐ残りの二つの式（式~\eqref{eq:GF1}、\eqref{eq:alphahat}）も FJ の処方でゲージによらないことを確かめた。$G_F$ の補正 $\hat\Delta$ はタドポールのために大きく $\mu$ に依存し、それが $v$ の走りの $1/\lambda$ の項と打ち消して $G_F$ を $\mu$ によらなくする。$\beta_t$ の処方では、同じタドポールの部分が $v_\beta$ に入り、$\hat\Delta$ と $v_\beta$ の両方がゲージに依存する。表~\ref{tab:plan} の FormCalc との比較は、極質量と $G_F$ についてはまだ行っていない（手順 (9) では $2\to2$ の振幅で FormCalc と MadLoop と比べた）。

\paragraph{測定値と $\MSbar$ のパラメータ。}手順 (7) で、FJ の処方の1ループの換算（式~\eqref{eq:fit}）が Buttazzo らの NLO と一致し、Lagrangian の結合はタドポールの処方によらないことを具体的に確かめた。FJ の処方では $\delta_W$、$\delta_Z$、$\hat\Delta$ がそれぞれ $\mu=M_t$ で約 $0.12$ と大きいが、$g$、$g'$、$y_t$ と $M_W$ の予言ではタドポールが打ち消す組み合わせだけが入る。1ループの換算の精度は、$\lambda$ で $\pm0.002$〜$0.003$、$g_2$、$g_Y$ で $\pm10^{-4}$ 程度で、$y_t$ では2ループと3ループの QCD（$-0.011$、$-0.003$）が欠かせない。

\paragraph{走り。}手順 (8) で、2ループの $\beta$ 関数のうち $y_t$、$g_s$、$\lambda$ だけの部分（式~\eqref{eq:beta2}）を本ノートの模型の図から求め、文献の式と記号として一致させた。$\lambda(M_{\mathrm{Pl}})$ への2ループの走りの効果（$-0.034$ から $-0.015$）のほとんどはこの部分から来て、$g,g'$ を含む2ループの項は $3\times10^{-4}$ しか効かない。$HHHH$ を補助の質量で求めるときは、クォークの運動項の対抗項を式~\eqref{eq:cmmq} の形で入れる必要がある。Landau ゲージではグルーオンの寄与の極が0なのでこの項は湯川の部分だけに現れ、$\lambda=0$ の質量0の計算との比較で確かめた。$\lambda$ の零点 $\Lambda_\lambda$ には、走りの次数（1ループと2ループで1.7桁）と換算の次数（1ループと2ループで0.5桁、$y_t$ の QCD の高次で3桁）の両方が大きく効く。FJ の処方の $v^2=\mu^2/\lambda$ は $\Lambda_\lambda$ で発散するので、FJ の $\MSbar$ の質量を高いスケールで使うことはできない。これは FJ の処方の弱点で、$\beta_t$ の処方の利点（ゲージを決めれば $v_\beta$ が滑らかに走る）の裏返しである。物理量（有効ポテンシャルの形、崩壊率）にはどちらの処方でも同じ結合 $\lambda,y_t,g$ が入る。

\paragraph{1ループの振幅とツール。}手順 (9) で、FJ の処方の $\MSbar$ の振幅が、on-shell の独立な実装（MadGraph の電弱 NLO の模型）と、パラメータの有限な換算 \eqref{eq:convOS} だけを通して一致することを確かめた。$\MSbar$ の振幅、$\delta M_V^2$、$\delta\ln\mathcal M_0$ はそれぞれ $\mu$ で大きく変わる（タドポールのため）が、on-shell の振幅では打ち消す。タドポールの図を作らない MadLoop には、FJ の処方を対抗項の頂点 \eqref{eq:fjct}（$\MSbar$ の極、タドポールの図そのもの、外線の on-shell の場の定数）として入れれば、本ノートの $\MSbar$ のパラメータのまま $\MSbar$ の振幅が得られる。この頂点をすべての頂点に広げた UFO（対抗項のラグランジアン、タドポールの頂点、外線の on-shell の場の定数）は、光子とクォークの付く過程でも、MadGraph の模型と換算 \eqref{eq:fjdiff} だけを通して一致し、軽いフェルミオンが質量0のどの過程の $\MSbar$ の振幅も MadLoop で求められるようになった。外線に質量のある粒子（$W$、$Z$、$t$、$H$）がある過程では、MadLoop は外線を $\MSbar$ の質量の殻の上に置くので、極質量への換算が別に要る。軽い質量を残す場合と QCD の補正（$\alpha_s$ の6フレーバーの $\MSbar$）はまだ確かめていない。

\paragraph{次の手順。}手順 (10) で真空の崩壊を求める。そこでは $\Lambda_\lambda$ の桁が結果を大きく左右するので、本ノートの1ループの換算ではなく、高次の換算を含む文献の値~\cite{buttazzo13,mr19} から出発し、本ノートの値との違いを不定性として示す。

\section{Feynman 則の導出}\label{app:rules}

\paragraph{ゲージ場と光子の結合。}式~\eqref{eq:L} の共変微分の中立な部分は、式~\eqref{eq:fields} で
\begin{equation*}
-i\bigl(gT^3W^3+g'YB\bigr)=-i\bigl[(g\sw T^3+g'\cw Y)A+(g\cw T^3-g'\sw Y)Z\bigr]=-i\Bigl[eQA+\frac{e}{\sw\cw}(T^3-\sw^2Q)Z\Bigr]
\end{equation*}
である（$g\sw=g'\cw=e$、$Y=Q-T^3$）。荷電の部分は $T^1W^1+T^2W^2=\frac1{\sqrt2}(\sigma^+W^++\sigma^-W^-)$（$\sigma^\pm=(\sigma^1\pm i\sigma^2)/2$）である。$\bar\psi i\slashed D\psi$ から表~\ref{tab:rules-f} の上の4行が出る。たとえば $\bar u_L\gamma^\mu d_LW^+_\mu$ の係数は $g/\sqrt2$ で、頂点は $i\frac{e}{\sqrt2\sw}\gamma^\mu P_L$ である。

\paragraph{湯川結合。}式~\eqref{eq:Phi} を入れると、$d$ 型の項は $iy_d\bar u_Ld_RG^+-\frac{y_d}{\sqrt2}\bar d_Ld_R(v+H+iG^0)+\mathrm{h.c.}$、$u$ 型の項は $\tilde\Phi=((v+H-iG^0)/\sqrt2,-iG^-)$ から $-\frac{y_u}{\sqrt2}\bar u_Lu_R(v+H-iG^0)+iy_u\bar d_Lu_RG^-+\mathrm{h.c.}$ である。$\bar d_Ld_R-\bar d_Rd_L=\bar d\gamma_5d$ から $\bar ddG^0$ の項は $-i\frac{m_d}vG^0\bar d\gamma_5d$ で、頂点は $\frac{m_d}v\gamma_5=-2T^3_d\frac{m_d}v\gamma_5$ になる。$\bar udG^+$ の係数は $iy_dP_R$（$d$ 型の項）と $-iy_uP_L$（$u$ 型の項のエルミート共役）の和で、頂点は $y_uP_L-y_dP_R=\frac{\sqrt2}v(m_uP_L-m_dP_R)$ である。

\paragraph{スカラーのポテンシャル。}$\mu^2=\lambda v^2$ のとき、$|\Phi|^2=\frac{v^2}2+X$、$X=vH+\frac12(H^2+G^{02})+G^+G^-$ とすると、ポテンシャルは定数を除いて $\lambda X^2$ である。$-\lambda v^2H^2$ が $M_H^2=2\lambda v^2$ を与え、$-\lambda v H(H^2+G^{02}+2G^+G^-)$ と $-\lambda(\frac12H^2+\frac12G^{02}+G^+G^-)^2$ から表~\ref{tab:rules-sv} の上の段が出る（同じ場の並べ方の数を掛ける。たとえば $HHH$ は $-\lambda v\cdot3!$）。

\paragraph{ゲージ場とスカラー。}$D_\mu\Phi$ の成分は
\begin{equation*}
\begin{aligned}
D_\mu\Phi_1&=-i\Bigl[\partial_\mu G^+-i\bigl(eA_\mu+e'Z_\mu\bigr)G^++\frac g2W^+_\mu(v+H+iG^0)\Bigr],\\
D_\mu\Phi_2&=\frac1{\sqrt2}\Bigl[\partial_\mu H+i\partial_\mu G^0+ig_ZZ_\mu(v+H+iG^0)-gW^-_\mu G^+\Bigr]
\end{aligned}
\end{equation*}
で、$e'=e(\cw^2-\sw^2)/(2\sw\cw)$、$g_Z=e/(2\sw\cw)$ である。$|D\Phi_1|^2+|D\Phi_2|^2$ を展開すると、2次の項として $M_W^2W^+W^-$、$\frac12M_Z^2Z^2$（$M_Z=g_Zv$）と混合 $M_W(W^+\cdot\partial G^-+W^-\cdot\partial G^+)+M_ZZ\cdot\partial G^0$ が、3次と4次の項として表~\ref{tab:rules-vs} が出る。$Z$、$W^\mp$、$G^\pm$ の3点の頂点 $\mp eM_W\frac{\sw}{\cw}$ は、$D\Phi_1$ の $e'$ の項（$\cw^2-\sw^2$ に比例）と $D\Phi_2$ の $g_Z$ の項の和で、$g_Z-e'=e\sw/\cw$ による。微分の付いた項の運動量は $\partial_\mu\phi\to-ip_\mu\phi$（入る運動量）で、たとえば $\frac g2W^-_\mu(H\partial^\mu G^+-G^+\partial^\mu H)$ から $G^+H\bar W$ の頂点 $\frac{e}{2\sw}(p_1-p_2)^{\mu_3}$ が出る。

\paragraph{ゲージ場の自己結合。}$-\frac14W^a_{\mu\nu}W^{a\mu\nu}$ の頂点は QCD の $f^{abc}$ を $\epsilon^{abc}$ に置き換えたもので、3点は $g\epsilon^{abc}\Gamma$ である。場 $X$ への $W^a$ の係数を $C^a_X$（$C_{W^\pm}=(1,\pm i,0)/\sqrt2$、$C_A=(0,0,\sw)$、$C_Z=(0,0,\cw)$）とすると、場 $X,Y,Z'$ の頂点は $\sum\epsilon^{abc}C^a_XC^b_YC^c_{Z'}$ 倍である。$\epsilon^{3bc}C^b_{W^+}C^c_{W^-}=-i$ から $AW\bar W$ は $-ig\sw\Gamma=-ie\Gamma$ になる。4点も同様である。

\paragraph{ゲージ固定。}式~\eqref{eq:gf} の $-\frac1{2\xi_Z}(\partial Z-\xi_ZM_ZG^0)^2$ は、交差項 $M_Z(\partial\cdot Z)G^0=-M_ZZ\cdot\partial G^0$（部分積分）で $|D\Phi_2|^2$ の混合を消し、$-\frac12\xi_ZM_Z^2G^{02}$ で $G^0$ に質量を与える。$-\frac1{\xi_W}F^+F^-$ も同様に $W$ と $G^\pm$ の混合を消し、$-\xi_WM_W^2G^+G^-$ を与える。$W$、$Z$ の運動項 $\frac12V(\partial^2+M^2)V$ にゲージ固定の $\frac1{2\xi}(\partial V)^2$ を加えた逆を取ると、式~\eqref{eq:propV} の伝播関数になる。

\paragraph{ゴースト。}BRST 変換 $s$ はゲージ変換 $\delta W^a=\partial\alpha^a+g\epsilon^{abc}W^b\alpha^c$、$\delta B=\partial\alpha^B$、$\delta\Phi=i(g\alpha^aT^a+\frac{g'}2\alpha^B)\Phi$ の $\alpha$ をゴーストに置き換えたものである（$D_\mu$ の符号から、この組み合わせで $D_\mu\Phi$ が共変に変換する）。$\bar u^aF^a$ を実の基底で書いて $W^\pm$ の基底に直すと $-(\bar u^+sF^++\bar u^-sF^-)$ になり、$\bar u^+$ は $u^+$ と対になる反ゴースト（FeynRules の \texttt{ghWpbar}）である。ゲージ部分 $-\bar u^k\partial\cdot sV^k$ は、反ゴーストも場と同じ実の行列で回るので $-\bar u^a\partial^\mu(D_\mu u)^a$ に等しく、部分積分の後 $g\epsilon^{abc}(\partial^\mu\bar u^a)W^b_\mu u^c$ から表~\ref{tab:rules-gh} の上の段が出る（$\partial\bar u\to-ip$）。スカラー部分は $s\Phi$ を成分で書いて
\begin{equation*}
\begin{aligned}
sG^+&=ieu^AG^++ie'u^ZG^+-M_Wu^+-\frac g2u^+(H+iG^0),\\
sG^-&=-ieu^AG^--ie'u^ZG^--M_Wu^--\frac g2u^-(H-iG^0),\\
sG^0&=-\frac{ig}2\bigl(u^-G^+-u^+G^-\bigr)-M_Zu^Z-\frac e{2\sw\cw}u^ZH
\end{aligned}
\end{equation*}
で（$sH$ は $\bar u^A$ にしか掛からないが、$F^A$ に Goldstone ボソンがないので現れない）、$-\bar u^ksF^k$ の Goldstone ボソンの部分 $\xi_ZM_Z\bar u^ZsG^0+\xi_WM_W(\bar u^+sG^++\bar u^-sG^-)$ から、ゴーストの質量 $\xi_ZM_Z^2$、$\xi_WM_W^2$ と表~\ref{tab:rules-gh} の下の段が出る。たとえば $\bar u^Zu^ZH$ は $i\cdot\xi_ZM_Z\cdot(-\frac e{2\sw\cw})=-i\xi_Z\frac{eM_W}{2\sw\cw^2}$ である。

\section{木のレベルの導出}\label{app:tree}

\paragraph{$W$ と $Z$ の崩壊。}$W^+\to f\bar f'$ の振幅は $\frac{g}{\sqrt2}\epsilon_\mu\bar u(p_1)\gamma^\mu P_Lv(p_2)$ である。スピンの和をとると、質量の項は $P_L(\slashed p_2-m_2)\gamma^\nu P_L=\slashed p_2\gamma^\nu P_L$ で落ち、偏極の和 $-g_{\mu\nu}+k_\mu k_\nu/M_W^2$ と縮約して
\begin{equation*}
\sum|\mathcal M|^2=\frac{g^2}2\Bigl[2p_1\!\cdot\!p_2+\frac{4(k\!\cdot\!p_1)(k\!\cdot\!p_2)}{M_W^2}\Bigr]=g^2M_W^2\Bigl[1-\frac{x_1+x_2}2-\frac{(x_1-x_2)^2}2\Bigr]
\end{equation*}
である。偏極の平均 $\frac13$ と2体の位相空間 $|\boldsymbol p|/(8\pi M_W^2)$、$|\boldsymbol p|=\frac{M_W}2\lambda^{1/2}$ を掛けて式~\eqref{eq:widths} の1行目になる。$Z\to f\bar f$ では結合を $\gamma^\mu(v_f-a_f\gamma_5)$、$v_f=(g_L+g_R)/2$、$a_f=(g_L-g_R)/2$ と書くと、よく知られた $\Gamma=N_c\frac{e^2M_Z}{12\pi}\beta_f[v_f^2(1+2x_f)+a_f^2\beta_f^2]$ で、$v^2+a^2=\frac12(g_L^2+g_R^2)$、$v^2-a^2=g_Lg_R$ から2行目の形になる。

\paragraph{$H$ とトップの崩壊。}$H\to f\bar f$ は $\sum|\mathcal M|^2=\frac{m_f^2}{v^2}\tr[(\slashed p_1+m_f)(\slashed p_2-m_f)]N_c=\frac{2m_f^2}{v^2}M_H^2\beta_f^2N_c$ で、位相空間 $\beta_f/(16\pi M_H)$ を掛けて3行目になる。$t\to bW^+$ は $W$ の崩壊と同じトレースで、$p_t=p_b+k$ を使うと $\sum|\mathcal M|^2=\frac{g^2}{2M_W^2}[(m_t^2-m_b^2)^2+M_W^2(m_t^2+m_b^2)-2M_W^4]$ になり、スピンの平均 $\frac12$ と位相空間 $\lambda^{1/2}/(16\pi m_t)$ を掛けて4行目になる。

\paragraph{$e^+e^-\to f\bar f$。}光子の振幅は $(ieQ_e)(ieQ_f)(-i/s)[\bar v\gamma^\mu u][\bar u\gamma_\mu v]$、$Z$ の振幅は $Q_eQ_f/s$ を $g_i^eg_j^f/(s-M_Z^2+iM_Z\Gamma_Z)$ に置き換えたもので、質量0のフェルミオンではヘリシティごとに分かれる。左巻きの $e^-$ から左巻きの $f$ への振幅の2乗は $(1+\cos\theta)^2\propto u^2$ に比例し、式~\eqref{eq:eeff} になる。光子だけでは $A_{ij}=Q_eQ_f/s$ で、$8e^4N_cQ_f^2(t^2+u^2)/s^2$ を再現する。

\paragraph{縦波の $W$ 対。}$W^-(k_1)$ は場 $W$ が、$W^+(k_2)$ は場 $\bar W$ が作るので、$AW\bar W$ の頂点の入る運動量は $(q,-k_1,-k_2)$、$q=p_1+p_2$ である。$\epsilon_L\simeq k/M_W$ とすると、ボソンの流れは
\begin{equation*}
\Gamma^{\sigma\mu\nu}(q,-k_1,-k_2)\frac{k_{1\mu}k_{2\nu}}{M_W^2}=\frac{(k_1\!\cdot\!k_2+M_W^2)(k_1-k_2)^\sigma}{M_W^2}=\frac s{2M_W^2}(k_1-k_2)^\sigma
\end{equation*}
で、$\bar v(p_2)(\slashed p_1+\slashed p_2)u(p_1)=0$ から $\bar v(\slashed k_1-\slashed k_2)u=-2\bar v\slashed k_2u$ なので、光子の図は $i\mathcal M_\gamma=(ieQ_e)(-i/s)(-ie)(-\frac s{M_W^2})\bar v\slashed k_2u$、すなわち $\mathcal M_\gamma\simeq\frac{e^2Q_e}{M_W^2}\bar v\slashed k_2u$ である。$Z$ の図はこれの $Q_e$ を $\frac{\cw}{\sw}(g_L^eP_L+g_R^eP_R)$ に置き換えたものである（$s/(s-M_Z^2)\to1$、伝播関数の $k_\rho k_\sigma$ の部分は質量0の電流で消える）。$\nu$ の図は $i\mathcal M_\nu=\bar v(\frac{ig}{\sqrt2}\slashed k_2P_L)\frac{i(\slashed p_1-\slashed k_1)}{t}(\frac{ig}{\sqrt2}\slashed k_1P_L)u/M_W^2$ で、$(\slashed p_1-\slashed k_1)\slashed k_1u(p_1)=-tu(p_1)$（$\slashed p_1u(p_1)=0$）から $\mathcal M_\nu\simeq\frac{g^2}{2M_W^2}\bar v\slashed k_2P_Lu$ になる。$g^2=e^2/\sw^2$ で和が式~\eqref{eq:eeww} である。

\section{$\MSbar$ の対抗項と $\beta$ 関数の導出}\label{app:rg}

\paragraph{規則 \eqref{eq:zrule}。}$X_0=\mu^{n_X\epsilon}Z_XX$（$n_X=1$：$g,g',g_s,y_f$、$n_X=2$：$\lambda$、$n_X=0$：$\mu^2$）で、1ループの $Z_X=1+c_X/\epsilon$ の $c_X$ は結合の2乗（$g^2$、$y^2$、$\lambda$）について1次の同次式である。木のレベルでは $\dd X/\dd\ln\mu=-n_X\epsilon X$ なので $\dd c_X/\dd\ln\mu=-2\epsilon c_X$ で、$\dd X_0/\dd\ln\mu=0$ から $\beta_X=-n_X\epsilon X+2c_XX$ を得る。$\epsilon\to0$ で $c_X=\beta_X/(2X)$ で、$\MSbar$ では $1/\epsilon$ を $\DUV$ にする。質量の2乗 $M^2=\prod X^{k_X}$ の裸の値は $\prod X_0^{k_X}$ から $\mu^\epsilon$ の因子が打ち消し（$M_W^2=g^2\mu^2/(4\lambda)$ では $\mu^{2\epsilon}/\mu^{2\epsilon}$）、$\delta M^2/M^2=\sum k_X(Z_X-1)=\frac{\DUV}2\dd\ln M^2/\dd\ln\mu$ で式~\eqref{eq:dM2} になる。

\paragraph{ゲージ結合。}1ループの $\beta$ 関数の係数 $b$（$K\beta_g=bg^3$）は、Weyl フェルミオン $F$ と複素スカラー $S$ について $b=-\frac{11}3C_2(G)+\frac23\sum_FS_2(F)+\frac13\sum_SS_2(S)$ である（QCD のノートの $\beta_0$ の一般化。$S_2$ は表現の Dynkin 指数、$U(1)$ では $Y^2$）。$SU(2)$：1世代に左巻きの二重項が4個（$Q_L$ の色3つと $L_L$）で $\frac23\cdot\frac12\cdot12=4$、Higgs で $\frac13\cdot\frac12$。$U(1)$：1世代の $\sum Y^2=6\cdot\frac1{36}+3\cdot\frac49+3\cdot\frac19+2\cdot\frac14+1=\frac{10}3$、3世代で $\frac23\cdot10$、Higgs で $\frac13\cdot2\cdot\frac14$。$SU(3)$：$-11+\frac23\cdot\frac12\cdot12$。

\paragraph{湯川結合。}$\bar\psi_L\phi\psi_R$ の形の結合の1ループの $\beta$ 関数は、三つの場の異常次元と頂点の補正の和である。Landau ゲージでは、フェルミオンの場のゲージ場による繰り込みが0になり、スカラーの場は $-3g^2C_2(\phi)$、頂点のゲージ場の交換は $-6g^2T_L\cdot T_R=-3g^2[C_2(\psi_L)+C_2(\psi_R)-C_2(\phi)]$ を与え（$\phi$ の電荷は $T_L-T_R$）、和はゲージによらない $-3g^2[C_2(\psi_L)+C_2(\psi_R)]$ になる。トップでは $-3[g_s^2(\frac43+\frac43)+g^2\frac34+g'^2(\frac1{36}+\frac49)]=-8g_s^2-\frac94g^2-\frac{17}{12}g'^2$、ボトムでは $g'^2$ の係数が $-3(\frac1{36}+\frac19)=-\frac5{12}$、レプトンでは $-3(\frac34g^2+(\frac14+1)g'^2)$ である。湯川の部分は、場の異常次元が $\Phi$ で $\mathcal T$、$Q_L$ で $\frac12(y_u^2+y_d^2)$、$u_R$ で $y_u^2$ で、頂点の補正（$\Phi$ の内線が $Q_L$ を $d_R$ に変える図）が $-2y_d^2$ なので、和は $\mathcal T+\frac32(y_u^2-y_d^2)$ である（いずれも $K$ で割る）。レプトンでは右巻きのニュートリノがないので頂点の補正がなく、$\mathcal T+\frac32y_\ell^2$ である。

\paragraph{$\beta_\lambda$ と $\gamma_{\mu^2}$。}Landau ゲージの1ループの有効ポテンシャルは、背景場 $\phi$（$H$ の方向）の関数として
\begin{equation*}
V=-\frac{\mu^2}2\phi^2+\frac\lambda4\phi^4+\frac1{4K}\sum_in_iM_i^4(\phi)\Bigl[\ln\frac{M_i^2(\phi)}{\mu^2}-c_i\Bigr]
\end{equation*}
で、$(n_i,M_i^2)$ は $W$：$(6,\frac{g^2}4\phi^2)$、$Z$：$(3,\frac{g^2+g'^2}4\phi^2)$、$H$：$(1,3\lambda\phi^2-\mu^2)$、Goldstone：$(3,\lambda\phi^2-\mu^2)$、フェルミオン：$(-4N_c,\frac{y_f^2}2\phi^2)$ である。$\dd V/\dd\ln\mu=0$、すなわち $(\partial_{\ln\mu}+\beta_\lambda\partial_\lambda+\gamma_{\mu^2}\partial_{\mu^2}-\gamma_\Phi\phi\partial_\phi)V=0$ を1ループで書くと
\begin{equation*}
\frac{\beta_\lambda}4\phi^4-\frac{\gamma_{\mu^2}}2\phi^2-\gamma_\Phi\bigl(-\mu^2\phi^2+\lambda\phi^4\bigr)=\frac1{2K}\sum_in_iM_i^4(\phi)
\end{equation*}
である。右辺の $\phi^4$ の係数は $12\lambda^2+\frac38g^4+\frac3{16}(g^2+g'^2)^2-\sum_fN_cy_f^4$、$\phi^2$ の係数は $-12\lambda\mu^2$ で、Landau ゲージの $K\gamma_\Phi^{\mathrm L}=\mathcal T-\frac94g^2-\frac34g'^2$（フェルミオンのループと、スカラーのゲージ場による $-3g^2C_2(\Phi)$）を入れると式~\eqref{eq:beta} の $\beta_\lambda$ と $\gamma_{\mu^2}$ になる。$\beta_\lambda$ と $\gamma_{\mu^2}$ は Lagrangian のパラメータの $\MSbar$ の $\beta$ 関数なので、Landau ゲージで求めてもゲージによらない。

\paragraph{$e$、$\sw^2$、$v^2$。}$\dd\ln e/\dd\ln\mu=\sw^2\beta_g/g+\cw^2\beta_{g'}/g'=\frac{e^2}K(-\frac{19}6+\frac{41}6)$ で式~\eqref{eq:erun} の1つ目になる。$\sw^2=g'^2/(g^2+g'^2)$ から $\dd\sw^2/\dd\ln\mu=2\sw^2\cw^2(\beta_{g'}/g'-\beta_g/g)$ で2つ目になる。$v^2=\mu^2/\lambda$ の走りは $\gamma_{\mu^2}/\mu^2-\beta_\lambda/\lambda$ に式~\eqref{eq:beta} を入れたもので、$\beta_\lambda/\lambda$ のゲージ場と湯川の4次の項が $1/\lambda$ の項になる。

\paragraph{場の繰り込み。}共変ゲージの非可換ゲージ場の繰り込み定数は、QCD のノートの $Z_3=1+\frac{g^2}K[(\frac{13}6-\frac\xi2)C_A-\frac43T_Fn_f]\DUV$ を Weyl フェルミオン（$\frac23S_2(F)$）と複素スカラー（$\frac13S_2(S)$）に一般化したもので、$SU(2)$ では $(\frac{13}6-\frac\xi2)\cdot2-\frac23\cdot\frac12\cdot12-\frac13\cdot\frac12=\frac16-\xi$、$U(1)$ では $-\frac23\cdot10-\frac13\cdot\frac12=-\frac{41}6$ である。後者は $-2(Z_{g'}-1)$ に等しい。共通の $\xi$ の $R_\xi$ ゲージは、対称な共変ゲージ $-\frac1{2\xi}[(\partial W^a)^2+(\partial B)^2]$ に $M_V$ に比例する項を足したものである。紫外の極の $k^2$ の係数は質量によらないので、対称な相の値で決まる。質量の基底へは、$W^3=\cw Z+\sw A$、$B=-\sw Z+\cw A$ と $\delta\theta=\sw\cw(\delta Z_{g'}-\delta Z_g)$（$\tan\theta=g'/g$）から、$A_0$ の $Z$ の係数が $\delta\theta+\frac12\sw\cw(\delta Z_W-\delta Z_B)$、$Z_0$ の $A$ の係数が $-\delta\theta+\frac12\sw\cw(\delta Z_W-\delta Z_B)$ になり、$\delta Z_B=-2\delta Z_{g'}$ で式~\eqref{eq:dZmix} になる。$\Sigma^{AZ}_T(0)$ の極は、裸の質量項 $\frac12M_{Z,0}^2Z_0^2$ の $M_Z^2\frac{\delta Z_{ZA}}2ZA$ が打ち消すもので、$\delta Z_g+\frac12\delta Z_W=-\frac{g^2}{2K}(3+\xi)\DUV$（共変ゲージの $\tilde Z_1/\tilde Z_3-1$ の $SU(2)$ の値）から求まる。

\section{タドポールの導出}\label{app:tadpole}

\paragraph{各ループ。}$\int\dd^Dk/(2\pi)^D\,(k^2-m^2)^{-1}=(i/K)A_0(m)$ を使う。3点の結合 $-ic$（$H$ と実のスカラー2本）のループは対称性因子 $\frac12$ で $T=cA_0/(2K)$、複素スカラーでは $cA_0/K$ である。$HHH$（$c=6\lambda v$）で $3\lambda vA_0(M_H)$、$G^0G^0H$（$c=2\lambda v$）で $\lambda vA_0(\sqrt{\xi_Z}M_Z)$、$G^+G^-H$ で $2\lambda vA_0(\sqrt{\xi_W}M_W)$ になる。フェルミオンのループは $-1$ とトレース $4m_f$ で $T=-4N_cm_f^2A_0(m_f)/(Kv)$ である。$W$ のループは頂点 $igM_Wg^{\mu\nu}$ と伝播関数 \eqref{eq:propV} の縮約で
\begin{equation*}
g_{\mu\nu}\Bigl[g^{\mu\nu}-(1-\xi)\frac{k^\mu k^\nu}{k^2-\xi M^2}\Bigr]\frac1{k^2-M^2}=\frac{D-1}{k^2-M^2}+\frac{\xi}{k^2-\xi M^2}
\end{equation*}
（$k^2/[(k^2-M^2)(k^2-\xi M^2)]$ を部分分数にした）から $T_W=\frac{gM_W}K[(D-1)A_0(M_W)+\xi_WA_0(\sqrt{\xi_W}M_W)]$ で、$Z$ は $\frac12$ と $gM_Z/\cw$ で同様である。ゴーストのループは $-1$ と結合 $-i\xi_W\frac g2M_W$（$u^+$、$u^-$ の2本）、$-i\xi_Z\frac{g}{2\cw}M_Z$ で $-\xi_WgM_WA_0(\sqrt{\xi_W}M_W)/K$、$-\xi_Z\frac{gM_Z}{2\cw}A_0(\sqrt{\xi_Z}M_Z)/K$ になり、ベクトル場のループの $\xi$ の項をちょうど打ち消す。$gM_W=2M_W^2/v$、$gM_Z/(2\cw)=M_Z^2/v$、$\lambda v=M_H^2/(2v)$ と $(D-1)A_0(M)=3A_0(M)-2M^2+O(\epsilon)$ で式~\eqref{eq:T} になる。紫外の極は $T_{\mathrm{UV}}=\frac{\DUV}{Kv}[6M_W^4+3M_Z^4+\frac32M_H^4+\frac{M_H^2}2(\xi_ZM_Z^2+2\xi_WM_W^2)-4\sum N_cm_f^4]$ である。

\paragraph{タドポールの寄与と真空のずれ。}頂点 $HXY$ にタドポールをつなぐと、$H$ の伝播関数 $i/(0-M_H^2)$ と $iT$ から頂点の $T/M_H^2=\Delta v$ 倍になる。これは木の頂点の $H$ を定数 $\Delta v$ に置き換えたもので、$HW\bar W$ では $i\frac{2M_W^2}vg^{\mu\nu}\Delta v$、すなわち $\Sigma^{WW}_T\supset-2M_W^2\Delta v/v$ で式~\eqref{eq:tadins} になる。ループの1点関数 $iT$ は有効作用の1次の項 $TH$ に当たるので、有効ポテンシャルは最小点の近くで $\frac12M_H^2h^2-Th$ で、最小点は $h=T/M_H^2=\Delta v$ にある。その点のまわりの木の Higgs の質量は $3\lambda(v+\Delta v)^2-\mu^2=2\lambda v^2+6\lambda v\Delta v$ で、式~\eqref{eq:tadins} の $\Sigma^H$ の寄与と一致する。

\paragraph{$v_\beta$ の走り。}$\beta_t$ の処方では、ラグランジアンの結合 $g,g',\lambda,y_f$ は同じ $\MSbar$ の値のまま、展開の点を $v_\beta$ にとり、繰り込まれたタドポールが消えるように $\mu^2$ の有限部分を決める。1ループの物理量が FJ の処方と同じになるのは $v_\beta=v+\Delta v|_{\MSbar}$ のときで、$v_\beta$ の対抗項は $v$ の対抗項に $\Delta v$ の紫外の極（$\xi$ を含む）を加えたものになる。$v$ の極 $\frac{\DUV}4v\,\dd\ln v^2/\dd\ln\mu$ の $1/\lambda$ の部分 $\frac{\DUV v}{K}\frac1{2\lambda}\bigl[\sum N_cy_f^4-\frac3{16}(2g^4+(g^2+g'^2)^2)\bigr]$ は、$\Delta v=T/M_H^2$ の極の $\xi$ によらないゲージ場とフェルミオンの部分（式~\eqref{eq:T} の $T_{\mathrm{UV}}$ から）と打ち消す。$\Delta v/v$ の $\ln\mu^2$ への依存は $A_0(m)$ の $m^2\ln\mu^2$ から来て
\begin{equation*}
\begin{aligned}
\frac{\dd}{\dd\ln\mu}\frac{\Delta v}v&=\frac{12M_W^4+6M_Z^4+3M_H^4+M_H^2(\xi_ZM_Z^2+2\xi_WM_W^2)-8\sum N_cm_f^4}{Kv^2M_H^2}\\
&=\frac1K\Bigl[\frac{X}\lambda+6\lambda+\frac14\bigl(\xi_Z(g^2+g'^2)+2\xi_Wg^2\bigr)\Bigr]
\end{aligned}
\end{equation*}
で、$X=\frac3{16}(2g^4+(g^2+g'^2)^2)-\sum N_cy_f^4$ である。一方、付録~\ref{app:rg} の $\beta_\lambda$ と $\gamma_{\mu^2}$ の関係から $\frac12K\,\dd\ln v^2/\dd\ln\mu=-K\gamma_\Phi^{\mathrm L}-6\lambda-X/\lambda$ なので、和は式~\eqref{eq:vbeta} になる。Landau ゲージで $v_\beta$ が $-\gamma_\Phi^{\mathrm L}$ で走ることは、Landau ゲージの有効ポテンシャルの最小点が場と同じに繰り込まれることと合う。一般の $R_\xi$ ゲージでは、ゲージ固定の項が $v$ を含むので、$v_\beta$ の走りは場の異常次元と一致しない~\cite{ssv13}。

\paragraph{Slavnov--Taylor 恒等式。}BRST 変換で $s\bar u^k=-F^k/\xi_k$ とすると、$\langle s(\bar u^k(x)F^l(y))\rangle=0$ と、ゴーストの運動方程式 $\langle\bar u^k(x)\,sF^l(y)\rangle=i\delta^{kl}\delta^4(x-y)$ から $\langle F^k(x)F^l(y)\rangle=-i\xi_k\delta^{kl}\delta^4(x-y)$ で、ループの補正はない。$F^+=\partial\!\cdot\!W^+-\xi_WM_WG^+$、$F^-$ を運動量 $k$ で書き（$\partial\to-ik$ を $x$ の側、$+ik$ を $y$ の側に）、$\langle F^+F^-\rangle=k^\mu k^\nu\langle W^+_\mu W^-_\nu\rangle+i\xi_WM_Wk^\mu\langle W^+_\mu G^-\rangle-i\xi_WM_Wk^\nu\langle G^+W^-_\nu\rangle+\xi_W^2M_W^2\langle G^+G^-\rangle$ とする。木の値は $k^2P_L+\xi_W^2M_W^2P_G=-i\xi_W$（$P_L=-i\xi_W/(k^2-\xi_WM_W^2)$、$P_G=i/(k^2-\xi_WM_W^2)$）である。1ループの補正は、各伝播関数を $P\,V\,P$（$V$ は1PI の Feynman 則の積）に置き換えたもので、$k_\alpha k_\beta V^{\alpha\beta}=-ik^2\Sigma_L$、$\langle W^+G^-\rangle$ の $V$ は $G^+\to W^+$ の $ik\Sigma^{GW}$、$\langle G^+W^-\rangle$ の $V$ は $W^+\to G^+$ の $ik\Sigma^{WG}$、$V^{GG}=i\Sigma^G$ である。和は $\frac{\xi_W^2}{(k^2-\xi_WM_W^2)^2}[ik^2\Sigma_L-M_Wk^2(\Sigma^{GW}-\Sigma^{WG})-iM_W^2\Sigma^G]$ で、これが0であることが式~\eqref{eq:st} の1つ目である。$Z$ も同じで、$\langle F^AF^Z\rangle=0$ からは $\frac{\xi_A\xi_Zk^2}{k^2(k^2-\xi_ZM_Z^2)}[-\Sigma^{AZ}_L-iM_Z\Sigma^{G^0A}]$ が0になる。$\langle F^AF^A\rangle$ は Goldstone ボソンを含まないので $\Sigma^{AA}_L=0$ である。展開の点が木のポテンシャルの最小点なので、タドポールの付いた図を含めた2点関数でこれらが成り立つ。

\section{検算の細部}\label{app:details}

\paragraph{模型ファイルのパラメータ。}\texttt{SM.fr} の外部パラメータは、ブロック \texttt{SMINPUTS} の \texttt{aEWM1}（$4\pi/e^2$、1番）と \texttt{aS}（$\alpha_s$、3番）、ブロック \texttt{MASS} の $M_Z$、$M_W$、$M_H$ と9個のフェルミオンの質量、ブロック \texttt{DECAY} の $W$、$Z$、$H$、$t$ の幅、ブロック \texttt{GAUGE} の $\xi_A,\xi_Z,\xi_W,\xi_G$（値1）である。内部パラメータは $e=\sqrt{4\pi/\texttt{aEWM1}}$、$\cw=M_W/M_Z$、$\sw=\sqrt{1-\cw^2}$、$v=2M_W\sw/e$、$\lambda=M_H^2/(2v^2)$、$\mu^2=\lambda v^2$、$y_f=\sqrt2m_f/v$（対角の行列 \texttt{yl}、\texttt{yu}、\texttt{yd}、実数）で、$g=e/\sw$、$g'=e/\cw$ は FeynRules の \texttt{Definitions} で頂点の中で置き換える。これは $(g,g',\lambda,\mu^2,y_f)$ と同じ数のパラメータの別の組で、どれも $\MSbar$ の量である。結合の次数は MadGraph の規約で、$e$ と湯川結合が \texttt{QED} を1、$g_s$ が \texttt{QCD} を1数える。粒子の名前と PDG の番号は MadGraph の標準模型と同じで、Goldstone ボソンは 250、251 である。

\paragraph{比べ方。}\texttt{generate\_SM.wl} は、FeynRules の頂点の Dirac 構造、計量、運動量、色の行列を評価されない記号（\texttt{gSM\$[mu]} など）に置き換えてから表と比べる。置き換えの規則の左辺はすべて \texttt{HoldPattern} で包む（手順 (1) の二つ目の問題）。差は $\cw=\sqrt{1-\sw^2}$ を入れて \texttt{Together} と \texttt{Simplify} で簡約する。4グルーオンの頂点の縮約される色の添字は名前を付け直し、構造定数は引数を並べ替えて符号を付ける。
